# Archive 目录说明

本目录用于存放**已完成阶段**或**一次性调试**资产，避免污染主开发目录。

## 子目录

- `reports/`：历史状态报告（保留最新报告在仓库根目录）。
- `docs_legacy/`：历史计划、早期审计记录、旧版规格文档原件。
- `scripts_legacy_debug/`：一次性诊断脚本与临时验证脚本。
- `root_misc/`：历史会话计划与一次性复现实验入口。

## 使用规则

- 主流程优先使用根目录与 `scripts/`、`src/`、`docs/` 下文件。
- 若需要复盘历史推理，可在 archive 中查阅，但不应直接作为当前实现依据。
