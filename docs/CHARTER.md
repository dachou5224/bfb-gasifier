# 项目章程（CHARTER）

版本：v0.1 · 2026-10-12 起草，2026-10-13 批准 · 目标所有者：项目负责人（用户）

本章程是所有 agent 开工前必读的唯一权威文件。只有目标所有者可以修改本章程和验收判据。与本章程冲突的任何文档、注释、交接记录和 skill 一律以本章程为准。

## 1. 北极星

在 Python 中复现 Hamel（1999/2001，VDI 学位论文《Mathematische Modellierung und experimentelle Untersuchung der Vergasung verschiedener fester Brennstoffe》）的鼓泡流化床气化模型与算法，使模型结果与 **Hamel 本人的模拟结果**相符。

- 主判据：Hamel 的模拟值（第 7 章出口 parity 图中的 Sim 值，以及轴向剖面图中的模拟曲线）。
- 辅判据：实验值，用于检验 Hamel 自称的偏差带（第 8 章：T ±10–15%，CO/CO₂/H₂ ±15%，CH₄ ±20%，碳转化率 ±15%）。
- 不以实验值作为“复现成功”的主要证据；也不得以实验出口反推任何模型输入。

## 2. 验收判据

### 2.1 数值前提（每个工况必须先满足）

- 最终解对**未修改的原方程**满足收敛门：气相、固相、能量各分块残差分别达标（具体阈值由 ADR 登记，不得放宽后不报）。
- 外部元素平衡（C/H/O）与总能量平衡闭合，偏差阈值由 ADR 登记。
- 状态有限、非负。

### 2.2 单工况通过（相对 Hamel 模拟值）

| 量 | 容差 |
|---|---|
| 出口（或平均自由空间）温度 | \|Δ\| ≤ 20 K |
| CO、CO₂、H₂、H₂O | \|Δ\| ≤ 0.015 mol/mol 或 ≤ 10% 相对，取较宽者 |
| CH₄ | \|Δ\| ≤ 0.005 mol/mol 或 ≤ 20% 相对，取较宽者 |
| 碳转化率 | \|Δ\| ≤ 3 个百分点 |

- 干基、湿基必须与原图一致，不得混比。
- 轴向剖面暂作定性比较（峰值位置、趋势、二次风处的跳变），待 T3 重新数字化模拟曲线后由目标所有者决定是否收紧。
- 容差只能由目标所有者修改。

## 3. 工况推进顺序

逐关推进，前一关全部通过才进入下一关：

1. WSV400 A
2. WSV400 B–F
3. VTT 常压 D、E
4. VTT 加压 1、6、13、14
5. HTW Wesseling 1、2
6. HTW Berrenrath

数据来源：`data/validation_cases.json`（工况输入与实验值）；`data/digitized/`（T3 交付的模拟值与实验值序列）。在 T3 交付前，出口模拟值暂用 `data/hamel_fig7_parity_digitized.json` 的 `sim` 字段，但须先完成图中工况标签与 `CASE_*` 的对应核对（见 T3）。

## 4. 文献来源

1. Hamel 论文是唯一主来源。
2. 其它文献（Wirsum 1997、Hegermann、Hilligardt 等）只有在 Hamel 对该子模型明确引用时才可使用，并标注“Hamel 引用的 X（Hamel 式号/页码）”。
3. 引入 Hamel 未引用的文献，须目标所有者批准并登记 ADR。
4. 任何涉及方程的任务卡，执行者动手前须按 `hamel-source-check` 交“原文答卷”，经总司令审查通过后才能写代码。
5. 原文没有说明的地方必须如实写“原文未说明”并上报裁定，裁定结果登记 ADR，代码注释标为“解释性选择”。禁止悄悄填补。
6. 禁止用当前或旧实现反推原文。

## 5. 求解手段的边界

- **允许**（须登记 ADR）：初值构造、Vorabrechnung（预计算）、阻尼、线搜索、同伦/延拓、雅可比近似。
- **禁止**：修改残差本身，包括 clip、下限截断、强制温度、残差锚点项、按条件关闭方程项。
- 唯一判定标准：最终解使未修改的原方程满足 §2.1。求解路径上的辅助手段不改变解的正确性，残差上的修改则会改变。

## 6. 代码规范

### 6.1 主线结构

- 唯一主线为仓库内 `hamel/` 包。旧代码只存在于归档分支 `archive/2026-10-12-snapshot`（tag `archive-2026-10-12`），不在主线目录中保留。
- 从归档迁入任何函数，须同时具备：审计记录（原文答卷或转录比对结论）＋论文锚点测试。
- 模块按论文章节划分：

| 模块 | 内容 | 论文 |
|---|---|---|
| `hamel/properties/` | 物性、组分、焓 | 附录及相关章节 |
| `hamel/hydrodynamics/` | u_mf、气泡、相含率、相间交换、自由空间流动 | 第 3 章 |
| `hamel/kinetics/` | 异相与均相反应速率 | 第 4 章 |
| `hamel/pyrolysis/` | 干燥、热解产率与元素分配 | 第 4 章相关节 |
| `hamel/balances/` | cell 物料与能量衡算 | 第 2 章 |
| `hamel/freeboard/` | 自由空间 | 相关章节 |
| `hamel/solver/` | Vorabrechnung＋Newton–Raphson | 相关章节 |
| `hamel/cases/` | 工况装配与对标 | 第 7 章 |

（章节号以 T2 索引为准，由 T4 及后续审计修正。）

### 6.2 规模与配置

- WSV400 全部通过前，`hamel/` 代码总量上限 8,000 行（不含测试）。
- 物理参数配置 ≤ 30 项；求解器参数单独成组。
- 禁止功能开关与双轨模式（如 `_thesis` / `engineering` 并存）。
- 超限须目标所有者批准。

### 6.3 命名与语言

- 反应编号、方程编号、符号一律以 Hamel 原文为准。
- 标识符为英文 snake_case，由 Hamel 符号或德文术语转写。
- 文档与注释用中文。
- 核心函数 docstring 注明来源，格式：`Source: Hamel Eq.x.y, S. N`。引用须能在 `refs/hamel/index.json` 中找到（由校验脚本检查）。
- 术语以 `GLOSSARY.md` 为准，`_Avoid_` 中列出的旧叫法不得再用。

### 6.4 继承的全局规则

- 全程 SI；唯一例外按原文登记 ADR（如 R8 内部压力换算）。
- Arrhenius 只通过统一工厂函数计算。
- 不添加 logging 框架、设计模式和抽象基类。

## 7. 测试

- 期望值必须来自论文：中间结果图表的数字化读数＞按原文公式独立手算＞性质测试（量纲、极限、守恒、单调性）。
- 用旧代码输出作为期望值的测试必须标注 `# 回归快照，非正确性证据`，且不能作为迁入门槛。
- 旧的约 1245 个测试不整体迁移，只随迁入的函数一起迁移并改写期望值。
- 默认测试集 5 分钟内跑完；单个工况完整求解标为 `slow`。
- 长求解一律带硬超时；超时即记录 TIMEOUT，不无限等待。

## 8. 角色与流程

| 角色 | 担任者 | 职责与权限 |
|---|---|---|
| 目标所有者 | 用户 | 定北极星、验收判据、工况顺序；批准章程修改、超限、新文献、ADR；唯一可合并到 main 的人 |
| 总司令 | Claude（独立会话） | 起草与维护任务卡、审查原文答卷和 PR、运行偏离检查、发现偏离时叫停并上报；基本只读，不写业务代码 |
| 执行者 | codex、cursor 等 | 只在任务卡范围内工作；越界或超预算即停下上报 |
| 辅助执行者 | 目标所有者另行指派 | 数字化、原文语料整理等重复性工作 |

工作流：

1. 每张任务卡一个分支，完成后提 PR。
2. 总司令对照任务卡审查：范围、验收证据、原文答卷、偏离信号；结论写进 PR 评论。
3. 目标所有者合并。agent 不得直接 push main。
4. 每次会话结束时工作树必须干净（已 commit）。

任务卡模板见 `docs/tasks/_TEMPLATE.md`。

## 9. 偏离信号

每次交接运行偏离检查脚本，任一项触发即要求总司令审查：

- 工作树不干净；
- 新增配置项没有对应 ADR；
- 单张任务卡净增代码超过 800 行；
- 新文件名呈阶段后缀模式（如 `_r12_r5`、`_v7`、`_stage3`）；
- 连续 2 周没有任何工况指标变化（此项触发后须目标所有者确认才能继续）。

总司令审查只问五个问题：

1. 推进了哪个工况指标？
2. 是否修改了方程或判据？如果是，依据是否回到原文？
3. 是否引入了新的平行实现或开关？
4. 是否有原文空白被悄悄填补？
5. 交接后工作树是否干净？
