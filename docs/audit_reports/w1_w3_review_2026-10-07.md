## 4. 根因解释与 W1 剩余问题

### 4.1 仅作行变换还不够

现有焦油行变换已将总反应行与输运比例行分开，但变量仍是两种库存各自的对数。失败点 TAR1 只有 5.45e-12 mol/s，要到本次配比候选约需增加 3.78e5 倍，对数位移约 12.84；TAR2 只需下降约 39%。

在原对数坐标里，保总量需要极不对称的两个变量变化。弱库存列几乎无法表达足够的配比修正，而强库存列同时影响总量和快速反应。把整体信赖域缩到 1e-4 附近会进一步限制这个有用方向。多轮迭代原则上仍可能展开微量变量，不能说对数坐标数学上绝对不可行；但当前子问题的尺度和坐标选择明显不适合这条方向。

建议沿每相的 `S=N1+N2` 和 `D=a2*N1-a1*N2` 构造变量基底：

```
N1 = a1*S + D
N2 = a2*S - D
-a1*S <= D <= a2*S
```

S 管反应总量，D 管比例输运。S 可以保留正变量表示；D 应按总量/输运尺度表示，而不是按快耗尽代表物自身的微量库存缩放。也可构造等价的反应计量零空间预条件。两种代表物仍有两个自由度，不设固定配比，不消去氧，不改变速率。

这类一般表示适用于当前模型中具有相同总反应进度的代表物。若未来更换为各代表物独立速率，应重新检查结构，不能直接沿用反应不变假设。

### 4.2 `constraint_stall` 不能解释成物理约束证据

当前标签来自步长缩到固定下限、存在活跃步幅边界且真实目标未下降。它没有验证非负约束下的一阶最优条件；“活跃边界”主要是人为信赖域边界，不等于物理可行集边界。本次找到非负、原门通过的邻近候选，已直接否定了用该标签说明“无可行调整”的解释。

### 4.3 温度尺度和停止精度应与差商解耦

目前温度对数步幅取 `radius*(1e-7/1e-4)`，停止半径也取气体差商步长 1e-4。差商步长控制导数截断/舍入误差，信赖域尺度控制允许的状态变化，两者没有这种必然比例。这里可能加重收敛慢，但本次主要卡点已有更直接的配比证据，不建议再次仅围绕这些常数调参。

保留 W1 的预测/实际下降机制，结合新变量基底重新定义尺度和可分辨步长。若缩域到停止边界，应检查实际预测改进是否低于数值噪声，而不是仅比较半径与差商步长。
