# P0–P4 后的系统诊断与下一轮工作计划

日期：2026-09-26。按用户后续要求，首个验证工况改为 Wesseling 1，第二工况为同装置 Wesseling 2。依据本日交接、当前源码、E8/P3 原始残差重算及两项局部测试。目标是从工况输入自动获得守恒、可验证且稳定快速的解。本轮不修改方程或生产默认值，不更新认证快照，不 commit。

## 1. 判断：已有端点，尚未形成可验证的求解流程

P0–P4 的进展有效：两相焦油、有限水力、自由空间炭和两区能量已经能够在具名核中共存，并得到通过分块门的状态。这证明了一组简化条件下存在数值可接受解；还没有证明任意合理初值、真实实验工况、多格模型都能稳定求解。

现在应停止把每一个文献或微量库存疑点都作为全项目串行前置条件。下一轮主线是：**保存可复现基线 → 自动求解与收敛基准 → 一个真实工况的完整输入/输出链 → 小范围工况和网格验证**。物理问题按对目标输出、守恒和收敛的影响插入这条主线。

当前不迁移生产入口的决定仍成立，但应有退出条件：同输入残差对照、自动求解回归、真实工况适配、最小多格守恒检查完成后，再决定集成方向。不能把“不迁移”变成长期维护两套模型而没有验证出口。

### 2.2 求解路径还依赖近根状态与多种补救步骤

`solve_e11_step9.py` 从先前近根文件出发，最多四次冻结 q 的对数最小二乘修正。这是有效的修正工具，但不是“给定工况即可自动求解”的证据。E7→E8 的长链本轮未复跑，P3 冷启动成功率、邻近工况成功率和端到端耗时都还未知。

`wirsum_1997_named_f_e8.py:532` 的内层最小二乘使用分块缩放；`:684` 的外层候选接受仍比较原单位 `norm(h)`。mol/s、kg/s、W 在这里混在一起。最终分块认证是正确的，但搜索目标不一致，可能使能量改善掩盖物料恶化，也可能拒绝有用的联合步。该机制需要统一，比继续尝试某一物种的局部消元更有系统价值。

内层每次雅可比以中心差分逐列计算，50 维时约需要 100 次残差求值；`max_nfev=800` 也不是包含自定义雅可比内部调用的总工作量预算。外层刷新、试探步和内层迭代叠加后，需要统计实际调用次数，不能只报迭代数。

现场单次测量 P(x) 约 0.078 s、冻结 F 约 0.0018 s；这不是性能基准，只提示轨迹刷新可能值得重点计时，尚不能认定它支配完整求解。不要直接对完整 P(x) 逐列中心差分而不先衡量成本。

### 2.3 现有 validation 入口不适合作为新模型的发布门

`tests/test_table2_LU.py` 中：

- 温度测试有非严格 xfail；不能把 pytest 没报错视为验证通过。
- `BFB_RELAX_VALIDATION` 可跳过严格输出比较。
- 温度误差取论文模拟值与测量值中较小者，混淆了原算法复现和实验验证。
- `tests/validation/config_phase1.py` 的历史配置含 R4=0.50、R5=0.75、R7=2.50 等倍率，不能继承为具名核的无调参基线。

数据也需按观测定义取用。例如 WSV400 A 的 `exit_temperature_K=980` 与 parity 中自由空间温度测量值 1135 K 并存。它们不能任取较近者；应分别对应出口温度、自由空间平均温度等明确观测量。论文模拟曲线和实验测量必须分列。

具名核默认给料仍是构造的原子进料和两档颗粒，并有固定 coal 类型入口。几何相近不代表已是某个实验工况，当前 1363/1384 K 不能直接与某一实验温度判误差。

## 4. 下一轮执行顺序与验收

### A. 固定基线并定义验证合同（建议一个工作单元）

另存 P3 包，不覆盖 E8：x、完整输入/模型选项、可重建 q 的配置、P(x)、原始每行 F、分块映射、所有相关源码 hash、环境版本、当前简化假设。当前 hash 列表未完整覆盖自由空间 physics 等依赖，需要补全；现有 E8 认证报告字段也没有完整列出 E11 的自由空间炭、焦油和两行能量，不能照搬字段冒充 P3 包装。

同时指定真实工况验证的观测量、测量来源、干湿基、温度位置/平均方式和容差；关闭 relaxed/xfail 作为通过途径。原文模型复现单列。容差取测量/数字化误差和事先声明的工程要求，不从结果倒推。

验收：任何人从同一包用当前代码可复算上述两份状态；验证结果明确分成数值通过、守恒通过、实验误差、模型覆盖范围四栏。

### B. 建立一个自动求解入口和小型鲁棒性基准（下一轮核心）

先保留现有能工作的冻结 q / 外层刷新结构，不一次重写求解器。统一候选接受的无量纲 merit 与缩放规则；固定一次求解中的缩放，最终仍用原单位分块门。轨迹刷新后必须检查真实复合残差。保持微量正氧的有效导数、非负域、零未知量的重新激活机制；小步停止或最小二乘停滞不算根。

统一统计：实际 F 调用、P 调用、雅可比调用、线性求解/轨迹耗时、回退次数、接受步长和最坏残差行。有限次数的回退失败后返回结构化失败原因，不继续无界叠加局部补救函数。

建议最小矩阵：

1. E7 保存起点按现有完整尺度路径到 E8，再到 P3，一条自动路径，不人工改向量。
2. P3 初值温度分别 ±50 K、正气体/库存乘 0.5 和 2 的四组扰动；扰动只是初猜，不改变物理输入，也不要求初猜守恒。零项由统一初值/活跃集机制处理。
3. 空气或燃料输入分别 ±5% 的邻近工况，使用连续工况热启动，目标尺度都必须回到 1。
4. 一个不读端点答案的确定性物理初值启动，单独标记冷启动。

每项要求原门通过并记录状态差异；不同解分支应报告，不能仅凭接近原答案验收。独立边界 C/H/O/总能量账使用原始进出流重建，不能只把残差行相加作为独立证据。

建议探索预算：近根/邻近工况每次 120 s，完整启动链每次 10 min；这些是防止卡住的初始工程预算，不是已达到的性能指标。超时即保存诊断并结束本次。建立实测基线后，优化项以相同硬件、相同矩阵的成功率、调用数和中位/P95 耗时比较；不能靠减少失败样本或放宽门提高速度。

### C. 接通一个真实工况（输入适配与 B 可交错推进）

首个验证工况固定为 `CASE_HTW_WESSELING_1`：HTW Wesseling 莱茵褐煤空气气化。紧随其后的对照为同装置 `CASE_HTW_WESSELING_2`：氧气／蒸汽气化。保留此前该空气工况的失败记录，作为回归问题来源；不继承历史调参倍率或把失败结果当初值答案。

两工况分别建立输入合同：燃料湿基给料、含水、干基元素与工业分析、粒度、压力、床高与几何、各级氧化剂的组分/流量/位置/温度、热损失，以及旋风分离、排灰和返料拓扑。空气总量与一次/二次份额不能重复计入；ER 用来核对氧量，不额外生成第二份供氧。Wesseling 2 的蒸汽绝对流量等缺口须回查原表或给出可追溯约束，不凭默认值补齐。

两者不是仅把 N2 去掉的单变量实验：给料、燃料分析及供气等按各自工况输入。共同装置和反应模型保持一致，不为通过第二工况另调速率。对照重点是氮气稀释、供氧/蒸汽、气速与传质、反应热和碳去向的耦合响应；不预设温度或组分一定向某个方向变化。

首例已含循环，因此旋风与返料闭合提前到本阶段。可以先用明确标注的冻结参数完成数值诊断，但正式物理验证必须说明参数来源、循环质量/焓账及其敏感性。关键输入缺失时保留 Wesseling 主线，将结果标为条件性预测，不自动换成无循环工况。

Wesseling 的分级供气与轴向温度/组分变化是关键。先用两区模型排查总进料、出口和守恒；它不能验收分级供气附近的局部峰值。多格扩展时必须显式表示实际注入位置，并优先细化该区域。

先从工况适配器跑当前两区模型，产出出口气、两个区域温度、碳转化、焦油/固体去向和守恒账。这一步是低阶模型的诊断性对比，不要求用两区模型重现细轴向峰值。此时无论误差大小，都要报告，不能先调速率再给用户看结果。

若两区预测明显偏差，按入口原子/焓 → 热解分配 → 净固体出口 → 主反应积分源 → 空间分辨率排查。优先选择能解释主要误差、且有守恒或文献证据的一个机制。一个问题最多两轮有明确假设的试验；未证实则归档并转向下一个高影响问题。

### D. 扩展到最小多格与跨工况验证

单工况能自动解后，将自由空间物种和能量也分格，与轨迹共用质量/焓边流。再按轴向梯度细化床层；不要同时增加大量粒级、年龄格和反应选项。每次只扩一个维度并从粗格保守映射初值。

验证固定输入下网格细化的出口与局部积分源变化。Wesseling 1 完成自动求解和初步实验对照后，立即运行 Wesseling 2；第二工况输入核对可提前进行。两工况使用同一求解入口、反应模型和验证规则，分别报告数值收敛、守恒与实验偏差，不逐工况拟合速率。随后再扩展其他燃料、压力及装置工况，检验模型泛化能力。

达到这些证据后重新审议生产集成；优先复用已验证的纯计算残差/闭合模块，避免再复制一套公式。迁移必须可在同输入上对照，不直接切默认。

## 5. 下一轮的完成定义
