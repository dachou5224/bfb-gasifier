# P2 水力尺度 0.96 卡点：自由空间氧耦合审查

日期：2026-09-24。审查对象：`docs/handoff_named_f_p2_hydro_2026-09-24.md` 与当前源码。

本轮只做诊断小试并新增审计材料。未修改生产源码、速率参数、验收门；未 commit，未覆盖尺度 0.5、0.9605625 的已有文件或正式 E8 快照；命运保持 0，P3 未启动。沿用科学审计与根因调查方法。

## 结论

交接的最后通过点可复现，但“自由空间微量氧不能进入联合对数步”和“ftol 停止说明驻点”这两项判断不成立。

在标量配平提供的正氧初值上，将自由空间氧重新纳入联合对数变量，**不消去气泡氧，也不更改任何反应式**，尺度 0.962 的冻结参数方程可同时求解至气体、焦油约 1e-15。再刷新一次参数并联立求解，尺度 0.962 的真实复合残差也通过原分块门。因而当前 0.9606 卡点至少有一个已证实的求解器原因：对正的自由空间氧进行硬排除，丢掉了与 CO、CO2 等物种同时修正的方向。

这证明局部卡点可越过，不证明水力尺度 1 或完整 E8 已收敛。本轮没有继续全程延拓。

## 2. 为什么标量配平会重新留下 CO/CO2 残差

`_e8_log_scaled_correct` 当前执行顺序是：

1. `_balance_freeboard_o2` 先单独配平自由空间氧。
2. 对数联合求解时，将小于等于 1e-12 mol/s 的自由空间氧以及两级旋风氧从变量中剔除，但保留方程行。
3. 联合求解后，再单独配平自由空间氧。

在第 2 步，求解器处理的是固定自由空间氧的受限问题；第 3 步又改变 R5 的反应程度，使刚才的 CO、CO2 等残差变化。它不是对完整联合问题的一次牛顿修正，也没有在雅可比中计入标量配平引起的隐式变化。因此受限问题停止不等于完整问题到了驻点。

在当前结果上，自由空间氧为 4.53678e-30 mol/s。以 `v = log(N/N_ref)` 为坐标，按当前残差尺度计算其雅可比列：

- CO 行：+0.00239439；CO2 行：-0.00239439；氧行：+0.00119720。
- 整列范数：0.00359159。
- 完整缩放目标 `phi = 0.5 ||F/scale||^2` 在这一个被剔除方向上的梯度为 **+7.62859e-6**，非零。

正负与 2:2:1 的比例符合 CO 氧化的计量。微小的氧状态量并没有在对数坐标里形成不可表示的无限大列；它提供了一条实际缺失的耦合方向。联合恢复该变量后，CO、CO2、焦油同时收敛，避免了逐块配平后的互相破坏。

R5 的氧幂次小于 1，原浓度坐标的导数在零附近很陡；但对正浓度采用对数坐标后，局部关系包含 `d r/d log(C) = beta*r`。完整流量坐标还需计入总浓度分母的导数；本次直接差商包含这些影响。不能把原坐标刚性直接等同为“对数联合步不可用”。

## 3. 对交接描述的修正

- `ftol` 表示目标函数相对改变量很小，不是驻点证明。应同时保存 `optimality`、梯度、约束活跃状态、实际物理残差，以及被排除列的梯度。本例恢复联合步后的 `optimality` 约为 1.55e-9；通过与否仍由原分块门决定。
- 氧从 0 到正值不是新的物理点火开关。当前 R5 等速率在该方向连续趋于零，但可能有奇异右导数。交接自己的扫描已包含 1e-40 至 1e-34 mol/s 的连续变化，不能概括成“任何可表示正氧都会导致不可控跳变”。
- 仅配平氧后 CO、CO2 各变化约两倍氧消耗量，是计量耦合的正常结果，并非应该将氧排除出联合求解的理由。
- 悬浮相氧量很小，本轮仍保留它并取得冻结参数根。因此现有证据不能把该列认定为不可逾越的根因。
- 两种焦油的聚合计量及浓度分母一致性仍是独立审计项。本轮不修改它们；求得当前实现的数学根也不能代替文献一致性验收。

## 4. 下一轮建议

1. **修正自由空间氧的活跃集规则。** 保留已经为正的微量自由空间氧，按其实际值建立对数坐标。标量配平可以作为正初值构造，但不要在联合求解前后反复覆盖它而从联合雅可比中删除它。无需气泡氧代数消去。
2. **明确零变量的重新激活机制。** 本次两级旋风氧仍为零，对应残差极小，全部行照常验收。不得据此永久冻结它们；一旦输运或反应使相关行需要修正，应给出物理一致的正初值或采用允许零边界的约束求解。标量初值现有固定区间 1e-45 至 1e-28 若不包根，会原样返回，需要显式报告并扩展括区，不能静默地把零变量继续锁死。
3. **保持完整联合导数与温度耦合。** 继续用固定对数差商步长检查稳定性，保存实际梯度和退出原因；不要为了消除本次地板再人为冻结温度或分开焦油与主气体。
4. **从本次 0.962 候选点独立复核后继续小步推进。** 先完成冻结 q 内解，再刷新 P 检查复合 H。冻结内解充分收敛后再评价 Picard 收缩率，不能把内解受限问题的残差地板归给外层。
5. **保留原验收与阶段顺序。** 水力 1、命运 0 通过后才开启命运；(1,1) 用 `recertify_named_e8` 认证后才更新正式快照。P3 仍关闭。尺度 0.962 通过不代表任何完整 E8 认证。

生产化前建议增加两个针对性测试：正的极微量自由空间氧不会因绝对阈值被剔除；内解返回时能够同时消除氧和 CO/CO2 的计量耦合残差。再做至少一次对数差商步长敏感性对照。本轮是有界诊断，不是通用求解器的完整验证。
