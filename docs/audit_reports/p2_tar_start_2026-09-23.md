原来的“45 维方程在水力尺度 0 找不到可接受起点”已通过诊断小试解决。尺度 0 和 0.5 的状态均通过原残差入口独立复算，达到气体、固体、焦油各自 L2 < 1e-6、能量绝对值 < 1 W 的原有门槛。

这些是**指定中间尺度的合格状态，不是完整 E8 认证**。从 0.5 直接跳到 1 的有界小试失败：8 次 Picard 后，气体 L2 = 4.7044e-4、固体 L2 = 7.6183e-5、焦油 L2 = 1.9276e-3，能量 = -0.4005 W。该失败状态没有替换尺度 0.5 的合格状态。不能据此判断尺度 1 无根；本轮没有进行更细的自适应延拓。

## 2. 确认的原因

### 2.1 E7 到新 E8 是方程结构变化，水力尺度 0 不再保证旧根成立

现场重新认证旧 43 维 E7：气体 L2 = 1.2468e-8，焦油 L2 = 1.9631e-13，能量 = 2.4011e-9 W，认证通过。

将其补成 45 维、气泡焦油置零，在 E7 的水力字段下得到残差 L2 = 0.0504490086。原因包括：共享焦油浓度改为各相浓度、气泡焦油源消失，以及新增的焦油交换行。水力参数插值没有对这些结构变化作连续过渡，因而缩小水力尺度不能把这个新系统自动退回旧 E7 方程。

`wirsum_1997_named_f_e8.py` 文件头仍称“未知量 43”“s=0 即已认证 E7 根”，已经过时。入口 `solve_named_e8_from_e7` 仍直接设置 `h_ok=0`，但没有先求解并验收新的尺度 0 状态。这是需要修正的延拓起点契约。

### 2.2 气泡约 0.03 mol/s 的跳变主要来自 R11，不是 R10

在同一 E7 状态和冻结参数下，仅比较源项定义改变：

| 气泡源项变化 / (mol/s) | R10 | R11 |
|---|---|---|
| CO | -2.1137e-7 | -0.02918575 |
| H2 | -9.0467e-8 | -0.02734728 |
| H2O | 0 | +0.02918575 |
| CH4 | 0 | -0.00911576 |
| O2 | +1.0569e-7 | 0 |

原来共享槽给气泡提供了非零焦油浓度；补维后气泡焦油为零，原有 R11 气泡源随之消失。这解释了初值残差的主要量级。旧 43 维路径上关于 R10 的困难不能直接作为新 45 维起点的主因。

### 2.3 交换符号正确，不应翻转

代码定义 `N_ex = K_bd V_b (C_b - C_d)`，正方向为气泡进入悬浮。主气体采用“流入 - 流出 + 源”，因此悬浮加交换、气泡减交换；焦油采用相反的整行符号“流出 - 流入 - 源”，因此悬浮减交换、气泡加交换。两种写法物理一致。

Hamel 式（2.4）、（2.5）的交换正方向与代码相反，不能只比较符号字符。气泡焦油为零且悬浮有焦油时，气泡焦油残差为负，表示需要补入气泡焦油；这不是反向传质证据。现有两相交换测试再次通过，但成对相消测试本身还不能取代方向性检查。

### 2.4 零焦油边界、差商和步裁剪共同破坏了局部牛顿模型

R10 含平方根焦油浓度。气泡焦油为零、气泡氧为正时，焦油方向没有有限的一阶导数。统一用极小正差商并不能得到一个稳定的零点雅可比。

对气泡 TAR1 列的现场差商：

| 扰动 / (mol/s) | 焦油自身残差列 | 气泡 CO 残差列 | 能量列 / (W/(mol/s)) |
|---|---|---|---|
| 1e-20 | 17672.5 | 376782 | 0 |
| 1e-16 | 323.821 | 4677.89 | -436557 |
| 1e-12 | 150.284 | 959.240 | -339583 |
| 1e-8 | 148.549 | 922.053 | -339586 |

前两列包含平方根边界的真实非光滑性；能量列为零则是差分相消，不代表物理导数为零。不能把“微量氧需要小扰动”的策略原样套到所有零分量。

复现 `_e8_active_step` 后，温度步为 -13.679 K，裁剪方向满足 `||Jp+F|| = 2.01678`，而 `F^T Jp = +0.0757472`。这个方向对于其自身线性模型也是上升方向。继续缩短线搜索步长不能修复被逐分量裁剪破坏的线性解。

### 2.5 求解用范数与物理验收门不是同一个量

当前部分路径直接把 mol/s、kg/s、W 混合成无权 L2，并要求整体小于 1e-6。尺度 0.5 的合格状态，其整体无权 L2 约 5.3815e-5，主要来自仅 5.3814e-5 W 的能量行；它明明满足全部指定门槛，却不能通过这种整体门。

应分开定义：求解器的无量纲目标函数，以及原单位下的分块验收。调整求解尺度不等于放宽验收门。

## 3. 有效的小试，以及它没有证明的内容

第一步：固定温度、固体和下游，气泡两个焦油初值设为 1.2e-5、1.8e-5 mol/s，同时求解床层 14 个气体变量和 4 个焦油变量。正变量使用 `x = x_ref exp(v)`。18 行残差降至 5.4060e-15，证明无需翻转交换符号或消去气泡氧，也存在有效求解路径。但此时能量为 -42.085 W，下游气体不平衡，不能当全系统根。

第二步：在尺度 0 的复合参数映射下联立修正全系统。对数坐标中的中心差商步长固定为 1e-4，温度坐标为 1e-7；这些是无量纲步长，不改变 SI 物理量。求解残差尺度为气体和焦油 0.01 mol/s、固体 0.001 kg/s、能量 1 W。SciPy 有界最小二乘作为诊断求根工具，最后用原物理残差验收。自动相对差商的两个试验没有达门；显式保持稳定差商步长的试验通过了尺度 0 全部分块门槛。

本轮没有将这些数值常数或工具加入生产求解器，也没有声称它是 Hamel 原文规定的求解方法。它提供的是“当前新残差存在合格起点，原求解实现并非唯一途径”的证据。尚未做初值、差商步长和残差尺度的系统敏感性验证。

下游原本为零的三个氧变量（21、28、35）保持零，**所有对应残差行仍参与全系统评价与验收**；尺度 0 自由空间氧行约 -1.17e-14 mol/s。气泡氧和悬浮氧等原本为正的微量变量始终参与求解。这不是气泡氧代数消去。后续若零变量的残差超门，必须重新进入活跃集，不能把此次的固定零集合固化为通用算法。

第三步：冻结参数内解、外层 Picard 更新，以同样方法小试水力尺度 0.1、0.5、1，命运为 0。前两个尺度通过，最后一个未通过。内层多次到达 80 次函数评估上限；报告只依据独立物理残差，不把求解器退出状态当认证。

## 4. 下一轮修改顺序

1. **先修正入口契约。** E7 只作为新模型的起始猜测；必须先取得并复核 45 维、尺度 0 的根，再初始化延拓的已接受尺度。同步修正 43/45 维与“s=0 等于 E7”的文档和测试。禁止把旧快照元数据当新模型通过证据。
2. **修正求解方向的形成方式。** 用正焦油起点避开平方根奇点；正微量物种保留。选择经过验证的正变量坐标或带约束线性子问题，避免在解出牛顿步后随意逐项裁剪。记录裁剪前后线性残差、实际下降量和预测下降量。若仍采用原坐标，能量与微量反应项应分别采用可靠的导数装配，不能用一个极小差商解决所有行。
3. **统一分块门和无量纲目标。** 保留气体/固体/焦油 L2 < 1e-6、|E| < 1 W，给线搜索一个有明确尺度的目标函数。不能再把含 W 的整体 L2 < 1e-6 当统一物理认证条件。
4. **从已复核的尺度 0.5 回退点继续。** 先收紧内层残差余量，再采用小尺度增量和失败二分；避免本轮 0.5→1 的大跳。每次冻结参数内解后必须重新计算复合残差再验收。失败候选不得覆盖最后通过点。无需重跑旧 43 维路径，也不要启动气泡氧消元。
5. **区分水力中间认证和完整 E8 认证。** 水力 1、命运 0 的通过只说明第一条参数路径完成。当前 `recertify_named_e8` 评价的是完整 `P(x)`，包含命运映射，不能把它混作前一阶段的门。先对明确标记的 `(hydro=1, fate=0)` 残差现场验收，再按既定顺序打开 Eq. 3.72；到 `(1,1)` 后运行完整 `recertify_named_e8`，通过后才更新正式端点快照。P3 继续关闭。

两相物种衡算的数学根通过，不等于全文物理实现已经全部对齐。例如当前两种焦油的反应源仍由总焦油浓度与固定混合计量分配，主气体与焦油的浓度分母也未完全统一；这些属于独立的模型一致性核查，不能由本轮求根成功自动验收，也不能无证据地归为本次初值失败的直接原因。
