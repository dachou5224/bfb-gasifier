# AA3：整炉和实验验证的出口

已认证的同伦点在 \(s=0.418\)，见 `aa1_aa2.json`。蒸汽 0、热损 0、干料生成焓 \(-3.96\times10^{6}\) J/kg。这一步没有走到 \(s=1\)。

数值路线按下面的顺序。具名核的 \(s=1\) 只是第一项。

1. 条件性的 \(s=1\) 数值根。
2. 输入固定之后，看同一点能否重复收敛，并记下每次校正的残差、雅可比和用时。
3. 接入整炉离散，以及输运、元素和分区能量账。
4. 用同一模型和同一求解器，对照表 7.1 的空气/蒸汽与氧/蒸汽。

四项目前都还没有完成。实验比较要等缺项有了来源之后。下面五项各自保留来源和空位，数值假设不写成测量，也不从出口反推。公开材料以后仍可能补上这些数。

| 输入 | 来源里有什么 | 数值假设 |
|---|---|---|
| 蒸汽 | 表 7.1 只写了空气/蒸汽或氧/蒸汽。印刷页 128–129 没有 kg/h，也没有蒸汽温度 | 0 kg/h |
| 热值与生成焓 | Hamel 表 2.2 把热值列为操作输入。表 7.1 没有热值口径，也没有数值 | 干料生成焓 \(-3.96\times10^{6}\) J/kg，示意值，不是高位或低位热值 |
| 进料粒级 | 10 档炭径来自 Dersch（1994），经 Hamel §2.2 进入模型。表 7.1 没有筛分质量 | 炭档 \(2\times10^{-4}\) m 和 \(3\times10^{-4}\) m |
| 分级注入 | 表 7.1 脚注写气化剂最多从 10 个层面进入。§7.1.2 写自由空间另有空气/蒸汽或氧/蒸汽。30.1 Nm³/h、37.5 Nm³/h 和 \(\xi=0.6\) 是历史值 | 按 \(\lambda_{O_2}\) 算出的气体全部进床底气泡入口。两区核放不下分级注入 |
