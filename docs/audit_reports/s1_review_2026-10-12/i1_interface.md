# I1 生产路径与具名核的接口差异

没有运行生产全炉求解，也没有把 50 维认证状态塞进多格 `Reactor`。两区核的未知量布局和生产 `pack_cell` 不是同一条向量。

| 项 | 具名核 stage 11 | 生产 `Reactor` |
|---|---|---|
| 气体未知量 | 床层密相、气泡、自由空间、两级旋风，各 7 个主组分 mol/s | 每个 cell 自己的气相。床是两相，自由空间和侧线通常是单相 |
| 固体 | 床层两档炭、两级旋风库存、灰、自由空间两档炭，单位 kg | `m_solid` 按 cell 和组分展开，另有返料腿 |
| 焦油 | 床、气泡、自由空间各两个代表物 | 生产物种表里的焦油槽，不按这三个槽打包 |
| 温度 | 床层和自由空间各一个，K | 每个 cell 一个温度，并有生产温度 fence |
| 负值 | 严格域里不把负浓度裁成 0 | `unpack_cell` 默认把负物流裁零 |
| 入口 | 条件边界把算出的空气全部放进气泡入口 | 连通图可以按层面把二次流送进不同高度。表 7.1 没有各层流量 |
| 氮硫 | NH3、H2S 旁路，不进气速和七组分反应 | 生产物种可以带这些组分；当前具名核没有把旁路并回去 |
| 能量 | 床层、自由空间两行，W | 逐 cell 能量，壁面热损走配置 |
| 认证向量 | 50 个数，对应上面的槽 | 维数随 `n_bed`、`n_freeboard`、旋风级数变化。不能逐项相减 |

因此总残差还没有对照。先要有同一套两区、同一输入、同一反应开关的生产 cell 组，才能把认证状态写进去，再比各相的入、出、交换、反应源、抛射、回落、旋风流和分区能量。在那之前，用总账抵消会盖住这些差异。

“最多十个注入层面”不是这套工况必须建十个 cell，也没有给出各层流量。网格加密要等注入分配有来源，或明确写成具名情景之后再做。
