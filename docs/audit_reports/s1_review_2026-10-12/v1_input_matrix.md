# V1 输入与观测合同

来源是 `data/validation_cases.json` 的两套 Wesseling 工况，以及 `wesseling12_input_ledger` 已经写明的缺项。没有用出口反推。数字化 ±5% 是读图误差，不是模型验收容差。
