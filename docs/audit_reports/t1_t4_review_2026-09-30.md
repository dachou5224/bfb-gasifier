## 2. 固定状态检验证据

### 2.1 “需要把焦油从 10^-18 抬到 10^-5”不成立

两气泡焦油为约 2.435e-18 mol/s，残差为 -1.2983e-5、-1.9989e-5 mol/s。但相对于对数变量 v=log(N/N0)，两行两列导数是：

```
             v_tar1          v_tar2
F_tar1       7.754974e-4     7.754899e-4
F_tar2       1.196482e-3     1.196470e-3
```

这些数是 mol/s 对无量纲 v 的导数，不能拿残差直接当库存改变量。采用三个相对差商步长 1e-3、1e-4、1e-5，主导方向稳定。

仅作诊断，在这个 2×2 块上用截断奇异值的最小二乘提取主导反应方向，得到两个 v 均约 0.0083585，即库存只增加 **0.84%**。两焦油残差就降到约 8.1e-9、5.4e-8 mol/s，远在 log_span=4 可达范围内。

但是，床层气体残差的改变量 L2 达到 3.33e-4 mol/s，总 merit 从 0.00359 升到 0.03381。因此该步不是可接受的全系统校正，更不是认证根。它证明的是：**小库存仍可支撑显著反应通量；瓶颈是联立耦合，不能靠独立焦油配平处理。**

### 2.2 两代表物的反应方向近共线

上述局部块最大奇异值约 2.016e-3，最小奇异值随差商步长在约 1e-16 至 4e-15 间变化。弱方向已经接近差分噪声，不能把其倒数解释成可信物理修正，也不能由此推断完整 50 维系统无根。

当前 `tar_sources_by_phase` 对两代表物使用同一个总焦油反应进度，再按固定计量分配。R10、R11 的 TAR 消耗比例相同：

- a1 = 0.3932584269662924；
- a2 = 0.6067415730337076。

所以每相的反应源只沿向量 (a1,a2) 变化。组合 `a2*F_tar1-a1*F_tar2` 中两种反应源都精确消失，剩下入口、出口与交换。其床层密相、气泡、自由空间残差分别约 1.97e-8、-1.64e-8、1.74e-7 mol/s。

这是**当前方程的代数结构**，不是本次重新裁定 Hamel 要求的物理闭合。当前原始坐标把“总焦油反应”和“组分比例输运”放在几乎平行的列里，并从含大反应项的残差差商恢复弱方向，数值上很不利。优先利用该结构做等价预条件，不增加新反应或阈值。

床温仅变化 +0.0332 K，自由空间温度 -0.0506 K。不能把问题简单归结为温度步长过大。

此处“内层实际残差”刷新热解但冻结水力；“完整残差”还刷新整个 P。小步仍出现相反趋势，支持检查遗漏的外层反馈导数。该结果尚未区分究竟是 Kbd、气速、抛射还是轨迹反馈主导，下一包应一次性分解这些贡献。

### 2.4 两个求解器口径问题

1. `wirsum_1997_named_f_e8.py:602–610,663–668`：预算退出回传最后一次非差商 `fun` 调用的坐标，记录时尚未判断其是否为已接受/最好点。外层完整残差门仍能阻止坏点认证，但这种返回方式会浪费已有改进，并污染不同算法的预算比较。T4 线性试验标记为 `jacobian_budget`，所以其最终值不足以否定该类坐标。
2. `wirsum_1997_named_f_control.py:322`：所谓冻结 merit 直接使用旧 q，而内层 `fun` 已随床温刷新热解。两者不是同一个目标。本点旧 q merit=0.00311109，真实内层 merit=0.00311658，差异不改变本次方向判断，但用于分类和退步时必须统一。

原始线性未知量的差商步长是 1e-4（其摩尔流变量单位为 mol/s），与微量焦油现值相差约 14 个数量级。对于 C_tar 的半阶速率，这不是局部导数。该路径的固定步长以及未作列尺度统一，都必须纳入试验解释；不能把“改成线性”当成唯一变量。

## 4. 下一轮工作包

顺序是 U1 → U2 → U3；U4 的输入溯源可以在不改变数值模型的情况下提前进行。不要扩展成新一轮全面物理改写。

### U1：统一评估与预算退出，短包

- 用同一函数定义内层目标：冻结水力、更新热解。控制器的内层/完整 merit 对比使用它。
- 预算退出返回已经完成评估的最好可行内层候选，排除差分探针；包括初始状态。明确这不是“外层已接受状态”，仍须完整 P 认证。
- 记录真实 F/J/P 次数、退出原因、初值/最好候选/完整残差。将校正器与控制器加入源码指纹。

验收：人为耗尽预算时，返回值的内层目标不比入口差；差分探针不被返回；原有外层接受门不变。固定 s=0.16 复现实验只做一次，不启动长路径。

### U2：构造完整耦合的可信方向，核心包

**先修正诊断模型，再选择求解策略。** 用已有 s=0.16 点，固定状态/方程/工作预算作比较。

1. 将焦油反应方向与输运比例方向分开。推荐先做可逆行变换：

   `G_sum = F1+F2`，`G_ratio = a2*F1-a1*F2`。

   `G_ratio` 直接由输运项组装，不从两个带大反应项的数相减后再求差商。必要时采用可逆变量变换 `S=N1+N2, D=a2*N1-a1*N2`；恢复关系为 `N1=a1*S+D, N2=a2*S-D`，非负约束为 `-a1*S <= D <= a2*S`。保持两个自由度，不擅自设 D=0。验收仍回到原始六行焦油残差。
2. 焦油、相关主气体、氧及温度参与同一个校正；禁止再把独立 2×2 配平当整体推进。微量氧保持活跃，相对差商做步长交叉验证。
3. 对候选方向检查完整 `H(x)=F(x;P(x))` 的方向导数，并分解“内层导数”与剩余 P 反馈。最多一个完整有限差分雅可比作为诊断基准；按实测成本设截止时间，不进行多次盲跑。若轨迹发生事件切换或积分未闭合，单独标记，不能把不可靠差分当连续导数。
4. 若完整导数给出下降方向，而冻结水力导数不给，优先补被证实缺失的反馈项或采用有完整残差保障的拟牛顿更新。不要默认每个生产迭代都重算完整 P 的全雅可比。若完整方向也失败，再区分列尺度、约束活跃集、数值秩和方程相容性，输出证据后停止。

验收：方向预测与小步真实 H 同向下降；改善原分块门，外部 CHO 不恶化到不相容；证明行/变量变换保持原始方程零点。不改速率、计量、浓度物理定义或验收门。此处变换是建议的数值实现，不能冒称 Hamel 原文指定算法。

### U3：恢复路径并建立速度基线

U2 通过后，先重验 s=0.08，再对 s=0.16 做一次受控求根。通过后才恢复到 s=1 的自适应路径，初猜取最近联合通过点；可加有限成本的切线/割线预测，但每一步都认证原方程。

每点报告实际墙钟、F/J/P 调用、分块门、两区能量、输运完成和独立 CHO。同样预算比较旧/新校正器；速度基线看到达同一联合通过状态的总成本，不能只报单次 F 提速。

若固定失败点没有明确改进，不再增加多个 320 s 同类续跑。若仍超过预算，只保留最后联合通过点及一个失败点的完整方向证据。不要把自动缩至 0.001 的路径称作数值问题已解决。
