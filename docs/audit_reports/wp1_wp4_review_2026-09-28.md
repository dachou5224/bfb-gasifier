# WP1–WP4 执行审阅与下一轮工作包

日期：2026-09-28。以当前源码、交接和固定状态小测试为依据。本轮不修改模型、不重解长链、不覆盖认证文件、不 commit。

## 1. 裁定

这轮有实质进展：共用控制器已经建立；燃料 +5% 有报告的认证端点；零变量不再全部锁死；Wesseling 输入开始独立于构造煤工况。但“工作包都完成”应改为“工作包均已开展，部分验收未闭合”。

目前同时存在两类直接阻塞：

- 求解控制器仍会长时间困在内层，且重激活、回退、超时统计没有闭合；
- Wesseling 的几何和颗粒输运接口尚不自洽，继续求根会努力求解一套失真的方程。

因此不继续扩大工况矩阵，也不把主力花在 E7 历史长链。下一轮先完成少量结构修正和接口门，再用同一入口解构造煤基准与 Wesseling 1。Wesseling 2 保持下一对照工况。

## 2. 新证据：Wesseling 接口需要先修

### 2.1 相体积超过实际床体积

`wesseling1_conditional_boundary` 用实际床体积与构造核床体积之比，分别放大原来的 0.32 和 0.10 m³。现场得到：

| 量 | 值 |
|---|---:|
| A × H_bed | 1.696460 m³ |
| V_d | 4.308470 m³ |
| V_b | 1.346397 m³ |
| (V_d+V_b)/(A H_bed) | 3.333333 |

构造核的两相体积之和 0.42 m³ 本来就不等于它的 A×H=0.126 m³，不能按比例搬到真实炉中。若 V_d/V_b 被解释为有效反应体积，必须有另外的物理定义和来源；当前适配按真实相体积使用，缺少这种说明。

修复要从 Hamel 相体积分数定义统一几何：先确定 V_d 是悬浮相总体积还是其中气体体积，再使床体积、气泡体积、悬浮相气/固体体积、交换面积和库存分母共用一个几何基础。不能只把这两个数除以 3.33 而保持其他相含率不动。

### 2.2 未判定轨迹被 tau 下限转成了新的物理出口

Wesseling 初值现场重算 `w_undecided=[1,1]`、`tau_s=[0,0]`。`fb_char_balance` 却做 `tau=max(tau_s,1e-6)`，然后装配

`m_eject - M_fb/tau - consume`。

因而“轨迹尚未判定”被转成 1 微秒的库存排出时间，同时回床/出炉权重均为零。即使不直接把未判定份额标成逃逸，库存排出与实际边流仍不一致。不能用这个残差认证 Wesseling 稳态。

应给 P(x) 增加输运闭合有效性：未判定部分对质量、占据和焓的贡献尚未收敛时，返回可诊断的未完成状态，不能以 tau 下限补成有效 q。该状态也不能被认定为物理无稳态。

固定 5 s 是数值积分窗口，不是 Hamel 的物理停留时间。不能为了得到所需库存随意加长窗口；但也不应禁止有误差控制的续积分。后续应使用回床/越顶事件、时间步收敛、尾部未决质量及占据误差控制，必要时延续尚未完成的轨迹。达到预算仍未闭合就报告输运未完成。只有有数学依据时才使用终端速度/尾部解析延拓，不能把截断时间直接当停留时间。

### 2.3 物料和能量合同仍不完整

`gas_phase_element_gap_kmol_h` 明确只含气体，未包含焦油、排炭、未释放物和其他出口。`external_element_balance_kmol_h` 目前只是输入字典相减，并未从一个实际模型状态组装完整外部账。单一标量相加检查也不能证明 C/H/O 各自循环抵消。工作包 3 尚不能称为完成独立守恒认证。

`h_f_dry_J_kg=-3.96e6` 是示意干燃料生成焓，不应与燃料高/低位热值混称。真实燃料能量输入需按统一参考态、组成和 HHV/LHV 关系构造；不能直接把热值填入生成焓字段。蒸汽、床料、供气分配等未知量继续记录缺口，已知的几何、给料基准和粒径不能用构造核默认值替代。

## 3. 新证据：控制器尚未完成上轮目标

### 3.1 冷启动仍缺求解变量

重激活后气泡 H2（9）和 CH4（11）仍为零，对应初始残差约 3.00e5 和 0.179 mol/s。它们继续被正值对数坐标排除。

当前只试气泡和自由空间焦油两个切片，以单行残差下降选择 0.1/1/10 倍的试探量，不是一般非负约束活跃集。单行不下降不能证明该变量在联合方向中应固定，尤其有快反应与计量耦合时。需要对有生成/输运来源的零变量允许可行的联合修正，并用边界最优性或完整方程检查决定是否留在边界；不能对所有零项添加同一常数。

代码还有一致性缺口：整组打开后未立即更新用于后续单行比较的 f；外层试打开若被拒绝，q 已换成 P(x_try)，accepted 却仍是旧状态。这会破坏 accepted、q、F、merit 的配套关系。应将这些量视为同一个已接受状态，候选全套通过后再一并替换。

### 3.2 “拒绝两次就停”没有构成有效回退

普通候选被拒绝后，accepted、q、内层参数都不变，再调用同一个确定性修正器通常会产生同一候选。没有缩小温度/状态信赖步，也没有沿联合方向回溯。两次拒绝只是重复计算。

应保留拒绝原因，调整步长/信赖范围或内层模型，再试一个不同的候选；有预算上限。温度 1.5 倍边界只是优化约束，不是物理证据。250–2500 K 也要标明是临时求解域还是物性适用域，不能凭数值范围宣称物理认证。

### 3.3 内层仍然可以占满全部预算

控制器仍给每次内层剩余全部时间、`max_nfev=800`。ftol 改为 1e-8 没有实现按复合误差调节内层精度，也没有及时返回候选的工作量上限。

温度 +50 K 记录约 60130 次 F、618 次 J、仅 3 次外层刷新。与旧记录相比耗时未降低；运行条件未完全受控，不能据此严格判定性能退化，但显然尚未取得整体提速证据。残差单次更快不足以抵消数百次雅可比装配。

下一步优先让每个内层在有限 J/F 预算内返回已接受迭代，而不是先大规模手写反应导数。剩余时间允许后续外层刷新；内层精度随 H 收敛逐步收紧，最终原单位门不变。

### 3.4 超时统计和最终认证仍有缺口

`_e8_log_scaled_correct` 只在 least_squares 正常返回之后写 stats。0.02 s 限时小测试抛 TimeoutError 后，stats 仍为空。失败时最需要的成本数据恰好丢失；重激活过程的 F 调用也未计入。

统计应在实际求值处累加或在 finally 汇总，返回最后已接受内层状态、终止原因；不把差分探针当候选。P 和重激活同样受统一 deadline 管理。

控制器初始分块门通过时可以直接返回，未统一检查全量有限值、非负域、温度域及输运闭合有效性。应设置一个所有成功出口共用的最终认证入口，不只在候选接受时检查温度。

### 3.5 测试通过尚不等于端点重认证

`test_wp4_controlled_reruns.py` 主要断言保存 JSON 的 passed、reason 和温度。这验证报告格式和状态标记，不能替代当前代码下重算燃料 +5% 的原始 F。本轮未重算该分支根，交接中的通过应作为运行记录保留，下一轮补可加载 x、输入和现场认证测试。

## 4. 下一轮工作包与顺序

### WP-A：修复控制器状态与预算契约

范围集中在控制器和内层适配，不改速率。

- 原子化更新 accepted/q/F/merit；组重激活后更新残差；补全零变量联合激活。
- 内层设置明确的 J/F 或迭代小预算，返回最后已接受状态；外层拒绝后实际缩步或改变信赖范围。
- 全路径调用统计、统一 deadline、每行能量和各块门比；统一最终认证。
- E7 入口随后接同一控制器，但不先跑完整链。

验收：确定性小测试覆盖“打开被拒绝后状态不变”“拒绝后第二候选不同”“超时统计非零且保存状态”“气泡 H2/CH4 可参与求解”“非法初态即使残差小也不通过”。再跑温度 +50 K、半尺度、冷初值三例。冷初值可暂未过门，但不得仍因必要变量锁死而失败。

### WP-B：修复真实工况几何与轨迹有效性

与 WP-A 独立推进，先固定状态，后联立求解。

- 统一床体积、相体积、气/固含率和库存定义；加入体积恒等式测试。
- tau 下限不得掩盖未判定轨迹；增加输运有效性门与有误差控制的事件续积分。
- 固定 Wesseling 初始气体场，单独验证各粒级抛射、回床/越顶、占据与反应后质量账，记录 dt/积分窗口收敛。

验收：几何恒等式成立；同一界面抛射/入流一致；未完成轨迹不能生成认证 q；延续积分得到闭合结果，或清楚标记何种气体场/轨迹仍未闭合。不能通过任意延长窗口或将 tau 设为 H/u_g 达标。

### WP-C：完整外部账和 Wesseling 输入证据

完成煤、水分、氧化剂、气体、焦油、固体净排出及必要未释放组分的 C/H/O 与焓账；内部循环按同一界面流逐元素抵消，焓用对应参考态。未建模 N/S 去向单独标明，不声称全元素认证。

优先补燃料能量基准、真实燃料粒级与炭粒级映射、已知二次风位置和量；蒸汽/床料/循环参数查原文，缺失继续标为条件输入。不要从出口反推。热损假设和生成焓不允许互相补偿来拟合温度。

验收：已认证构造煤端点先有完整独立账；Wesseling 1 输入账与适配器使用量逐项相符；对任意试探状态都可出具完整不平衡报告，无需先求根。

### WP-D：有限、可比较的联立重跑

只在 WP-A 状态契约、WP-B 几何/轨迹门通过后启动。

1. 当前 P3 与燃料 +5% 保存端点现场重认证。
2. 从已认证空气 0.975 出发，采用同一控制器尝试到 0.95。参数延拓记录实际步长和失败原因，不把任意 0.01 步长阈值当物理分支终点。
3. Wesseling 1 先求一个输入明确、输运有效的两区条件状态，报告所有残差和独立账；通过后才给出口预测。
4. 若大幅改变压力/尺寸/给料需参数延拓，沿输入显式定义路径，中间点不叫 Wesseling；目标必须完全到达，冷启动另列验证。
5. Wesseling 2 输入审查可提前，但待第一例流程通过后再作同模型对照。轴向峰值留待真正多格物种/能量模型。

每个长测试最多一次基准加一次针对明确改动的复跑；没有新证据不延长到十分钟。完成上述基础修正后若仍慢，再按 profile 逐块加入解析/稀疏雅可比并做 Jv 检查。

## 5. 本轮交付与限制

本轮新增固定状态探针及 `evidence.json`，路径 `docs/audit_reports/wp1_wp4_review_2026-09-28/`。现场确认体积倍率、tau 下限、残留零变量和超时统计丢失；没有运行整炉或复算新的参数分支根。

下一轮成功标准不是再增加一个“已完成工作包”标签，而是：控制器能返回有效、可审计的候选；Wesseling 方程具有一致几何与闭合输运；完整外部账可计算。在这些条件下得到的收敛或失败，才足以指导后续物理模型诊断。
