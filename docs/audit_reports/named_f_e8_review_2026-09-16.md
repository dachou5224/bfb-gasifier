# F_E8 二次评估与下一轮工作计划

日期：2026-09-16。依据 `handoff_named_f_e8_2026-09-16.md`、当前未提交代码、Hamel 原文和本轮小型探针。只新增审查文档与探针，没有改生产代码或默认值，没有重跑约 8 分钟的完整反应链。交接所述 E8 端点收敛沿用其已有记录；本轮新增结论不依赖重新求得该根。

**结论：具名核已经具备有价值的多反应联立求解能力，上一轮的主要数值问题也有修复；但“登记项取消完毕”不等于原始模型闭合。下一轮应先做源项与闭合关系的一致性修复，再扩展水力与分区能量。暂不优先增加旋风分离律、返料腿库存或接入生产求解器。**

## 1. 已有进展应该保留，完成口径需要收紧

代码核对确认：R12 在零氧、正氢处保留了非零氧右导数；R10 的残差入口不再裁剪状态；端点认证重新直接装配完整速率 F，并分开气体、固体、焦油和能量阈值；`composite_P` 与 `frozen_q` 已具名。这些是实质进展。

当前 F_E8 更准确的描述是：**一个共同温度、两粒径床炭、床层两相气体、单槽自由空间气体、冻结旋风输运、局部 DAEM/轨迹反馈的约化联立核。** 仓库 R9/H₂S、自由空间焦油和炭反应仍未包含；焦油仍是全床共享出口槽。应把“全部反应接入”改为“所选反应集已接入指定区域”。

登记不能代替物理覆盖表。例如 `freeboard_reaction` 已取消省略，不代表自由空间完整反应集；`tar_transport` 已取消，不代表焦油的逐相、逐区输运已经闭合；`energy_wall_heat` 取消仅说明可传入 Q，默认 Q=0 仍是绝热假设。建议为每个过程登记区域、物相、未知量、源项基准、闭合公式与尚存假设。

## 2. 本轮确认的问题

### 2.1 甲烷重整的相别和速率基准仍未对齐原文——优先级最高

Hamel §5.2.5、Eq. 5.50–5.51，**PDF 57 / 印刷 94–95**：甲烷重整速率以 `mol/(s·kg_Asche)` 给出；印刷 95 页紧接公式明确说明，该反应由于固体催化才达到显著速率，模拟程序只在载固悬浮相考虑。

当前仓库编号 R7 对应这条反应：

- `src/kinetics/gas_reactions.py::rate_R7` 直接返回 `k*p_CH4`，docstring 声称是体积速率；没有灰库存/灰密度参数。
- `src/solvers/wirsum_1997_stiffness_full_gas.py::gas_homogeneous_source` 对 R7 不区分 dense/bubble。
- `named_f.py::fb_gas_source` 使用 bubble 路径，因此无灰自由空间也会发生该“灰催化原式”的重整。

R8 已通过灰密度关掉气泡相，但 R7 仍未同步处理。这是物理适用范围和单位基准问题，不能被完整速率残差很小所验证。原式质量基准转换为体积源需要明确催化载体质量，例如 $r_V=\rho_{ash}r_m$，或者直接计算 $\xi=M_{ash}r_m$。具体前因子和分压单位还应逐项核验，**不能只机械乘一个灰密度，也不能用当前根不移动作为修正约束**。

建议把“不得改 rate_*”解释为不得无依据调参；一旦确认原文单位/相别不一致，必须修正。修正可能移动旧根，这正是模型纠错应有的结果。

### 2.2 E8 的非温度雅可比块仍来自 E7，命运翻转后不再匹配 F

`named_f_e8.py::jacobian_named_e8` 用 E7 组装所有 N/M 列，仅用 E8 残差替换 T 列。E8 改变粗粒逃逸后，床固体出口、旋风入口和返料粒径分配都已改变，它们对 M 的导数也随之改变，不是只补 T 列就够。

本轮在默认合法初值上，只改变温度、比较固体残差行的单列有限差分，**没有求根，也没有接近反应大数行做消差**：

| 温度 | 离开权重 | 实际 $\partial F_{M,coarse}/\partial M_{c1}$ | 当前 J 同项 |
|---|---|---:|---:|
| 800 K | [1,1] | 0.3775862 s⁻¹ | 0 |
| 1420 K | [1,0] | 0 | 0 |

800 K 时细床库存对应返料导数应约 0.3724138，J 仍给 0.75；粗床库存列也出现约 0.0625 s⁻¹ 的偏差。1420 K 同组固体列差异约 10⁻⁹，符合当前分支上 E7/E8 相同的事实。

**这个错误发生在已经翻转后的分支内部，不是“恰好碰到跳跃才没有导数”。** 因而不能等决定事件 Newton 或光滑化后再修。应先在当前 $q=P(x)$ 下组装正确的 N/M 块，然后另行处理命运边界。

### 2.3 0/1 命运跳跃主要来自过度离散；超时还被当成逃逸

Hamel Eq. 3.72–3.73，PDF 30–31 / 印刷 41–42，采用初速分布；Eq. 3.82–3.96，PDF 32–33 / 印刷 44–47，建立轨迹与停留关系。当前 `particle_fate_for_mean_launch` 仅使用平均初速，故整档颗粒同时逃逸/回落，产生强烈 0/1 切换。

此外，`coupled_f_two_bin_pyro.py::_k_eject_weights` 只区分 `returns` 与其他返回值；`undecided` 也被赋成 $w_{leave}=1$。底层轨迹默认最多计算 5 s。**未判定不是逃逸的物理证据。** 本轮未证明现有 1420 K 根使用了超时分支，但这个分支规则会污染后续扫描与外层刷新，必须先改清。

正确顺序不是先给 0/1 权重套任意 sigmoid。应先恢复有原文依据的初速分布积分，用各初速样本的通量权重合成逃逸/回落率，返回驻留时间及未判定质量份额。随着速度积分与时间/空间精度加密，验证通量和占据量是否稳定。连续分布通常会缓和平均轨迹造成的整体翻转，但不能预先保证所有参数下全局光滑。

### 2.4 当前 P 仅更新密度，且更新后的 q 不可直接再次当参考输入

E8 保持气速、黏度、气泡参数、交换与大部分几何不变，只令 $\rho_g=\rho_{ref}1100/T$。当前 K 不动、命运分支不变时，E8 等于 E7 是实现的预期结果，**不是外层耦合能力的强验收**。

还需解决参考状态接口：`outer_P_named(x,nq)` 从输入 `nq` 读取密度，若调用者把已经更新的 q 传回，则再次乘 1100/T。本轮探针：

| T | 第一次更新 ρ | 用输出 q 再更新一次 ρ |
|---|---:|---:|
| 800 K | 1.1 | 1.5125 kg/m³ |
| 1420 K | 0.6197183 | 0.4800635 kg/m³ |

当前 composite 路径始终从原始 q 求值，故不能据此说它已经历史依赖；但该 API 不能原样接入“把新 q 传入下一外迭代”的用法。应拆出不可变参考输入 b 与状态依赖结果 q，使用 $q=P(x;b)$。最终水力还必须从 N、T、P、组成与截面积一致计算气速、密度等，不能把温度缩放孤立扩成完整 P。

### 2.5 DAEM 未释放部分在局部账本中存在，却没有进入联立系统出口/剩余物方程

`pyrolysis_ledger.map_one_state` 返回 `nC_unreleased_vm`。但 `outer_P_named` 只取气体和焦油源，丢弃未释放部分；能量行仍输入全份新鲜燃料焓，出口只有气体、焦油、炭和灰，没有未转化 VM 的出口焓或相应状态。

探针给出默认原料下：

- 800 K、τ=1 s：DAEM 转化率 0.57970684，未释放 C 为 **0.08026155 mol/s**。
- 1420 K、τ=1 s：转化率 0.999995781，未释放 C 仍为约 **8.06×10⁻⁷ mol/s**。

这些数是默认原料的映射探针，不是本轮重新求出的 E8 根。它说明高温近完全转化把一个闭合缺口压得很小，却没有解决低温或更短停留时间下的问题。对连续稳态进料，未释放量必须有进一步停留/转化、未转化出口或显式库存方程；不能只在诊断账本中“记着”，又在全炉物料中消失。

下一轮先确定实际采用的模型：完整转化受限基线，或允许部分转化且带剩余物料去向的模型。不要为了补缺口再给 VM 添加任意 K。尤其不要把 800 K 命运翻转当作已验证的物理解支；该状态下热解账首先不闭合。

### 2.6 原料碳基准的修改仍未等于恢复 Hegermann 产率

`fractions_on_named_carbon_pool` 的 VM_RESCALED 分支返回焦分率 0、焦油分率 $x_t/(1-x_k)$；实际乘的却是固定给料定义的 VM 碳池。它仅在 $n_{C,VM}=(1-x_k)n_{C,fuel}$ 时能恢复 Hegermann 的焦油目标。当前固定碳份额固定，而 $x_k$ 随 T/P 变化，因此这一条件一般不成立。

目前代码避免了重复计算固定碳，但仍采用“固定炭给料 + VM 内重分配”的具名近似。应把 `hegermann_koks_minus_fixed` 从旁路诊断提升为模型基准检查，不能以总 C 守恒证明产率复现。Hamel Eq. 4.21–4.24、Tabelle 4.3，PDF 41–42 / 印刷 63–64，以原料碳定义焦/焦油分率；参数的莱茵褐煤适用范围也必须声明。

### 2.7 焦油共享槽与浓度定义不满足严格两相总浓度约束

七种主要气体各相先被归一化为 $\sum_jC_{p,j}=P/(RT)$；焦油随后按全床出口流率另算正浓度，并放入两相。若它被理解为同一物相中的真实气体组分，则总浓度超过 P/RT。本轮默认初值探针得到比例 **1.0020344**；这个 0.2% 是该探针的值，不是最终根误差或所有工况上界。

共享焦油槽可作为稀焦油近似，但必须说明相间瞬时分配假设、分母及误差条件。将其扩到自由空间前，应先建立床出口焦油流及按相浓度的统一口径；否则添加 R10/R11 只会传播原有不一致。

### 2.8 全系统一个 T 和一条总能量方程，尚未覆盖原文逐 cell 热耦合

当前 E7 允许床与自由空间具有不同气体组成，但共享同一个温度，并只闭合总进出口能量。这隐含足以维持共同温度的区间热交换，却没有计算该热交换需要的物理通量。

Hamel Eq. 2.7–2.8，PDF 19 / 印刷 19，是**每个 cell** 的能量衡算；每个 cell 内可以用一个温度，不等于整炉只有一个温度。即使全局能量残差小，也可能同时存在床层缺热、自由空间多热而互相抵消。将下一步仅定义为“再打开水力 P”仍不足以恢复反应—传质—热反馈。

### 2.9 两粒径 cohort 也有需要明示的有效反应近似

`cohort_split_rates` 将代表库存 M 按跨级分时间平均消耗。令 $a=d_{fine}/d_{coarse}$，其粗粒消耗与先前计算的瞬时表面动力学消耗之比为

$$\frac{R_{cohort}}{R_{surface}}=\frac{1+a+a^2}{3}.$$

默认 a=2/3，比例为 **19/27≈0.7037**。气固源使用同一 cohort 消耗，因而仍可守恒，但这不是“仅加迁移而有效反应源完全不变”。该平均可作为有说明的队列近似，须规定 M 是当前库存还是入队代表质量，并通过粒径网格加密/单颗粒参考积分检验。不要仅凭 `rate_formula_changed=False` 宣称无反应近似。

## 3. 认证与数值实现还应补的两项

`endpoint_certified` 当前证明合法状态满足所装配的方程阈值，不检查独立全系统元素闭合、EOS 一致性或完整 P。`q_consistency_l2` 实际比较状态更新后与冻结初始 q 的残差差异，它不是 $q-P(x)$；非零可能正是正常反馈，不应作为闭合误差使用。

`bound_feasible_direction` 将在最小 α 下越界的方向分量直接置零。这已明确不改 F，优于残差 clip，但仍是修正方向，且受数值 `lambda_min` 影响，不是由物理活跃集条件推导。E7/E8 在修改方向后丢弃 `_changed`，也未重新输出 $Jp+F$ 与下降方向诊断。应在最终实际方向上检查这些量；从已认证旧状态回退时，应显式报告 `returned_state_source`，不要让被回退覆盖的 x 与原迭代诊断混为一份结果。

此外，R8 Eq. 5.47 的原图本轮再次核对：PDF 57 / 印刷 94 的字面数字存在严重解释疑点，当前 `-3.6893+4019/T` 不是已完成原图核验的无争议转录。应单列原文疑误与当前采用式，结合 Eq. 5.43 的热力学定义和原始动力学文献核查，不能用目标温度反推。该项也不应因“会移动已经认证的根”而无限搁置。

## 5. 下一轮具体计划与验收门槛

**P0：修源项语义和当前 F/J，一轮内完成，不扩维。**

- 建立 R1–R12 的原文编号、区域/物相、速率单位、催化质量基准、气固计量表；先修 R7 的相别/灰基准，R8 疑式单列核验。
- 修 E8 在当前 q 下的全部非温度雅可比块；保留 800/1420 K 分支内对照。重做 0.1/0.5/1 K 温差敏感性，不把改变 FD 作为替代正确装配。
- 给原始 J、修改矩阵、最终可行方向与回退结果分别记录证据。
- 验收：逐反应元素零和、无灰时催化反应归零、各合法分支的 Jv/方向差分一致；不要用旧根温度不变验收。

**P1：补全物料/能量账本，确定具名核真正求什么。**

- 决定固定碳/VM 与 Hegermann 总原料基准的关系，消除对温度变化不相容的双重定义。
- DAEM 部分转化必须交代剩余物的稳态去向；原料、释放物、剩余物和出口焓用同一基准。
- 明确焦油的逐相分配与总浓度口径；把稀组分近似与严格 EOS 分开。
- 验收：多个 T、τ、进料与灰含量下，独立于内部残差的 C/H/O/灰及总焓账；同时覆盖明显未完全热解的状态。

**P2：建立一致的床面输运和有限水力 P。**

- 引入不可变参考输入；从当前气体流率/组成、T/P、面积一致得到气速和密度，再更新必要物性、水力与交换。
- 先将初速分布用于轨迹统计，明确未判定通量与驻留占据；检查单样本→分布积分及网格加密结果。
- 旋风仍用冻结 K，单独做敏感性，不强行解决文献缺口。
- 验收：同 x 重算无历史；总气流变化能反映到 u_g；初速积分、轨迹时长/精度加密后通量与驻留收敛；F 和全部导数使用同一 q。

**P3：拆分床层与自由空间能量，再扩自由空间物种。**

- 先至少两个反应区各自温度/能量方程，惰性旋风可保持明确的无热损透传；床面双向固体与气体携带同一焓流。
- 验证逐区能量及相加后的整体能量。不能仅额外加一个 T 而没有配对热流。
- 此后优先扩自由空间焦油输运/反应，再加显式炭库存与反应；每次扩维保留完整的上下游物料句柄和计量。

**P4：只读对照生产，再决定迁移。**

先在同一几何、进料、温度、组分、库存和冻结 q 下比较两条路径的源项、传质、输运和焓流；差异能逐项解释后，再考虑借用生产模块或切换求解入口。生产外层刷新与默认值仍不切。本轮不建议以全炉 LU 作为下一步验收。

阶段验收通过后才重算完整反应链，并保存端点 x、q、原始 F、源码 hash，避免每次短检查都从头跑八分钟。源码或模型改变后旧端点只作初值，必须重新认证，不能缓存旧布尔值作为通过证据。
