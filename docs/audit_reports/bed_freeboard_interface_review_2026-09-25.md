# 床层顶面—自由空间第一格接口审计

日期：2026-09-25。延续 E11 炭库存审查。本轮只新增审计报告、固定状态小测试及证据，不修改模型、参数或快照，不求整炉根，不 commit，不推进 P4。

## 1. 核心结论

**床面抛出量应在床顶界面由局部床料状态和气泡破裂模型决定一次，并作为同一股守恒流同时进入床顶出流和自由空间第一格入流。后续回落、到达上一格或最终出炉，是这股抛出流的轨迹结果，不能反过来代替床面抛出量。**

项目当前存在两套不同实现：

- 具名 E11 核为一个等效床层区加一个整个自由空间区，并非实际的多床层 cell 与多自由空间 cell 图。它由几何总库存归一化的 `K_eject*M_char` 决定炭抛出量。
- 实际 `Cell` 路径由床顶 wake 型上行系数乘炭/灰库存给出初始流量；自由空间入口虽再次计算 roof+wake，随后却归一化回原输入量，抛射公式对入口总量和当前粒级分配均被抵消。

两条路径均不能仅凭函数名称认定已经实现 Hamel 的完整式（3.67）。本报告将两者分开列出，生产路径仅做接口源码审查和局部函数测试，没有把其运行状态混入 E11。

## 2. 原文定义的过渡

文献：项目内 Hamel（2001）VDI 博士论文。PDF 页序从 1 开始，每张扫描含两页印刷页。

印刷页 36，PDF 第 28 页，§3.2：

> An der Wirbelschichtoberfläche wird durch zerplatzende Blasen Feststoff aus der Wirbelschicht in den Freiraum geschleudert. Ein Teil der Partikel wird mit dem Gasstrom aus dem Reaktor ausgetragen, während der Großteil der Feststoffs zurück in die Wirbelschicht fällt.

床面气泡破裂将固体抛入自由空间；部分随气流离开反应器，大部分返回床层。这直接区分了“床面总抛出”和“最终携出”。

床内一般轴向搬运与床面破裂不是同一边界条件。Hamel §3.2.1 先计算床面 roof/wake 抛射通量，再于 §3.2.2 指定初速度分布，§3.2.3–3.2.4 计算气体运动、颗粒轨迹和库存。

正确的数据流应为：

```text
床顶局部状态、床料组成和粒径/密度
    → 床面总固体抛射通量 F0 [kg/(m²·s)]
    → 乘床面面积 A，按物种/粒级分配 [kg/s]
    → 按初速度及必要的形状分布划分轨迹束
    → 同一总流量进入自由空间第一格
    → 格内占据、反应、向上穿越或向下返回
    → 跨床面返回量作为床顶入流
```

### 2.1 抛射机制

印刷页 37，PDF 第 28 页：

$$F_{0,r}=\rho_p(1-\varepsilon_d)\varepsilon_bu_b\frac{3\bar d_p}{d_b}\quad(3.53),$$

$$F_{0,w}=\rho_p(1-\varepsilon_d)\varepsilon_bu_b\zeta_wf_w\quad(3.54).$$

其中 roof 是气泡顶盖来源，wake 是气泡尾涡来源。这些是通量，不是 cell 内库存，也不是外部燃料给料。

印刷页 38–40，PDF 第 29–30 页进一步引入气泡聚并。定义

$$S=\sum_{k=2}^{n_B}(k-1)P''_k,$$

印刷页 40 的最终总通量式（3.67）为

$$F_0=\rho_p(1-\varepsilon_d)\varepsilon_bu_b\left[\frac{3\bar d_p}{d_b}+\left(\zeta_wf_w-\frac{3\bar d_p}{d_b}\right)S\right].$$

其前的原句是：

> Unter Berücksichtigung der Wahrscheinlichkeit einer Einzelblaseneruption ergeben Gleichung (3.52) und (3.64) eingesetzt in (3.66) folgende Korrelation für den gesamten Feststoffausstoß:

即总通量还考虑了单个气泡破裂的概率。它不等于无条件把完整 roof 和完整 wake 两项相加。式（3.65）还给出 `zeta_w*f_w` 随 `u0/umf` 的分段关系。因此当前固定 0.4×0.25 的 roof+wake 相加是简化闭合；缺少聚并权重不一定导致通量偏小，也不能靠直接提高常数修正。

### 2.2 抛出量与初速分布是不同层次

印刷页 41–42，PDF 第 30–31 页，式（3.72）—（3.73）以已有 F0 为总量，按高斯初速度分布分配，平均初速为 `1.53 ub`，参数 sigma 为 0.6。离散初速权重应保持总流量，不应再生成第二份抛出量。

回落颗粒也必须先进入第一格，贡献在格时间与库存。若某颗粒在第一格内即转向返回，它对第一格上边界的流量为零，但对床面入流和第一格库存均不为零。

## 3. 当前具名 E11 核：什么决定了抛出量

调用链：

```text
outer_P_named
  → finite_hydro_from_x
  → 对各粒级 k_eject_from_geo
      → eject_bed_top
      → eject_size_class_mass_flows
  → edges_from_x: m_eject = K_eject * M
  → fb_char_balance: m_eject - M_fb/tau - consume
```

`k_eject_from_geo` 用一个“纯物种、总份额为 1”的调用取得总固体抛射能力，然后除以几何床料总库存：

$$M_{geom}=\rho_p(1-\varepsilon_d)(1-\varepsilon_b)A H_{bed},$$

$$K_i=\frac{A F_{0,i}}{M_{geom}},\qquad \dot m_{eject,i}=A F_{0,i}\frac{M_i}{M_{geom}}.$$

因此当前实现的实质是：**把各物种/粒级在几何总床料中的质量分率乘到抛射能力上。** `eject_bed_top(m_char=1)` 中的 1 只提供组成，并不是抛射 1 kg/s 的约束。

在当前固定 roof+wake 近似下，可化简为

$$K_i=\frac{\varepsilon_bu_b}{(1-\varepsilon_b)H_{bed}}\left(\frac{3d_i}{d_b}+0.1\right).$$

面积、固体密度和悬浮相固含率在这个系数中约掉了，但仍决定几何库存和质量分率。粒级逐一用自身直径计算 roof，隐含了粒级选择性；原文总通量的平均床料粒径并不自动规定这种分配。应明确分配假设，不能把各粒级的“纯床料总通量”直接相加。

### 3.1 现有状态的数量级

固定读取 `bfb_p2_e11.npz`，未重新求根：

| 量 | 当前值 |
|---|---:|
| 床面面积 | 0.126 m² |
| 等效床高 | 1 m |
| 几何床料库存 Mgeom | 84.4074 kg |
| 粗粒炭库存 | 0.0172406 kg |
| 灰库存 | 0.205681 kg |
| 粗粒炭质量分率 M/Mgeom | 0.000204255，即 0.0204255% |
| 粗粒参数下 roof 通量 | 0.483638 kg/(m²·s) |
| wake 通量 | 11.284882 kg/(m²·s) |
| 对应的总床料抛射能力 A F0 | 1.482833 kg/s |
| 实际粗粒炭抛出流 | 0.000302875 kg/s |
| K_eject | 0.0175676 s⁻¹ |

wake 占粗粒参数下总通量约 95.9%。因此当前炭抛出量小，并非公式算出的总床料抛射能力小，主要是乘入的炭质量分率很低。

按当前 0.3 mm、1400 kg/m³ 的纯炭球假设，单颗粒质量约 1.98e-8 kg，上述炭流对应每秒约 1.53 万颗等效颗粒。此数只是按模型尺寸和纯炭密度换算，不能用于含灰、多孔真实颗粒的精确计数。

### 3.2 必须补清的床料背景

炭加灰的已表示库存约 0.223 kg，远小于 84.4074 kg 的几何库存。两者之间约 84.18 kg 的差额在此具名核中不是显式的炭/灰未知量。

若它代表真实存在的惰性床料，用几何总床料分母稀释炭可能合理；但需明确惰性物种、粒径、密度、库存，以及其是否参与抛射和返回。若没有这层物理背景，就不能把 Mgeom 当作任意数值归一化常数，更不能据此认证炭抛出量。

也不能简单改成 `M_char+M_ash` 归一化。这会把全部床料抛射能力强行分给少量炭灰，可能大幅抬高炭流，改变了物理假设。

### 3.3 该核还没有真正的“第一格”分辨率

当前 `H_freeboard=2 m`，轨迹直接按整个自由空间判回床或到顶。`w_leave` 对应到达整个自由空间顶部，而不是第一格上边界。这个核能够做总区库存闭合，但不能据它证明多个自由空间 cell 的逐格质量/库存/能量接口正确。

需先统一第一格高度、坐标原点与轨迹起始高度。分格后每一格都应统计轨迹在格时间、向上穿界和向下穿界；改变第一格厚度不应改变床面 F0，只应改变格内库存与越过该格上边界的比例。

## 4. 实际多 cell 路径：入口公式被归一化抵消

这一节只针对 `src/core/` 的真实 Cell 连接实现，不用其结果替代具名核。

### 4.1 床顶首先给出上行流

`bed_upflow_coefficient` 对床内格计算 wake 型搬运系数，顶格再乘 `zeta_w`：

$$K_{top}=\frac{f_w\zeta_w\varepsilon_bu_b}{(1-\varepsilon_b)\Delta h_{top}}.$$

随后 `_solid_upflow_rates` 给出 `K_top * M_{top,component,size}`。这条决定初始流量的路径是 **wake-only**，没有 roof 项，也没有式（3.67）的聚并组合。

`refresh_explicit_freeboard_transport_from_closure` 读取这股上行炭灰流，经过年龄/粒径分配后送入自由空间模型。传入名为 `m_char_classes_bed_top`、`m_ash_classes_bed_top` 的量在此是 kg/s 流量，不是 kg 库存；接口命名应澄清，不能把它们再按库存乘一次 K。

### 4.2 自由空间端看似重算，实际透传

`_build_size_class_bundles` 中，roof/wake 使用同一个平均直径，故每档原始流量可写为

$$\dot m_i^{raw}=C\frac{s_i}{\sum s_i}.$$

随后乘 `total_feed/total_raw`，得到

$$\dot m_i=\dot m_i^{raw}\frac{\sum s_i}{C}=s_i.$$

所以对于当前正输入分支，**不仅总量、连各粒级流量也完全回到输入值。** 此处计算 roof/wake 对初始抛射量没有影响；粒径等参数仍可能影响后续轨迹。

小测试保持两档输入为 0.0011、0.0022 kg/s，把气泡速度改为 0.5、1、2 倍，输出始终是这两个值，总量始终 0.0033 kg/s。

这不是证明发生了质量“双重抛射”：归一化确实防止第二次生成质量。但它说明实际绝对源由上游 wake-only 系数决定，不能把下游写有 roof+wake 的函数当作 Hamel 总抛射闭合已接通的证据。解决方式应是只有一处计算界面源、两端引用同一股流，而不是删除归一化后让两端各算一套。

### 4.3 回落与气体接口

`_set_bed_solid_ab_in_from_freeboard_source` 将自由空间最底格的向下流作为床顶输入，原则上正确。气体接口把床顶 `N_d+N_b` 作为自由空间入口，将自由空间气泡槽置零；这是气体物种衡算的单相处理，不代表颗粒驱动场可以立即丢掉破裂气泡气体的速度信息。

还需做一项单独接口检查：某轨迹从上部格下降经过多格时，只在最终穿过床面时回床一次，不能把每格的回落流累计后重复送回床层。本轮追踪了接口调用，未用完整多格运行认证这条轨迹账。

### 4.4 顶格厚度的当前局部缩放是合理的

测试保持顶格局部炭浓度不变，将厚度从 1 m 改为 0.5、0.25 m，同时将库存按厚度缩放。上面的生产 K 按 `1/dh` 增长，上行流均为 2.90428e-4 kg/s，局部网格不变性成立。

因此不能把“系数含 cell 高度”一律认定为错误。要保证分母是与该库存对应的体积：具名单区用全床 H，真实顶格用局部 dh。把全床 H 与顶格 M 混搭才会造成网格依赖。

## 5. 建议的接口契约与修改顺序

### 5.1 把床面当成一个守恒边界，而不是两端各自的源

建立明确的界面量：

- 总固体抛射通量 F0 与面积 A；
- 每个物种、粒级、年龄/形状、初速束的向上质量流；
- 每个物种、粒级的实际反应后返回质量流；
- 向上流携带床顶焓，向下流携带返回颗粒焓；
- 床顶床料组成分母及惰性床料库存来源。

床顶残差使用 `-m_up + m_down`，自由空间第一格使用同一份 `+m_up - m_down`。任何供给变化通过这组共同方程重新平衡；不把抛出流简单钳制到外部新鲜给料，因为内部抛出—回落循环流可以远大于净给料。

### 5.2 先补全床顶状态与抛射模型，再改下游接口

1. 明确几何总床料与活性炭/灰库存关系，补齐惰性床料和代表粒径/密度的来源。
2. 从床顶局部状态计算表面气泡参数；区分顶格中心值与床面值。当前具名核冻结 `db=0.21 m`、`eps_b=0.13` 是有限核假设，不能宣称已完成多格床面外推。
3. 对照 Hamel 式（3.55）—（3.67）完成聚并概率及 roof/wake 组合；声明颗粒组成和粒级分配模型。先用已知概率的极限测试，不靠拟合库存确定抛射常数。
4. 将这一个抛射结果同时用于床顶出流和自由空间入流。生产自由空间端改为明确接收已定质量流，不再用会被抵消的“二次 F0 计算”掩盖源的归属。
5. 细分自由空间轨迹，分别计算第一格库存、上下穿界与床面回落，接上先前审计指出的气体运动和质量—焓流一致性问题。

### 5.3 必须通过的接口测试

- **两端对账：** 每个粒级的床顶出流等于第一格入流；回落也逐项相等，组合残差里内部边流严格相消。
- **全回落：** 顶部出炉流为零，床面抛出和返回仍可非零，第一格库存仍可为正。
- **分格不变性：** 固定床面状态，改变顶格/第一格厚度，床面抛出流不变；只改变局部占据与穿越概率。
- **物种稀释：** 加入惰性床料或改变炭份额时，区分总床料通量和炭通量，不能自动把全部通量分给炭灰。
- **机制极限：** 无聚并时恢复 roof 极限；其他概率和流化工况按原式响应。不要要求初始源对实际控制参数完全不敏感。
- **能量：** 同温、无反应、全回落时，跨床面净固体焓为零；有反应则与实际返回质量一致。仅总炉能量闭合不够。
