# 第 4 章干燥与热解的原文歧义，及床料粒径（ADR 0014 X3）的闭合

> **状态：提议中。** 本 ADR 裁定 T16 比对（`refs/hamel/transcription/ch4_pyrolysis_diff.md`）“交给目标所有者的项”与差异表中的“原文有歧义”各条，并闭合 ADR 0014 的阻塞项 X3。只用 Hamel 原文内部证据、物理定义与已批准的 ADR。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 逐项裁定

### 1. 表 7.2 的挥发分

表 7.2（PDF 76 右 / S. 133）标 „Flüchtige (waf)“，数值 53,0 / 68,4 / 83,0 与 KURKELA_1992 Table 1（p. 3，“wt%, dry basis”）的干基挥发分相同，干基闭合 53,0 + 42,7 + 4,3 = 100（T16 已核）。第 4 章的莱茵褐煤路径（式 4.21–4.24，S. 63–64）的输入只有 P_WS、T_WS 与燃料的 x_C,B(waf)、x_H,B(waf)，不读挥发分（T16 头号问题第 2 条）。

**裁定**：VTT 工况 1–4（莱茵褐煤）的焦炭与焦油产率按式 (4.21)–(4.24)，不使用表 7.2 的挥发分行。标签 (waf) 记为印刷错误（数值为干基，与 Kurkela 相同）；若后续需要（例如泥炭或木材路径），按干基使用。ADR 0005 待定第 2 项由本条了结。

### 2. x_C,B(waf) 与 x_H,B(waf)

式 (4.23)、(4.24) 的输入按无水无灰基（waf）；表 7.2 给出的是 wf（无水基）的 C、H 与灰。无水无灰基的定义就是从无水基中扣除灰分。

**裁定**：x_i,B(waf) = x_i,B(wf) / (1 − x_Asche,wf)，i = C、H、O、N、S。莱茵褐煤（灰 4,3 %）：x_C = 63,8 / 0,957 = 66,67 %，x_H = 4,6 / 0,957 = 4,81 %。这是基准换算，不是解释性选择。

### 3. x_C,Gas 的基准

式 (4.26)：x_C,Gas = x_C,B(waf) − x_Koks,B(waf) − x_C,Teer·x_C,B(waf)。右侧三项都是“kg / kg 燃料（waf）”：x_C,B 是燃料碳的质量分数，x_Koks,B 由式 (4.23) 定义为 kg 焦炭 / kg 燃料，x_C,Teer·x_C,B 同理。左端只能是“kg C / kg 燃料（waf）”，与式 (4.26) 的单位行一致。

**裁定**：x_C,Gas 按燃料（waf）计；符号表“相对于燃料中的碳”的定义句为笔误。同理 x_C,Koks、x_C,Teer 是“相对于燃料碳”的分率（它们在式 4.23、4.26 中都乘以 x_C,B）。

### 4. 褐煤焦油不含氧

式 (4.24) 的焦油质量 = 焦油中的碳 + 按原煤 H/C 配上的氢，式中没有 O、N、S 项；式 (4.26)、(4.27) 也只从气相中扣除焦油的 C、H，其余元素“全部进入气相”。第 5 章 S. 95 写明莱茵褐煤的焦油在模型中以苯和萘表示，二者都只含 C、H。

**裁定**：褐煤焦油由 C、H 组成，按苯与萘的混合物表示，其比例按 S. 95 使摩尔 H/C 等于原煤（ADR 0010 第 10 条已记）。燃料中的 O、N、S 全部进入气相元素池。

### 5–7. 式 (4.3)、(4.11)、(4.12)

- **式 (4.3)**（S. 52）：干燥锋面向颗粒中心移动时 dr_e/dt < 0，而已干壳层中 ∂T/∂r > 0（热流向内）；两侧同号要求右侧为 −h′_v·w_0,tr·ρ_s·dr_e/dt。**裁定**：取负号。
- **式 (4.11)**（S. 53）：正文写 „Gaußsche Normalverteilung“，前置因子 1/(σ√(2π)) 是正态密度的归一化系数；指数为正时 ∫f dE 发散。**裁定**：指数为 −(E − E₀)²/(2σ_E²)。
- **式 (4.12)**（S. 54）：左端无量纲；∫₀^{R₀} r² dr 的量纲为长度³，体积平均的系数为 3/R₀³。**裁定**：前置因子为 3/R₀³。

三项都是由物理定义确定的读法，不是两个 agent 的字形分歧（目标所有者 2026-10-16 的规则）。印面转录不改，代码注明 `ADR 0015`。

### 8. 图 4.11

图题写式 (4.21) 与焦炭，图的纵轴与曲线为焦油（T16 已核）。**裁定**：以图为准，图题为印刷错误。只影响读图，不影响模型。

### 9. 热解气组成的平衡

§4.3（S. 69–70）按附录 A1 在恒定 T、P 下最小化自由焓，但没有写 T、P 取什么、干燥水是否并入、焦炭与焦油怎样从元素池中扣除。

- **元素池（原文推出）**：式 (4.26)、(4.27) 已给出扣除焦炭与焦油后的气相 C、H；正文写其余元素全部进入气相。因此元素量 b_i 为：C、H 取式 (4.26)、(4.27)，O、N、S 取燃料（waf）中的全部量；焦炭与焦油是预先扣除，不作为附录 A1 的源汇物质 N_Q。
- **干燥水（解释性选择）**：式 (4.21)–(4.27) 都按 waf 计，水分不在其中；干燥是水分的物理蒸发。干燥水作为 H₂O 单独进入其释放所在的 cell，不并入热解平衡的元素池。
- **温度与压力（解释性选择）**：取床层平均温度 T_WS 与床层压力 P_WS，与产率式 (4.21)、(4.22) 的输入相同（外层循环中更新）。
- **物种**：S. 69 的 „z.B.“ 清单（CO、CO₂、CH₄、C₂H₄、NH₃、H₂S、H₂O、H₂）。气相衡算中未单列的物种如何处理，在实现任务卡中按 GLOSSARY 的物种表登记。

### 10. 释放沿高度进入 cell（解释性选择）

S. 12：在“加入的燃料参与所算出的固体混合”的假定下，按反应器高度确定水与热解产物的释放，再把每一格分到的份额赋给格子（无公式）。ADR 0007、0009 已经规定了床区固体按存量份额随整体固体流输运。

**裁定**：在预计算中，对燃料粒级 k（ADR 0014 D2）：

1. **两个库存**：W_k,i 为 cell i 中尚未干燥的燃料，P_k,i 为已干燥、尚未热解的燃料，二者都以“加入燃料（原样）的当量质量”计，组成固定（水分 x_w、灰 x_A、waf 部分 1 − x_w − x_A，按表 7.2 与 ADR 0014）。实际固体质量为 W + (1 − x_w)·P，计入 cell 的固体存量（ADR 0014 的 m_inert,i = M_i − Σ m_j,k,i 中一并扣除）。
2. **输运**：W、P 与同粒级的焦炭使用相同的输运闭合（床区 ADR 0007/0009；进入自由空间的部分按 ADR 0016 第 9、10 条的输运系数）。新燃料作为 W 加入进料所在的 cell。
3. **转化（依次、一级）**：
   - 干燥：W → P，速率 W_k,i / τ_dry,k；释放水 x_w·W_k,i / τ_dry,k（kg/s），作为 H₂O 进入 cell i 的气相。
   - 热解：P → 焦炭 + 灰，速率 P_k,i / τ_pyr,k；释放气体与焦油 (1 − x_w − x_A)·(1 − x_Koks,B)·P_k,i / τ_pyr,k，组成按第 9 项与式 (4.23)–(4.27)；生成焦炭 (1 − x_w − x_A)·x_Koks,B·P_k,i / τ_pyr,k 与灰 x_A·P_k,i / τ_pyr,k，进入 cell i 的粒级 k 固体（焦炭、灰的粒径按第 11 项）。
4. **时间常数（由单颗粒模型定义，有限）**：在床层平均温度 T_WS 下运行式 (4.1)–(4.12) 的单颗粒模型，得剩余水分份额 Y_w(t) 与剩余挥发分份额 Y_v(t) = 1 − V(t)/V_∞（V_∞ 为式 4.10–4.12 的极限释放量）。取平均释放时间 T_w = ∫₀^∞ Y_w dt、T_v = ∫₀^∞ Y_v dt；二者对指数趋近的过程都有限，不需要“热解完成”的截断判据。令 τ_dry,k = T_w，τ_pyr,k = T_v − T_w。两级串联一级过程的平均释放时间为 T_w 与 T_w + τ_pyr，在 T_v ≥ T_w 时恰为 T_w 与 T_v，因此单颗粒模型中干燥与热解同时进行（外层热解、内核干燥）的情形在一阶矩意义上保留。
   - **有效域**：T_v ≥ T_w。若某粒级 T_v < T_w（平均而言热解先于干燥完成），两级串联无法匹配 T_v，该粒级超出本闭合的有效域：实现须报告（粒级、T_w、T_v）并停止，不得取 τ_pyr = 0 冒充匹配。这一情形若在第 1 关出现，作为新的阻塞项交总司令裁定。
   - **即时极限（τ = 0，不作除法）**：τ_dry,k = 0 时 W_k,i ≡ 0，加入与迁入 W 的流直接作为 W → P 的转化流（并按 x_w 释放水）；τ_pyr,k = 0（T_v = T_w）时 P_k,i ≡ 0，W → P 的转化流直接作为热解流，按上式分配为气体与焦油、焦炭和灰。实现以“τ = 0 时该库存不设状态、入流即转化流”的代数映射处理，不调用 P/τ。
   - **零含量**：x_w = 0 时定义 Y_w ≡ 0、T_w = 0（即 τ_dry = 0）；V_∞ = 0 时定义 Y_v ≡ 0，该粒级没有热解气体与焦油释放，P → 焦炭 + 灰按 τ_pyr = 0 的即时极限处理。归一化分母为零时一律按这些定义，不作除法。
5. **闭合**：每个 cell 与全炉都须满足：加入燃料 = 水释放 + 气体与焦油释放 + 生成焦炭 + 生成灰 + 未转化燃料随出流（排灰、带出）离开 + 存量变化（稳态为 0），按质量与 C、H、O、N、S 元素分别检查，容差按 ADR 0012（元素 ≤ 0,1 %）。未转化燃料随带出或排灰离开的量单列报告。
6. **外层**：这些释放与生成量在牛顿内层保持不变，由外层更新（与 ADR 0009、ADR 0012 的分工一致）。

这一做法把 S. 12 的“燃料参与固体混合”写成与 ADR 0007/0009 相同的输运闭合，没有引入新的经验分配式。归档代码中的 ζ 或 ζ^0,5 分配式不采用。首次运行报告须给出 τ_dry、τ_pyr、各 cell 的水与热解产物释放份额、未转化燃料的去向及闭合检查。

### 11. 床料粒径（闭合 ADR 0014 X3，解释性选择）

ADR 0014：VTT 的床料为焦炭与灰，没有惰性砂；床料粒径决定 ε_b、ε_d、u_mf 与 Geldart 分类。

**裁定**：床区平均粒径 d̄_P 取床区各 cell 中焦炭各粒级的质量平均（存量来自式 2.6 的牛顿解，外层更新）：d̄_P = Σ_k m_k d_k / Σ_k m_k。灰在 ADR 0014 中按 m_inert,i = M_i − Σ m_j,k,i 计；第 4、5 章的燃尽模型（shrinking particle）没有写灰的去向，本 ADR 将灰视为分布在焦炭各粒级中、按同一粒径计。床区各 cell 取同一个 d̄_P（床区质量平均），用于式 (3.1)–(3.4) 与 Geldart 分类；外层迭代的初值取燃料粒径分布的质量平均。

## 实现约束

- 第 2、3、5、6、7 条是定义或代数推出，代码注明 `ADR 0015` 与原文页码；第 1、4 条注明原文依据；第 9 条中的干燥水与 T、P，以及第 10、11 条为解释性选择，注明 `解释性选择：ADR 0015`。
- 第 10、11 条在第 1 关首次完整运行时报告各 cell 的释放份额与床区平均粒径；按 ADR 0013 冻结，不按出口结果改动。

## 证据状态

依据 T16 冻结稿（`87e6fa6`）与比对稿（已经审查，原句与页码已对照页面图像）；表 7.2 与 KURKELA_1992 Table 1 的对照见 T16 头号问题；S. 95 的模型焦油见 ADR 0010 第 10 条。

## 审查记录

- PR #69 审查：指出第 10 项把干燥与热解作为同一库存的两个一级消耗，且释放量等同于消耗量，会重复消耗、丢失焦炭与灰；单颗粒模型的热解只渐近完成，没有有限的“热解时间”。已修订：分“未干燥”“已干燥未热解”两个库存依次转化，干燥只释放水，热解释放气体与焦油并生成焦炭与灰；时间常数取单颗粒模型的平均释放时间（有限，保留两过程重叠的一阶矩）；规定各 cell 与全炉的质量、元素闭合。
- PR #69 复审：指出 T_v < T_w 时取 τ_pyr = 0 既不匹配一阶矩，又使 P/τ_pyr 除零；零水分或零挥发分时 Y、T 的归一化分母为零。已修订：T_v ≥ T_w 为有效域，超出时报告并停止，第 1 关若出现则作为新阻塞项；τ = 0 的即时极限改为不作除法的代数映射；零含量时 Y、T 另行定义。
