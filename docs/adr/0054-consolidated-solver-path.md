# 合并求解路径：牛顿变量、三层试探规则与初值构造（取代 ADR 0045、0049、0052 及其修订，修订 ADR 0017 第 7 项、ADR 0043）

> **状态：已批准（2026-11-04）。** 2026-11-03 起草；2026-11-04 按 M5 审计修订三处，第 2 项的 τ 容差经目标所有者确认。 目标所有者 2026-11-02 决定第 1 项：停止“一次停止写一条 ADR”，在限时诊断之后写一条合并的求解路径 ADR。2026-11-03 同意起草。本 ADR 只规定求解手段（CHARTER §5：初值构造、阻尼、雅可比近似），不改方程、残差、闭合、冻结值与收敛门。诊断中的两项模型层障碍（O4 Corella 有效域、O7 灰的闭合）不在本 ADR 处理，交 M5 审计与目标所有者。按 CHARTER v0.10 §8，审查方审查后由总司令批准，目标所有者可否决。

## 依据

研究底稿 `docs/research/solver-path-bounded-diagnostic.md`（PR #145）；工具 `tools/solver_path_diagnostic.py`；运行记录 `reports/research-solver-path/diagnostic/`。工况 1，主线 `21a255c`。

- **现行规则下，外层第 1 轮内层走不动**：
  - 起点不可行（O1）：初值构造的收敛解有 3 项存量在 [−τ, 0) 内，内层可行条件要求 ≥ 0，0 次迭代。
  - 把这 3 项记为 0 后，第 2 次迭代阻尼失败：O₂ 把可行步长压到 7,7·10⁻⁷（O2）。
- **四项合用时第 1 轮内层 CONVERGED**（85 次迭代；归一残差气体 7,0·10⁻⁷、固相 3,2·10⁻⁷、能量 5,1·10⁻⁸）。第 2 轮 26 次收敛。四项是：
  - 气体出流的对数变量；
  - O₂ 出流的幂变量；
  - 三层试探规则；
  - Corella 外推（仅诊断，不属本 ADR）。

  消融：去掉前三项中任一项都阻尼失败——无幂变量 2 次停于 O₂；无三层规则 4 次停于零存量；无对数变量 26 次停于最底格气泡相 H₂。
- **O₂ 的真解**：外层第 1 轮内层解中，非进风格的 O₂ 出流在 10⁻²⁰ mol/s 以下，最低 9,6·10⁻⁴⁵；进风格在 10⁻¹⁵–10⁻⁷。R5 对 O₂ 为 0,5／0,3 级（Hamel Eq. 5.36、Tab. 5.3, S. 90–91）。
  - 在 x 上，ADR 0043 的差分步长（1,8·10⁻⁸）远大于 x，导数低估 10³–10⁵ 倍（`docs/research/solver-path-alternation-o2.md` 第 3 节）。
  - √x 型函数的牛顿步向零冲过头（Δx/x ≈ −2）。
  - 在 ln x 上不越界，但对进风格每步只能前进有限量（o2log 12 次只把残差从 0,3137 降到 0,2901）。
  - 在 s = x^n 上，R5 项近似线性。
- **零存量**：存量为 0、牛顿分量为负时，ADR 0017 第 7 项的可行条件使任何 α > 0 都不可行（O3）。T26l 的零起点是同一机制，ADR 0052 修订已在初值构造中把非负移到收敛解上检查。
- **原文**：Wirsum（1998）S. 21–23 的阻尼只要求欧氏范数严格下降，**没有非负检查**；没有写雅可比用解析式还是差分，也没有零浓度的处理（T18 答卷问题 2；全文检索）。试探点上的非负检查是 ADR 0017 第 7 项加的，属求解路径约束。

## 裁定（求解手段）

### 1. 内层牛顿的变量

牛顿迭代、差分雅可比、行列缩放与阻尼在变换后的变量 y 上进行；残差始终在 x = x(y) 上按原式评价。

| 未知量 | 变量 | 差分与列缩放的尺度 s_y |
|---|---|---|
| O₂ 出流 | s = Ṅ^n，n 为该相 R5 的 O₂ 级数：床区悬浮相 0,5，床区气泡相与自由空间 0,3（Hamel Tab. 5.3, S. 91） | ṅ_ref^n |
| 其余气体出流（每轮内层起点上 Ṅ > 0 者） | z = ln Ṅ | 1 |
| 起点上 Ṅ = 0 的气体出流（第 1 关为 Ar：进气中 Ar 并入 N₂，ADR 0014 C1） | Ṅ（不变换） | ṅ_ref（ADR 0043） |
| 固相存量、温度 | 不变换 | 按 ADR 0043、ADR 0037 |

- **变换的定义域与逆映射**（#146 审查）：
  - 对数变量：z ∈ ℝ，Ṅ = exp(z) > 0。exp 溢出得到非有限值时，按第 2 项第 1 层不可评价。
  - 幂变量：s 是牛顿直接更新的实变量，允许域为 s ≥ 0，Ṅ = s^(1/n)，s = 0 对应 Ṅ = 0（可评价：R5 在 c_O2 = 0 处有定义）。
  - 试探点或差分点上 s < 0 时：按第 2 项第 2 层**不可接受，继续减半**，不评价残差。不得把负 s 平方或取绝对值折返为正 Ṅ（n = 0,5 时 (−s)² 与 s² 相同，会把另一支当作可行点；n = 0,3 时负底数的非整数幂不是实数）。实现可以用带符号的逆映射 sign(s)·|s|^(1/n) 把负 s 映为负 Ṅ，但只能用于让试探被拒，不能接受。
  - 差分点：s 列的前向差分为 s + h（h > 0），不会越过 0；若别的规则使差分点 s < 0，按第 2 项第 1 层“差分点不可评价”处理。
- 差分步长 h = √ε·max(|y|, s_y)，列缩放 C = diag(max(|y|, s_y))，行缩放 R 不变（ADR 0043 第 3 项在 y 上执行）。
- 分组差分按 ADR 0046：变换不改变列的位置与邻接。
- 每轮内层在当前点重算雅可比（ADR 0017 第 6 项）不变。
- 变换在每轮内层起点由当前 x 确定，内层中不改变。

**与 ADR 0043 第 1 项的关系（M5 审计）**：ADR 0043 第 1 项撤回了 ADR 0042 的对数变量。本项对气体出流重新采用对数变量，在气体出流上明文取代 ADR 0043 第 1 项；固相与温度仍按 ADR 0043。ADR 0043 依据的三条失效机理在本项下的情形如下：

- **审计 1-2**（初值远低于解的变量取对数后，列量级 x·∂F/∂x ≈ 10⁻²⁰，Δy 达 10¹⁷，exp 溢出）：
  - 初值远低于解的正是 O₂（10⁻²³ mol/s，而进风格的解在 10⁻¹⁵–10⁻⁷）。本项对 O₂ 不取对数，取 s = Ṅ^n，R5 在 s 上近似线性，列量级不随 x 趋零。
  - 诊断中 o2log（对 O₂ 取对数）复现了这一机理：Δy 达 10⁹，每步只接受 i ≈ 30。
  - 其余气体在起点上不远低于解：焦油初值按 ADR 0045 第 2 项取热解产率，不是 10⁻²⁰。
- **审计 1-1**（痕量列在 ADR 0041 的相对步长下不可分辨）：本项在 ln Ṅ 上取步长 √ε·max(|z|, 1)，对应 Ṅ 的相对变化约 10⁻⁸·max(|z|, 1)。它是相对扰动，不是 ADR 0041 那种可能小于半个 ulp 的绝对扰动。诊断中 85 次迭代每次雅可比都可解。
- **审计 1-3**（ADR 0042 第 2 项的不可分辨判据有误）：本项不用该判据，不逐列放大步长。

实现后的验证另报每次迭代 y 上最大的步长分量与雅可比求解是否成功（见“预先登记的验证”第 4 条）；若再现 Δy ≥ 10⁶ 或雅可比不可解，按停止上报。

### 2. 三层试探规则（取代 ADR 0017 第 7 项的“可行条件”与 ADR 0052 第 1 项第 3 步修订）

内层牛顿与初值构造的固相牛顿用同一套规则：

1. **可评价**：x(y) 有限；残差可评价且有限。速率式、物性或焦炭分配报出的定义域错误，以及试探点越出速率式适用范围（ADR 0022），按不可评价处理并继续减半。自由空间有效域（ADR 0026 第 5 项）在试探点和差分点上同样按不可评价处理。现行内层在这里停止（DOMAIN_STOP），本项改为缩步，与 ADR 0052 一致；起点或收敛解超域时仍停止。
2. **试探点约束**：
   - 不变换的气体出流 ≥ −τ_n（τ_n = 1·10⁻¹²·ṅ_ref，舍入容差）；
   - 幂变量 s ≥ 0（第 1 项的允许域；s < 0 即拒绝，不设容差）。对数变量按构造为正；
   - 温度 > 0；
   - 初值构造中，最底床格灰分 > 0（A5 排灰总流率有定义）。
3. **收敛解检查**（不在试探点上检查）：
   - 存量 ≥ −τ（τ = 1·10⁻¹²·M_tot，ADR 0052 修订）；
   - 各床格惰性物 ≥ 0；
   - 不变换的气体出流 ≥ −τ_n；
   - 初值构造中排灰灰分量 ≥ 0。

   任一不满足即停止并报告，不截断。

   **τ 容差与 CHARTER §2.1**：§2.1 要求最终解“非负”。目标所有者 2026-11-04 确认：内层与初值构造的收敛解上，“非负”按舍入容差判定，即存量 ≥ −τ、不变换的气体出流 ≥ −τ_n。[−τ, 0) 与 [−τ_n, 0) 内的值按原值报告，不改写。差分雅可比使恰为零的存量带 10⁻²⁰ 量级的舍入值（诊断第 1 轮：2 项，−5,6·10⁻²⁰、−2,2·10⁻²⁰ kg）。

阻尼的范数、严格下降与 i ≤ 30 不变（ADR 0017 第 7 项）。在 [−τ, 0) 内的存量和在 [−τ_n, 0) 内的气体出流按舍入值传给下一步（下一轮外层、报告），不改写为 0。在本规则下，O1 的起点可以评价，不需要交接修正：不改写 [−τ, 0) 存量重跑收敛组合，结果与改写为 0 时逐位相同（85 次迭代，温度差 0 K；#145 审查回复）。

### 3. 初值构造（取代 ADR 0045 第 3、4 项、ADR 0049、ADR 0052）

1. 温度按 ADR 0035 第 3 项；气相按 ADR 0045 第 2 项（全炉平衡组成，另加焦油初值；O₂ 按平衡组成）。床区焦炭按 ADR 0017 第 9 项第 3 点，自由空间存量取 0。
2. 用这一状态做第一次预计算。
3. **固相子系统**：固定气相、温度与冻结量，以全部固相为未知量求原残差的固相行。每次评价按当前状态重算排灰（ADR 0014 A5，含 ADR 0053 后的 `_drain_terms`）与床区向下流（ADR 0009 第 2 项、ADR 0053）。阻尼牛顿，试探规则按第 2 项，固相门按 ADR 0012 第 1 项。
4. **交替**：以收敛固相与按同一状态重算的排灰、反应汇、改送回馈重做预计算，回到第 3 步。交替中间的预计算里，A5 余额为负时取同式的负值（不按 ADR 0014 A5 的符号停止）。交替判据与次数不变：界面流与回落的相对变化 < 1·10⁻²，或 5 次。
5. **交替结束**时检查：
   - 最后一次预计算的 A5 排灰灰分量 ≥ 0；
   - 最后一次固相解满足第 2 项第 3 层。

   不满足即停止并报告。
6. 第一次外层以构造的状态作为上一轮单元解（ADR 0045 不变）。

### 4. 外层

- 外层规则（ADR 0012 第 2 项、ADR 0017 第 10 项）不变。
- 外层每轮预计算中的 A5 余额为负时，按 ADR 0014 A5 停止（DOMAIN_STOP）并报告带出灰、带入灰与余额；本 ADR 不放宽。诊断中外层第 2 次预计算的余额为 −9,07 g/s（O7，闭合嫌疑，未证明），交 M5 审计与目标所有者。

### 5. 撤销

- ADR 0045 第 3 项（块顺序求解）与第 4 项；第 1、2 项由第 3 项第 1 步引用保留。
- ADR 0049 全部；ADR 0052 全部及其修订（内容并入第 2、3 项）。
- ADR 0043 第 1 项在气体出流上的部分（撤回对数变量），由第 1 项取代；ADR 0043 的“固体子系统可解性预检”（只报告，已无调用方）。
- ADR 0017 第 7 项的“可行条件”一条（由第 2 项取代），其余各条不变。
- ADR 0009 有效域第 3 条中“该迭代点不在可行域内，由阻尼牛顿法缩短步长回到可行域”一句：改为试探点上不检查 m_inert,i ≥ 0，在收敛解上检查（第 2 项第 3 层），收敛解不满足时仍按该条报告。试探点上惰性物为负时，以它为催化剂质量的 R8、R9、R11（ADR 0014 A6）按原式评价；速率式报定义域错误时按第 2 项第 1 层缩步。第 3 条其余部分不变。

## 预先登记的验证（实现后、重跑之前）

在 `21a255c` 的冻结模型上，以本 ADR 的实现（不带 Corella 外推）跑工况 1 外层 1 轮，判据：

1. **复现诊断的停止点**：
   - 初值构造 4 次交替结束，A5 排灰灰分量 +0,153 g/s（±1 %）；
   - 第 1 轮内层不出现 O1、O2、O3、O5 类的停止；
   - 停止原因只能是最底床格温度到达 900 °C、Corella 拒绝差分点（O4）。
2. **复现收敛**：在测试或 `tools/` 中临时外推 Corella（不进 `hamel/`），第 1 轮内层 CONVERGED。外推写法与诊断相同：把 `hamel.kinetics.homogeneous._CORELLA_HIGH_K` 置为 +∞，即高温段参数用到 900 °C 以上（`tools/solver_path_diagnostic.py` 的 `corellaX`）。判据：迭代数不超过 100，三块归一残差 ≤ 1·10⁻⁶；收敛解与 `reports/research-solver-path/diagnostic/outer.json` 中 `rounds[0]` 的 `bed_temperature_c`、`freeboard_temperature_c` 逐格相差 < 1 K。基准复现命令：`tools/solver_path_diagnostic.py build`，再 `inner --variant gaslog,o2pow,relax,corellaX`（PR #145）。
3. 任一条不满足即停止上报，不调参数。
4. 每次迭代报告 y 上最大的步长分量、雅可比求解是否成功；出现 Δy ≥ 10⁶ 或雅可比不可解时停止上报（ADR 0043 审计 1-2 的复核）。

- `tools/solver_path_diagnostic.py` 在实现合并后改为只调用正式实现，或删除；`tools/alternation_diagnostic.py` 的符号放宽随之删除。

## 不在本 ADR 内

- O4：外层第 1 轮内层解的最底床格 920 °C 超出 Corella 有效域（ADR 0010 第 9 条）。
- O7：外层第 1 轮内层解这一过渡状态上，按现行闭合（M_i 冻结、床灰粒级随焦炭）算出的带出灰远大于进料灰，A5 余额为负。这是闭合嫌疑，未证明不存在可行的外层不动点。

两项都属冻结项，由 M5 审计与目标所有者决定。实现本 ADR 不依赖它们的结论；在冻结模型下，第 1 关仍会停在 O4。
