# 参考轨迹按粒级内部的粒径与球形度取样；界面捕获区取界面两侧各半格；登记敏感性 S17

> **状态：提议中。须目标所有者明确批准（目标所有者 2026-10-29 已同意方向）。** 依据 M4 独立审计（2026-10-29，cc、codex、cursor 三家独立会话；报告不入库，结论由总司令整合）与 STATUS 中 2026-10-29 的预先登记：本 ADR 在任何第 1 关出口结果出来之前登记，依据均与验收量无关（ADR 0013 第 4 条）。悬停闭合维持 A（ADR 0026，F17 不变）。修改冻结项 F10（自由空间轨迹的球形度）与 F29（自由空间轨迹）。按 CHARTER v0.10 §8，审查方审查后由总司令批准，并须目标所有者明确批准。

## 依据

- **原文明说**（页面图像已核）：
  - S. 45（PDF 32 右）：轨迹计算假定颗粒形状因子分布在 0,3 ≤ φ_S ≤ 1,0，平均值是程序输入，无数据时取 0,8。
  - S. 49（PDF 34 右）：解析法提速，使粒径、起始速度与球形度类别可以分得更细，更好地逼近实测固体浓度剖面。
- **现行实现的离散效应**：每个粒级只用一个代表粒径（ADR 0023 的 Sauter 平均径）与单一 φ_S = 0,8 计算参考轨迹。工况 1 初值点上，粒级 3（0,25–0,5 mm）的代表粒径恰在夹住带内，整个粒级的抛出都记为悬停；按 ADR 0023 第 2 项的粒级内分布，φ_S = 0,8 时粒级 3 只有约 51 % 的质量落在夹住带 0,261–0,372 mm 内（总司令复算），叠加 φ_S 分布后为 49–51 %。M4 三家审计均指出单一代表值造成“整级悬停”的离散放大。
- **捕获区**：ADR 0047 第 3 项把界面稳定点的捕获区 R* 取为相邻两整格之并。床面抛出的样本起步就在 R* 内，捕获时刻被定为 0，被捕获前约 1,4–12 s 的自由飞行段全部记入悬停状态，最下两格的自由状态消失（T26h 报告；cursor 审计的独立 RK4）。

## 裁定

### 1. 参考轨迹按粒级内部取样（解释性选择）

- **粒径**：粒级 k 的边界 [a_k, b_k] 按 ADR 0023（最细一档下限 0,0291 mm）。粒级内按 ADR 0023 第 2 项，质量在 ln d 上均匀；取 N_d 个等质量分位点的中点 d_k,m（在 ln d 上等分 N_d 段，取各段中点），每点权重 1/N_d。
- **球形度**：在 [0,3; 1,0] 上取截断正态分布，标准差 σ_φ = 0,1，位置参数取使截断后均值恰为 0,8 的值（σ_φ = 0,1 时约 0,806）。原文给出范围与均值，没有给出分布形状，截断正态与 σ_φ 是本 ADR 的解释性选择。取 N_φ 个等概率分位点的中点，每点权重 1/N_φ。床区仍用平均值 φ_S = 0,8（ADR 0024 不变）。
- **样本**：每个粒级的参考轨迹为 N_d × N_φ × 48 条（48 为 ADR 0028 的起始速度样本），总权重为 1。取 N_d = N_φ = 8。抛出份额、停留时间、边界穿越、自由与悬停拆分、零自由参考存量等按全部子样本加权汇总（ADR 0016 第 9、10 条，ADR 0026 第 2、3 项，记账规则不变）。
- **θ**：粒级 k 在格 j 当地生成的颗粒，也按同样的 N_d × N_φ 子样本各取一条当地生成轨迹；θ_k,j 为捕获时刻为 0 的子样本的权重之和，取值在 [0, 1]。ADR 0026 第 3 项“θ 只取 0 或 1”由此改为 [0, 1] 之间的份额，两状态方程中 θ 与 (1 − θ) 的写法不变。
- **只影响输运**：反应、颗粒数、迁移、颗粒温度仍用粒级代表粒径 d_k（ADR 0023、0044 不变）。悬停状态的滑移 u_r（ADR 0035 第 4 项）取被捕获子样本按权重平均的 v_t；自由状态的滑移仍按参考轨迹的停留时间加权（ADR 0047 第 4 项）。
- **加密（只报告）**：N_d、N_φ 各自加倍时，a、b、拆分、θ 与悬停份额的相对变化写入首次运行报告的数值加密一节。

### 2. 界面捕获区取界面两侧各半格（修订 ADR 0047 第 3 项、ADR 0026 第 2 项的界面情形）

- 界面 h_j 的稳定点，其捕获区取 R*_j = [h_j − Δh_下/2, h_j + Δh_上/2]，Δh_下、Δh_上为界面上下两格的格高。它是固定的几何区间，不是可调参数；记账仍按“最后一次进入 R*”，与 δ_h、δ_u 无关。
- 捕获时刻之前的停留，照常计入所在格的自由状态。
- **悬停状态归属**：被捕获的颗粒停在界面上，其悬停状态记在**界面下方的格**（颗粒在该格的上升气流上达到力平衡）。这是解释性选择。
- **转入悬停状态的记账**（补充 ADR 0026 第 3 项）：最后一次进入 R* 发生在格内（下方格的上半格边界，或上方格的下半格边界），不在格界面上。对发生这次进入的格 i，定义格内转入系数 c_i,k = （该格内最后一次进入 R* 的加权通量）/ m̂_i,k，使 c_i,k·m^f_i,k 从格 i 的自由状态转入界面下方格的悬停状态。格 i 是界面下方格或上方格，二者相邻，仍在块三对角结构内（ADR 0046）。自由状态方程增加出流项 −c_i,k·m^f_i,k，悬停状态方程增加对应入流；两式相加后 (j, k) 的式 (2.6) 不变，逐格与全炉守恒。床面抛出中起步即在 R* 内且此后不离开的份额，仍按 F^ej,t 直接计入悬停状态。
- 零自由参考存量（ADR 0026 第 3 项）按新的 R* 判定；最下两格的自由状态一般会恢复。

### 3. 敏感性 S17：逐格表观气速（候选 D）

- 颗粒轨迹的格内气速改取表观气速 u_0 在格内的高度平均（锥段按截面变化），其余同基准。只报告，不据此改选（ADR 0013）。
- 依据：M4 三家审计都把 D 定位为敏感性。说明：逐格平均下，工况 1 初值点的粒级 3 不被夹住；若锥段改用连续表观气速，锥段内仍有稳定点（cc、cursor 审计），因此 S17 的结论依赖格内平均方式。
- ADR 0030 的敏感性运行由 16 次增为 17 次；另把 σ_φ = 0,05、0,15 登记为数值加密一节的报告项（不作敏感性运行）。

### 4. 记录

- ADR 0016 第 7 条（u_g = u_gb(h)）的性质改记为“解释性选择（依据较强）”：原文 §3.2.3 给出的唯一自由空间气速是 u_gb，但没有一句把式 (3.82) 的 u_g 与 u_gb 等同（M4 三家一致）。
- 已知局限（cc 审计）：把 u_gb 作为整个截面的气速时，u_gb·A 比实际体积流多 20–70 %；鬼泡速度是气泡气体射流的局部速度。本 ADR 不据此改模型。

## 实现约束

- 第 1、2 项注明 `解释性选择：ADR 0048`；第 3 项在 `campaign.py` 登记 S17。
- 测试：粒级内分位点与权重（质量在 ln d 上均匀）；截断正态的均值为 0,8；N_d = N_φ = 1 且 φ 取 0,8、R* 取整格时退化为现行结果（逐位）；θ 为份额时两状态方程之和仍是式 (2.6)；格内转入系数的守恒（逐格、全炉）；R* 为半格时捕获时刻与记账对 δ 减半不变；悬停状态记在界面下方格。
- 报告：工况 1 初值点第 1 轮预计算的新旧对照（各粒级回落、带出、悬停份额与位置，θ，a、b、c，零自由参考存量），以及 N_d、N_φ 加倍的变化。
- ADR 0030 冻结清单：F10 补注轨迹的球形度分布；F29 补注粒级内取样与半格捕获区；敏感性补 S17。ADR 0016、0026、0047 加补注。
