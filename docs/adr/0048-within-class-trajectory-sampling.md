# 参考轨迹按粒级内部的粒径与球形度取样；界面捕获区取界面两侧各半格；登记敏感性 S17

> **状态：已批准（2026-10-29，目标所有者明确批准）。** 依据 M4 独立审计（2026-10-29，cc、codex、cursor 三家独立会话；报告不入库，结论由总司令整合）与 STATUS 中 2026-10-29 的预先登记：本 ADR 在任何第 1 关出口结果出来之前登记，依据均与验收量无关（ADR 0013 第 4 条）。悬停闭合维持 A（ADR 0026，F17 不变）。修改冻结项 F10（自由空间轨迹的球形度）与 F29（自由空间轨迹）。按 CHARTER v0.10 §8，审查方审查后由总司令批准，并须目标所有者明确批准。

## 依据

- **原文明说**（页面图像已核）：
  - S. 45（PDF 32 右）：轨迹计算假定颗粒形状因子分布在 0,3 ≤ φ_S ≤ 1,0，平均值是程序输入，无数据时取 0,8。
  - S. 49（PDF 34 右）：解析法提速，使粒径、起始速度与球形度类别可以分得更细，更好地逼近实测固体浓度剖面。
- **现行实现的离散效应**：每个粒级只用一个代表粒径（ADR 0023 的 Sauter 平均径）与单一 φ_S = 0,8 计算参考轨迹。工况 1 初值点上，粒级 3（0,25–0,5 mm）的代表粒径恰在夹住带内，整个粒级的抛出都记为悬停；按 ADR 0023 第 2 项的粒级内分布，φ_S = 0,8 时粒级 3 只有约 51 % 的质量落在夹住带 0,261–0,372 mm 内（总司令复算），叠加 φ_S 分布后为 49–51 %。M4 三家审计均指出单一代表值造成“整级悬停”的离散放大。
- **捕获区**：ADR 0047 第 3 项把界面稳定点的捕获区 R* 取为相邻两整格之并。床面抛出的样本起步就在 R* 内，捕获时刻被定为 0，被捕获前约 1,4–12 s 的自由飞行段全部记入悬停状态，最下两格的自由状态消失（T26h 报告；cursor 审计的独立 RK4）。

## 裁定

### 1. 参考轨迹按粒级内部取样（解释性选择）

- **粒径**：粒级 k 的边界 [a_k, b_k] 按 ADR 0023（最细一档下限 0,0291 mm）。粒级内按 ADR 0023 第 2 项，质量在 ln d 上均匀；取 N_d 个等质量分位点的中点 d_k,m（在 ln d 上等分 N_d 段，取各段中点），每点权重 1/N_d。
- **球形度**：在 [0,3; 1,0] 上取截断正态分布，标准差 σ_φ = 0,1，位置参数取使截断后均值恰为 0,8 的值（σ_φ = 0,1 时约 0,806）。原文给出范围与均值，没有给出分布形状，截断正态与 σ_φ 是本 ADR 的解释性选择。取 N_φ 个等概率分位点的中点，每点权重 1/N_φ。床区仍用平均值 φ_S = 0,8（ADR 0024 不变）。
- **样本**：每个粒级的参考轨迹为 N_d × N_φ × 48 条（48 为 ADR 0028 的起始速度样本），总权重为 1。取 N_d = N_φ = 8。抛出份额、停留时间、边界穿越、自由与悬停拆分、零自由参考存量等按全部子样本加权汇总（ADR 0016 第 9、10 条，ADR 0026 第 2、3 项，记账规则不变）。
- **θ**：当地生成的份额按第 2 项的源格→目标格拆分（θ↑、θ↓），见第 2 项；ADR 0026 第 3 项“θ 只取 0 或 1”不再适用。
- **只影响输运**：反应、颗粒数、迁移、颗粒温度仍用粒级代表粒径 d_k（ADR 0023、0044 不变）。悬停状态的滑移 u_r（ADR 0035 第 4 项）取被捕获子样本按权重平均的 v_t；自由状态的滑移仍按参考轨迹的停留时间加权（ADR 0047 第 4 项）。
- **加密（只报告）**：N_d、N_φ 各自加倍时，a、b、拆分、θ 与悬停份额的相对变化写入首次运行报告的数值加密一节。

### 2. 界面捕获区取界面两侧各半格（修订 ADR 0047 第 3 项、ADR 0026 第 2、3 项的界面情形）

**捕获区与归属（解释性选择）**

- 界面 h_j（格 j 与其上方格 j + 1 之间）的稳定点，其捕获区取 R*_j = [h_j − Δh_j/2, h_j + Δh_(j+1)/2]，即下方格的上半格加上方格的下半格。它是固定的几何区间，不是可调参数；记账仍按“最后一次进入 R*”，与 δ_h、δ_u 无关。
- 被捕获的颗粒停在界面上，其悬停状态记在**界面下方的格 j**（颗粒在该格的上升气流上达到力平衡）。因此每个格、每个粒级至多有一个悬停状态，对应它上方的那个界面。
- 捕获时刻之前的停留与边界穿越，照常计入所在格的自由状态（ADR 0016 第 9、10 条）。

**源格→目标格**

对某一子样本（粒径、球形度），只有满足夹住条件的界面才有 R*。在格 i 内，R* 的边界只有格中点：若格 i 上方的界面对该子样本是稳定点，中点以上属于 R*_i；若下方的界面是稳定点，中点以下属于 R*_(i−1)。因此格 i 中发生的“最后一次进入 R*”只有两种，各有确定的目标悬停格：

| 事件 | 发生位置 | 目标悬停格 |
|---|---|---|
| 向上越过格 i 中点、此后不离开 R*_i | 格 i | 格 i（本格，记为 ↑） |
| 向下越过格 i 中点、此后不离开 R*_(i−1) | 格 i | 格 i − 1（下方相邻格，记为 ↓） |

最下一格的中点以下没有捕获区（床面不是稳定界面），该格只有 ↑。床面抛出的样本起步于床面，不在任何 R* 内，因此 F^ej,t = 0，抛出颗粒的捕获全部经下面的 c 项记账。

**系数**（均由加权参考轨迹求得，按粒级 k）：

- 格内转入系数 c↑_i,k、c↓_i,k = （格 i 内对应事件的加权通量）/ m̂_i,k；
- 当地生成：格 i 的当地生成子样本从格中点出发，初速取当地准稳态速度（ADR 0016 第 9、10 条）。起点正落在两个 R* 的分界上，按初速方向归属：初速向上的归 R*_i，向下的归 R*_(i−1)。此后不离开该 R* 的子样本，其权重之和记为 θ↑_i,k 或 θ↓_i,k；其余为 1 − θ↑ − θ↓，进入格 i 的自由状态。

**各项流的去向**（对格 i、粒级 k；m^f、m^t 为自由、悬停存量）：

- 自由状态出流增加 (c↑ + c↓)·m^f_i,k；
- 格 i 的悬停状态入流增加 c↑_i,k·m^f_i,k + θ↑_i,k·M^in_i,k；
- 格 i − 1 的悬停状态入流增加 c↓_i,k·m^f_i,k + θ↓_i,k·M^in_i,k；
- 格 i 的自由状态接收 (1 − θ↑ − θ↓)·M^in_i,k；
- M^in 为由更大粒级迁入粒级 k 的焦炭（两状态之和，ADR 0026 第 3 项、ADR 0044）；随迁移的灰与燃料 W、P 按同一份额分配（ADR 0031、0032、0044）。灰随燃尽释放仍进入同一格 k = 1 的自由状态（ADR 0026 第 4 项第 2 点不变）；
- c 流与 θ 流携带的焦炭、灰、燃料按源状态的组成，焓按源状态的温度计；↓ 项是格 i 到格 i − 1 的相邻格传输，在两格各自的衡算中分别出现，只有两格合计才抵消。逐格与全炉的质量、元素、能量守恒；
- ADR 0026 第 3 项中由相邻格穿越界面直接进入悬停状态的 a^t、b^t 项：在半格 R* 下，最后一次进入 R* 总发生在格中点而不在格界面上，因此 a^t = b^t = 0，由 c↑、c↓ 取代。

**闭合 B、C（S13、S14）**：ADR 0038 改送的“进入悬停状态的流”相应改为 c↑·m^f、c↓·m^f、θ↑·M^in、θ↓·M^in（F^ej,t 与 a^t、b^t 已为零），按 ADR 0038 改送床区最上一格或出口，携带的组成与焓同上。

**零自由参考存量**按新的 R* 判定（ADR 0026 第 3 项的有限性论证不变）；最下两格的自由状态一般会恢复。

### 3. 敏感性 S17：逐格表观气速（候选 D）

- 颗粒轨迹的格内气速改取表观气速 u_0 在格内的高度平均（锥段按截面变化），其余同基准。只报告，不据此改选（ADR 0013）。
- 依据：M4 三家审计都把 D 定位为敏感性。说明：逐格平均下，工况 1 初值点的粒级 3 不被夹住；若锥段改用连续表观气速，锥段内仍有稳定点（cc、cursor 审计），因此 S17 的结论依赖格内平均方式。
- ADR 0030 的敏感性运行由 16 次增为 17 次；另把 σ_φ = 0,05、0,15 登记为数值加密一节的报告项（不作敏感性运行）。

### 4. 记录

- ADR 0016 第 7 条（u_g = u_gb(h)）的性质改记为“解释性选择（依据较强）”：原文 §3.2.3 给出的唯一自由空间气速是 u_gb，但没有一句把式 (3.82) 的 u_g 与 u_gb 等同（M4 三家一致）。
- 已知局限（cc 审计）：把 u_gb 作为整个截面的气速时，u_gb·A 比实际体积流多 20–70 %；鬼泡速度是气泡气体射流的局部速度。本 ADR 不据此改模型。

## 实现约束

- 第 1、2 项注明 `解释性选择：ADR 0048`；第 3 项在 `campaign.py` 登记 S17。
- 测试：
  - 粒级内分位点与权重（质量在 ln d 上均匀）；截断正态的均值为 0,8。
  - **兼容测试**：显式注入现行代表粒径（ADR 0023 的 Sauter 平均径，不是 N_d = 1 的对数中点）、单一 φ_S = 0,8 与整格 R*（ADR 0047 旧规则）作为单节点基准时，逐位复现现行结果。注意：N_d = 1 的对数中点是几何平均 √(ab)（粒级 3 为 0,3536 mm），不等于 Sauter 平均径（0,3466 mm），不得为通过此测试而改变生产取样规则。
  - 源格→目标格：上方格当地生成、初速向下、起步即捕获（θ↓）的颗粒记入下方格的悬停状态；同一源格、同一粒级的子样本分别被上方与下方界面捕获时，c↑、c↓ 分别计入正确的目标格；两种情形下逐格与全炉质量、元素、能量守恒。
  - S13、S14 下 c 流与 θ 流按 ADR 0038 改送且守恒。
  - R* 为半格时捕获时刻与记账对 δ 减半不变；最下一格只有 ↑。
- 报告：工况 1 初值点第 1 轮预计算的新旧对照（各粒级回落、带出、悬停份额与位置，θ，a、b、c，零自由参考存量），以及 N_d、N_φ 加倍的变化。
- ADR 0030 冻结清单：F10 补注轨迹的球形度分布；F29 补注粒级内取样与半格捕获区；敏感性补 S17。ADR 0016、0026、0047 加补注。
- 由 T26j 实现。
