# T25b 停下上报各项的裁定：n_0 的整数检查、有效域检查的时机、初值温度、u_r 与床层子步

> **状态：已批准（2026-10-21）。** T25b（PR #100）按停止条件上报：工况 1 被 n_0 的整数检查挡住；放行后第一次外层判为 Geldart A；基准初值 T_ad = 971,5 K 低于产率式下界 1073 K；式 (5.18) 的 u_r 与床层几何积分的子步数未登记。本 ADR 逐项裁定。规模超限（单卡与 `hamel/` 总量）属于目标所有者（CHARTER §6.2、§9），不在本 ADR。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 1. n_0 = 139,5 与 T19 的整数检查（实现与 ADR 不符）

ADR 0019 第 2 项明确：n_0 = φ·(D/d_h)² 按换算值使用、不取整（φ 只有两位有效数字）。T19 的 `orifice_volumetric_flow` 要求正整数，并有测试锁定 10,5 必须报错。这是 T19 实现早于 ADR 0019、与之不符的检查，按 ADR 0013 第 6 条属于可随时修正的实现错误。**裁定**：式 (3.37) 的 n_0 接受正的实数（有限、> 0），改 T19 的检查与对应测试；不取整，也不改 ADR 0019。由 T25b 在本 PR 内修正，并在 PR 中写明。

## 2. 经验关联式的适用范围与 Geldart 判类：在收敛解上判定

第一次外层用初值构造的床料（ADR 0017 第 9 项：燃料粒径分布）判类。最细一档（0,0506 mm，占 11,6 %）使表面/体积调和平均径 d̄_sv = 196 μm，(ρ_s − ρ_f)·d′ = 223,5 ≤ 225，判为 A。稳态床料中细粒大部分被带出，床区粒径分布与燃料不同；初值的床料只是求解路径的起点。

**裁定（求解手段，细化 ADR 0024 第 4 项与 T22 的适用范围检查）**：
- Geldart 判类与产率式（表 4.3，1073–1273 K、0,1–2,5 MPa）的适用范围，是**解**的有效域条件，在外层收敛（ADR 0012 第 2(a) 项）后、做第 2(b) 项一致性复核时判定；不满足即报告并停止（非 B 类、产率式越界），不改式、不外推接受。
- **真实类别始终计算并记录**：每次外层迭代按 ADR 0024 求 d̄_sv 与 Geldart 类别并记录（迭代号、d̄_sv、类别、与式 (8) 界线的距离）。记录的类别不得被下面的延拓改写。
- **非 B 类中间态的延拓（求解手段，不是原文对非 B 类的定义）**：外层尚未收敛时，若真实类别不是 B，床区流体力学的以下三处按 B 类系数计算，只用于求解路径：
  - 式 (3.11) 悬浮相空塔速度 u_d：取 B/D 的采用式 u_mf + (u_0 − u_mf)/3（Hamel S. 25）；
  - 式 (3.14) ψ_b：取 B 类值（技术布风器 0,76，Hamel S. 26）；
  - 式 (3.16) υ_b：取 B 类按容器直径的分段式（Hamel S. 26）。
  - 其余各式（u_mf、ε_d、气泡直径与上升速度、交换系数等）按原式计算，不受类别影响。
  - 实现：T19 的 `suspension_superficial_velocity`、`psi_b`、`upsilon_b` 不改，仍对非 B 类报错；预计算在调用这三处时传入延拓类别 `"B"`，真实类别另存另报。不得把类别字段本身强改为 B。
  - 外层收敛后，第 2(b) 项一致性复核在真实类别下重算预计算；真实类别不是 B 时，按上一条报告并停止。延拓下得到的解不作为结果。
- **经验范围越界与源项不可构造分开**：
  - “只记录、不停止”仅适用于仍能生成**有限、非负**源项的经验范围越界，即产率式（表 4.3）的温度、压力区间越界与上面的非 B 类延拓。
  - 以下保护保持即时生效，不因本项延后：非有限值；非正的物性（密度、黏度、比热、扩散系数等）；负产率（焦炭、焦油、气相任一元素）与负元素池；无定义的参数（式在该点不可求值）。现有 `lignite_yields` 等函数的拒绝不得删除或放宽。
  - 外层预计算遇到上述情况时，**停止并报告**（迭代号、量、值、所在 cell 与粒级），不截断产率或温度、不外推、不另设恢复分支；如需恢复办法，另立 ADR。
  - 最终解的有效域检查照本项第 1 条执行。
- 牛顿试探点上的反应速率越界，仍按 ADR 0022 C4 判为不可行、缩步，本项不改。

## 3. 初值温度（细化 ADR 0017 第 9 项）

基准运行的全炉气相绝热平衡把燃料全部碳计入气相并扣除 21,7 kW，得 971,5 K，使第一次外层的产率式越界。**裁定（求解手段）**：各格初值温度取 T_init = min(max(T_ad, 1073 K), 1273 K)，即投影到产率式的适用温度区间；初值气体组成仍按 ADR 0017 第 9 项。初值只影响求解路径；报告给出 T_ad 与 T_init。绝热对照（T_ad = 1095,7 K）不受投影影响。

## 4. 式 (5.18) 与式 (4.9) 的相对速度 u_r（细化 ADR 0017 第 20 项）

Re = u_r·d_P/ν_g 中的 u_r 原文未给数值（T25b 答卷）。**裁定（解释性选择）**：
- **床区**：颗粒在悬浮相中的平均速度取 0，u_r 取悬浮相的间隙气速 u_d/ε_d（式 3.10、3.11 的 u_d，T19）。
- **自由空间，自由状态**：u_r 取该 (cell, 粒级) 参考轨迹上的滑移速度按停留时间加权的平均值
  ū_r,i,k = Σ_s w_s ∫_{s 在 i 内、未捕获} |u_g(h) − u_P| dt ／ Σ_s w_s ∫_{s 在 i 内、未捕获} dt，
  其中样本 s 与权重 w_s 与 ADR 0016、0028 的参考轨迹记账相同，积分区间与 T23b 的自由停留时间相同（捕获后的时段不计）。抛出颗粒在上升、折返段的滑移与 v_t 差别可能很大，不能用 v_t 代替。实现：T25b 在 `hamel/freeboard/accounting.py` 的轨迹积分中按 cell 累加 ∫|u_g − u_P| dt，与停留时间同步输出；不另行积分轨迹。某 (cell, 粒级) 自由停留时间为 0 时，该处没有自由状态（ADR 0026），不需要 u_r。
- **自由空间，悬停状态**：u_r 取 v_t,k（ADR 0016 第 8 项的阻力）。依据：稳定平衡点上 u_P = 0、u_g(h*) = v_t,k；捕获邻域（ADR 0034）内的偏差与 δ_u 同阶。
- 两者都是以平均滑移代入 Re 的近似（Sh、Nu 对 Re 非线性），属于模型近似，不是精确轨迹滑移。报告给出各 (cell, 粒级) 的 ū_r,i,k／v_t,k。
- T25b 答卷曾拟用格中点鬼泡速度，那是气体速度而不是相对速度，不采用。

## 5. 床层几何积分的子步数

ADR 0014 A4 的 ρ_P 反求要对床区几何存量 ∫(1 − ε_b)(1 − ε_d)·ρ_P·A dh 积分；T25b 每格用 8 个 RK4 子步（`intervals_per_cell = 8`），ADR 0020 未登记。**裁定（求解器参数）**：写入 `SolverConfig` 的 `bed_integration_intervals_per_cell = 8`，加密判据：子步数加倍时 ρ_P 与 M_i 的相对变化 < 1·10⁻⁶（与内层门同级）。由 T25b 在本 PR 内登记字段并给出加密结果。
