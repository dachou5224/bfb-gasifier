# T25b 停下上报各项的裁定：n_0 的整数检查、有效域检查的时机、初值温度、u_r 与床层子步

> **状态：提议中。** T25b（PR #100）按停止条件上报：工况 1 被 n_0 的整数检查挡住；放行后第一次外层判为 Geldart A；基准初值 T_ad = 971,5 K 低于产率式下界 1073 K；式 (5.18) 的 u_r 与床层几何积分的子步数未登记。本 ADR 逐项裁定。规模超限（单卡与 `hamel/` 总量）属于目标所有者（CHARTER §6.2、§9），不在本 ADR。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 1. n_0 = 139,5 与 T19 的整数检查（实现与 ADR 不符）

ADR 0019 第 2 项明确：n_0 = φ·(D/d_h)² 按换算值使用、不取整（φ 只有两位有效数字）。T19 的 `orifice_volumetric_flow` 要求正整数，并有测试锁定 10,5 必须报错。这是 T19 实现早于 ADR 0019、与之不符的检查，按 ADR 0013 第 6 条属于可随时修正的实现错误。**裁定**：式 (3.37) 的 n_0 接受正的实数（有限、> 0），改 T19 的检查与对应测试；不取整，也不改 ADR 0019。由 T25b 在本 PR 内修正，并在 PR 中写明。

## 2. 经验关联式的适用范围与 Geldart 判类：在收敛解上判定

第一次外层用初值构造的床料（ADR 0017 第 9 项：燃料粒径分布）判类。最细一档（0,0506 mm，占 11,6 %）使表面/体积调和平均径 d̄_sv = 196 μm，(ρ_s − ρ_f)·d′ = 223,5 ≤ 225，判为 A。稳态床料中细粒大部分被带出，床区粒径分布与燃料不同；初值的床料只是求解路径的起点。

**裁定（求解手段，细化 ADR 0024 第 4 项与 T22 的适用范围检查）**：
- Geldart 判类与产率式（表 4.3，1073–1273 K、0,1–2,5 MPa）的适用范围，是**解**的有效域条件，在外层收敛（ADR 0012 第 2(a) 项）后、做第 2(b) 项一致性复核时判定；不满足即报告并停止（非 B 类、产率式越界），不改式、不外推接受。
- 外层迭代过程中（尚未收敛），按印刷式照常计算，越界只记录（迭代号、量、值、界限），不停止；Hilligardt 式 (3.11)、(3.14) 照用。这些中间值只影响求解路径；最终报告与验收只用通过第 2(b) 项的那一组（ADR 0012）。
- 牛顿试探点上的反应速率越界，仍按 ADR 0022 C4 判为不可行、缩步，本项不改。

## 3. 初值温度（细化 ADR 0017 第 9 项）

基准运行的全炉气相绝热平衡把燃料全部碳计入气相并扣除 21,7 kW，得 971,5 K；实际床层温度高于此（焦炭并未全部气化），这一初值偏低，并使第一次外层的产率式越界。**裁定（求解手段）**：各格初值温度取 T_init = min(max(T_ad, 1073 K), 1273 K)，即投影到产率式的适用温度区间；初值气体组成仍按 ADR 0017 第 9 项。初值只影响求解路径；报告给出 T_ad 与 T_init。绝热对照（T_ad = 1095,7 K）不受投影影响。

## 4. 式 (5.18) 与式 (4.9) 的相对速度 u_r（细化 ADR 0017 第 20 项）

Re = u_r·d_P/ν_g 中的 u_r 原文未给数值（T25b 答卷）。**裁定（解释性选择）**：
- **床区**：颗粒在悬浮相中的平均速度取 0，u_r 取悬浮相的间隙气速 u_d/ε_d（式 3.10、3.11 的 u_d，T19）。
- **自由空间**：u_r 取该粒级的终端沉降速度 v_t,k（ADR 0016 第 8 项的阻力）。依据：自由空间颗粒在气流中的滑移速度趋于 v_t；悬停颗粒（ADR 0026）恰好以 v_t 相对气体运动。T25b 答卷曾拟用格中点鬼泡速度，那是气体速度而不是相对速度，不采用。

## 5. 床层几何积分的子步数

ADR 0014 A4 的 ρ_P 反求要对床区几何存量 ∫(1 − ε_b)(1 − ε_d)·ρ_P·A dh 积分；T25b 每格用 8 个 RK4 子步（`intervals_per_cell = 8`），ADR 0020 未登记。**裁定（求解器参数）**：写入 `SolverConfig` 的 `bed_integration_intervals_per_cell = 8`，加密判据：子步数加倍时 ρ_P 与 M_i 的相对变化 < 1·10⁻⁶（与内层门同级）。由 T25b 在本 PR 内登记字段并给出加密结果。

- ADR 0030 冻结清单相应补列：F24（u_r）、数值检查来源补 ADR 0035 第 5 项。
