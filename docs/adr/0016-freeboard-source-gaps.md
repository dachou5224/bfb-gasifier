# §3.2 自由空间的原文歧义：轨迹闭式、固体含量、回落与带出

> **状态：已批准（2026-10-17）。** 本 ADR 裁定 T17 比对（`refs/hamel/transcription/ch3_2_freeboard_diff.md`）“原文有歧义，作为 ADR 候选”的 11 条，并补齐 ADR 0009 要求自由空间交回的三样量（各 cell 固体含量、床面回落、出口带出）。只用 Hamel 原文内部证据、物理定义与已批准的 ADR。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 逐项裁定

### 第 11 条：轨迹闭式与运动方程不相容

T17 用代入核验：式 (3.93)–(3.95)（Δ > 0）与初条件和运动方程相容；式 (3.96) 不满足 dh/du_P = u_P/q；式 (3.98)、(3.99) 不保持初速；式 (3.103) 的分子分母不满足 ∫u du/q，对调 Ψ 与 Ψ₀ 也不能修复。

**裁定**：颗粒运动以运动方程 (3.82)、(3.88)（S. 44–45）为准，u_g 按第 7 条取 u_gb(h)（式 3.74）。式 (3.90)、(3.91) 的系数 B、C 含 u_g；u_gb(h) 随高度按指数衰减时，A、B、C 不是常数，闭式 (3.93)–(3.95) 的推导前提（常系数）不成立。因此：

1. **所有轨迹**对原方程 (3.82)/(3.88) 与 dh/dt = u_P 作数值积分，系数在每一积分步按当地 h 处的 u_gb(h)、气体物性与颗粒粒径取值；相对速度 u_g − u_P 换号时阻力方向随之改变（原方程本身含这一点，不需要单独的分支切换）。
2. 不使用印刷的式 (3.93)–(3.96)、(3.98)、(3.99)、(3.103) 求解。式 (3.93)–(3.95)（已核与常系数方程相容）只作单元测试基准：在 u_g 取常数（u_gb,0 = u_0）且 Δ > 0 的情形下，数值积分须与闭式一致。
3. 积分步长与收敛：步长加密一倍时，各 cell 停留时间与回落、带出份额的相对变化须小于 1e-4（与 ADR 0012 外层判据同级），步长写入 `SolverConfig`。

数值积分求解的是原文的原方程，不修改任何方程（CHARTER §5）。归档代码中的交叉比不采用（它不是印刷式）。d_P* 与 Δ 的符号只在测试中用于选择闭式情形，不参与求解。

### 第 9、10 条：固体含量、回落、带出（补齐 ADR 0009 的接口）

S. 45：求解运动方程是为了得到各粒级在自由空间的停留时间，„um somit den Feststoffgehalt in den Bilanzräumen berechnen zu können“。S. 48：回落是 Δ < 0 的一种情形。原文没有给出由停留时间到含量、以及回落与带出的换算式（T12、T17）。

轨迹只描述颗粒怎样运动；自由空间里焦炭还在气化与燃烧，粒级还在迁移（式 2.6 含反应源汇与粒级迁移项，S. 17）。若把同一样本质量流原样记为各边界的流量和最终的回落、带出，又把存量直接定为 Σ ṁ_s·t_s,i，则全自由空间被强制为“回落 + 带出 = 抛出”，与式 (2.6) 的反应项冲突。因此轨迹只给出输运系数，实际量由式 (2.6) 定。

**裁定（解释性选择）**：
1. **参考轨迹（无反应）**：对每个粒级 k，把床面抛出按式 (3.72) 的起始速度分布（第 6 条）离散为若干样本，各带份额 dF_s（Σ dF_s = 1），按第 11 条积分到落回床面高度或到达出口高度为止，颗粒粒径沿轨迹不变。对单位抛出流量记录：样本在 cell i 内的停留时间 t_s,i（上行、下行都计），以及穿过各 cell 上、下边界的方向。
2. **输运系数**：由参考轨迹得 cell i、粒级 k 的参考存量 m̂_i,k = Σ_s dF_s·t_s,i，参考向上出流 Û_i,k（穿过 i 上边界向上的 dF_s 之和）与向下出流 D̂_i,k（穿过 i 下边界向下的 dF_s 之和）。定义 a_i,k = Û_i,k / m̂_i,k、b_i,k = D̂_i,k / m̂_i,k（1/s）。
   - **床面样本到不了的 cell（m̂_i,k = 0）**：该粒级在该 cell 的存量与式 (2.6) **照常保留**，因为较大粒级缩粒迁移来的颗粒可以在当地生成。其输运系数取“当地生成参考轨迹”：颗粒自 cell i 的中点出发，初速取当地准稳态速度 u_g(h_i) − v_t,k（v_t,k 为该粒级在当地的终端沉降速度，由式 3.82 令加速度为零得到），按第 11 条积分到离开 cell i 为止；停留时间为 t_i,k，从上边界离开则 a_i,k = 1/t_i,k、b_i,k = 0，从下边界离开则反之。不得以 ε 分母、删除状态或删除源项处理 m̂ = 0。
   - 床面样本可达的 cell 中，经粒级迁移进入的颗粒与床面来的颗粒共用同一组 a、b（同一 cell 同一粒级的固体按完全混合处理，与 ADR 0007 一致）。
   - **有效域：内部悬停**。气速随高度下降时，若某粒级的 v_t,k 落在自由空间气速的范围内，原方程在 u_g(h*) = v_t,k 处有稳定平衡（该处 du_g/dh < 0），颗粒趋近悬停，既不落回床面也不到出口，参考停留时间发散，a、b 无定义。参考轨迹（含当地生成参考轨迹）中只要有一个 dF_s > 0 的样本趋近这样的稳定平衡，该粒级即**超出本闭合的有效域**：实现须检测并报告（粒级、h*、v_t,k、所在 cell），停止求解，不得以截断飞行时间、强制判为回落或带出代替。检测判据（与 h* 的距离、速度阈值）由实现任务卡写明并做单元测试。这一情形若在第 1 关出现，作为新的阻塞项交总司令裁定有限输运闭合（候选：悬停颗粒只由反应缩粒移出，其可行性取决于该粒级在 h* 处有非零的反应或迁移去路），裁定前不运行。
3. **实际流量（与 ADR 0007 同形）**：牛顿内层中，cell i 粒级 k 的向上出流 = a_i,k·m_i,k，向下出流 = b_i,k·m_i,k，m_i,k 为式 (2.6) 的未知存量。自由空间最下一格的入流是 ADR 0009 第 1 项的床面抛出；其余边界的入流是相邻格的出流。式 (2.6) 的反应源汇与粒级迁移照常计入。
4. **回落与带出**：回落 = 自由空间最下一格的向下出流，作为床区最上一格来自上方的入流（ADR 0009 第 1 项）；带出 = 出口格的向上出流，即 ADR 0009 第 6 项的 ṁ_aus，之后按 ADR 0014 X2、X2a 离开体系。二者都是实际质量流，已扣除沿途反应。
5. **无反应时的一致性**：在有效域内（所有样本都在有限时间内落回床面或到达出口），无反应、无粒级迁移时，第 3 步的线性稳态方程组（各格出流均为正，解唯一）的解就是参考量 m̂、Û、D̂ 乘以抛出流量，即回落 + 带出 = 抛出，固体含量 = Σ 质量流 × 停留时间，与 S. 45 的目的句一致。实现须以此作单元测试。
6. **灰与外层**：灰按 ADR 0015 第 11 条取所在粒级的粒径，使用同一组 a、b；回落、带出与排灰用同一套实际质量定义参加 ADR 0014 A5 的灰平衡。a、b 依赖气体物性、u_gb(h) 与粒径，在外层循环中随温度与气体组成更新，在牛顿内层固定（与 ADR 0009、ADR 0012 的分工一致）。

这一做法与 ADR 0007 的“流量 = 系数 × 存量”同形，把 S. 45 由停留时间求固体含量的目的写成可与反应耦合的输运系数；沿轨迹的缩粒与反应不在系数中，由式 (2.6) 的粒级迁移与反应项承担。

d_P* 只用来选择解析解的情形（S. 48），不作为切割粒径。

### 第 7 条：u_g

式 (3.82) 用 u_g；§3.2.3（S. 42–43）给出自由空间的气体运动（鬼泡与射流），式 (3.74) 定义 u_gb(h)；Hamel 写明采用的是鬼泡初速。§3.2.3 的作用就是给出颗粒轨迹所需的气体速度。**裁定**：u_g = u_gb(h)（式 3.74）。二次风进入自由空间后的气速：§3.2 未讨论；u_gb(h) 衰减所趋近的表观气速按所在高度的实际气体体积流计（二次风口以上包含二次风），这一处理为解释性选择。

### 第 8 条：Re_∞

式 (3.86) 保留 24/Re_∞，Re_∞ 无数值。按名称，Re_∞ 指雷诺数趋于无穷时的阻力极限。**裁定**：取极限，24/Re_∞ → 0，z = 73,69·exp(−5,0784·φ_S)（与式 3.84 的高雷诺数项一致）。

### 第 6 条：式 (3.72) 的 σ 与 dF

S. 42 写采用 Martens 的高斯分布，均值 ≈ 1,53·u_b，σ = 0,6，称为 Varianz，放在标准差的位置，没有单位。均值以 u_b 的倍数给出。**裁定（解释性选择）**：σ 为 u_P,0/u_b 的标准差（无量纲），即 u_P,0 ~ N(1,53·u_b, (0,6·u_b)²)；按 u_P,0 的区间对密度积分得各样本的份额 dF，份额和归一为 1；u_P,0 ≤ 0 的部分不发射（计入床面回落）。另一读法（0,6 为方差或以 m/s 计）列于此，不采用。

### 第 5 条：式 (3.67)

式 (3.67) 的式面用 (1 − ε_d)，与式 (3.53)（以 ε_d 修正后的顶盖式）一致；句子引用的式 (3.52) 是 ε_mf 的形式。ζ_w·f_w 可取式 (3.65) 或 S. 39 的 0,25 × 0,4；ADR 0009 第 1 项已采用 S. 39 的 f_w = 0,25。**裁定**：照式面用 (1 − ε_d)；ζ_w = 0,4、f_w = 0,25（S. 39），与 ADR 0009 一致；式 (3.65)（Milioli und Foster 1995 的改进）不采用。

### 第 1–4 条：聚并概率的细节

- **第 1 条**：句子说 C 是半球面积与球冠面积之比，式 (3.61) 印的是球冠除以半球（1 − cos ξ），式 (3.62) 也使用 1 − cos ξ。**裁定**：照两式（互相一致），C = 1 − cos ξ；句子的语序不作依据。
- **第 2 条**：半角 30°（Clift und Grace）与 48°（Briens et al. 1988）并列。S. 38 写明聚并概率的方法是 Briens et al. (1988) 提出、Baron et al. (1990) 扩展的。**裁定**：取 48°，与所用方法的出处一致；下标按 ξ_l（Halbwinkel）。
- **第 3 条**：式 (3.55) 的 σ = 0,4 出现在 Δl/d_b 的分布中，Δl/d_b 无量纲。**裁定**：σ 为该无量纲比的标准差。
- **第 4 条**：式 (3.63) 的初值未印。**裁定**：P″₁ = P″，即 P″_k = (1 − P″)^{k−1}·P″（几何分布），求和自 k = 2 起，n_B = 5（S. 39 写“可以限制为 5”）。

## 实现约束

- 第 3、11 条为物理或原方程推出，注明 `ADR 0016`；其余为解释性选择，注明 `解释性选择：ADR 0016`。
- 第 9、10 条的样本数与第 11 条的积分步长是求解器参数，写入 `SolverConfig`；样本数加倍时 a、b 的相对变化须小于 1e-4，首次运行报告给出加密检查（只报告，不据此改选，ADR 0013）。
- 单元测试至少包括：常气速 Δ > 0 时数值积分与式 (3.93)–(3.95) 一致；无反应时第 3 步的解等于参考轨迹的记账（第 9、10 条第 5 步）。
- 首次运行报告须给出：各粒级的参考回落与带出份额、实际回落与带出流量、自由空间各 cell 的固体含量与反应消耗、自由空间的元素与质量闭合。
- 第 1 关碳转化率直接取决于带出（工况 1 不循环，碳损失全部来自带出，KURKELA_1992 p. 7），本 ADR 的第 6、9、10 条在首次运行报告中须单列。

## 审查记录

- PR #69 审查：指出 (1) 取 u_g = u_gb(h) 后方程系数随高度变化，常系数闭式 (3.93)–(3.95) 不再是解；(2) 把样本质量流原样记为流量、回落与带出，并直接规定存量，与式 (2.6) 的反应源汇冲突。已修订：所有轨迹按当地系数数值积分，闭式只作常气速测试基准；参考轨迹只给出输运系数 a、b，实际存量与流量（含回落、带出）由式 (2.6) 连同反应在牛顿解中确定，无反应时退化为参考记账。
- PR #69 复审：指出 (1) u_g 随高度下降时，v_t 落在气速范围内的颗粒会在内部稳定悬停，参考轨迹不终止，a、b 无定义，唯一稳态的说法须限于有效域；(2) m̂ = 0 时删除该粒级状态会丢掉粒级迁移来的源项。已修订：内部悬停列为有效域之外，须检测、报告并停止，第 1 关若出现则作为新阻塞项裁定，不以截断代替；m̂ = 0 时保留状态，输运系数取自 cell 中点出发的当地生成参考轨迹；无反应一致性限定在有效域内。
- **2026-10-17：总司令批准**（CHARTER v0.10 §8，目标所有者可否决）。审查方三轮审查，末轮复审通过（PR #69）；目标所有者已合并。本批准在后续 PR 中补记。文中各“有效域之外”的情形若在第 1 关出现，作为新的阻塞项交总司令裁定，裁定前不运行。
