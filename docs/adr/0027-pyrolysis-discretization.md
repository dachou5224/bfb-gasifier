# 单颗粒干燥与热解的离散参数

> **状态：已批准（2026-10-20）。** 编号为 0027。0025 已用于平衡初值的一步阻尼，0026 留给自由空间悬停闭合。本 ADR 只登记 `SolverConfig` 里热解积分用的五个字段，以及任务卡要求写明的几处读法。不改式 (4.1)–(4.12)、(4.21)–(4.27)。审查方为 codex。

## 问题

S. 53 的二次温度函数没有印出系数。同步干燥与热解期间不能改用准稳态剖面。时间常数是整段释放曲线的积分，剩余份额降到某个阈值就截断会少算尾部。径向网格、时间积分、活化能节点和尾积分的温度阈值都还没有登记。

## 裁定

`SolverConfig` 增加下列字段。`assemble_case` 使用 `SolverConfig()`，因此默认值就是本 ADR 的取值。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `pyrolysis_radial_intervals` | 24 | 干壳坐标和干燥后整球共用的径向区间数。须为不小于 4 的偶数 |
| `pyrolysis_time_rtol` | 1·10⁻⁶ | 式 (4.1) 的 BDF 相对容差。绝对容差为该值乘床温；锋面半径的绝对容差为该值乘外半径 |
| `pyrolysis_activation_nodes` | 16 | 式 (4.11) 的高斯–埃尔米特节点数 |
| `pyrolysis_tail_delta_t_k` | 0,02 | 颗粒上每一点与 T_WS 之差都小于此值（K）后，停止时间积分 |
| `pyrolysis_initial_shell_fraction` | 1·10⁻³ | 干壳初厚度和锋面停止位置，都相对外半径 |

离散：

- 壳层坐标 ξ = (r − r_e)/(R − r_e)，ξ ∈ [0, 1]。直接离散式 (4.1)，不补 S. 53 没印的二次函数系数。
- 式 (4.3) 取 −dr_e/dt，式 (4.11) 的指数取负号，式 (4.12) 的前置因子取 3/R₀³。沿用 ADR 0015 第 5–7 项。
- r_0 与 R_0 都取粒级代表粒径的一半，d_k 用 ADR 0023 的 `fuel_size_class_diameters`。
- 环境温度 T_a 取床层平均温度 T_WS。热解只发生在已干壳层，湿核保持在蒸发温度，不积累暴露。
- λ_s = a ρ_P c_P。a、ρ_P、c_P 用表 4.1，λ_s 由导温系数的定义得出，不另取数。
- 蒸发温度由 μ(H₂O, L) = μ(H₂O, g) 在床压下解出，凝相不作压力修正。c_w(T_e − T_0) 用 H₂O(L) 的焓差。w_0,tr = x_w/(1 − x_w)，x_w 为收到基水分。
- 颗粒传热用式 (4.8)、(4.9)。Re = u_r d / ν，Pr = c_p μ / λ，物性取膜温。u_r 和周围气体组成由调用方传入。
- 壳厚小于 `pyrolysis_initial_shell_fraction` 时，表面仍取蒸发温度，锋面速度取 α(T_WS − T_e)/(ρ w h′)。这一段计入 T_w 和 T_v，不把它从积分里丢掉。
- 进入温度带之后，每个活化能节点的尾积分为 Y_E(t*)/k(E)，k 在 T_WS 上计算。误差界取同一 Y_E 在 T_WS − ΔT 与 T_WS 两个速率下的尾积分之差。颗粒初温高于床温时这个界不成立，积分直接失败。
- 床温不高于蒸发温度且水分大于 0 时，锋面不会向内移动，积分失败。

收敛：把径向区间数加倍、把 `pyrolysis_time_rtol` 收紧到十分之一、或把活化能节点从 16 增到 24，T_w、T_v、τ_pyr 的相对变化都要小于 1·10⁻³。16 个径向区间在工况 1 最粗一档 d_k = 2,4885 mm 上，径向加倍后 τ_pyr 的相对变化为 1,1·10⁻³，过不了这道门，所以默认取 24。

时间常数仍按 ADR 0015 第 10 项：τ_dry = T_w，τ_pyr = T_v − T_w。T_v < T_w 时报错。零水分时 Y_w ≡ 0，τ_dry = 0。V_∞ = 0 时 Y_v ≡ 0，τ_pyr = 0，并且先于有效域检查。这两种情形不作除法。τ = 0 的库存不进入线性方程组，入流即转化流。

释放份额的质量与 C/H/O/N/S 闭合沿用 ADR 0012，元素相对燃料中该元素的进料不超过 0,1 %。该元素进料为 0 时，分母改用燃料质量流量，避免除以 0。不另设阈值。
