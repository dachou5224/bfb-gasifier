# 求解驱动的字段名与单次运行硬超时

> **状态：已批准（2026-10-22）。** T25c 把 ADR 0012、ADR 0017 第 7–8 项已经裁定的数写入 `SolverConfig`，并给 CHARTER §7 的硬超时一个数。超时以前没有数值。本 ADR 不改收敛门，不改残差。审查方为 codex。

## 字段

这些名字都在 `hamel/cases/config.py` 的 `SolverConfig` 上。数值除 `wall_timeout_s` 外都来自已经批准的 ADR，这里只固定字段名，避免另设一套阈值。

| 字段 | 取值 | 来源 |
|---|---|---|
| `nu_max` | 200 | ADR 0017 第 8 项。内层 ν 超过此数记 NOT_CONVERGED |
| `outer_round_limit` | 100 | ADR 0017 第 8 项。外层轮数超过此数记 NOT_CONVERGED |
| `damping_index_limit` | 30 | ADR 0017 第 7 项。阻尼指数 i 从 0 到此数，含两端 |
| `residual_tolerance` | 1·10⁻⁶ | ADR 0012 第 1 项。三块相对残差，也用于 ADR 0017 第 13 项的床底守恒残差 |
| `outer_temperature_tolerance_k` | 0,1 K | ADR 0012 第 2(a) 项 |
| `outer_relative_tolerance` | 1·10⁻⁴ | ADR 0012 第 2(a) 项。分母用全炉尺度 |
| `element_balance_tolerance` | 1·10⁻³ | ADR 0012 第 3 项。即 0,1 % |
| `energy_balance_tolerance` | 5·10⁻³ | ADR 0012 第 3 项。即 0,5 %，分母是燃料低位热值功率 |
| `wall_timeout_s` | 90 000 s | 本 ADR。单次运行（基准或某一次敏感性）的墙钟上限 |

差分步长按 ADR 0043：√ε_mach·max(|x_n|, s_n)。s_n 仍不另设字段。

## 硬超时

T25b 在 PR #100 测得工况 1 的一轮预计算约 530 s（冒烟子进程 533 s）。同一次冒烟把单轮墙钟上限登记为 900 s。外层失败判据是 100 轮。本卡不改预计算的速度。

`wall_timeout_s` = 100 × 900 s = 90 000 s。每一轮预计算若都停在已经登记的 900 s 上限内，轮数判据会先于时钟触发。某一次调用不返回时，到点杀掉该运行的进程组，状态记 TIMEOUT。530 s 只包含一轮预计算，不包含内层牛顿。牛顿若把单轮拉过 900 s，时钟可以先于 100 轮触发，报告仍记 TIMEOUT，不记成未收敛。

## 固体未知量的差分尺度

ADR 0017 第 6 项写 s_n 为「m 的参考存量」，没有给式。**解释性选择**：固体未知量（存量，kg）的 s_n 取该轮床区几何存量之和 M_tot。气体未知量取 Ṅ_ref，温度取 1 K。M_tot 随外层更新；某一轮的差分只用该轮的 M_tot。这只影响差分步长，不改残差。

## 实现约束

- 注明 `求解器参数：ADR 0037`。`wall_timeout_s` 与固体尺度的选择是本 ADR 的新内容；其余字段的数值仍以 ADR 0012、ADR 0017 为准。
- 超时在运行边界用进程组杀掉。循环内部另看同一个截止时间，以便在两次预计算之间停下。

## 审查记录

- **2026-10-22：总司令批准**（CHARTER v0.10 §8，目标所有者可否决）。随 T25c 由审查方复审通过（PR #104）。`wall_timeout_s` 只作失败判据；按约 530 s 一轮，预计单次运行 10–30 轮约 1,5–4,5 h。
- 2026-10-26 维护：差分步长的取值改由 ADR 0041 规定。本 ADR 的 s_n 只在 x_n = 0 时进入步长，固体尺度仍取 M_tot。
- 2026-10-28 维护：差分步长改由 ADR 0043 规定，恢复为 √ε_mach·max(|x_n|, s_n)。s_n 在 |x_n| 小于尺度时进入步长，固体尺度仍取 M_tot。
