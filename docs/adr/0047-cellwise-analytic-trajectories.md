# 自由空间颗粒轨迹改为逐格常系数解析解（修订 ADR 0016 第 7、11 条，取代 ADR 0028 的步长、ADR 0034 的势能井与 ADR 0036 第 1 项）

> **状态：提议中。须目标所有者明确批准。** 目标所有者 2026-10-28 决定先做两项提高计算效率的改动（ADR 0046 与本 ADR），以便后续试算。本 ADR 回到 Hamel 原文的逐格解析轨迹，修改已冻结的 ADR 0016 第 7、11 条及其下游参数，因此除审查方审查、总司令批准外须目标所有者明确批准。依据与研究见 `docs/research/freeboard-trajectory-cellwise.md`（PR #121）。

## 依据（页面图像已核）

- **S. 45（PDF 32 右）**：数值积分（Runge–Kutta）求颗粒运动“即使在高性能计算机上”也使计算时间长到不可接受；按 Wirsum (1998) 取 c_W = 24/Re + z（式 3.85），使运动方程 (3.82) 可解析求解。
- **S. 46–47（PDF 33）**：式 (3.88) du_P/dt = A·u_P² + B·u_P + C，系数 (3.89)–(3.91) 含 u_g，括号内外两套符号分别对应颗粒慢于气体（含下落）与快于气体；按 Δ = 4AC − B² 的符号分两种解。
- **S. 48（PDF 34 左）**：在 cell 模型中先确定颗粒在衡算空间边界上的速度，以决定用哪种解——解析解**逐格**应用，格内系数为常数。
- **S. 49（PDF 34 右）**：解析法比数值积分快约 50 倍。
- 现行 ADR 0016 第 7、11 条取连续的 u_gb(h) 并对全部轨迹数值积分；T26b 起每轮预计算约 530 s，主要花在轨迹上，并带来格内连续平衡点、窄根（ADR 0036）与势能井（ADR 0034）等复杂机制。

## 裁定

### 1. 格内气速（解释性选择）

自由空间第 i 格的气速取常数 ū_g,i = 该格内 u_gb(h) 沿高度的平均值；u_gb(h) 仍按 ADR 0016 第 7 条（式 3.74–3.76，二次风口以上的表观气速含二次风）。原文写明逐格应用，但没有说明格内取哪个值；可选的还有格中点值或入口边界值。工况 1 初值点上，最下格（含锥段）的格内平均为 1,2251 m/s、格中点为 1,2316 m/s，相差 0,0065 m/s（0,53 %）；其上各格相差不超过约 0,0008 m/s。最下格的差异直接改变第一个界面夹住窗口的上界，因此取法不是无关紧要的；两种取法下，φ_S = 0,8 时粒级 3 都在二次风入口界面被夹住，但这不说明所有轨迹与捕获结果等价。本 ADR 选高度平均，作为明示的解释性选择。气体物性仍按各格取值。

### 2. 格内解（求解手段）

- 系数 A、B、C 按式 (3.89)–(3.91)，z 按 ADR 0016 第 8 条。u_P < ū_g,i 时用括号内符号，u_P > ū_g,i 时用括号外符号。
- 解用研究底稿第 2 节自行推导并核验的闭式（与 RK4 相对差约 10⁻¹²）：
  - Δ > 0：θ₀ = arctan((2A·u₀ + B)/√Δ)，u(τ) = [√Δ·tan(θ₀ + √Δ·τ/2) − B]/(2A)，h(τ) = h₀ − (1/A)·ln[cos(θ₀ + √Δ·τ/2)/cos θ₀] − B·τ/(2A)；
  - Δ < 0：s = √(−Δ)，E(τ) = [(Ψ₀ + s)/(Ψ₀ − s)]·e^{−sτ}，Ψ₀ = 2A·u₀ + B，u = [s·(E + 1)/(E − 1) − B]/(2A)，h(τ) = h₀ + [(s − B)·τ − 2·ln|(E₀ − e^{sτ})/(E₀ − 1)|]/(2A)；
  - |Δ| ≤ 10⁻¹⁰·B²：按 Δ = 0 的极限，r = −B/(2A)，v₀ = u₀ − r，u = r + v₀/(1 − A·v₀·τ)，h = h₀ + r·τ − (1/A)·ln|1 − A·v₀·τ|。
  印刷的式 (3.96)、(3.98)、(3.99)、(3.103) 不用（ADR 0016 第 11 条已核其有误）；(3.93)–(3.95) 与上式相同。
- **事件**：在格内按闭式推进到最早发生的事件：(a) 到达本格上界或下界——在单调段上对 h(τ) 求根（二分，绝对容差 10⁻¹² m）；(b) u_P 穿过 ū_g,i——由 τ(u) 的闭式（∫du/Q）直接求出，换用另一套符号继续；(c) u_P = 0（转向）——同样由 τ(u) 求出。到达界面后以界面上的速度为初值进入相邻格。

### 3. 归宿与捕获（细化 ADR 0026 第 2 项）

- 格内气速为常数时格内没有平衡点。稳定点只在界面：下方格 ū_g > v_t、上方格 ū_g < v_t（v_t 按各自格的物性）。其捕获区 R* 为这两格之并（ADR 0026 第 2 项的界面情形）。
- 颗粒在该界面两侧往复、振幅衰减。某次穿过该界面时 |u_P| ≤ δ_u（ADR 0034 的 1·10⁻² m/s），且按闭式 h(u) 求得越过界面后到转向的距离不超过 δ_h（1·10⁻³ m），判为捕获。捕获时刻仍按“最后一次进入 R*”记账（ADR 0026 第 2 项），与 δ 无关。
- 其它归宿：到达出口为带出；回到床面为回落；ADR 0028 的时间上限（80 s）仍只用于报错。
- 若某格 |ū_g − v_t| ≤ 10⁻¹²·v_t（中性），报告并停止，不作判定。

### 4. 不变的部分

参考轨迹、抛出样本与权重（ADR 0016 第 6、9、10 条，ADR 0028 的 48 个样本）、停留时间与穿越记账、输运系数及其拆分（ADR 0026 第 3 项）、零自由参考存量、各闭合（ADR 0031、0032、0038、0044）都不变。ADR 0035 第 4 项的自由状态滑移 ∫|u_g − u_P|dτ 按段解析计算（段内 u_g 为常数，∫u_P dτ 为高度差，在 u_P = u_g 处分段）。

### 5. 撤销与参数

- 撤销：ADR 0016 第 11 条的数值积分；ADR 0028 的积分步长字段 `freeboard_max_step_s` 与步长加密检查；ADR 0034 的格内根搜索、势能井与能量判据；ADR 0036 第 1 项（逐根 δ_h）——界面捕获区的半宽为半个格高，远大于 δ_h。
- 保留：`freeboard_ejection_samples`（48，样本数加倍的加密检查不变）、`freeboard_time_limit_s`、`freeboard_delta_h_m`、`freeboard_delta_u_m_s`。

## 影响

- 每轮预计算的轨迹部分预计降低一到两个数量级；T23、T23b 的数值积分、势能井与根搜索代码由解析推进替换，`hamel/` 行数预计减少。
- 这是模型层面的改变（格内常气速），参考系数与悬停的位置会变化。悬停不因此消失：工况 1 初值点上，粒级 3 在二次风入口界面仍被夹住（研究底稿第 3 节）。悬停闭合（ADR 0026 的 A）不变。
- 轨迹中的球形度分布（S. 45、49）不在本 ADR 内，另行裁定。

## 实现约束

- 注明 `解释性选择：ADR 0047`（第 1 项）与 `求解手段：ADR 0047`（第 2、3 项）；docstring 引 `Source: Hamel Eq.3.88, S. 46` 等。
- 测试：各闭式与高精度 RK4（相同的逐格常系数）一致，相对差 < 10⁻⁸；u_P 穿过 u_g、转向、跨界面的事件；界面捕获的往复与 δ 无关性（δ 减半捕获时刻与记账不变）；带出、回落；中性格的停止。
- 报告：工况 1 初值点上新旧参考系数（a、b、拆分、θ、悬停）与预计算耗时的对照——只报告，不作通过门（模型已改变）。
- ADR 0030 冻结清单相应修改；与 ADR 0016、0028、0034、0036 加补注。
- 由 T26h 实现。
