# WSV400 工况 F 的氧含量印刷值 4,16 视为小数点错位，取 41,6 Gew.-%（wf）

表 7.4（PDF 81 右 / S. 143）中，工况 F 燃料的 O（wf）印为 4,16 Gew.-%。按此值，F 的灰分（wf）与 C、H、O、N、S（wf）之和为 0,23 + 51,85 + 6,15 + 4,16 + 0,14 + 0,01 = 62,54 Gew.-%，元素组成不闭合；同一张表中 A–E 一组的相应之和为 99,97 Gew.-%。若 O 取 41,6，F 之和为 99,98 Gew.-%，与 A–E 一致；其它任何单项都无法通过类似的修正使总和闭合。因此判定印刷值为小数点错位，新主线取 **41,6 Gew.-%（wf）**。

这是对原文的解释性选择（CHARTER §4.5）。`data/cases/wsv400.json` 中该字段记为 `status: derived`，`formula` 写明“印刷值 4,16 视为小数点错位，取 41,6；校验：灰 + C + H + O + N + S = 99,98 Gew.-%（ADR 0003）”。代码中使用该值处注明 `解释性选择：ADR 0003`。

依据工况 F 得出的任何结论，都应注明它依赖本裁定。
