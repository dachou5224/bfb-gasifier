# 悬停状态的粒级内漂移：缩粒使平衡界面上移（修订 ADR 0026 第 1 项与 ADR 0044 第 3 项的悬停状态）

> **状态：提议中。** 目标所有者 2026-10-30 同意起草。这是模型边界变更（冻结项 F17），须目标所有者明确批准；审查方审查后由总司令登记批准。按 STATUS 2026-10-29 的预先登记，本 ADR 只依据与验收量无关的证据；批准后，以 A 加本 ADR 的结果作为新基准，与闭合 A 的登记结果并列报告，不替换、不删除。

## 依据

- **Hamel S. 86，式 (5.11)**：焦炭颗粒按外表面反应、随转化缩小，焦炭密度恒定（ADR 0044 的依据）。故 m ∝ d³，单位焦炭质量消耗系数 α_s（ADR 0044 第 2 项）给出 d ln d/dt = −α_s/3。
- **ADR 0047 第 3 项**：粒径 d、球形度 φ 的颗粒只在 ū_g,j > v_t,j(d, φ) 且 v_t,j+1(d, φ) > ū_g,j+1 的界面（几何格 j 与其上方格 j + 1 之间）上有稳定点，v_t,i 按格 i 自己的气体物性计算。ADR 0048 第 2 项：该界面的悬停状态记在格 j。
- **ADR 0026 第 1 项**：悬停颗粒“只能通过反应减少质量，并随缩粒迁移到更小的粒级……再被带出或回落”。在单一代表粒径、整格捕获区下，跨出整个粒级是唯一可分辨的出口。ADR 0048 引入粒级内取样与半格捕获区后，同一粒级被分到多个界面，粒级内部的界面窗口已可分辨，而悬停状态仍只能在跨出整个粒级时离开。
- **T26j 预启动点**（PR #133，`docs/research/hover-drift-closure.md`）：闭合 A 下粒级 3 悬停焦炭 34,7 kg，锥段下沿一格体积比 1,58，超出 ADR 0026 第 5 项的有效域；按粒级内漂移估算，悬停降到 14–19 kg，各格体积比不超过 0,48。超域对自由空间温度强烈敏感，这一点本身不能证明 A 在耦合解处不可行；采用本 ADR 的理由是第 3 项的结构论证，预启动点的数值只说明影响的量级。

## 裁定

### 1. 物理图像（解释性选择，修订 ADR 0026 第 1 项）

悬停颗粒缩小时 v_t 连续下降。v_t,j+1 降到上方格气速 ū_g,j+1 时，颗粒离开界面 j 的稳定点。此时它在格 j + 1 中恰好开始上升，去向由它在界面 j + 1 是否稳定决定，逐个球形度取样按各格自己的物性判定（第 2 项）：

- 若格 j + 1 不是最上一格，且该粒径在界面 j + 1 的窗口非空（即 v_t,j+2 > ū_g,j+2 在离开点仍成立），转入格 j + 1 的同粒级悬停状态；
- 否则转入格 j + 1 的同粒级自由状态，此后由该状态的输运系数（a^f、b^f、c↑、c↓，ADR 0048）处理。

只比较两格气速 ū_g,j+1 与 ū_g,j+2 不够：相邻格物性不同时，气速大小顺序既不是下一界面稳定的充分条件，也不是必要条件。

若粒径先降到粒级下界 a_k（k > 1），按 ADR 0044 迁往粒级 k − 1，落点照现行 θ↑、θ↓ 与自由状态的拆分（ADR 0048 第 2 项），不改。

**最细粒级（k = 1）**：ADR 0044 取 m_p,0 = 0、q_1 = 0，粒级 1 的颗粒在本级内燃尽，没有迁出。本 ADR 保留这一边界：粒级 1 的窗口下沿为 a_1 的部分不迁移、不漂移（μ_j,1 = 0），这部分质量留在本悬停状态由反应消耗。粒级 1 的窗口下沿在 a_1 以上的部分照常漂移。a_1 是外推的取样下界，不是物理边界；留在本状态燃尽是与 ADR 0044 一致的截断，列入第 5 项。

### 2. 窗口与系数（解释性选择）

对粒级 k、几何格 j 的悬停状态，按 ADR 0048 的球形度取样 φ_p（p = 1…N_φ）：

- **窗口**：d_hi,j(φ_p) 由 v_t,j(d, φ_p) = ū_g,j 定义，d_lo,j(φ_p) 由 v_t,j+1(d, φ_p) = ū_g,j+1 定义；窗口为 (d_lo,j, d_hi,j)，与粒级区间 [a_k, b_k] 求交得 [d′_lo, d′_hi]，为空时该 φ_p 不贡献。v_t,i 对 d 单调，二分求根。相邻界面 j 与 j + 1 的窗口在 d_lo,j = d_hi,j+1 处首尾相接，因为两者都由格 j + 1 的物性与 ū_g,j+1 定义。
- **下沿去向**（逐个 φ_p 判定）：d′_lo = a_k 时为粒级迁移（k = 1 时见第 1 项，不迁移）；否则为漂移，格 j + 1 不是最上一格且 φ_p 在界面 j + 1 的窗口非空（d_lo,j+1 < d_hi,j+1）时去向为格 j + 1 的悬停状态，否则为格 j + 1 的自由状态。
- **路径长度**：L_p = ρ_k·ln(d′_hi/d′_lo)，ρ_k = ln(d_k/d_(k−1)) / ln(b_k/a_k)。ρ_k 把粒级区间上的 ln d 按比例映射到 ADR 0044 的迁移路径（代表粒径 d_k → d_(k−1)），使整个粒级落在同一窗口时，本 ADR 与 ADR 0044 逐项相同。粒级 1 没有 d_0，取 ρ_1 = 1。
- **出口因子**：沿用 ADR 0044 第 3 项的质量空间守恒离散，长度为 L 的路径出口系数为 1/(e^{3L} − 1)（整条路径时即 q_k = m_(k−1)/(m_k − m_(k−1))）。
- **权重** ω_p：该悬停状态的参考轨迹捕获中 φ_p 子样本所占的权重份额（按 ADR 0048 的子样本权重，对该格该粒级全部起点的捕获求和）。没有捕获的悬停状态，ω_p 取其窗口非空的 φ_p 等权。
- **冻结量**：
  - 进入上方格悬停状态的漂移因子 δ^h_j,k = Σ_p ω_p / (e^{3L_p} − 1)，对去向为悬停的 p 求和；
  - 进入上方格自由状态的漂移因子 δ^f_j,k，对去向为自由的 p 同样求和；
  - 迁移因子 μ_j,k = Σ_p ω_p / (e^{3L_p} − 1)，对下沿为 a_k 的 p 求和；k = 1 时 μ_j,1 = 0。
  - 同一（格，粒级）的不同 φ_p 可以有不同去向，两个漂移因子分别累计，不合并为一个去向。

### 3. 衡算（修订 ADR 0044 第 3 项的悬停状态；自由状态不变）

对格 j、粒级 k 的悬停状态（焦炭存量 M_C，灰存量 M_A）：

- 焦炭反应消耗 α_s·M_C、灰随燃尽释放 α_s·M_A：不变；
- 焦炭迁往 k − 1：α_s·M_C·μ_j,k；灰随迁移：α_s·M_A·μ_j,k（取代悬停状态的 q_k）；
- 焦炭漂移 α_s·M_C·(δ^h_j,k + δ^f_j,k)、灰漂移 α_s·M_A·(δ^h_j,k + δ^f_j,k)：从本状态扣除，δ^h 部分进入格 j + 1 的同粒级悬停状态，δ^f 部分进入格 j + 1 的同粒级自由状态。悬停状态中的燃料按现行处理（ADR 0048 与热解释放），不漂移；
- 漂移流的组成与焓按源状态，温度按格 j，是格 j 到格 j + 1 的相邻格传输，在两格各自的衡算中分别出现；
- α_s 按悬停状态自己的输入（ADR 0044 第 2 项、ADR 0035 第 4 项），反应仍用代表粒径 d_k（ADR 0048 第 1 项）。

**为什么不重复计账**：一个颗粒的 ln d 单调减小，沿途只有两类边界：粒级下界 a_k（粒级迁移）与稳定窗口边界（漂移）。每次缩小只跨过一条边界，每条边界上的通量只记一次。本 ADR 把悬停状态的粒级迁移限制在窗口含 a_k 的部分（μ），漂移只在其余部分（δ）。同一 φ_p 的各窗口互不重叠、首尾相接，沿一条窗口链的路径长度之和就是该 φ_p 在稳定范围内的路径长度，不超过整个粒级。当所有 φ_p 的窗口都覆盖整个粒级、下沿都是 a_k 时，δ^h = δ^f = 0、μ = q_k（k > 1），k = 1 时 μ = 0 = q_1，退化为 ADR 0044。

### 4. 不变的部分

- 自由状态的消耗、迁移与输运（ADR 0044、0048）；参考轨迹、捕获判据与记账（ADR 0047、0048、0050）；有效域（ADR 0026 第 5 项）；θ↑、θ↓ 的落点拆分。
- 闭合 B、C（S13、S14，ADR 0038）不设悬停状态，没有漂移。S17 的气速变化通过 ū_g 进入窗口。
- 求解手段、收敛门、外层规则与冻结值。

### 5. 已知近似（报告，不作修正）

- 漂移到格 j + 1 的颗粒按格 j + 1 自己的 ω_p 计算后续因子，不追踪到达者的 φ 组成。
- 一阶离散假定窗口内质量集中于上沿（与 ADR 0044 的代表粒径离散同一性质）；研究底稿中与按 ln v_t 均匀入射的精确链相比，存量相差约 6 %。
- α_s 取代表粒径 d_k，不随窗口内的粒径变化。
- 粒级 1 窗口下沿为 a_1 的部分留在本悬停状态燃尽（第 1 项），不追踪 a_1 以下的继续缩小。

## 实现约束

- 注明 `解释性选择：ADR 0051`；ADR 0026 第 1 项、ADR 0044 第 3 项加补注。
- ADR 0030 冻结清单：F17 改为“反应限制的滞留（A）加粒级内漂移（ADR 0051）”，注明闭合 A 的登记结果保留并列报告。
- 测试：
  - 窗口：相邻界面的窗口首尾相接（d_lo,j = d_hi,j+1，同一 φ_p）；空窗口不贡献；
  - 退化：所有窗口覆盖整个粒级且下沿为 a_k 时 δ^h = δ^f = 0、μ = q_k，残差与 ADR 0044 逐位相同；粒级 1 同样情形 μ = 0；
  - 去向：按各格物性逐 φ_p 判定，含变物性反例（审查给出：ρ_P = 1000 kg/m³、φ = 0,8，格 j + 1 物性 (5 kg/m³, 4·10⁻⁵ Pa·s)、ū_g,j+1 = v_t(0,4 mm)，格 j + 2 物性 (3 kg/m³, 2·10⁻⁵ Pa·s)、ū_g,j+2 = v_t(0,3 mm)：ū_g,j+1 < ū_g,j+2 而界面 j + 1 仍稳定，应进入悬停状态）；格 j + 1 为最上一格时进入自由状态；同一（格，粒级）的 φ_p 去向不同时 δ^h、δ^f 分别累计；
  - 粒级 1：完整窗口与部分窗口（下沿分别为 a_1 与 a_1 以上）的焦炭、灰质量与能量守恒，μ_j,1 = 0；
  - 守恒：漂移的焦炭、灰在两格质量与能量方程中逐格扣除与接收，焓按源格温度（只改源格温度时核对两格，不只查全炉）；全炉碳、灰守恒；
  - 同一 φ_p 沿窗口链的路径长度之和不超过 ρ_k·ln(b_k/a_k)；手算一个两窗口的例子核对 δ、μ 与去向；
  - ADR 0046 的依赖结构：漂移只连接相邻格，不需单独成组；分组雅可比与逐列差分逐位相同。
- 报告：各（格，粒级）的 δ^h、δ^f、μ 与 ω_p，以及逐 φ_p 的窗口与去向；与闭合 A 同一点上的悬停存量与体积比对照。
- 由 T26k 实现。

## 审查记录

- PR #135 审查：(1) 漂移去向只比较 ū_g,j+1 与 ū_g,j+2，相邻格物性不同时不对，且不同 φ_p 的去向可能不同，单一 δ 配单一去向会丢信息；(2) 粒级 1 取 ρ_1 = 1 时窗口下沿为 a_1 会给出非零 μ 并迁往不存在的粒级 0，退化声明不成立。已修订：去向按各格物性逐 φ_p 判定，漂移因子拆为 δ^h、δ^f 分别累计，补变物性反例测试；粒级 1 保留 ADR 0044 的 q_1 = 0，下沿为 a_1 的部分留在本状态燃尽，补完整与部分窗口的守恒测试。研究底稿见 PR #136。
