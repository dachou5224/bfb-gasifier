# 焦炭缩粒的粒级迁移（式 2.6 的 ṁ_← 与 ṁ_→）

> **状态：提议中。** 式 (2.6) 含粒级迁移项 ṁ_←,j,k,i（自其它粒级进入 k）与 ṁ_→,j,k,i（自 k 进入其它粒级），T8 冻结稿记录“收缩、长大由哪一个粒径演化式给出，本章未写”。第 5 章（S. 84–85）写明烧损采用 shrinking particle 模型、焦炭密度恒定（式 5.11），但没有给出离散粒级之间的迁移式。ADR 0015 第 10 项、ADR 0026 第 3 项都假定迁移与粒级质量成正比，T25a 装配须有明确的迁移式。本 ADR 补齐。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 背景

- 粒级 k = 1 … K，代表粒径 d_1 < d_2 < … < d_K（燃料粒级按 ADR 0023；焦炭沿用同一组粒级，ADR 0015 第 11 项）。单颗粒焦炭质量 m_p,k = ρ_C·π·d_k³/6（ρ_C 按 ADR 0017 第 19 项）。
- 粒级 k 在 cell i 的焦炭存量 M_k,i，颗粒数 N_k,i = M_k,i / m_p,k（灰对颗粒数的计入按 ADR 0017 第 19 项，见第 4 项）。
- 单颗粒的焦炭消耗速率 r_p,k,i（kg/s）：R1、R2、R4 为单颗粒速率乘 M_C；R3 按焦炭质量，r_p,k,i = R3 的质量速率 / N_k,i（T20）。只有消耗，没有长大（褐煤焦炭没有生长机理）。

## 裁定（解释性选择）

1. **离散方式**：shrinking particle 的颗粒在本粒级内保持代表粒径 d_k，因反应失去的质量以“颗粒从 d_k 缩到 d_(k−1)”的方式表示。为了使质量在离散后严格守恒，单位时间从粒级 k 迁到 k − 1 的颗粒数取

   n_k,i = N_k,i·r_p,k,i / (m_p,k − m_p,(k−1))，

   于是粒级 k 失去 n_k,i·m_p,k，粒级 k − 1 得到 n_k,i·m_p,(k−1)，两者之差 n_k,i·(m_p,k − m_p,(k−1)) = N_k,i·r_p,k,i 恰为反应消耗的焦炭质量，进入气相源项。m_p,0 = 0：最小粒级的颗粒缩到零，全部消耗，不再迁移。
2. **式 (2.6) 中的各项**：对粒级 k、cell i，
   - ṁ_r,k,i = −N_k,i·r_p,k,i（反应消耗，与 T20 的速率一致）；
   - ṁ_→,k,i = n_k,i·m_p,(k−1)（迁往 k − 1 的焦炭质量）；
   - ṁ_←,k,i = n_(k+1),i·m_p,k（自 k + 1 迁入的焦炭质量；k = K 时为 0）。

   代入式 (2.6)：粒级 k 的净变化为 −N_k r_p,k − n_k m_p,(k−1) + n_(k+1) m_p,k，对 k 求和后迁移项逐对抵消，只剩反应消耗，全炉碳守恒。
3. **与质量成正比**：在给定气相状态下，r_p,k,i 与 m_p,k 只依赖粒级与气相，故 n_k,i 与 M_k,i 成正比，ṁ_r 与 ṁ_→ 都与 M_k,i 成正比。这正是 ADR 0015 第 10 项、ADR 0026 第 3 项所用的性质（单位质量的消耗速率 r^R 与迁移速率 r^M 对同一粒级的各状态相同）：r^R_k = r_p,k / m_p,k，r^M_k = (r_p,k / m_p,k)·m_p,(k−1)/(m_p,k − m_p,(k−1))。
4. **灰**：床区的灰按 ADR 0014 对 ADR 0009 的修订处理（m_inert,i），不随粒级迁移；自由空间的灰按 ADR 0026 第 4 项随焦炭迁移与释放。颗粒数中计入的灰（ADR 0017 第 19 项）只影响 R1、R2、R4 的颗粒数与外表面，不改变本项的焦炭质量记账。
5. **依据**：这是 shrinking particle 在离散粒级上的最简守恒表示（颗粒数守恒的迎风格式，迁移数由反应消耗精确确定），只用第 5 章已采用的单颗粒速率与恒定焦炭密度，不引入新的经验式。粒级划分越细，代表粒径的跳变越小。首次运行的 cell 数加倍敏感性之外，不另做粒级加密（粒级由 ADR 0023 的燃料筛分决定，不是数值参数）。

## 实现约束

- T25a 按第 2 项装配式 (2.6) 的 ṁ_r、ṁ_←、ṁ_→；单元测试：单 cell、无输运时各粒级的稳态与解析解一致；全炉焦炭碳的消耗等于气相碳源；最小粒级不迁出。
- 注明 `解释性选择：ADR 0031`。
