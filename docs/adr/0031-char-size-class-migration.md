# 焦炭缩粒的粒级迁移（式 2.6 的 ṁ_← 与 ṁ_→）与含灰颗粒的组成

> **状态：提议中。** 式 (2.6) 含粒级迁移项 ṁ_←,j,k,i（自其它粒级进入 k）与 ṁ_→,j,k,i（自 k 进入其它粒级），T8 冻结稿记录“收缩、长大由哪一个粒径演化式给出，本章未写”。第 5 章（S. 84–85）写明烧损采用 shrinking particle 模型、焦炭密度恒定（式 5.11），但没有给出离散粒级之间的迁移式。本 ADR 补齐，并与已批准的 ADR 0017 第 19 项（颗粒按焦炭加灰计）、ADR 0026 第 3、4 项（两状态、自由空间的灰）统一口径。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 颗粒的组成与颗粒数（与 ADR 0017 第 19 项一致）

- 粒级 k = 1 … K，代表粒径 d_1 < … < d_K（燃料粒级按 ADR 0023；焦炭沿用同一组粒级，ADR 0015 第 11 项）。
- 颗粒是焦炭与灰的复合颗粒，密度 ρ_P（ADR 0014 A4；ADR 0017 第 19 项 ρ_C = ρ_P）。**单颗粒总质量** m_p,k = ρ_P·π·d_k³/6。
- 对某一（cell i，粒级 k，状态 s）的焦炭存量 M_C 与灰存量 M_A，**颗粒数** N = (M_C + M_A)/m_p,k（即 ADR 0017 第 19 项），**焦炭质量分数** f_C = M_C/(M_C + M_A)，灰分数 f_A = 1 − f_C。单颗粒焦炭质量 m_pC,k = f_C·m_p,k。
  - 床区：灰不按粒级作未知量（ADR 0014 对 ADR 0009 的修订），按 ADR 0017 第 19 项把 m_inert,i 按焦炭质量比例分到各粒级，于是同一 cell 各粒级 f_C 相同：f_C,i = Σ_k M_C,k,i /(Σ_k M_C,k,i + m_inert,i)。
  - 自由空间：各（粒级，状态）的灰存量 M_A 是未知量（ADR 0026 第 4 项），f_C 各自计算。
- 单颗粒的焦炭消耗速率 r_p（kg C/s）：R1、R2、R4 为单颗粒速率（按外表面，粒径 d_k）乘 M_C；R3 按焦炭质量，r_p = R3 的质量速率 / N（T20）。只有消耗，没有长大。

## 裁定（解释性选择）

1. **离散方式**：复合颗粒在本粒级内保持代表粒径 d_k 与组成 f_C；因反应失去焦炭时，以“颗粒从 d_k 缩到 d_(k−1)、组成不变”表示，缩小时同体积中的灰随之释放。为使焦炭质量在离散后严格守恒，单位时间从粒级 k 迁到 k − 1 的颗粒数取

   n = N·r_p / (f_C·(m_p,k − m_p,(k−1)))，m_p,0 = 0。

2. **各项**（对一个（cell，粒级 k，状态））：
   - 焦炭反应消耗：ṁ_r,C = −N·r_p；
   - 焦炭迁往 k − 1：ṁ_→,C = n·f_C·m_p,(k−1)；
   - 灰随迁移：n·f_A·m_p,(k−1)（即焦炭迁移 × M_A/M_C，与 ADR 0026 第 4 项第 1 点一致）；
   - 灰随燃尽释放：n·f_A·(m_p,k − m_p,(k−1)) = N·r_p·M_A/M_C（与 ADR 0026 第 4 项第 2 点一致；床区释放的灰并入 m_inert,i，自由空间释放到同格 k = 1 的自由状态）。

   粒级 k 失去的焦炭 n·f_C·m_p,k 等于反应消耗加迁出；对 k 求和后迁移项逐对抵消，只剩反应消耗，与气相碳源相等。最小粒级（m_p,0 = 0）缩到零，焦炭全部消耗，灰全部释放。M_C = 0 的状态按 ADR 0026 第 4 项第 3 点处理（k > 1 不存在纯灰，不计算 f_A/f_C）。

3. **单位焦炭质量的速率**：r^R = N·r_p / M_C = r_p /(f_C·m_p,k)，r^M = r^R·m_p,(k−1)/(m_p,k − m_p,(k−1))。它们依赖 f_C，因此**同一粒级的自由状态与悬停状态若灰焦比不同，单位焦炭质量的速率也不同**。ADR 0026 第 3 项中“两个状态的单位质量速率相同”一句，只在两状态 f_C 相同时成立，由本项细化为：两条状态方程各用本状态的 r^R、r^M（以及本状态的 N、f_C），两式相加仍是式 (2.6)，其中 ṁ_r 与 ṁ_→ 为两状态之和。逐格守恒不受影响。

4. **依据**：这是 shrinking particle 在离散粒级上的最简守恒表示（颗粒数守恒的迎风格式，迁移颗粒数由反应消耗精确确定），只用第 5 章已采用的单颗粒速率、恒定颗粒密度与 ADR 0017 第 19 项的颗粒数，不引入新的经验式。粒级由 ADR 0023 的燃料筛分决定，不作数值加密。

## 实现约束

- T25a 按第 2、3 项装配；单元测试至少包括：
  - 无灰：单 cell、无输运时各粒级的稳态与解析解一致；
  - **非零灰、两种灰焦比的独立手算例**：核对颗粒数 N（与 ADR 0017 第 19 项一致）、气相碳源 = 固相碳汇 = Σ N·r_p、灰的迁移与释放守恒；
  - 两状态灰焦比不同时，两条状态方程之和等于式 (2.6)；
  - 最小粒级不迁出，灰全部释放。
- 注明 `解释性选择：ADR 0031`。

## 审查记录

- PR #93 审查：指出原稿以 N = M_C/m_p 计颗粒数，与 ADR 0017 第 19 项的 N = (M_C + M_A)/m_p 冲突（含灰时气相源相差一倍）；且两状态灰焦比不同时单位质量速率不同。已修订：统一为复合颗粒，m_p 为单颗粒总质量，N 按 ADR 0017 第 19 项，迁移颗粒数 n = N r_p /(f_C (m_p,k − m_p,k−1))，灰随迁移与燃尽释放与 ADR 0026 第 4 项一致；细化 ADR 0026 第 3 项为各状态用本状态的速率；补非零灰、两种灰焦比的测试。
