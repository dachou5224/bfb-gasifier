# 焦炭反应的颗粒数按焦炭质量计，消除 m_C → 0 处的奇异（修订 ADR 0017 第 19 项、ADR 0031、ADR 0026 第 4 项）

> **状态：已批准（2026-10-28，目标所有者明确批准）。** M3 审计（2026-10-27）发现 4-1：现行闭合在 m_C → 0⁺ 时残差奇异，在 m_C = 0 处间断。本 ADR 修改已冻结的解释性选择（ADR 0030 F15、F21），依据是闭合的数学缺陷与 Hamel 原文，与验收量无关（ADR 0013 第 4 条）。会改变床区与自由空间的焦炭消耗，从而影响验收量，因此除审查方审查、总司令批准外，须目标所有者明确批准。

## 问题（M3 审计 4-1，总司令已核对代码）

- ADR 0017 第 19 项与 ADR 0031 把颗粒当作焦炭加灰的复合颗粒，颗粒数 N = (M_C + M_A)/m_p,k（`hamel/kinetics/heterogeneous.py` 的 R1 颗粒数取 m_C + m_A）。R1、R2、R4 的单颗粒速率 r_p 按外表面计，与颗粒内焦炭的多少无关。
- 于是焦炭消耗 N·r_p 在 M_C → 0 时不趋于 0（审计在失败点悬停 k3 扫描：M_C ≤ 10⁻⁷ kg 后消耗稳定在 2,6·10⁻⁹ kg/s），焦炭行对 M_C 的导数约为 0。
- 灰释放 = 消耗 × M_A/M_C 随 1/M_C 发散（M_C = 10⁻¹⁵ kg 时灰残差 −10,5 kg/s，10⁻¹⁸ 时 −1,0·10⁴）。
- M_C = 0 时 ADR 0026 第 4 项第 3 点整体切换（m_A 置 0、入流改记到 k = 1），残差间断。

## 原文（总司令核对页面图像）

- **S. 73（PDF 46 右）**：反应器模型通常假定焦炭颗粒（„Kokspartikel“）按 shrinking particle 模型反应，即反应速率与颗粒外表面成正比，转化使颗粒直径减小（Bild 5.1）。考虑灰层附加扩散阻力的是 shrinking core 模型，用于灰分很高的煤；Hamel 没有采用它。Bild 5.1 中 shrinking particle 的颗粒没有灰层。
- **S. 84–85（PDF 52）**：本工作继续以 shrinking particle 描述燃尽。
- **S. 86（PDF 53 左）**，§5.1.2：燃烧对象是“干燥与热解后剩下的焦炭颗粒”；式 (5.11) R_C = (ρ_C/M_C)·dV_P,C/dt，“假定焦炭密度恒定”，体积是焦炭的体积 V_P,C；式 (5.12)–(5.14) 的 A_P 是该颗粒的外表面。
- **S. 112–113（PDF 66）**，第 6 章的实验分析：灰层在燃尽中被剥除时，灰层的扩散阻力消失，得到 shrinking particle 的式子。

即：原文规定按外表面反应、颗粒随转化缩小，外部灰层不保留扩散阻力（未采用 shrinking core）。**原文没有说明焦炭颗粒内部是否含矿物灰，也没有给出由焦炭与灰的混合存量换算颗粒数的方法。** ADR 0017 第 19 项“颗粒数按焦炭加所含灰计”与本 ADR 的“颗粒数按焦炭计”都是解释性选择，原文不能在两者之间作出裁定。本 ADR 的修改动机是现行闭合的数学缺陷（上节）与新闭合在 M_C → 0 时的连续极限，不是原文已排除含灰颗粒。

## 裁定（解释性选择，均为本 ADR 新选取的闭合，原文未给出）

1. **反应颗粒数**：R1、R2、R4 的反应颗粒数取 N_C = M_C / m_p,k，m_p,k = ρ_P·π·d_k³/6；继续以 ρ_P 充当焦炭的表观密度（ADR 0017 第 19 项的 ρ_C = ρ_P 不变）。R3 按焦炭质量计，不变。颗粒温度（式 5.22）按直径 d_k 的单颗粒计算，不变。
2. **各状态的单位焦炭质量消耗系数**：对每个（cell，粒级，状态 s），定义
   α_s = [r_p,s(R1) + r_p,s(R2) + r_p,s(R4)] / m_p,k + (R3 的单位焦炭质量速率)，
   其中 r_p,s 为该状态的单颗粒质量速率（kg C/s），按该状态自己的输入计算——自由状态与悬停状态的 u_r 不同（ADR 0035 第 4 项、F24 不变），颗粒温度与 Sh、Re 也随之不同，因此 α_s 一般不同。α_s 与该状态的灰焦比无关。
3. **粒级迁移与灰**（修订 ADR 0031 第 1、2 项；沿用其守恒离散，颗粒从 d_k 缩到 d_(k−1)，同体积中的灰随之迁移或释放）。对状态 s，记 q_k = m_p,(k−1)/(m_p,k − m_p,(k−1))（m_p,0 = 0）：
   - 焦炭反应消耗：α_s·M_C；
   - 焦炭迁往 k − 1：α_s·M_C·q_k；
   - 灰随迁移：α_s·M_A·q_k；
   - 灰随燃尽释放：α_s·M_A。
   各项对存量线性，不再出现 M_A/M_C。ADR 0031 第 3 项“两状态各用本状态的速率”保留；其中“速率依赖 f_C”一句取消。
4. **取消 m_C = 0 的切换**（修订 ADR 0026 第 4 项第 3 点）：上式在 M_C = 0 时连续，k > 1 的灰按同一线性式迁移和释放，不再把 m_A 置零或改记灰入流。实现须一致处理灰输运、灰入流的去向与状态有效域（ADR 0026 第 5 项）。ADR 0026 第 4 项第 1、2、4 点与灰平衡不变。
5. **床区**：床区各粒级的 R1、R2、R4 同样按 N_C 计，床区惰性物 m_inert 不再计入反应颗粒数。

## 影响

- 第 3 项的反应汇与迁移项在 M_C → 0 时线性趋于 0，在 M_C = 0 处连续；焦炭行中**反应汇项**对 M_C 的导数为 −α_s（有限、非零）。完整的焦炭行还含输运、迁入等项。这只说明本闭合消除了 M_A/M_C 与 m_C = 0 切换带来的奇异与间断，不说明完整残差的所有奇异点都已消除。
- R1、R2、R4 的消耗按焦炭质量分数 f_C 降低（床区约按 f_C,i，自由空间按各状态的 f_C）；R3 不变，因此合计消耗不是整体乘 f_C。灰分高、焦炭少的床区，R1、R2、R4 的消耗显著下降。这改变验收量，依据与验收量无关。
- 审计 4-2（悬停存量的量级）不因本 ADR 消除。由 T26f 的预检给出事实后另行处理。

## 实现约束

- 注明 `解释性选择：ADR 0044`；ADR 0017 第 19 项、ADR 0031、ADR 0026 第 4 项第 3 点加补注指向本 ADR。
- ADR 0030 冻结清单：F21 改为“按焦炭颗粒数的守恒离散（ADR 0031，经 ADR 0044 修订）”；F15 补注颗粒数口径。
- 测试：M_C → 0 时消耗、迁移、释放线性趋于确定极限，反应汇项导数有限；M_C = 0 处连续；自由与悬停状态 u_r 不同时 α_s 不同；单 cell 无输运时与解析解一致；全炉碳、灰守恒；非零灰、两种灰焦比的手算例；R3 不随灰焦比变化。
- 由 T26f 之后的任务卡实现（可与初值构造同卡，视规模而定）。`hamel/` 规模由该卡核算。
