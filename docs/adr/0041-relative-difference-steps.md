# 内层雅可比的差分步长按变量自身取值，线性求解加列缩放

> **状态：已批准（2026-10-27）。** T26b 的 15 次 DAMPING_FAILED 由 T26c（PR #112）在基准失败点诊断。本 ADR 依据该诊断修改 ADR 0017 第 6 项与 ADR 0037 中差分尺度的规定，只改求解手段，不改方程、残差、收敛门与冻结值（CHARTER §5）。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 证据（T26c 诊断与失败点 `reports/t26c-diagnosis/baseline/failure.npz`）

- **噪声被排除**：在同一份冻结量下收紧颗粒温度与膜温求解，‖F_tight − F‖ = 0；同一点重算 F 与保存值逐位相同。
- **雅可比与函数不一致**：沿牛顿步 Δx，‖J·Δx − [F(x + hΔx) − F(x)]/h‖ / ‖J·Δx‖ 在 h = 10⁻¹⁰…10⁻¹² 仍为 4,2–5,0；全部可行的 h 上 g(h) 都不低于 g(0)。
- **差分步长远大于变量本身**：ADR 0017 第 6 项的步长为 √ε·max(|x_n|, s_n)，气体流量的 s_n 为 Ṅ_ref = 1,197 mol/s，固体存量的 s_n 为 M_tot（ADR 0037）。失败点上：
  - 床区两相与自由空间共 24 个 O₂ 流量为 8,5·10⁻²⁴ 到 4,0·10⁻²⁰ mol/s（其中自由空间 8 个为 1,24·10⁻²² 到 7,79·10⁻²¹ mol/s），差分步长 1,8·10⁻⁸ mol/s，是变量的 10¹²–10¹⁵ 倍；312 个气体未知量中 48 个的步长超过变量的 10³ 倍；
  - 固体存量的步长与变量之比中位数 1,5·10⁻²，最大 4,2·10³（悬停焦炭 1,4·10⁻¹¹ kg）。
- **这些变量所在的残差对它们强非线性**：R5（CO 氧化，式 5.36、表 5.3）对 c_O₂ 是 0,3 次（气泡相、自由空间）或 0,5 次（悬浮相），在 c_O₂ → 0 处导数无界；复合颗粒的灰焦比 m_A/m_C（ADR 0026 第 4 项、ADR 0031）在 m_C → 0 处同样无界。步长跨过变量本身的多个数量级时，差分列是割线而不是导数。
- **后果**：J 的 2-范数条件数 5,1·10¹⁹，按行列范数平衡后仍为 1,8·10¹⁹；O₂ 列的范数达 3,5·10¹³。牛顿步使大量存量与流量变负（例如床区焦炭由 0,11 kg 到 −0,45 kg），可行的步长只剩 h ≲ 10⁻¹⁰，而在这些步长上方向又不是真实的下降方向。

## 裁定（求解手段）

1. **差分步长**（修改 ADR 0017 第 6 项）：第 n 列的前向差分步长
   - x_n ≠ 0 时取 δ_n = √ε_mach·|x_n|；
   - x_n = 0 时取 δ_n = √ε_mach·s_n（s_n 仍按 ADR 0017 第 6 项与 ADR 0037）。
   温度未知量的 |x_n| 总大于 1 K，结果与现行规则相同。差分仍为前向差分、每次迭代在当前点重算。差分点仍须满足 ADR 0017 第 7 项的可行条件；x_n > 0 时 x_n + δ_n > 0 恒成立。
2. **线性求解的缩放**：求牛顿步时解 (R·J·C)·y = −R·F，Δx = C·y，其中 R 为 ADR 0012 参考流的行缩放（与归一残差同一组 Ṅ_ref、ṁ_ref、Q̇_ref），C = diag(max(|x_n|, δ_n/√ε_mach))。在精确运算下 Δx 不变；这只改善浮点求解。仍不显式求逆。
3. 阻尼、可行条件、收敛门、ν_max 与外层规则都不变（ADR 0012、0017 第 7、8 项、ADR 0037）。

## 验证（实现后、重跑之前，只报告）

在 T26c 保存的基准失败点与工况 1 的初值点各做一次：

- 用新规则重算 J 与牛顿步，按 T26c 第 6 项的方向检查：报告 h = 10⁻¹…10⁻¹² 上 g(h) 与相对差；
- 从初值点运行外层第 1 轮的内层牛顿，报告迭代历史（T26c 的诊断记录）与终止状态。

若新规则下牛顿方向在小步长上仍不是下降方向，或内层仍以 DAMPING_FAILED 终止，**停止，不重跑**，报告结果；后续办法（例如对正值未知量作变量代换）另立 ADR。

## 审查记录
- PR #113 审查：通过；校正 O₂ 流量的计数（床区两相与自由空间共 24 个，自由空间 8 个）与自由空间的数值范围。审查方提示：本 ADR 的论据须在 #112 补全最大残差方程依赖列的诊断后再核对；相对差分在多变量残差中可能出现相消误差，须按已登记的验证与停止条件执行。
- **2026-10-27：总司令批准**（CHARTER v0.10 §8，目标所有者可否决）。T26d 仍须在 #112 合并后派发。
- 2026-10-27 维护（按 #113 审查提示，用 #112 补全后的诊断核对论据；裁定不变）：T26c 第 8 项补到最大残差方程的 62 个依赖列后，把步长放大到 10²、10⁴ 倍时变化最大的是自由空间最下一格粒级 3 的悬停焦炭列（0,99、1,0）与悬停灰列（0,79、79），对应灰焦比 m_A/m_C 在 m_C → 0 处的无界导数（该格悬停焦炭 1,4·10⁻¹¹ kg、悬停灰约 3,7·10⁻⁶ kg）。床顶悬浮相与自由空间最下一格的 O₂ 列只变化 6·10⁻⁶–6·10⁻⁴，说明在 1×–10⁴× 步长范围内这些列由对 O₂ 一次的项主导；R5 的 0,3/0,5 次项是否在 √ε·|x| 量级的步长上起作用，这一实验不能判定，由 T26d 的验证给出。证据一节中“R5 使 O₂ 列成为割线”一句因此只是未证实的可能原因，主要证据是悬停列的强非线性、方向导数相差 4–5 倍与步长/变量比。
