# 按块三对角结构分组差分构造内层雅可比

> **状态：提议中。** 目标所有者 2026-10-28 决定先做两项提高计算效率的改动（本 ADR 与 ADR 0047），以便后续试算。本 ADR 属求解手段，不改方程、残差、差分步长、阻尼与收敛门（CHARTER §5）；它只改变同一组差分列的计算顺序，结果与逐列差分逐位相同。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 依据

- Hamel S. 20（PDF 20 左），§2.3：衡算变量只依赖本格与相邻格，函数矩阵为**块三对角**；只有非相邻的物流（如旋风返料）产生额外的非零块。
- ADR 0017 第 6 项已允许“可按块结构分组”。T25c 实现的是逐列差分：第 1 关 498 个未知量，一次雅可比约 685 次全炉残差评价、约 185 s（T26e 记录），是内层迭代耗时的主体。

## 裁定（求解手段）

1. **节点链**：把每个未知量归入一个节点：床区各格（自下而上），接着自由空间各格（自下而上）。床顶格与自由空间最下格相邻。节点 n 的残差行只依赖节点 n − 1、n、n + 1 的未知量，另加第 3 项列出的非相邻耦合。
2. **分组**：节点序号模 3 相同、且在各自节点内序号相同的列可以同时扰动；每组一次残差评价，对每一行只取该行所在节点的邻域（n − 1…n + 1）中被扰动的那一列，按 ADR 0043 的步长换算该列的差分。理想情况下评价次数约为 3 × 每个节点的最大未知量数。
3. **非相邻耦合**：凡使某节点的残差依赖不相邻节点未知量的项，其相关列**单独成组**（逐列差分）。至少包括：S13、S14 的改送流（ADR 0038，自由空间各格 → 床区最上一格或出口）；其它装配中存在的非相邻项由实现逐一列出，并在 PR 中说明。第 1 关基准没有旋风返料（ADR 0014 X2）。
4. **差分步长、可行条件、有效域检查**都与逐列差分相同：组内各列的扰动同时施加，试探点须满足 ADR 0017 第 7 项；不可行或超域时，该组退回逐列差分，仍不可行则按现行规则报错。
5. **一致性要求**：分组得到的雅可比必须与逐列差分**逐位相同**（被同组扰动的其它列不影响该行时，该行的残差值不变）。每次运行在第 1 次内层迭代把分组雅可比与逐列差分比较一次；不一致即停止并报告不一致的行列（说明第 1、3 项的依赖结构有遗漏，属程序错误），不改用近似。
6. 线性求解不变（ADR 0043 的行列缩放、稠密 LU）。块三对角消元只节省毫秒级的时间，不在本 ADR 范围内。

## 实现约束

- 注明 `求解手段：ADR 0046`；依赖结构从 `vector.py` 的未知量表（zone、balance_index）得到，不依赖数值上恰好为零的元素来判定无依赖。
- 测试：玩具问题与工况 1 的一个状态上，分组雅可比与逐列差分逐位相同；人为加入一个非相邻耦合而未登记时，第 5 项的比较能发现并停止；不可行组退回逐列。
- 报告：每次雅可比的残差评价次数与耗时，与逐列差分对照。
- 由 T26i 实现。
