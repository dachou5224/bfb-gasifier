# 第 1 关首次运行的统一冻结清单与敏感性运行

> **状态：已批准（2026-10-20）。** M1 里程碑审计（2026-10-18）建议在 M2 之前把分散在各 ADR 中的冻结选择与敏感性运行汇成一张清单（ADR 0022 B；STATUS 里程碑审计 M2）。本 ADR 是对 ADR 0013 的延伸：只汇总已批准 ADR 的内容，不作新的裁定；与原 ADR 不一致时以原 ADR 为准，并须修正本清单。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。T25c 的运行框架与报告按本清单实现；M2 审计据此核对。

## 冻结规则（ADR 0013 总则）

- 首次运行前冻结的是：截至 T26 派发时已批准的全部 ADR 所作的选择（2026-10-23 由 ADR 0040 第 3 项把原文“0001–0032”改为此句；T26b 派发前须核对没有处于 proposed 的 ADR）。下表列出有数值或有替代方案、容易被误改的项，不是全部。
- 冻结项的修改须另立 ADR，依据只能是与验收量无关的新证据，或证明实现与 ADR 不符的程序错误（ADR 0013 第 4 条）。
- 敏感性运行只报告，不据此改选。

## 首次运行报告的必报诊断量

除 7 个验收量与收敛门外，报告须给出（按来源 ADR 汇总）：

- ADR 0013：全部冻结选择及其来源行号。
- ADR 0014：ρ_P 与 Geldart 类别、Ṁ_drain 与其中的灰分量、计算气速与 KURKELA 表 5 的对照（只作对照）。
- ADR 0016：各粒级的参考回落与带出份额、实际回落与带出流量、自由空间各 cell 的固体含量与反应消耗、自由空间元素与质量闭合、数值积分与闭式的比对。
- ADR 0017：气泡相总流诊断、绝热平衡初值 T_ad、迭代次数与阻尼失败情况。
- ADR 0022：各格 d_b/D 与 d_b > D 的格数；ρ_P 可行区间（由 S9–S12 给出）。
- ADR 0024：各外层迭代的 d̄_sv、Geldart 类别及与式 (8) 界线的距离。
- ADR 0026：各（cell，粒级）的悬停滞留量与占比、悬停焦炭消耗占比、h*、两个有效域指标与界限的距离。
- ADR 0029：k_W 与壁面总散热（与 21,7 kW 的相对差）。
- 数值加密检查：ADR 0016、0026、0027 登记的参数，ADR 0028（自由空间轨迹的样本数与步长）、ADR 0033（颗粒温度数值参数）、ADR 0034（捕获邻域 δ_h、δ_u）、ADR 0035 第 5 项与 ADR 0036（床层几何积分子步、逐根 δ_h 的加密）：单独成节，与敏感性运行分开。
