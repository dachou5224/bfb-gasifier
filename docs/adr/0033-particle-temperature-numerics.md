# 式 (5.22) 与膜温耦合的数值参数

> **状态：已批准（2026-10-20）。** PR #98 审查要求把这四个求解器参数按字段名登记。它们只控制式 (5.22) 的牛顿迭代，以及颗粒温度与式 (4.9) 膜温的对齐。不改反应速率，也不截断残差。未收敛时试探点不可评价（`KineticsInputError` 或 `TrialNotEvaluable`），交给 T25c 按 ADR 0022 C4 判为不可行。

## 问题

式 (5.22) 是单颗粒能量平衡，残差单位是 W。传热系数按式 (4.9) 在膜温上计算，膜温又依赖颗粒温度，所以外层还要对齐一次。Hamel 没有给出容差和轮数。这四个数决定一个试探点上的残差能否算出来，属于 CHARTER §9 的求解器参数。

## 裁定

`SolverConfig` 增加下列字段。装配时把它们写入 `FrozenQuantities` 的同名字段，不在残差函数里另设默认值。

| 字段 | 取值 | 含义 |
|---|---|---|
| `particle_tolerance_w` | 1·10⁻⁴ W | 式 (5.22) 牛顿法停止条件：能量残差的绝对值不超过此值 |
| `particle_max_iterations` | 25 | 上述牛顿法的轮数上限 |
| `coupling_tolerance_k` | 1·10⁻³ K | 用新的颗粒温度重算膜温和对流系数之后，颗粒温度变化不超过此值 |
| `coupling_max_iterations` | 16 | 膜温对齐的轮数上限 |

依据：

- `coupling_tolerance_k` 比 ADR 0012 第 2 项外层温度变化判据 0,1 K 紧两个数量级。一次残差评价里留下的膜温不一致，小于外层宣布对齐时允许的温度变化。
- 工况 1 的临时试探（1100 K，七个粒级直到 d_k = 2,4885 mm，气相含氧）上，膜温对齐在 8 轮和 12 轮都不收敛，16 轮收敛。因此轮数取 16，不取更小的数。
- 同一试探在 `particle_tolerance_w` = 1·10⁻⁴ W、25 轮内，式 (5.22) 的内层牛顿能够返回温度。容差作用在能量残差上，不作用在反应速率上。

有灰而无焦炭（m_C ≤ 0 且 m_A > 0）时不调用这四个参数：灰不能充当焦炭表面，也不提供焦炭反应热。灰的输运和 R8、R9 的灰质量不受影响。m_C = m_A = 0 的空库存仍计算比速率，用来判断悬停状态是不是“无反应”。
