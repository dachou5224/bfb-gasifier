# 逐根的捕获高度邻域与床层几何积分的自适应子步

> **状态：已批准（2026-10-21）。** T25b（PR #100）按 ADR 0035 改完后，工况 1 的第一次外层停在两个登记值上：(1) ADR 0034 的 δ_h = 1·10⁻³ m 大于某个稳定根的捕获区半宽 1,899·10⁻⁴ m；(2) ADR 0035 第 5 项的子步加密门在最上一个床格未过（8→16 时 M_i 相对变化 6,025·10⁻⁶ > 1·10⁻⁶，其余七格为 8,2–8,7·10⁻⁷，ρ_P 为 3,920·10⁻⁷）。两者都是求解器参数，不是原文量。本 ADR 修改 ADR 0034 的 δ_h 规则与 ADR 0035 第 5 项的子步数，不改两者的加密门、不改式与记账。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 1. δ_h 按根取值（修改 ADR 0034“求解器参数”一节）

ADR 0034 规定 δ_h 大于 h* 到 R* 外边界距离的一半（下称半宽 w）时失败，不截断。这条的目的是保证邻域留在捕获区内部；δ 只决定在何时停止积分，记账用最后一次进入 R* 的时刻，δ 足够小以后再减小不改变 a^f、a^t、b^f、b^t（ADR 0034 加密 (ii)）。捕获判定还要求能量不等式成立，邻域本身不是捕获的充分条件。因此在 w 很小的根上用更小的 δ_h 不削弱判定，只是更晚停止积分。

**裁定（求解手段）**：

- 每个稳定根使用自己的高度邻域 δ_h,eff = min(δ_h, w)，δ_h 仍为 `SolverConfig.freeboard_delta_h_m` = 1·10⁻³ m；δ_u 不变。
- δ_u 与 `freeboard_max_step_s` 的乘积必须小于该根的 δ_h,eff，否则失败（与 ADR 0034 同一条件，改为逐根检查）。默认值下乘积为 2·10⁻⁶ m。
- 势能取样间距已是 min(1·10⁻⁴ m, w/4)，不改。
- 删去 ADR 0034 中“不把 δ 截到这个距离上”一句；其余不变。
- **报告**：列出 δ_h,eff < δ_h 的每个根：所在 cell 与粒级、h*、到所在捕获区上下边界的距离、w、δ_h,eff。工况 1 首次出现的这个根（w = 1,899·10⁻⁴ m）须在 T25b 的 PR 中说明其位置，并说明是格内根还是靠近界面的格内根。
- **加密**（对 ADR 0034 加密 (ii) 的逐根写法）：基准组每个根用 δ_h,eff = min(δ_h, w)、δ_u；加密组同一根直接用 δ_h,eff/2 = min(δ_h, w)/2、δ_u/2，并对加密组重新检查 δ_u/2·步长 < δ_h,eff/2。只把配置字段 δ_h 减半不算加密：w < δ_h/2 时 min(δ_h/2, w) 仍等于 w，高度邻域没有变。工况 1 在出现 δ_h,eff < δ_h 的 (cell, 粒级) 上比较两组的 a^f、a^t、b^f、b^t、m̂、ū_r 与自由状态是否存在，相对变化须 < 1·10⁻⁴（ADR 0034 的门）；报告两组逐根实际使用的 δ_h,eff 与 δ_u。

## 2. 床层几何积分的自适应子步（修改 ADR 0035 第 5 项）

固定 8 个子步在工况 1 初值流场上只差最上一格未过门；流场随外层迭代改变，固定的任何一个数都不保证以后的迭代仍过门。门本身（与内层同级的 1·10⁻⁶）不放宽。

**裁定（求解器参数）**：

- `bed_integration_intervals_per_cell = 8` 改为每格的**起始**子步数，默认值不变。
- 床层积分不是逐格独立的问题：气泡直径自下而上逐格传递，ρ_P 又由全床总存量反求（ADR 0014 A4）。因此加密以**整床**为单位：所有床格使用同一子步数 n，从起始值开始；每次把 n 加倍后，用同一 n 重新反求 ρ_P 并重算整床 profile，再与上一组整床结果比较。各格 M_i 与 ρ_P 的相对变化都 < 1·10⁻⁶ 时停止，采用加倍后（较细）的一组。不得把在不同 n、不同 ρ_P 或不同上游气泡边界条件下分别算出的单格结果拼在一起。
- 新增 `SolverConfig.bed_integration_max_intervals_per_cell = 256`；某格加倍到上限仍未过门则失败并报告该格的各次相对变化，不截断、不放宽门。
- 对称相对差的分母取两个数中绝对值较大的一个（同 ADR 0034）。
- **报告**：每次外层迭代最终采用的 n，以及最后一次加倍时各格 M_i 与 ρ_P 的相对变化。最上一格与其余各格收敛速率不同的原因（例如床面、d_b/D 或气泡生长起点落在该格内）在 T25b 的 PR 中说明，只作诊断。

## 实现约束

- 第 1 项注明 `求解手段：ADR 0036`，第 2 项注明 `求解器参数：ADR 0036`。
- 测试：(a) 构造 w < δ_h/2 的稳定根，验证不再失败、基准组 δ_h,eff = w，加密组实际使用的高度邻域为 w/2（断言实际值，不只断言配置字段），并比较两组的 a、b、m̂、ū_r 与自由状态是否存在；δ_u·步长 ≥ δ_h,eff 时仍失败，加密组的同一条件单独检查。(b) 构造需要加密才能过门的床，验证整床重算、ρ_P 与各格 M_i 同时作为终止条件，以及到上限时失败。
- ADR 0030 冻结清单的数值检查来源补列 ADR 0036。
- 由 T25b 在 PR #100 内实现。若因此超出 1300 行单卡上限，停下上报。

## 审查记录

- PR #103 审查：指出加密只减半配置 δ_h，在 w < δ_h/2 时有效高度邻域不变。另提示整床 profile 与 ρ_P 反求相互耦合，不能拼接逐格结果；本 ADR 不批准扩大 T25b 的 1300 行预算。已修订：加密组直接用 δ_h,eff/2 与 δ_u/2，并重新检查步长条件，测试断言实际邻域；子步改为整床统一 n 加倍、每次重新反求 ρ_P 并重算整床。
- **2026-10-21：总司令批准**（CHARTER v0.10 §8，目标所有者可否决）。审查方复审通过（PR #103）。
