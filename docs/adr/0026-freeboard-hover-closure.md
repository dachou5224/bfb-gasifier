# 自由空间内部悬停的闭合：反应限制的滞留

> **状态：提议中。** 目标所有者 2026-10-19 在四个候选（A 反应限制的滞留、B 视为回落、C 视为带出、D 改用表观气速）中选定 **A**，这是模型边界选择，性质与 ADR 0014 的 X2 相同。本 ADR 把 A 写成可实现的闭合，并取代 ADR 0016 第 9、10 条中“内部悬停即停止求解”的规定。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 背景

- ADR 0016 第 7 项取 u_g = u_gb(h)（鬼泡速度，式 3.74–3.76），自床面的气泡上升速度沿高度衰减到表观气速；锥段扩径也使表观气速下降。沉降速度 v_t 落在下降段气速范围内的颗粒，在 u_g(h*) = v_t、du_g/dh < 0 处有稳定平衡（ADR 0016 第 9、10 条“有效域：内部悬停”）。
- T27 预检（PR #84）：情景 B、C（燃料转入气相）下，代表粒径 0,3466 mm 的粒级（0,25–0,5 mm，占燃料质量 22,3 %）在 ε_mf、φ_S 的全部 9 个角点都会悬停，悬停带约 0,26–0,59 mm；焦炭缩粒迁移时，大颗粒也要经过这一粒径带。按 ADR 0016，第 1 关因此不能运行。
- Hamel S. 48：在 cell 模型中先求颗粒在衡算空间边界上的速度，以决定用 Fall 1 还是 Fall 2 的解；颗粒比气体慢、回落或小于界限直径时为 Fall 2。原文没有“悬停”这一情形，也没有给出处理办法（T17、T12）。

## 裁定

### 1. 物理图像

悬停颗粒停留在平衡高度 h* 所在的 cell，不随气体向上、也不向下输运；它只能通过反应（R1–R4）减少质量，并随缩粒迁移到更小的粒级（式 2.6 的粒级迁移项），更小的粒级沉降速度更低，再按 ADR 0016 的输运系数被带出或回落。滞留量由式 (2.6) 在该 cell 的稳态决定：进入悬停状态的质量流 = 该状态下的反应消耗 + 迁移出该粒级的质量流。这一闭合只用原文的衡算式与反应式，不指派悬停颗粒的去向。

### 2. 悬停的判定（取代 ADR 0016 有效域中的“停止求解”）

**平衡点**：对每个粒级 k，按 ADR 0016 第 8 项的阻力求终端沉降速度 v_t,k（随当地气体物性变化），在自由空间内求 u_g(h) = v_t,k 的全部根。du_g/dh < 0 的根为稳定平衡 h*（稳定结点或稳定焦点），du_g/dh > 0 的根为鞍点。

**捕获判据**：样本（床面抛出样本或当地生成参考轨迹，ADR 0016 第 9、10 条第 1、2 步）在积分过程中，一旦同时满足 |h − h*| ≤ δ_h 与 |u_P| ≤ δ_u（对某个稳定平衡 h*），即判为被 h* 捕获。起步就在平衡点（h = h*、u_P = 0）的轨迹立即判为捕获。

- δ_h 取 min(δ_h,0, h* 到所在 cell 上下边界距离的一半)，因此捕获点总在 h* 所在的 cell 内（第 3 项的转移是同一 cell 内的转移）；δ_h,0 与 δ_u 是求解器参数，写入 `SolverConfig`，由 T23 的参数 ADR 按字段名登记，并做加密检查（减半时 a、b、c 的相对变化 < 1·10⁻⁴）。
- 判据不依赖转向次数：过阻尼（单调趋近）与欠阻尼（振荡趋近）的轨迹都会进入任意小的邻域。
- **判定必然终止**：运动方程 du_P/dt = f(h, u_P) 与 dh/dt = u_P 构成平面自治系统，阻力使 ∂f/∂u_P < 0 处处成立，向量场的散度恒为负；按 Bendixson 判据，相平面中没有闭轨。因此每条轨迹只有三种结局：离开自由空间下边界（回落）、离开上边界（带出）、趋近某个平衡点。趋近稳定平衡的轨迹在有限时间内进入捕获邻域；鞍点只有一条测度为零的稳定流形，数值轨迹不会停在鞍点，而会离开它，继续走向前两种结局或某个稳定平衡。实现中仍设一个只用于报错的积分时间上限（写入 `SolverConfig`），超限即报告失败，不作判定，不截断。
- 判定之前的轨迹照常记账：各 cell 的停留时间与穿过边界的方向（ADR 0016）。被捕获的份额 dF_s 记入 h* 所在 cell 的 Ĉ。
- 实现须对以下构造做单元测试：过阻尼单调趋近（PR #90 审查给出的例子：d = 0,3 mm、ρ_P = 1000 kg/m³、u_g(h) = v_t − 0,01·(h − 1)，自 h = 1,1 m 起步）、欠阻尼振荡趋近、起步在平衡点、真正离开自由空间的轨迹（单调递增气速）。

### 3. 自由状态与悬停状态（逐 cell 的完整方程）

只在出现稳定平衡的（cell j，粒级 k）设悬停状态；其余（cell，粒级）只有自由状态，衡算即 ADR 0016 的式 (2.6)。对设有悬停状态的 (j, k)，存量 m_k,j = m^f_k,j + m^t_k,j，两条稳态方程为：

- **自由状态**：0 = Σ_{i≠j}（相邻 cell 流入 j 的自由流）+ F^ej_k,j − (a_k,j + b_k,j + c_k,j)·m^f_k,j − r^R_k,j·m^f_k,j + M^in_k,j − r^M_k,j·m^f_k,j
- **悬停状态**：0 = c_k,j·m^f_k,j − r^R_k,j·m^t_k,j − r^M_k,j·m^t_k,j

其中 F^ej 为床面抛出（只在自由空间最下一格）；r^R、r^M 为单位质量的反应消耗速率与迁移出该粒级的速率（R1、R2、R4 按颗粒数，R3 按焦炭质量，都与粒级质量成正比，T20；迁移按式 2.6 的粒级迁移项），两个状态相同；M^in 为由更大粒级迁移进入粒级 k 的质量流（来自两个状态），**一律进入自由状态**（缩小后的颗粒按其自身粒级的轨迹与 c 重新判定是否被捕获）。c_k,j 只把同一 cell 的自由状态转入悬停状态，没有跨 cell 的项。两式相加：

0 = （流入 j 的自由流）+ F^ej − (a + b)·m^f − r^R·m − r^M·m + M^in

即 (j, k) 的式 (2.6)：向上、向下出流只来自自由状态，反应与迁移作用于全部存量。a、b、c 都由参考轨迹求得：判定前的停留与穿越计入 m̂、Û、D̂，捕获份额计入 Ĉ，三者都在同一 cell 记账，逐 cell 与全炉都守恒。两个状态在 T25 中各为一个未知量。

### 4. 自由空间中的灰

悬停颗粒含灰（ADR 0015 第 11 项；ADR 0017 第 19 项）。灰不反应，若不规定去向会在悬停状态无限累积。**裁定**（只用于自由空间；床区仍按 ADR 0014 对 ADR 0009 的修订）：

1. **随迁移**：粒级 k > 1 的灰随焦炭迁移，灰的迁移质量流 = 焦炭迁移质量流 × (m_A / m_C)，按同一状态（自由或悬停）计算。
2. **随燃尽释放**：粒级 k > 1 的焦炭因反应消耗时，按同一比值 m_A/m_C 释放灰，释放的灰进入**同一 cell 最小粒级（k = 1）的自由状态**，作为细灰按 ADR 0016 的 a、b 输运。
3. **零焦炭**：粒级 k > 1 的任一状态若 m_C = 0，则该状态 m_A = 0，进入它的灰流直接进入同一 cell k = 1 的自由状态（纯灰颗粒不在 k > 1 的粒级中存在）。由此 m_A/m_C 只在 m_C > 0 时计算，不出现 0/0。
4. **最小粒级**：k = 1 允许纯灰，按 a、b 输运；k = 1 若设有悬停状态且有灰流入，则悬停状态的灰没有去向，按第 5 项报告并停止。

全炉灰平衡：加入的灰 = 排灰 + 带出（含细灰），与 ADR 0014 A5 一致。T25 验收须覆盖：空库存（m_C = m_A = 0）为零流；灰焦比很大时守恒；焦炭燃尽后灰全部进入 k = 1 并离开体系。

### 5. 有效域

- **无反应、无迁移**：该粒级在 h* 所在 cell 的反应与迁移速率都为零时，悬停状态没有稳态，报告并停止。
- **最小粒级被捕获**：k = 1 设有悬停状态且有灰流入时（第 4 项第 4 点），报告并停止。
- **滞留量的物理上限**：悬停状态与自由状态的固体体积之和，不得超过该 cell 体积的 (1 − ε_mf)（ε_mf 按 ADR 0024）。超出时报告（粒级、cell、滞留量），停止求解，不截断。
- 其它情形按 ADR 0016 不变。ADR 0016 第 9、10 条第 5 步“无反应时的一致性”只适用于没有悬停的粒级。

### 6. 报告与敏感性（只报告，不据此改选，ADR 0013）

首次运行报告须给出：各（cell，粒级）的悬停状态滞留量及其占该 cell 固体的份额、悬停状态的焦炭消耗占全炉焦炭消耗的份额、h*、以及第 5 项两个有效域指标与界限的距离。另做两次敏感性运行，把悬停样本分别按候选 B（捕获时计为床面回落）与候选 C（计为出口带出）处理，给出 7 个验收量、尤其碳转化率的差值。这两次运行只用于说明悬停闭合对结果的影响，不作为选择依据。

## 对 ADR 0016 的修改

ADR 0016 第 9、10 条“有效域：内部悬停”一段中，“该粒级即超出本闭合的有效域……停止求解……裁定前不运行”由本 ADR 第 2–5 项取代；检测按该段的物理条件（u_g(h*) = v_t、du_g/dh < 0）与本 ADR 第 2 项的捕获判据。ADR 0016 其余内容不变。批准时在 ADR 0016 加补注。

## 实现约束

- T23（自由空间）实现第 2 项的判定与 a、b、c 的计算；T25（求解器）实现第 3 项的两个状态、第 4 项的灰迁移与第 5 项的有效域检查。

## 审查记录

- PR #90 审查：指出 (1) 方向翻转不是捕获的必要条件，过阻尼时颗粒单调趋近 h*（审查给出数值反例），起步在平衡点也没有转向；(2) 跨 cell 的捕获转移使逐 cell 相加不回到式 (2.6)；(3) 灰焦比在 m_C = 0 时无定义，末级灰的去向未定。已修订：捕获判据改为进入平衡点邻域（|h − h*| ≤ δ_h、|u_P| ≤ δ_u），δ_h 限于 h* 所在 cell 内，以 Bendixson 判据说明判定必然终止，测试覆盖过阻尼、欠阻尼、平衡点起步与离开四类；写出逐 cell 的自由、悬停两条方程，捕获只在同一 cell 内转移，迁移进入的质量一律进入自由状态；灰规定随迁移、随燃尽释放到 k = 1、零焦炭时不存在于 k > 1，最小粒级被捕获且有灰时停止。
