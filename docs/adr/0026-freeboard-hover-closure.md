# 自由空间内部悬停的闭合：反应限制的滞留

> **状态：提议中。** 目标所有者 2026-10-19 在四个候选（A 反应限制的滞留、B 视为回落、C 视为带出、D 改用表观气速）中选定 **A**，这是模型边界选择，性质与 ADR 0014 的 X2 相同。本 ADR 把 A 写成可实现的闭合，并取代 ADR 0016 第 9、10 条中“内部悬停即停止求解”的规定。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 背景

- ADR 0016 第 7 项取 u_g = u_gb(h)（鬼泡速度，式 3.74–3.76），自床面的气泡上升速度沿高度衰减到表观气速；锥段扩径也使表观气速下降。沉降速度 v_t 落在下降段气速范围内的颗粒，在 u_g(h*) = v_t、du_g/dh < 0 处有稳定平衡（ADR 0016 第 9、10 条“有效域：内部悬停”）。
- T27 预检（PR #84）：情景 B、C（燃料转入气相）下，代表粒径 0,3466 mm 的粒级（0,25–0,5 mm，占燃料质量 22,3 %）在 ε_mf、φ_S 的全部 9 个角点都会悬停，悬停带约 0,26–0,59 mm；焦炭缩粒迁移时，大颗粒也要经过这一粒径带。按 ADR 0016，第 1 关因此不能运行。
- Hamel S. 48：在 cell 模型中先求颗粒在衡算空间边界上的速度，以决定用 Fall 1 还是 Fall 2 的解；颗粒比气体慢、回落或小于界限直径时为 Fall 2。原文没有“悬停”这一情形，也没有给出处理办法（T17、T12）。

## 裁定

### 1. 物理图像

悬停颗粒停留在平衡高度 h* 所在的 cell，不随气体向上、也不向下输运；它只能通过反应（R1–R4）减少质量，并随缩粒迁移到更小的粒级（式 2.6 的粒级迁移项），更小的粒级沉降速度更低，再按 ADR 0016 的输运系数被带出或回落。滞留量由式 (2.6) 在该 cell 的稳态决定：进入悬停状态的质量流 = 该状态下的反应消耗 + 迁移出该粒级的质量流。这一闭合只用原文的衡算式与反应式，不指派悬停颗粒的去向。

### 2. 悬停的判定（取代 ADR 0016 有效域中的“停止求解”）

参考轨迹（床面抛出样本与当地生成参考轨迹，ADR 0016 第 9、10 条第 1、2 步）积分时，样本在自由空间内**经过一个最高点（速度由向上转为向下）之后，又由向下转为向上**（即上升、到达最高点下落、再被气流托起）时，判为悬停。起步时向下运动的当地生成参考轨迹，在出现最高点之前的转向不计。

- 判定之前的轨迹照常记账：各 cell 的停留时间 t_s,i 与穿过各边界的方向（ADR 0016 第 9、10 条第 1、2 步）。
- 判定时，该样本的份额 dF_s 记为从“判定所在 cell 的自由状态”流入“h* 所在 cell 的悬停状态”（见第 3 项）。
- 判定规则用方向变化，不用飞行时间截断或与 h* 的距离阈值；稳定平衡附近的阻尼振荡必然在最高点之后再次转向；没有稳定平衡时，越过最高点的颗粒一路下落到床面，不会再转向。实现须对构造的单调递减气速做单元测试（必然判定）与对单调递增气速（不判定）做对照。
- 第一次转向后直接落回床面或到达出口的样本，仍按 ADR 0016 计为回落或带出。

### 3. 自由状态与悬停状态

对出现悬停的（cell，粒级），把该粒级在该 cell 的存量分成两部分，二者之和就是式 (2.6) 的粒级存量 m_k,i：

- **自由状态** m^f：按 ADR 0016 第 9、10 条第 2、3 步的输运系数向上、向下出流（a·m^f、b·m^f），另有流入悬停状态的系数 c_i,k = Ĉ_i,k / m̂_i,k（Ĉ 为参考轨迹中在该 cell 被判为悬停的 dF_s 之和），a、b、c 都由不含悬停后段的参考轨迹求得。
- **悬停状态** m^t（只在 h* 所在的 cell）：入流为各 cell 自由状态的 c·m^f 之和；没有输运出流；出流只有反应消耗与粒级迁移。

两部分颗粒相同、所处气体相同，单位质量的反应速率与迁移速率相同（R1、R2、R4 按颗粒数，R3 按焦炭质量，都与粒级质量成正比；T20）。两部分的衡算式相加就是该（cell，粒级）的式 (2.6)，原方程不变；分开写只是给出 m^f 与 m^t 的分配，作为求解时的附加闭合（两个状态在 T25 中各为一个未知量）。

### 4. 灰随焦炭迁移

悬停颗粒含灰（ADR 0015 第 11 项：灰按所在焦炭粒级计；ADR 0017 第 19 项：颗粒数按焦炭加灰计）。灰不反应，若不随焦炭离开该粒级，悬停状态的灰会无限累积。**裁定**：在自由空间中，灰的粒级迁移质量流 = 焦炭的粒级迁移质量流 × (m_A,k,i / m_C,k,i)，即灰随焦炭按该粒级的灰焦比迁移；最小粒级的灰按 ADR 0016 的输运系数被带出。床区的灰仍按 ADR 0014 对 ADR 0009 的修订处理（m_inert,i = M_i − Σ m_j,k,i），不受本项影响。

### 5. 有效域

- **无反应、无迁移**：该粒级在 h* 所在 cell 的反应与迁移速率都为零时，悬停状态没有稳态，报告并停止。
- **滞留量的物理上限**：悬停状态与自由状态的固体体积之和，不得超过该 cell 体积的 (1 − ε_mf)（ε_mf 按 ADR 0024）。超出时报告（粒级、cell、滞留量），停止求解，不截断。
- 其它情形按 ADR 0016 不变。ADR 0016 第 9、10 条第 5 步“无反应时的一致性”只适用于没有悬停的粒级。

### 6. 报告与敏感性（只报告，不据此改选，ADR 0013）

首次运行报告须给出：各（cell，粒级）的悬停状态滞留量及其占该 cell 固体的份额、悬停状态的焦炭消耗占全炉焦炭消耗的份额、h*、以及第 5 项两个有效域指标与界限的距离。另做两次敏感性运行，把悬停样本分别按候选 B（第二次转向时计为床面回落）与候选 C（计为出口带出）处理，给出 7 个验收量、尤其碳转化率的差值。这两次运行只用于说明悬停闭合对结果的影响，不作为选择依据。

## 对 ADR 0016 的修改

ADR 0016 第 9、10 条“有效域：内部悬停”一段中，“该粒级即超出本闭合的有效域……停止求解……裁定前不运行”由本 ADR 第 2–5 项取代；检测仍按该段的物理条件（u_g(h*) = v_t、du_g/dh < 0）与本 ADR 第 2 项的方向判据。ADR 0016 其余内容不变。批准时在 ADR 0016 加补注。
