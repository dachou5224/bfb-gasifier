# 自由空间内部悬停的闭合：反应限制的滞留

> **状态：已批准（2026-10-20）。** 目标所有者 2026-10-19 在四个候选（A 反应限制的滞留、B 视为回落、C 视为带出、D 改用表观气速）中选定 **A**，这是模型边界选择，性质与 ADR 0014 的 X2 相同。本 ADR 把 A 写成可实现的闭合，并取代 ADR 0016 第 9、10 条中“内部悬停即停止求解”的规定。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 背景

- ADR 0016 第 7 项取 u_g = u_gb(h)（鬼泡速度，式 3.74–3.76），自床面的气泡上升速度沿高度衰减到表观气速；锥段扩径也使表观气速下降。沉降速度 v_t 落在下降段气速范围内的颗粒，在 u_g(h*) = v_t、du_g/dh < 0 处有稳定平衡（ADR 0016 第 9、10 条“有效域：内部悬停”）。
- T27 预检（PR #84）：情景 B、C（燃料转入气相）下，代表粒径 0,3466 mm 的粒级（0,25–0,5 mm，占燃料质量 22,3 %）在 ε_mf、φ_S 的全部 9 个角点都会悬停，悬停带约 0,26–0,59 mm；焦炭缩粒迁移时，大颗粒也要经过这一粒径带。按 ADR 0016，第 1 关因此不能运行。
- Hamel S. 48：在 cell 模型中先求颗粒在衡算空间边界上的速度，以决定用 Fall 1 还是 Fall 2 的解；颗粒比气体慢、回落或小于界限直径时为 Fall 2。原文没有“悬停”这一情形，也没有给出处理办法（T17、T12）。

## 裁定

### 1. 物理图像

悬停颗粒停留在平衡高度 h* 所在的 cell，不随气体向上、也不向下输运；它只能通过反应（R1–R4）减少质量，并随缩粒迁移到更小的粒级（式 2.6 的粒级迁移项），更小的粒级沉降速度更低，再按 ADR 0016 的输运系数被带出或回落。滞留量由式 (2.6) 在该 cell 的稳态决定：进入悬停状态的质量流 = 该状态下的反应消耗 + 迁移出该粒级的质量流。这一闭合只用原文的衡算式与反应式，不指派悬停颗粒的去向。

### 2. 悬停的判定：以“最后一次进入捕获区”记账（取代 ADR 0016 有效域中的“停止求解”）

**平衡点**：对每个粒级 k，按 ADR 0016 第 8 项的阻力求终端沉降速度 v_t,k（随当地气体物性变化），在自由空间内求 u_g(h) = v_t,k 的全部根。du_g/dh < 0 的根为稳定平衡 h*（稳定结点或稳定焦点），du_g/dh > 0 的根为鞍点。

**捕获区 R***：h* 所在的 cell；h* 恰在两格的界面上时，R* 为这两格的并。R* 是有正宽度的区间。

**归宿判定**：运动方程 du_P/dt = f(h, u_P)、dh/dt = u_P 构成平面自治系统，阻力使 ∂f/∂u_P < 0，向量场散度恒负；按 Bendixson 判据，相平面中没有闭轨，每条轨迹的归宿只有三种：离开自由空间下边界（回落）、离开上边界（带出）、趋近某个平衡点（鞍点的稳定流形测度为零，数值轨迹会离开鞍点）。积分进行到归宿确定为止：
- 回落、带出：到达边界即确定；
- 被 h* 捕获：轨迹进入邻域 |h − h*| ≤ δ_h、|u_P| ≤ δ_u 即确定。δ_h、δ_u **只用于确定归宿**，取得足够小，使进入邻域后轨迹不再离开 R*（δ_h 不超过 h* 到 R* 外边界距离的一半；R* 外边界到 h* 的距离总为正，因此 δ_h > 0，h* 在界面上时也不退化）；
- 只用于报错的积分时间上限写入 `SolverConfig`，超限即报告失败，不作判定、不截断。

**记账**：被捕获样本的**捕获时刻**定义为它**最后一次进入 R*** 的时刻；起步时就在 R* 内且此后从未离开的，捕获时刻为 0。
- 捕获时刻之前的停留与边界穿越，照 ADR 0016 计入自由状态的 m̂、Û、D̂；
- 捕获时刻之后的全部停留归悬停状态，不计入 m̂；
- 最后一次进入 R* 时穿越的那条边界上的通量，记为**进入所进入那一格的悬停状态**（R* 为两格之并时，自下方进入计入下格，自上方进入计入上格）；起步就在 R* 内且不再离开的当地生成轨迹，捕获记在起步所在格。

这样的记账只依赖轨迹的归宿与最后一次进入 R* 的时刻，**与 δ_h、δ_u 无关**：δ 足够小以后，再减小 δ 只会延后归宿确定的时刻，不改变捕获时刻与各项记账。实现以“δ 减半时 a、b 与各捕获份额的相对变化 < 1·10⁻⁴”验证 δ 已足够小，并与样本数、步长的加密检查分开报告。

**测试**（T23）：
- 单 cell 稳定结点的解析例：当地生成样本起步在 R* 内、单调趋近 h*，捕获时刻为 0，自由状态 m̂ = 0，全部记入悬停状态，δ 减半结果不变（对应 PR #90 复审的解析例，并包含首轮审查的过阻尼数值例）；
- 欠阻尼振荡趋近；起步在平衡点；
- h* 恰在界面上：两侧来流分别记入各自所进入格的悬停状态，逐格与全炉守恒；
- 离开自由空间的对照（单调递增气速，或 v_t 高于、低于整段气速的递减剖面），不判捕获。

### 3. 自由状态与悬停状态（逐 cell 的完整方程）

> 2026-10-20 补注：“两个状态的单位质量速率相同”只在两状态灰焦比相同时成立；一般情形各状态用本状态的 r^R、r^M（ADR 0031 第 3 项），两式之和仍是式 (2.6)。燃料库存在悬停格的处理见 ADR 0032。

只在 R* 所含的（cell j，粒级 k）设悬停状态；其余只有自由状态，衡算即 ADR 0016 的式 (2.6)。

**系数**（均由参考轨迹求得）：自由状态的向上、向下出流系数 a、b 按 ADR 0016（a = Û/m̂，b = D̂/m̂），并按穿越边界后的归宿拆成两部分：a = a^f + a^t、b = b^f + b^t，其中 a^t·m^f（b^t·m^f）是这次穿越即为最后一次进入 R* 的通量，进入相邻格的悬停状态；a^f、b^f 的通量进入相邻格的自由状态。床面抛出 F^ej 同样拆为进入自由空间最下一格自由状态与悬停状态的两部分 F^ej,f、F^ej,t。由更大粒级迁移进入粒级 k 的质量 M^in（来自两个状态），按粒级 k 在该格的当地生成参考轨迹的归宿分配：其捕获时刻为 0 时全部进入悬停状态（θ_k,j = 1），否则进入自由状态（θ_k,j = 0）。

**参考轨迹集合与零自由参考存量**（修订 ADR 0016 第 9、10 条第 2 步中“床面样本到不了的格只用该格中点出发的当地轨迹”一句）：

- 格 j、粒级 k 的系数 a、b 及其拆分，由一个参考集合 S_k,j 中所有轨迹在格 j 内的**自由段**（最后一次进入 R* 之前在 j 内的停留与从 j 穿出的通量）求得：
  - 床面抛出样本在 j 内有自由段时，S_k,j 取床面抛出样本（按 dF_s 加权，ADR 0016）；
  - 否则 S_k,j 取自由空间**所有格**的当地生成参考轨迹（每格一条、权重相同），包括从相邻格出发、穿入 j 的轨迹在 j 内的自由段，而不只取从 j 中点出发的那一条。
- **有限性**：任何进入 j 自由状态的通量，都来自某条参考轨迹的一次“非最后一次”进入 R*，或一次进入非 R* 的格；该轨迹此后还会离开 j 或在 j 内停留一段正的时间才最后一次进入 R*，因此它在 j 内有正长度的自由段。按上面的取法，这条轨迹属于 S_k,j，故只要 j 的自由状态有入流，m̂_k,j > 0，a、b 及其拆分有限。
- **零自由参考存量**：若 S_k,j 在 j 内没有自由段（m̂_k,j = 0），则由上一条，j 的自由状态没有任何入流（所有进入 j 的通量都在最后一次进入 R* 时记入悬停状态，当地迁移入流 θ = 1）。此时 (j, k) **不设自由状态**：没有自由未知量与自由方程，a、b 及其拆分不作数值输出（T23 标为“自由状态不存在”），存量只有 m^t，格 j 的式 (2.6) 就是下面的悬停状态方程。不用除数下限、零值或任何未登记的分支替代。
- **测试**（T23、T25）：构造“参考 m̂ = 0、悬停状态有非零入流、反应汇非零”的格，检查自由状态被省略、系数没有 0/0、悬停状态的稳态 m^t = 入流 /(r^R + r^M) 有限、逐格与全炉守恒。

对设有悬停状态的 (j, k)，存量 m_k,j = m^f_k,j + m^t_k,j，两条稳态方程为：

- **自由状态**：0 = Σ_i（相邻格 i 的 a^f_i·m^f_i、b^f_i·m^f_i 中流入 j 的部分）+ F^ej,f − (a_j + b_j)·m^f_j − (r^R_j + r^M_j)·m^f_j + (1 − θ_j)·M^in_j
- **悬停状态**：0 = Σ_i（相邻格 i 的 a^t_i·m^f_i、b^t_i·m^f_i 中流入 j 的部分）+ F^ej,t − (r^R_j + r^M_j)·m^t_j + θ_j·M^in_j

r^R、r^M 为单位质量的反应消耗与迁移出该粒级的速率，两个状态相同（R1、R2、R4 按颗粒数，R3 按焦炭质量，都与粒级质量成正比，T20）。悬停状态没有输运出流。两式相加：

0 = Σ_i（相邻格流入 j 的全部通量）+ F^ej − (a_j + b_j)·m^f_j − (r^R_j + r^M_j)·m_j + M^in_j

即 (j, k) 的式 (2.6)。所有转移都发生在相邻格之间的界面上或格内，逐格与全炉都守恒，没有非相邻格的项；相邻格 i 的出流仍是 (a_i + b_i)·m^f_i，格 i 的式 (2.6) 不变。两个状态在 T25 中各为一个未知量。

### 4. 自由空间中的灰

悬停颗粒含灰（ADR 0015 第 11 项；ADR 0017 第 19 项）。灰不反应，若不规定去向会在悬停状态无限累积。**裁定**（只用于自由空间；床区仍按 ADR 0014 对 ADR 0009 的修订）：

1. **随迁移**：粒级 k > 1 的灰随焦炭迁移，灰的迁移质量流 = 焦炭迁移质量流 × (m_A / m_C)，按同一状态（自由或悬停）计算。
2. **随燃尽释放**：粒级 k > 1 的焦炭因反应消耗时，按同一比值 m_A/m_C 释放灰，释放的灰进入**同一 cell 最小粒级（k = 1）的自由状态**，作为细灰按 ADR 0016 的 a、b 输运。
3. **零焦炭**：粒级 k > 1 的任一状态若 m_C = 0，则该状态 m_A = 0，进入它的灰流直接进入同一 cell k = 1 的自由状态（纯灰颗粒不在 k > 1 的粒级中存在）。由此 m_A/m_C 只在 m_C > 0 时计算，不出现 0/0。
4. **最小粒级**：k = 1 允许纯灰，按 a、b 输运；k = 1 若设有悬停状态且有灰流入，则悬停状态的灰没有去向，按第 5 项报告并停止。

全炉灰平衡：加入的灰 = 排灰 + 带出（含细灰），与 ADR 0014 A5 一致。T25 验收须覆盖：空库存（m_C = m_A = 0）为零流；灰焦比很大时守恒；焦炭燃尽后灰全部进入 k = 1 并离开体系。

### 5. 有效域

- **无反应、无迁移**：该粒级在 h* 所在 cell 的反应与迁移速率都为零时，悬停状态没有稳态，报告并停止。
- **最小粒级被捕获**：k = 1 设有悬停状态且有灰流入时（第 4 项第 4 点），报告并停止。
- **滞留量的物理上限**：悬停状态与自由状态的固体体积之和，不得超过该 cell 体积的 (1 − ε_mf)（ε_mf 按 ADR 0024）。超出时报告（粒级、cell、滞留量），停止求解，不截断。
- 其它情形按 ADR 0016 不变。ADR 0016 第 9、10 条第 5 步“无反应时的一致性”只适用于没有悬停的粒级。

### 6. 报告与敏感性（只报告，不据此改选，ADR 0013）

首次运行报告须给出：各（cell，粒级）的悬停状态滞留量及其占该 cell 固体的份额、悬停状态的焦炭消耗占全炉焦炭消耗的份额、h*、以及第 5 项两个有效域指标与界限的距离。另做两次敏感性运行，把悬停样本分别按候选 B（被捕获的通量计为床面回落）与候选 C（计为出口带出）处理，给出 7 个验收量、尤其碳转化率的差值。这两次运行只用于说明悬停闭合对结果的影响，不作为选择依据。

## 对 ADR 0016 的修改

ADR 0016 第 9、10 条“有效域：内部悬停”一段中，“该粒级即超出本闭合的有效域……停止求解……裁定前不运行”由本 ADR 第 2–5 项取代；检测按该段的物理条件（u_g(h*) = v_t、du_g/dh < 0）与本 ADR 第 2 项的捕获判据。ADR 0016 其余内容不变。批准时在 ADR 0016 加补注。
