# m³(V_N) 采用 DIN 1343 标准状态（273,15 K，101 325 Pa），摩尔体积取 0,022414 m³/mol

> **状态：已批准（2026-10-14）。** DIN 1343 是 Hamel 没有引用的外部标准，按 CHARTER §4.3 由目标所有者批准，批准记录见文末。

## 原文情况

Hamel 的气体体积流量以 m³(V_N) 给出（例如表 7.4 的 Primärluft 50 m³(V_N)/h，PDF 81 右 / S. 143）。符号表把这类体积流量定义为“bezogen auf Normzustand”，并列有“Molvolumen im Normzustand”这一符号，单位为 m³(V_N)/mol（PDF 8 左 / S. XII），但全书没有给出标准状态的温度、压力或摩尔体积的数值。符号表另有参考压力 P₀ = „Bezugsdruck 101300 Pa“（PDF 7 右 / S. XI），它是另一个量，不是标准状态压力。

## 裁定内容

采用 **DIN 1343 标准状态：T_N = 273,15 K，p_N = 101 325 Pa**，按理想气体计算摩尔体积 V_M = R·T_N / p_N = **0,022414 m³/mol**（R = 8,314 J/(mol·K)）。体积流量换算为摩尔流量：Ṅ = V̇_N / V_M。

- **采用范围**：仅限于把 Hamel 及其引用文献中以 m³(V_N) 表示的体积流量，换算为摩尔流量。
- **外部来源**：DIN 1343（Referenzzustand, Normzustand, Normvolumen），出版信息见 https://www.dinmedia.de/de/norm/din-1343/1505240 。
- 不得把 P₀ = 101 300 Pa 当作 p_N 使用。

## 依据与局限

- **定义层面**：m³(V_N)（Normkubikmeter）在德语工程文献中通常指 DIN 1343 的标准状态。但这只说明通行用法，**不能证明 Hamel 实际采用的就是 DIN 1343**。
- **相容性检查**（不是证明）：以 WSV400 工况 A（表 7.4）为例，
  - 干燃料量 m_dry = 35,2 × (1 − 0,273) = 25,5904 kg/h；
  - 理论需氧量 n_O2,st = m_dry · (w_C/M_C + w_H/(4·M_H) + w_S/M_S − w_O/(2·M_O)) = 1,034923 kmol/h，所用原子量 M_C = 12,011、M_H = 1,008、M_O = 15,999、M_S = 32,06 kg/kmol，元素质量分数取自表 7.4（wf）；
  - 空气量 = n_O2,st × λ_O2 / 0,21 × V_M = 1,034923 × 0,4532 / 0,21 × 22,414 = 50,06 m³(V_N)/h，表 7.4 为 50 m³(V_N)/h。
  - 两者相容。但按 101 300 Pa 与 101 325 Pa 计算只差约 0,025%，小于表值的精度，因此这一检查**无法**区分两种压力，也不能作为 Hamel 采用 DIN 1343 的证据。若改用整数原子量，复算会得到约 50,25，差别来自原子量取值。
- “空气含氧 21 mol%”在此只用于相容性检查；进气组成本身仍是待裁定的缺口（见 `data/cases/wsv400_gaps.md`）。

这是对原文的解释性选择（CHARTER §4.5），并引入外部来源（§4.3）。批准后，换算处注明 `解释性选择：ADR 0004`。

## 补记：VTT 数据来源自身的标准状态（2026-10-14）

Hamel 表 7.2 的数据来源 KURKELA_1992 在 Table 3、Table 4 的注中写明：“Nm³ = standard cubic meter at 273,15 K, 101,3 kPa”（`docs/kurkela1992.pdf` p. 5、p. 8）。其压力 101,3 kPa 与 Hamel 符号表的 P₀ = 101 300 Pa 相同，与本 ADR 采用的 DIN 1343 值 101 325 Pa 相差 0,025%，小于表值的精度。因此对 VTT 数据继续使用同一个 V_M = 0,022414 m³/mol，不另设摩尔体积；这一来源事实只作记录，不改变本 ADR 的裁定与批准范围。
