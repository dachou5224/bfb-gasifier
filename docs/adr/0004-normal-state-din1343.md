# m³(V_N) 采用 DIN 1343 标准状态（273,15 K，101 325 Pa），摩尔体积取 0,022414 m³/mol

Hamel 的气体体积流量以 m³(V_N) 给出（例如表 7.4 的 Primärluft 50 m³(V_N)/h，PDF 81 右 / S. 143）。符号表把 V_N 类流量定义为“bezogen auf Normzustand”，并列有“Molvolumen im Normzustand”这一符号，单位 m³(V_N)/mol（PDF 8），但全书没有给出标准状态的温度、压力或摩尔体积的数值。

新主线按德语技术文献的通行定义，采用 **DIN 1343 标准状态：T_N = 273,15 K，p_N = 101 325 Pa**，并按理想气体计算摩尔体积 V_M = R·T_N / p_N = **0,022414 m³/mol**。体积流量换算为摩尔流量：Ṅ = V̇_N / V_M。

## 依据

- 定义层面：m³(V_N)（“Normkubikmeter”）在德语工程文献中即指 DIN 1343 的标准状态。
- 数据层面的交叉验证：WSV400 工况 A（表 7.4）的干燃料量为 35,2 × (1 − 0,273) = 25,59 kg/h，按元素分析计算的理论需氧量为 1,035 kmol/h；乘以 λ_O2 = 0,4532，按空气含氧 21 mol% 折算，再乘 V_M，得 50,06 m³(V_N)/h，与表 7.4 的 50 m³(V_N)/h 相差 0,1%。

## 注意

- 符号表中的参考压力 P₀ = 101 300 Pa（PDF 7）是另一个量（用于其它关系式），不得与 p_N 混用。
- “空气含氧 21 mol%”在此只作交叉验证使用；进气组成本身仍是待裁定的缺口（见 `data/cases/wsv400_gaps.md`），须另行裁定。

这是对原文的解释性选择（CHARTER §4.5）。换算处注明 `解释性选择：ADR 0004`。
