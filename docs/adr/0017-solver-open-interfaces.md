# 求解器与实现阶段的未定接口：未知量形式、雅可比、阻尼、初值、外层、附录 A1 读法与零散参数

> **状态：已批准（2026-10-18）。** 本 ADR 裁定 T18 答卷（`refs/hamel/answers/T18-solver-structure.md`）中标“待定”的各项、T14 答卷附录 A1 中交总司令确认的读法，以及实现卡 T19–T25 需要的零散取值。依据为 Hamel 原文、Wirsum §2.3.3（ADR 0002 的采用范围）、已批准的 ADR 与数学推导。按 CHARTER §5，求解路径上的手段（初值、阻尼、雅可比近似、外层顺序）不改变解的正确性；判定标准仍是最终解使未修改的原方程满足 ADR 0012。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 逐项裁定

### 1. 表号

Bild 2.2 写 „Tab. 3.1“、„Tab. 3.2“，正文 S. 11 与 S. 13 印出的是表 2.1、表 2.2。ADR 0011 第 13 条已裁定 Bild 2.2 的章号比本书目录大 1；表号是同一偏移。**裁定**：配置读入的是表 2.1、2.2。

### 2. 预计算的名单与顺序

S. 12 的名单是流动、离析、干燥与热解；Bild 2.2 的三框是流动、干燥与热解、惰性料校正。两者合并为四步，按数据依赖排序：

1. **流动**（T19）：ε_b、u_b、ε_d、K_bd、Ṁ_auf、M_i、ρ_P（ADR 0014 A4）。
2. **离析**：ADR 0016 第 9、10 条的输运系数 a、b（T23）。床面抛出用第 1 步的气泡量。
3. **干燥与热解**：ADR 0015 第 10 项的释放份额（T22）。燃料进入自由空间的部分用第 2 步的 a、b，所以排在离析之后。
4. **惰性料（VTT 为灰）校正**：ADR 0009 第 4 项、ADR 0014 A5 的排灰。

每次回到 A 都按这四步全部重算。依据：S. 12 写明温度与物流回馈到流动和干燥热解；离析与灰校正依赖二者。

### 3. 气相未知量

式 (2.4)、(2.5) 的未知流是 Ṅ_d,j,i、Ṅ_b,j,i（S. 16），输运项对它们是线性的（浓度、交换流与反应速率随这些未知量非线性变化，完整残差不是线性函数）。**裁定**：气相未知量取各 cell、各相、各组分的出流 Ṅ_l,j,i（mol/s）。相的体积流 V̇_l,i = Σ_j Ṅ_l,j,i·R_g·T_i/P_i（附录 A1 的理想气体假定，S. 163），浓度 C_l,j,i = Ṅ_l,j,i/V̇_l,i 为派生量。

由此推出：相的总流由衡算决定，不由流动模型强加。式 (2.4)、(2.5) 中两相之间只有交换项 Ṅ_ex（ADR 0011 第 3 条：K_bd·V_b·(C_d − C_b)），没有对流交换项；若再把流动模型的可见气泡流强加为气泡相总流，就要在原方程上另加一项，CHARTER §5 不允许。流动模型只用全炉气体总流（外层取上一轮的值）计算气泡量。

进料的分相：布风器进气按式 (3.7)、(3.8) 的两相分配进入最下一格（分配份额在预计算中给出，内层冻结）；cell 中段的进气（二次风）若在床区内，按同一分配进入该格。首次运行报告给出各格衡算得到的气泡相总流与流动模型可见气泡流之比，作为诊断。

### 4. 自由空间 cell 的相数

§3.2.3 的鬼泡与射流描述的是颗粒轨迹所用的气速（ADR 0016 第 7 条），不是一个衡算相；床面以上 ε_b = 0。**裁定**：自由空间各格只有一个气相（式 2.4，无交换项）。床区最上一格的悬浮相与气泡相出流都作为自由空间最下一格的入流。

### 5. 能量未知量

式 (2.1) 每格加一个能量变量；式 (2.7) 每格一个能量衡算；ADR 0012 第 2(a) 项比较温度。**裁定**：每格一个温度 T_i，气、固同温；各股流的焓由 T_i 与物性（ADR 0018）求得。式 (5.22) 的颗粒温度是由 T_i 求出的派生量，不是未知量。

### 6. 雅可比

Wirsum 第 2 步把 F′ 写在 x_0（T18 问题 2 的三种读法）。CHARTER §5 允许雅可比近似。**裁定**：每次内层迭代在当前点 x^(ν) 用前向差分重算雅可比；步长 h_n = √ε_mach·max(|x_n|, s_n)，s_n 为该类变量的尺度（Ṅ_ref、m 的参考存量、1 K）。差分可按块三对角结构分组以减少残差评价次数；分组方式不影响结果。理由：冻结雅可比只改变收敛速度，不改变解；每步重算对第 1 关的规模可以承受，且减少因冻结雅可比而无法下降的情形。

### 7. 阻尼

按 Wirsum 第 4、5 步（ADR 0002）：

- **范数**：式 (2.23) 的欧氏范数取在归一残差上：各块残差除以 ADR 0012 第 1 项的参考流后组成向量。原文 F 的分量单位不同（mol/s、kg/s、W），不归一则欧氏范数由能量块主导；归一只改变缩步路径。
- **严格下降**：按第 4 步取 “<”。
- **上限**：i ≤ 30（2⁻³⁰ ≈ 1·10⁻⁹）。没有满足条件的 i 时，内层判为“阻尼失败”，报告当前状态并停止本次求解，不换用其它策略（T18 问题 2 的待定项）。
- **可行条件**：试探点除范数下降外还须满足：全部 Ṅ_l,j,i ≥ 0、m_j,k,i ≥ 0、m_inert,i ≥ 0（ADR 0009 有效域第 3 条）、T_i > 0、残差有限。不满足则继续减半，与范数条件共用同一上限。这是求解路径上的约束，不改残差。
- **试探点上的残差**：反应项与传热项在试探点重算；只有预计算冻结的量保持不变（T18 问题 2，已非待定）。

### 8. 终止条件

- **成功**：只按 ADR 0012 的收敛门（内层门、外层 (a)、外层 (b)、外部平衡）判定。Wirsum 的终止条件 2（步长小于 δ）不作为成功判据。
- **失败**：内层 ν > ν_max = 200，或外层超过 100 轮，判为 NOT_CONVERGED 并报告；另按 CHARTER §7 带硬超时，超时记 TIMEOUT。
- 这三个数写入 `SolverConfig`（求解器参数，本 ADR 登记）。

### 9. 初值（a 类）

只用工况输入，不用实验出口值或 Hamel 的模拟结果：

1. **温度与组成**：把全炉进料（燃料按元素分析与生成焓、气化剂、蒸汽、吹扫氮）作为一个整体，用附录 A1 的自由焓最小化在 P_WS 下求绝热平衡（第 1 关按 ADR 0014 X1 扣除壁面散热总量），得到温度 T_ad 与组成 y_ad。附录 A1 只处理理想气体（S. 163），这里也只作气相平衡：燃料中的全部元素都进入气相元素池，不引入石墨等凝相，也不由平衡求剩余碳；床区的焦炭初值另由第 3 步给定（不从气相元素池中扣除，因为初值只影响求解路径）。各格 T_i = T_ad。
2. **气体流**：各格气体总流 = 该格以下全部进气的平衡产物总流；组成取 y_ad；床区按第 3 项的进料分相份额分到两相。
3. **固体存量**：床区各格的焦炭存量 m_k,i = M_i·(1 − w_A,0)·x_k，其中 x_k 为燃料粒级的质量分数（ADR 0014 D2），w_A,0 = x_A/(x_A + x_Koks,B·(1 − x_w − x_A)) 是燃料完全热解而未气化时焦炭加灰中的灰份额；自由空间各格的存量取 0 加上一个尺度为 1·10⁻⁶·M_tot 的正值（使第 7 项的可行条件在起点成立）。

b 类初值（以前的模拟结果）允许使用，报告中须写明来源。初值只影响求解路径；若不同初值收敛到不同的解，如实报告全部解，不按出口目标挑选（ADR 0013）。

### 10. 外层

- **后续轮次**：内层从上一轮单元解出发（T18 问题 3 读法 (a)/(c)，数值相同）。初值框只在全程序开始时用一次，与 Bild 2.2 的返回线一致（A 在初值框之后）。
- **第一次外层**：把第 9 项的初值当作“上一轮单元解”，供预计算中依赖温度、物流与存量的各项使用：m_inert,i = M_i − Σ m_j,k,i，VTT 排灰按初值的灰份额计算，惰性补料（有砂床装置）取 0。

### 11. 停留时间与离析输出

S. 12 点名的气体与固体停留时间：ADR 0015、0016 已用各自的闭合给出了它们的作用（释放份额、输运系数），停留时间本身不进入任何方程。**裁定**：作为诊断输出（各格、各粒级），不参与迭代。离析的输出就是 ADR 0016 的 a、b 与床面抛出，内层冻结。

### 12. 交换流与气体流

由第 3 项，气体流是未知量，不冻结。交换流 Ṅ_ex = K_bd·V_b·(C_d − C_b)（ADR 0011 第 3 条）：K_bd 与 V_b 是预计算量（内层冻结），浓度随未知量变化，所以交换流在试探点重算。T18 清单第 1、5 项因此不属于内层冻结量；ADR 0012 第 2(a) 项仍把它们列为外层监测量。

### 13. ADR 0009 有效域第 5 条

床区最下一格的整体守恒残差（诊断量）的容差取 |残差|/ṁ_ref ≤ 1·10⁻⁶，与 ADR 0012 固相块同一阈值。超出则按该条报告边界定义不一致。

### 14. 非负

收敛解须满足：全部 Ṅ_l,j,i ≥ 0、m_j,k,i ≥ 0、m_inert,i ≥ 0、T_i > 0；ADR 0009 的 Ṁ_ab,i ≥ 0 按该 ADR 报告。不满足即不通过 §2.1，不作截断。

### 15. 附录 A1 的读法（T14 交总司令确认的各项）

附录 A1 用牛顿法解式 (A.26) 的 N_E 个方程，未知量为 λ_k。以下读法由求导与迭代的定义唯一确定：

- **式 (A.24)、(A.25)、(A.26) 的指数位置**：exp(−c_j + Σ_k λ_k a_kj) 依赖 j，只能留在对 j 求和的每一项之内。
- **n_l^+ 与 N_l^+**：同一个源汇物质的物质的量；大小写是印刷差异（式 A.32 用大写）。
- **式 (A.28) 的雅可比**：对式 (A.26) 的左端求 ∂/∂λ_s，得 Σ_j q_ij·a_sj·exp(−c_j + Σ_k λ_k a_kj)。线性方程为 Σ_s [Σ_j q_ij a_sj y_j] Δλ_s = −F_i；式 (A.29) 正是这一形式，印刷版面中 (Σ_s a_sj) 的位置不改变这一结果。
- **式 (A.29) 的 y_j^(l)**：第 l 次迭代上的 exp(−c_j + Σ_k λ_k^(l) a_kj)；依式 (A.15)，收敛时它就是摩尔分数。
- **式 (A.30)**：牛顿迭代的阻尼更新 λ_k^(l+1) = λ_k^(l) + η·Δλ_k^(l)。不论右端上标印的是 1 还是 l，“Anwendung des Newton-Verfahrens auf das Gleichungssystem (A.26)”（S. 167）都要求逐次迭代；印刷的左端 (2) 是第一次更新的写法。
- **式 (A.31) 的范围**：j 只取平衡组分 1 … N_S − N_Q。源汇物质不以指数形式出现（式 A.3、A.32 中它们是给定的 N_l^+），对它们没有这一条件。
- **式 (A.40) 右端第一项**：由式 (A.39) 移项（S. 168 写明 (A.40) 是 (A.39) 的变形），右端第一项只能是 b_i^+/N；印刷的 b_i^+ 漏了 /N（左端是摩尔分数量级，b_i^+ 是物质的量，量纲不合）。

### 16. 附录 A1 的数值参数

- η：每次迭代从 0,5 开始，若式 (A.31) 对某个 j 不成立则减半，直到成立（S. 167 只给 0 < η < 1，并要求选 η 使式 A.31 成立）；减半次数上限 30，超限判为平衡计算失败并报告。
- **初值**（S. 168 只给出由式 (A.35)–(A.40) 求初始 λ 的方法，没有给 y_j^(l) 与 N）：取 y_j^(l) = 1/(N_S − N_Q)（均匀分布），N 由式 (A.33) 用这组 y_j^(l) 算出；式 (A.40)（按上项读法）对 λ 是线性方程组，解一次得初始 λ，再进入式 (A.27) 的牛顿迭代。**零元素**：在构造均匀 y_j^(l)、N、q_ij 与初始 λ 之前，对每个 b_i^+ = 0 的元素，从待平衡组分中移除所有 a_ij > 0 的组分（包括多元素组分，例如缺氧时移除 O₂、H₂O、CO、CO₂），并删除该元素的方程；返回结果时把这些组分补回为 0。这样既不会在无约束下生成该元素，也避免式 (A.34) 的分母为零。已知源汇物质 N_l^+ 仍按给定量独立处理。
- **收敛门**：须同时满足 (a) 式 (A.26) 全部 N_E 行的残差 |F_i(λ)| ≤ 1·10⁻¹⁰，其中第 1 行来自摩尔分数归一化（式 A.19、A.20）；(b) 式 (A.34) 的 D ≤ 1·10⁻¹⁰，N_j = N·y_j，N 由式 (A.33) 算出。只检查元素平衡会接受伪收敛：例如只含 H₂、b_H = 1 mol，取 y_H₂ = 0,5，式 (A.33) 给出 N = 1 mol，元素平衡 2·N·y = 1 恰好成立，但 Σy = 0,5，不是平衡解；(a) 的归一化行排除这种情形。迭代上限 200 次。
- 这些参数写入 `SolverConfig`。

### 17. 式 (5.22) 的 ε_P 与 σ

S. 87 写 Ross et al. (1981) 给出 0,79 ≤ ε_P ≤ 0,91，Hamel 未写取值。**裁定**：ε_P = 0,85（区间中点，解释性选择）。首次运行报告给出 ε_P 取 0,79 与 0,91 时 7 个验收量的变化，只报告，不据此改选（ADR 0013）。式 (5.22) 辐射项中的 σ 是辐射换热项中的斯特藩–玻尔兹曼常数 σ_S（物理定义；数值按 ADR 0018 第 3 项）。

### 18. 自由空间的均相反应

S. 90 区分悬浮相（含固体）与无固体的气泡相，表 5.3 等按相给出参数（冻结稿第 9、10 节）。自由空间的气体中固体浓度远低于悬浮相。**裁定（解释性选择）**：原文按相给出两组参数的反应，在自由空间取“无固体气泡相”的一组；原文只给一组的反应照用。Corella 焦油反应的催化剂质量在自由空间取该格的固体存量（ADR 0016 第 9、10 条的实际存量），与 ADR 0014 A6 “cell 中固体质量”的口径一致。

### 19. 焦炭颗粒密度

式 (5.11) 假定焦炭密度恒定，但没有给数值（T14）。T20 由粒级存量换算颗粒数需要它。VTT 的床料只有焦炭与灰（ADR 0014），灰按 ADR 0015 第 11 项分布在焦炭各粒级中、粒径相同，即床料颗粒就是含灰的焦炭颗粒；ADR 0014 A4 已由床层压降确定了这些颗粒的密度 ρ_P。**裁定（解释性选择）**：

- ρ_C = ρ_P（ADR 0014 A4，外层更新）。
- 粒级 k 在 cell i 的颗粒数 N_k,i = (m_C,k,i + m_A,k,i)/(ρ_P·π d_k³/6)，其中粒级的灰量 m_A,k,i = m_inert,i·m_C,k,i/Σ_k m_C,k,i（灰按焦炭质量比例分到各粒级，ADR 0015 第 11 项）。

有砂床的装置另行裁定。

### 20. 式 (5.22) 的对流传热系数

式 (5.22) 含 A_P·α_P,g·(T_P − T_∞)，原文未给 α_P,g（T14）。Hamel 在第 4 章给出颗粒与气体之间传热的 Nu 关联式 (4.9)：Nu_P = 2 + 1,2·Re^{1/2}·Pr^{1/3}（S. 53），是本书唯一的颗粒传热关联式。**裁定（解释性选择）**：α_P,g = Nu_P·λ_g/d_P，Nu_P 用式 (4.9)；Re = u_r·d_P/ν_g，与式 (5.18) 传质所用的 Re 相同（同一颗粒、同一相对速度）；Pr = c_p·μ_g/λ_g（定义）；气体物性按 ADR 0018，取式 (5.20) 的膜温 T_m = (T_∞ + T_P)/2。
