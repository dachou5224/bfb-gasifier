# 初值构造先解自由空间块（修订 ADR 0045 第 3 项的步骤顺序）

> **状态：提议中。** T26g（PR #130）按 ADR 0045 第 4 项停止：第一次焦炭块求解解出负存量。本 ADR 只调整初值构造的步骤顺序，属求解手段（CHARTER §5 允许的初值构造），不改方程、闭合、收敛门与冻结值。目标所有者 2026-10-29 同意并入 T26j。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 证据

- **T26g 验证**（`reports/t26g-validation/`）：ADR 0045 第 3 项第 1 步的起点把自由空间存量取 0；第一次预计算中自由空间回落为 0，ADR 0009 的递推把床面抛出 Ṁ_auf,0 ≈ 0,265 kg/s 全部当作净上行传到床区每个界面。在这组冻结流量下，焦炭块的线性解有 87 项负存量（床区焦炭合计 −3,1 kg，最小 −0,527 kg），`lstsq` 复算相对差 3·10⁻¹²，不是数值误差。ADR 0045 的交替（解固相 → 重做预计算）本可纠正冻结流量，但第一步即按第 4 项停止，交替没有开始。这是 ADR 0045 步骤顺序的缺陷。
- **总司令的验证实验**（T26g 分支代码，暂存目录，不入库）：在同一起点，固定床区焦炭，只解自由空间焦炭块，得到的自由空间各格自由焦炭为 0,02–0,07 kg，没有负值；随后在灰块的残差评价处，最下一格因悬停焦炭（粒级 3，68 kg，上限约 6,05 kg）超出 ADR 0026 第 5 项的有效域而停止。即：先解自由空间可以消除负存量；但在这一初值状态与现行单代表值轨迹下，闭合 A 超出有效域。后者由 ADR 0048 实现后的重做确认，再按 STATUS 2026-10-29 的预先登记处理。

## 裁定（求解手段）

ADR 0045 第 3 项的步骤改为：

1. 起点：同 ADR 0045 第 3 项第 1 步（气相、温度按第 1、2 项；床区焦炭按 ADR 0017 第 9 项第 3 点；自由空间存量取 0）。
2. 用这一状态做一次预计算，得冻结量。
3. **先解自由空间**：固定气相、温度、冻结量与床区焦炭，依次解自由空间焦炭块（线性）、按 ADR 0017 第 19 项由床区焦炭计算床区灰分配、解自由空间灰块（线性）。只更新自由空间存量。
4. 以这一状态（床区焦炭不变）重做预计算。自由空间回落此时与床面抛出自洽，ADR 0009 递推得到的床区界面流不再含伪净通量。
5. 之后按 ADR 0045 第 3 项第 3–5 步（完整的块顺序求解与交替，至多 5 次）进行。

停止条件不变（ADR 0045 第 4 项，按 T26g 任务卡与 ADR 0045 实现约束的写法）：任何阶段的线性系统奇异、负存量、床区焦炭总量为零、回代不过固相门，或有效域拒绝（回代未完成时记“未完成（有效域拒绝）”），都停止并报告，不截断、不绕过。第 3 步中的停止同样适用。

## 实现约束

- 注明 `求解手段：ADR 0049`；ADR 0045 第 3 项加补注指向本 ADR。
- 测试：构造“自由空间存量为 0 时整体解为负、先解自由空间后为正”的小例子；第 3 步只改自由空间存量；第 3 步内的负存量与有效域拒绝按停止条件上报。
- 报告：第 3 步解出的自由空间各格、各状态存量与体积比；第 4 步前后床区界面流与回落的对照。
- 由 T26j 实现。
