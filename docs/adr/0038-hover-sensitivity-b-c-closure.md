# 悬停敏感性运行 S13、S14 的逐格闭合（候选 B、C）

> **状态：提议中。** ADR 0026 第 6 项要求另做两次敏感性运行，把悬停样本分别按候选 B（被捕获的通量计为床面回落）与候选 C（计为出口带出）处理，但没有给出逐格的系数与存量闭合。T25d 任务卡（PR #105）审查指出：只改全炉归宿份额，不能得到逐格的实际输运。本 ADR 补上这一闭合。它只用于 S13、S14；基准运行与其余敏感性运行仍按 ADR 0026 的候选 A。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 1. 物理含义

候选 A 下，进入悬停状态的通量在所进入的格内滞留，只因反应与迁移离开。B、C 不是另一个物理模型：在稳定平衡 h* 下方 u_g > v_t、上方 u_g < v_t，被捕获的颗粒没有回落或带出的轨迹。B、C 是两个边界情形：把原本进入悬停状态的通量**立即**送到床面或出口，用来给出悬停闭合对验收量的影响范围。因此本 ADR 不为这些通量构造穿越中间格的轨迹，也不给它们中间格的停留时间。

## 2. 闭合（改送进入悬停状态的各项流）

参考轨迹、捕获判定与系数 a^f、a^t、b^f、b^t、F^ej,f、F^ej,t、θ 的求法完全按 ADR 0026 第 2、3 项，不改。B、C 只改 ADR 0026 第 3 项中**进入悬停状态的四项流**的去向：

- 相邻格 i 的 a^t_i·m^f_i、b^t_i·m^f_i 中流入 j 悬停状态的部分；
- 床面抛出的 F^ej,t；
- 当地迁移入流 θ_j·M^in_j。

| 候选 | 这四项流送往 | 说明 |
|---|---|---|
| B | 床区最上一格，粒级 k 的固体入流（与 ADR 0016 的自由空间回落流同一入口） | 计为床面回落 |
| C | 自由空间出口，粒级 k 的固体出流（与 ADR 0016 的带出流同一出口，再进入 ADR 0014 X2 的旋风段） | 计为出口带出 |

由此：

- **不设悬停状态**：B、C 下所有 (j, k) 都没有悬停未知量与悬停方程；m^t ≡ 0。ADR 0026 第 5 项中只针对悬停状态的有效域检查（无反应无迁移、最小粒级被捕获）不适用；滞留量上限只对自由状态检查。
- **自由状态**：方程与 ADR 0026 第 3 项的自由状态方程相同（相邻格的 a^f、b^f 入流，F^ej,f，(1 − θ_j)·M^in_j，出流 (a_j + b_j)·m^f_j，反应与迁移汇）。源格 i 的出流仍是 (a_i + b_i)·m^f_i，不变；变的只是其中 a^t、b^t 部分的接收方。
- **零自由参考存量**：ADR 0026 第 3 项中 m̂_k,j = 0 的 (j, k) 在 B、C 下也不设自由状态；它在 A 下的悬停入流按上表改送，该格该粒级存量为 0。
- **非相邻项**：这四项流从格 i（或床面、或格 j 本身）直接送到床区最上一格或出口，是本 ADR 仅为 S13、S14 引入的非相邻耦合。雅可比按 ADR 0017 第 6 项的差分求，包含这些项；不另设近似。
- **随行的量**：改送的流携带源状态的焦炭、灰（ADR 0031）与燃料 W、P 库存（ADR 0032）按同一系数一起改送；焓按源状态的固体温度计。灰随燃尽释放到 k = 1（ADR 0026 第 4 项）不变。

## 3. 守恒

每一项改送流在源处减去、在床面或出口加上同一质量与元素，因此全炉质量、元素与能量守恒不变；逐格守恒对每个格成立（源格少的正是改送出的流，接收方多的也是这一项）。

## 4. 实现约束与测试

- 自由空间记账参数取 A（默认）、B、C；取 A 时与现行实现逐位相同。B、C 是 ADR 0026 第 6 项授权的敏感性替代闭合，残差的耦合与 A 不同，不是只改迭代路径的数值手段；注明 `模型边界选择（敏感性）：ADR 0026 第 6 项、ADR 0038`。
- 改送流按源状态固体温度携带的焓，须同时进入接收端（床区最上一格或出口）与外部能量平衡（ADR 0012 第 3 项）的记账；不得在接收端改按顶格或底格温度计焓。
- 测试（T25d）：
  - **固定状态的记账测试**：固定同一组源状态、自由存量、参考系数与输入流，比较改送前后（A 记账与 B、C 记账）：接收端增量恰为四项流之和，源端只扣一次；质量、C/H/O 元素与随行焓逐项抵消；B、C 下悬停未知量不存在。
  - **分别求解的运行**：A、B、C 各自满足逐格与全炉质量、元素、能量守恒；B、C 的实际回落或带出流按“普通自由状态贡献 + 改送贡献”分项核对。各运行与 A 的差值只报告，不要求等于改送流之和（B 的返料、C 的直接带出与悬停状态的取消都会改变自由状态的存量与反应）。
  - 取 A 时残差与冻结量逐位不变。
- 报告：S13、S14 给出 7 个验收量与基准的差值（ADR 0026 第 6 项、ADR 0030），以及改送流占该粒级自由空间总入流的份额。

## 审查记录

- PR #105 复审：指出“B、C 比 A 多出的流量等于改送量”只在固定同一状态的记账比较中成立，分别求解的运行中自由状态贡献本身会变化。已修订：测试分为固定状态的记账测试与分别求解运行的守恒、分项核对；写明 B、C 是敏感性替代闭合而非数值手段，改送焓按源温度同步进入外部能量平衡。
