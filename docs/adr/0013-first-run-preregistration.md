# 第 1 关首次运行预登记：暂定项的判定方法与冻结

> **状态：已批准（2026-10-17）。** 本 ADR 落实方向审计的建议 1。目标所有者于 2026-10-17 明确授权“复审59，如无问题，执行合并”；codex 对提交 911620e 复审通过，按该授权登记批准。

## 问题

ADR 0006、0010、0011 登记了若干“第 1 关首次完整运行时复核”的暂定项。若每一项都按“哪个更接近 Hamel 的 7 个出口目标值”来选，组合超过 24 种，而 CH₄、H₂O 的读数误差与容差同量级；ADR 0006 本身又是用同一组目标反推的。这样即使第 1 关通过，也只是离散调参的结果，不再是独立的复现证据（方向审计第 6 条）。

## 总则

1. **判定在首次完整运行之前完成，并冻结。** 每个暂定项只能用**与 CHARTER §2.2 验收量无关**的证据判定：Hamel 中间结果图表（第 3、5 章的计算曲线）、Hamel 的文字陈述、物理一致性。不得用第 1、2 关（VTT 加压 1–4）的出口温度、气体组成或碳转化率来选择。
2. **没有独立证据的项，现在就按文字证据定下默认，冻结，不做以出口目标为准的 A/B。** 敏感性可以报告，但报告不构成改选的依据。
3. **首次运行的结果如实登记。** 通过与否按 CHARTER §2.2 判定；不通过时做诊断。
4. **冻结项的修改**须另立 ADR，且依据只能是：(a) 与验收量无关的新证据，或 (b) 证明实现与 ADR 不符的程序错误。“改了以后更接近目标值”不是可接受的依据。
5. **第 2 关（VTT 加压 2–4）作固定规则的跨工况检验**：使用与第 1 关完全相同的冻结选择，不得重新选择，两关结果一并报告。它不是完全独立的验证：ADR 0006 曾用工况 2–4 的 Hamel 模拟出口做过反推表，工况 2 的吹扫氮计入选择已参考其出口；这部分信息已经用过，取消未来的 A/B 不能撤销。第 2 关只能说明“规则固定后跨工况是否仍成立”。
6. 实现错误（代码与 ADR 不符）随时可修，修正须在 PR 中写明，不受本条限制。

### 第 1、2 项的判定规则（计算前固定）

> 2026-10-18 补注：本节规则由 ADR 0022 A1 取代（图注缺容器直径、ε_mf、φ_S、n_0、h_A，无法执行）。第 1、2 项冻结为 ADR 0011 的暂定读法；Bild 3.5、3.3 的读数（PR #73，cursor 按目标所有者指派完成）只作诊断。

1. **读数**：由目标所有者用工具数字化 Bild 3.5（PDF 26 右 / S. 33）的五条计算曲线（u_0 − u_mf = 0,1、0,2、0,3、0,4、0,6 m/s），每条在 P = 0,2、0,5、1,0、1,5、2,0、2,5 MPa 处取点；只读计算曲线，不读测量点。读数误差 σ_d 按工具精度登记（同 Bild 5.11 的格式）。Bild 3.3（S. 32）的 u_b,r 曲线按同样方式在相同压力处读点，误差 σ_u。
2. **计算**：按图注条件（T = 25 °C，d_P = 0,7 mm，ρ_P = 2600 kg/m³，h = 0,55 m）对 2 × 3 = 6 种组合计算同样的点。
3. **主判据**：Bild 3.5 上的归一化均方根偏差 E = √(mean(((d_calc − d_read)/σ_d)²))。
4. **判定**：
   - **合格**：E ≤ 3 的组合为拟合合格；E > 3 的组合排除。
   - **主图候选集合**：设合格组合中最小的 E 为 E_min，凡 E ≤ E_min + 1（与最优组合的差别不超过一个读数误差）的合格组合都进入候选集合 C；不按排序位置截取，C 可以含 1 至 6 个组合。
   - 若 C 只含一个组合，选它。
   - 若 C 含两个或更多组合，用 Bild 3.3 对 C 中**全部**组合计算同样的 E′，按同一规则（合格 E′ ≤ 3，候选 E′ ≤ E′_min + 1）在 C 内形成集合 C′；C′ 只含一个组合时选它。
   - 以下情形**不选取**，第 1、2 项保留未决，上报总司令与目标所有者，沿 ADR 0011 原有路径处理（是否查阅 Heinbockel 1995 由目标所有者决定）：没有合格组合；C′ 仍含两个或更多组合；某组合在图注条件下无解。不得以数值最小者代替分辨力。
5. 判定的读数、计算值、E 与结论写入本 ADR，判定后冻结。

### 第 3 项：改为 (5.45) 的依据

ADR 0010 第 3 条写“第 6、7、8 章都没有写模拟用了哪一个式子”，并以倾向性证据暂定 (5.49)。复核原文后发现一处遗漏：§5.1.1.2 简化模型的说明（PDF 49 右 / S. 79）写明 „Als Gasphasenreaktion wird die homogene Wassergasreaktion (Wen und Chaung 1979) eingebunden, um die im Vergaser vorliegenden Gaskonzentrationen nachzubilden.“ 这是全书唯一一句写明 Hamel 的程序**实际使用了**某一个水煤气速率式的话：Wen und Chaung (1979) 即式 (5.45)。

局限：该句在简化模型中，简化模型的气化动力学用的是 Sowa（1991），与主模型的 Hobbs 不同，所以不能证明主模型也用 (5.45)。a_R8 = 0,02 是 Wen und Chaung 为气流床所用的值，简化模型取多少原文未写。即便如此，“程序中确有 (5.45)”的直接陈述，强于 (5.49) 的间接倾向。

**裁定**：冻结速率式的形式为 (5.45)，p 取 atm（ADR 0010 第 2 条）；k_eq,R8 仍取式 (5.43)（ADR 0010 第 1 条）。ADR 0010 第 3 条的“比较前默认 A”与“A/B 比较”由本条取代。

**a_R8 单列**：S. 79 支持的只是速率式的形式，不支持任何 a_R8 数值；S. 94 写明 0,02 是 Wen und Chaung 为他们自己的气流床气化炉所用。因此 a_R8 = 0,02 不是 Hamel 主模型参数的来源事实，若采用，是本项目把一个气流床参数**外推**到流化床的解释性选择。可选方案：
- (a) 采用 0,02，标为外推的解释性选择，在代码与首次运行报告中注明；
- (b) 保留 a_R8 待定，在找到与验收量无关的依据（Hamel 原文其它位置，或目标所有者批准查阅 Wen und Chaung 1979）之前不运行第 1 关。

两式的单位都是每 kg 灰（mol/(s·kg_Asche)），催化剂质量按 ADR 0014（VTT 为床料中的灰）计。

**目标所有者决定（2026-10-17）**：采用方案 (a)，a_R8 = 0,02。这是把 Wen und Chaung 的气流床参数外推到流化床的解释性选择，不是 Hamel 主模型参数的来源事实；代码中注明 `解释性选择（外推）：ADR 0013`，首次运行报告中列明。不得按出口结果改动。
