# CHARTER §2.1 的收敛阈值与平衡阈值

> **状态：提议中。** 本 ADR 登记 CHARTER §2.1 要求“由 ADR 登记”的数值前提：各分块残差的收敛阈值、外层循环的对齐判据、外部元素平衡与总能量平衡的偏差阈值。阈值属于验收判据，由目标所有者决定（CHARTER §8）：目标所有者 2026-10-17 已同意下列数值。本 ADR 经审查方审查表述后登记。

## 原文情况

Hamel 没有给出数值。S. 11（PDF 15 右）只写程序开始时读入用户给定的控制量，其中包括“Fehlerschranken für das Zellenmodell”；S. 20 写明求解用阻尼 Newton–Raphson（ADR 0002）。因此阈值是项目自己的选择，不是复现对象。

## 裁定

### 1. 内层（牛顿法）收敛门

对**未修改的原方程**（CHARTER §2.1、§5），各分块残差的最大绝对值除以该块的参考流，均须达到：

| 分块 | 判据 | 参考流 |
|---|---|---|
| 气相（式 2.4、2.5：每种气体、每相、每个 cell） | ‖r‖∞ / Ṅ_ref ≤ 1·10⁻⁶ | Ṅ_ref = 全炉进口气体总摩尔流（mol/s） |
| 固相（式 2.6：每个粒级、每个 cell） | ‖r‖∞ / ṁ_ref ≤ 1·10⁻⁶ | ṁ_ref = 燃料干基质量流（kg/s） |
| 能量（式 2.7：每个 cell） | ‖r‖∞ / Q̇_ref ≤ 1·10⁻⁶ | Q̇_ref = 燃料低位热值功率（W），按收到基低位热值乘燃料质量流 |

用相对残差，是因为三块的量纲与量级不同（mol/s、kg/s、W），除以参考流后判据才可比。

### 2. 外层循环（预计算与单元模型的对齐）

外层收敛由两部分组成，两部分都满足才算外层收敛。

**(a) 迭代变化判据**（相邻两次外层迭代之间，k 与 k−1）：

| 量 | 判据 | 归一化 |
|---|---|---|
| 各 cell 温度 | \|T_i^k − T_i^{k−1}\| ≤ 0,1 K | 绝对值，不归一化 |
| 各股整体固体流（ADR 0009 的 Ṁ_auf,i、Ṁ_ab,i、带出量、惰性补料、排灰） | \|x^k − x^{k−1}\| / ṁ_ref ≤ 1·10⁻⁴ | ṁ_ref = 燃料干基质量流（同第 1 项） |
| 各 cell 几何存量 M_i 与惰性床料量 m_inert,i | \|x^k − x^{k−1}\| / M_tot ≤ 1·10⁻⁴ | M_tot = 全炉床区几何存量之和 Σ M_i（取第 k 次） |
| 各股气体流（两相、各 cell 出流与交换流） | \|x^k − x^{k−1}\| / Ṅ_ref ≤ 1·10⁻⁴ | Ṅ_ref 同第 1 项 |

分母一律取**全炉固定尺度**，不取该量自身的旧值。因此某股流在新旧两次都为 0（例如床底 Ṁ_ab,N = 0，或第 1 关不循环时的回流）时变化为 0，满足判据；只有一方为 0 时按其绝对变化相对全炉尺度判断。不得另设 ε 分母，也不得为避开零值而改动物理量（CHARTER §5）。

**(b) 最终一致性检验**：(a) 满足后，用最终的单元解**重新计算一次全部预计算输出**（流动量、气泡与交换系数、整体固体流与存量、热解释放份额、自由空间回落与带出，即一切由单元解反馈到预计算的量），不再迭代，直接以这组预计算输出代入未修改的原方程，计算各分块残差；须满足第 1 项的内层收敛门。只有通过 (b)，才宣布外层收敛；报告与验收使用的输出，是通过 (b) 的这一组自洽状态。

(b) 保证最终解对“与自身一致的预计算”满足原方程，而不只是对上一轮冻结的预计算满足。预计算输出的完整清单由 T18 的数据流规格给出；清单确定前，(b) 至少覆盖上表中出现的各量。

### 3. 外部平衡（收敛后核验）

用 T9 的外部元素平衡检查器（`hamel/cases/balance.py`）核验进出口：

| 判据 | 阈值 |
|---|---|
| 元素平衡 C、H、O：\|进 − 出\| / 进 | ≤ 0,1 %（每种元素分别） |
| 总能量平衡：\|进 − 出 − 热损失\| / Q̇_ref | ≤ 0,5 % |

“出”包括出口气体、带出与排灰的固体；“热损失”为壁面与内置传热面的热流（式 2.7 的 Q̇_W、Q̇_WÜ）。

### 4. 判定

- 第 1、2 项都满足，且第 3 项都满足，才算 CHARTER §2.1 的“收敛”；只满足第 1 项不算。
- 状态须有限、非负（CHARTER §2.1），并满足 ADR 0009 的有效域。
- 任一项不满足时，工况指标表记为“未收敛”，并报告未达标的分块、cell 与数值；不得放宽阈值后不报（CHARTER §2.1）。

## 依据

- 平衡阈值远严于验收容差：CHARTER §2.2 中 CO 的容差为 ±0,015（摩尔分数），0,1 % 的元素不平衡对出口组成的影响远小于此，因此平衡误差本身不会左右验收结论。
- T1 探针中旧代码的碳缺口约 −0,56 mol/s，求解器仍报 SOLVED。按本 ADR 的第 3 项，该结果会被直接判为不收敛。

## 修改

阈值的任何修改须由目标所有者决定，并修订本 ADR；不得在代码中另设一套阈值。阈值作为求解器参数，写入 `SolverConfig`，并在代码中注明 `ADR 0012`（CHARTER §9：求解器参数须有 ADR）。

## 证据状态

S. 11 的“Fehlerschranken für das Zellenmodell”依据页面文本层（T12 答卷已引用同页）；目标所有者 2026-10-17 在对话中同意上述数值。

## 审查记录

- PR #58 首轮：指出 (1) 外层“相对变化”未定义分母与零值规则，床底 Ṁ_ab,N = 0 等合法零值会造成 0/0；(2) 只比较温度与固体量不能保证预计算与单元解自洽。已修订：第 2 项改为按全炉固定尺度归一化（流量用 ṁ_ref、Ṅ_ref，存量用 M_tot，温度用绝对值），写明零值判定，并加入气体流；新增“最终一致性检验”，以最终单元解重算全部预计算输出后，原方程须满足内层收敛门，输出使用这一组自洽状态。
