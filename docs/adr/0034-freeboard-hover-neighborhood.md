# 自由空间悬停邻域与稳定根的搜索

> **状态：待审查。** 编号为 0034（0033 已由 PR #98 的颗粒温度数值参数使用）。ADR 0028 登记了样本数、步长和时间上限，并写明 δ_h、δ_u 由 T23b 补登。本 ADR 登记这两个 `SolverConfig` 字段，以及找稳定根时用的界面残差、并根距离和格内搜索。不改式 (3.82)，也不改 ADR 0026 的记账。审查方为 codex。

## 问题

ADR 0026 第 2 项把被捕获定为进入邻域 \(|h-h^*|\le\delta_h\)、\(|u_P|\le\delta_u\)。δ 只用来确定归宿。δ_h 不得超过 h* 到捕获区外边界距离的一半。原文没有这两个数，也没有规定怎样在离散的格上找 \(u_g(h)=v_t\) 的根。

记账用的是最后一次进入捕获区 R* 的时刻，不是进入邻域的时刻。δ 足够小以后再减小，只延后停止积分的时刻，不改变捕获时刻和 a^f、a^t、b^f、b^t。

## 求解器参数

`SolverConfig` 增加下列字段。`assemble_case` 使用 `SolverConfig()`，因此默认值就是本 ADR 的取值。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `freeboard_delta_h_m` | 1·10⁻³ m | 高度邻域。只用于判定捕获 |
| `freeboard_delta_u_m_s` | 1·10⁻² m/s | 速度邻域。只用于判定捕获 |

δ_h 大于 h* 到 R* 外边界距离的一半时积分失败，不把 δ 截到这个距离上。δ_u 与 `freeboard_max_step_s` 的乘积不小于 δ_h 时也失败，避免一步跨过邻域。默认值下这个乘积是 2·10⁻⁶ m，小于 1·10⁻³ m。这两条只保证邻域在捕获区内部、而且一步跨不过去。它们不保证进入邻域之后的惯性行程仍留在 R* 内。时间上限仍是 ADR 0028 的 80 s，到时只报错，不改判归宿。

## 稳定根

每个格用该格的气体密度和粘度算 v_t。du_g/dh < 0 的根是稳定平衡，斜率大于 0 的根不进入捕获区。

界面根：相邻两格在界面上的 \(|u_g-v_t|\) 都不超过 1·10⁻⁸ m/s，并且两侧指向各格内部的差商都小于 0。这时 R* 是这两格的并。两侧斜率都大于 0 则不是捕获点。两侧斜率符号不一致则失败，不猜该记入哪一格。

格内根：每格 32 等分。相邻样本残差变号时，在该区间二分 60 次。差商步长取 1·10⁻⁴ m 与四分之一格宽中的较小者；根靠边界时改用单侧差商。格内根与某个界面根相距不超过 1·10⁻⁶ m 时并入该界面根，避免同一点被收成两个平衡。

这四个数（1·10⁻⁸ m/s、1·10⁻⁶ m、32、60）和差商步长不是 `SolverConfig` 字段。它们只决定根落在哪一格，不参与 a、b 的除法。

每个稳定根使用自己的捕获区。轨迹最终进入哪个根的不变区域，最后一次进入时刻就按那个根的 R* 回溯。相邻两个根的捕获格不相交时，从一个根的格子穿入另一个根的格子要记成离开和进入，不能把这些格子并成一个捕获区。

## 不变区域

速度为零时的加速度记为 a(h, 0)。阻力对速度的导数为负，所以

d/dt (½ u_P² − ∫_{h*}^h a(z, 0) dz) = u_P (a(h, u_P) − a(h, 0)) ≤ 0。

在某个根自己的 R* 里，从 h* 向两侧走，只要 −a 在上方为正、a 在下方为正，势能就升高。势能还低于两侧势垒的状态到不了势垒，也就离不开这个 R*。势垒取恢复力消失处或外边界之前的最后一块，哪一侧更近就由那一侧定势垒；另一侧只积到同一势能。

取样间距是 1·10⁻⁴ m，不超过半宽的四分之一。每一块在两端和中点计算离开 h* 的势能线密度，块上的上、下界取这三个数的最大和最小。这是解释性选择，不是 `SolverConfig` 字段。线密度降到不大于 0 就停止，不把势垒外的状态算进不变区域。

判定捕获要同时满足两件事：状态落在这个根的 δ 邻域里，并且上面的能量不等式成立。只进了邻域、能量还够穿出 R* 的，继续积分。因此不能只把 δ 调小来代替这个势垒。

## 加密

两组分开报。相对变化都要小于 1·10⁻⁴。对称相对差的分母取两个数中绝对值较大的一个；两个数都是 0 时记为 0。

(i) 样本数从 48 增到 96，步长从 2·10⁻⁴ s 减到 1·10⁻⁴ s。

- 带出：u_g = v_t + 4 m/s，3 格共 1,5 m，u_b = 1 m/s。最下一格的 a^f 与 m̂ 相对变化为 3,89·10⁻⁵，上面两格更小。回落、带出份额和 a^t、b^f、b^t 的相对变化不超过 2·10⁻¹⁵。
- 悬停：两格共 2 m，h* = 1,2 m，气速坡度 0,8 s⁻¹，u_b = 0,15 m/s，δ_h = 0,08 m、δ_u = 0,01 m/s。下格 a^t 与 m̂ 的相对变化为 3,18·10⁻⁶。上格自由状态不存在，加密后仍不存在。

(ii) δ 减半。同一悬停例、12 个样本，δ_h 从 0,08 m 减到 0,04 m，δ_u 从 0,01 m/s 减到 0,005 m/s。四个系数、m̂ 和各份额逐位相同，相对变化为 0。单格稳定结点把 δ_h 从 0,02 m 减半，欠阻尼轨迹再入捕获区时把 δ_h 从 0,01 m 减半，捕获时刻和记账同样不变。

两条反例用来核对势垒，不改上面的加密数字：

- 格 [0, 1] 与 [1, 2]，u_g − v_t = −2(h−0,5)(h−1)(h−1,5)。稳定根在 0,5 m 和 1,5 m，捕获格相邻。从 0,75 m、5 m/s 出发，归宿是 1,5 m 那个根，进入格 1 之前的停留保留，悬停通量记在穿出格 0 的那一次。
- h* = 0,9975 m，坡度 0,01 s⁻¹，d = 3 mm。半宽 0,00125 m，默认 δ 通过半宽检查。从平衡点以 0,0099 m/s 出发会先离开格 0。默认 80 s 结束时粒子已经回到格内，势能也低于势垒，但还没有进入 δ 邻域，积分报错，不记成起步即捕获。时间上限放到 200 s 后，捕获时刻是回到格 0 的那一次；δ 减半，这次时刻和自由停留不变。
