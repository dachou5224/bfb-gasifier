# VTT 加压工况 1、2 暂定计入料斗吹扫氮气（随燃料进入的惰性 N₂）

## 问题

Hamel 表 7.2（PDF 76 右 / S. 133、PDF 77 左 / S. 134）只列一次风、二次风和蒸汽。其数据来源 KURKELA_1992 的 Table 4（p. 8）和 Table 5（p. 9）另有一行 “Nitrogen feed, Nm³/h”；p. 5 说明燃料在料斗中用氮气加压后由螺旋给料。这一路氮气是否进入 Hamel 的模拟，原文没有说明（ADR 0005 待定事项 1）。北极星是复现 Hamel 的模拟结果（CHARTER §1），所以要判断的是 **Hamel 当时是否计入了它**。

这里要区分两件事：
- **文献事实**：VTT 装置在各试验点确实有这股吹扫氮气，数值见 Table 4、5。这一点没有疑问，可作为 `cited` 数据记录。
- **模型选择**：Hamel 的模拟是否计入了它。这正是本 ADR 要裁定的，而原文没有直接证据。

这一路氮气不可忽略：褐煤工况 1 为 6,2 Nm³/h，约占总风量 81,9 Nm³/h 的 7,6%。

## 依据：用 Hamel 的模拟结果按碳平衡反推

用 Bild 7.10（`data/digitized/fig_7_10.json`，已随 #28 合并）读出的 Hamel 模拟值：

- 进入气相的碳 n_C = X_C · ṁ_B·(1 − w_H2O)·w_C / M_C，ṁ_B、w_H2O 取表 7.2，w_C = 0,638，M_C = 12,011 kg/kmol；
- 出口总气量 = n_C / (y_CO + y_CO₂ + y_CH₄)；
- 模拟出口 N₂ = (1 − y_CO − y_CO₂ − y_H₂ − y_CH₄ − y_H₂O) × 出口总气量 × V_M，V_M = 22,414 m³/kmol（ADR 0004）。

不确定度按两种方式给出：
- **全端点枚举**：五个气体分量与 X_C 都取 `est_error` 的端点，枚举全部组合，相当于所有读数同时偏到最不利方向，是保守上界；
- **统计估计（1σ）**：假设各读数误差相互独立，且在 ±`est_error` 内均匀分布（σ = est_error / √3），线性化合成。

结果（Nm³/h）：

| 工况 | 中心值 | 全端点枚举 | 1σ | 只算空气中的 N₂（79 %） | 空气 + 吹扫 N₂ |
|---|---|---|---|---|---|
| 1（不循环） | 71,9 | 62,0–83,4 | 2,85 | 64,7（偏离 2,5σ） | 70,9（偏离 0,4σ） |
| 2（循环） | 73,9 | 64,0–85,2 | 2,85 | 70,4（偏离 1,2σ） | 73,6（偏离 0,1σ） |
| 3（循环） | 88,1 | 76,5–101,5 | 3,40 | 77,3（偏离 3,2σ） | 80,8（偏离 2,1σ） |
| 4（循环） | 87,8 | 76,1–101,2 | 3,37 | 83,0（偏离 1,4σ） | 85,5（偏离 0,7σ） |

全端点枚举的数值与 codex 在 PR #29 审查中的独立复算一致。可复算的脚本见附录。

**推断强度**：在“读数误差相互独立”的假设下，工况 1、2 都更符合“计入吹扫氮”；但在全端点最不利组合下，两种假设在四个工况中都不能排除。因此这只是**倾向性证据，不是证明**。此外，推算忽略了焦油中的碳与 C₂ 烃，并把 NH₃、H₂S 等微量组分并入剩余份额，这些结构性误差没有计入上表。工况 3、4 的中心值比两种假设都高，说明方法在循环工况上另有系统偏差，原因不明。旁证：Kurkela 实测的工况 1 出口 N₂（+Ar）为 50,2 vol% × 141,7 Nm³/h = 71,1 Nm³/h，与“空气 + 吹扫 N₂”一致，但这只说明实际装置如此，不说明 Hamel 的模型如此。

**方法说明**：本推算利用的是 Hamel 的**模拟**出口（不是实验出口，CHARTER §1 禁止的是以实验出口反推输入），而且只在两种离散的解释之间作选择，没有拟合任何连续参数。

## 裁定（暂定）

1. **适用范围仅限工况 1、2**：模型计入料斗吹扫氮气，作为惰性 N₂，流量取 KURKELA_1992 Table 5（p. 9）的 “Nitrogen feed”：工况 1 为 6,2 Nm³/h，工况 2 为 3,2 Nm³/h；按 ADR 0004 换算为摩尔流量。
2. **进入位置**：随燃料从燃料口进入（燃料口在布风板以上 0,12 m，ADR 0005），依据是 p. 5 的料斗加压给料说明。这是解释性选择。
3. **温度**：原文没有给出。不在本 ADR 中裁定，装配时为 `missing`，不得静默取默认值；留待能量衡算模块的原文答卷。
4. **其余工况待裁定**：工况 3、4（第 2 关）在查明上述系统偏差后另行裁定；工况 5–15（后备与扩展工况）没有对应的 Hamel 模拟证据，暂不裁定。它们的吹扫氮数值可以作为文献事实以 `cited` 记录，但在裁定前不得作为模型输入装配。
5. **复核条件**：第 1 关模型首次完整运行时，对工况 1 做一次事先声明的 A/B 比较（计入 / 不计入吹扫氮），按 CHARTER §2.2 的 7 个验收量与 Hamel 模拟值比较。若“不计入”在多数验收量上明显更接近 Hamel，则修订本 ADR。这一比较只用于在两种离散解释之间作选择，不得借机调整其它输入；比较的设置与结果须写入本 ADR。
6. 石灰石进料不在本 ADR 范围内（褐煤工况均为 0）。

## 附录：复算脚本

在仓库根目录执行（需已合并的 `data/digitized/fig_7_10.json`）：

```python
import json, itertools, math
d = json.load(open("data/digitized/fig_7_10.json"))
cases = {c["case_label_in_figure"]: c for c in d["cases"]}
err = d["est_error"]
# 表 7.2：燃料量 kg/h、含水量、一次风、二次风（m³(V_N)/h）；KURKELA_1992 Table 5：吹扫 N₂
K = {"1": (46.9, .118, 51.8, 30.1, 6.2), "2": (41.4, .117, 51.6, 37.5, 3.2),
     "3": (41.4, .119, 51.4, 46.5, 3.5), "4": (49.0, .118, 62.2, 42.8, 2.5)}
G = ["CO", "CO2", "H2", "CH4", "H2O"]

def n2(s, xc, mf, w):
    n_c = mf * (1 - w) * 0.638 / 12.011 * xc / 100
    return (1 - sum(s[g] for g in G)) * n_c / (s["CO"] + s["CO2"] + s["CH4"]) * 22.414

for k, (mf, w, pa, sa, pg) in K.items():
    c = cases[k]; s = {g: c[g][1] for g in G}; xc = c["X_C"][1]
    base = n2(s, xc, mf, w)
    full = [n2({g: s[g] + e * err[g] for g, e in zip(G, sg)}, xc + sx * err["X_C"], mf, w)
            for sg in itertools.product((-1, 1), repeat=5) for sx in (-1, 1)]
    var = 0.0
    for g in G:
        t = dict(s); t[g] += 1e-5
        var += ((n2(t, xc, mf, w) - base) / 1e-5 * err[g] / math.sqrt(3)) ** 2
    var += ((n2(s, xc + 1e-4, mf, w) - base) / 1e-4 * err["X_C"] / math.sqrt(3)) ** 2
    print(k, round(base, 2), round(min(full), 2), round(max(full), 2), round(math.sqrt(var), 2),
          round((pa + sa) * 0.79, 1), round((pa + sa) * 0.79 + pg, 1))
```
