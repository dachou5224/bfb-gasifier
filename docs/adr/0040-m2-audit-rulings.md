# M2 审计后续：验收量口径、床区 D_g、冻结范围与两项诊断的授权

> **状态：提议中。** M2 里程碑审计（2026-10-23，目标所有者开设的独立会话，基于 origin/main `ee27b79`）判 T26 暂缓派发，阻塞项为 1-1（T̄_FRB 与 X_C 的计算口径无 ADR 来源）与 1-2（床区 D_g 未按 ADR 0021 第 4 项逐格计算）。本 ADR 裁定这两项，并处理审计中须在 T26 前定下的 1-3、1-4、1-5、1-6、3-7。其余审计项写入 T26 任务卡。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 1. 验收量 T̄_FRB 与 X_C 的计算口径（审计 1-1）

**原文**：
- 符号表（PDF 008，S. XII）：T_FRB „mittlere Freiraumtemperatur“，K。
- Bild 7.10 图题（PDF 078）：„Vergleich von Messungen mit den Simulationsergebnissen für die mittlere Freiraumtemperatur und den Gesamtkohlenstoffumsatz“。
- §8（PDF 087，S. 155 附近）：Kurkela 与 Stahlberg (1992)、Leppälahti 与 Kurkela (1991) 只给出自由空间温度与床温而没有测点位置，因此“为了仍能比较”，选平均自由空间温度作比较量。同段定义总碳转化率为“随产品气离开的碳与加入的碳之比”，碳损失来自床区排灰和未被旋风分离、随气体带出的焦炭颗粒。
- 原文没有给出平均的权重。

**裁定（解释性选择，首次运行前冻结）**：
- **T̄_FRB** = Σ_i T_i·Δh_i ／ Σ_i Δh_i，对自由空间全部 cell（含锥段，ADR 0014 B）按高度加权，T_i 为 cell 的气体温度。依据：Hamel 选这一量正是因为测点高度未知，沿高度的平均不偏向任一测点；按高度加权与 cell 数无关，S16（cell 加倍）下口径不变。现行 8 个等高 cell 上它等于算术平均，与 `driver.py` 现有结果相同；实现须改为显式按 Δh 加权。不报告体积加权等其它口径，避免在看到结果后另选口径。
- **X_C** = 自由空间出口气体（含焦油蒸气）中的碳 ／ 加入燃料中的碳。分母只计燃料碳；分子不计带出焦炭与排灰中的碳。这与原文定义及 CHARTER §2.2 的“转化为干气加焦油的碳”一致；现行实现即此口径，本条只作登记。
- 两项列入 ADR 0030 冻结清单（F26、F27）。

## 2. 床区 D_g 与床区气体物性（审计 1-2）

ADR 0021 第 4 项规定 D_g 取式 (5.20) 在 **cell 气体温度** 与压力下的值。现行 `_bed_gas` 用床区按摩尔流量加权的平均温度求一个 D_g，全床共用；S5（Fuller）却逐格计算，S5 的差值因此同时改了公式和温度口径。

**裁定**：
- **D_g 逐格**：这是实现与 ADR 0021 不符，按 ADR 0013 第 6 条修正。各床格的 K_bd 用该格气体温度下的式 (5.20) D_g 计算，与 S5 的逐格写法同一结构；S5 只改公式，不改温度口径。注明 `实现修正：ADR 0021、ADR 0040`。
- **床区流体力学的气体物性**（ρ_g、μ_g、ν_g，用于 u_mf、气泡生长积分、ε_d 等）：沿用床区按摩尔流量加权的平均温度与组成计算的一组值。**解释性选择**：气泡直径沿床高连续积分（ADR 0036 整床加密），逐格换物性会在格界面引入不连续；床区接近等温。报告每次外层迭代床区各格气体温度与该平均温度的最大偏差。这一选择列入冻结清单（F28）。

## 3. 求解路径常数与冻结范围（审计 1-3、1-5、1-6）

- **1-3**：ADR 0020 的标量搜索参数现为 `precalc.py` 的模块常量，数值与 ADR 0020 一致。ADR 0020 由 cursor 随 T19 起草，PR #78 审查退回的 P2 即由它登记，随 PR #78 复审通过后合并，但 frontmatter 一直停在 proposed，批准记录漏登。**裁定**：本 PR 补登 ADR 0020 的批准（不改其数值），并修订其实现约束：允许以模块常量实现，注明 `求解器参数：ADR 0020`；不移入 `SolverConfig`（不增加字段）。
- **1-5**：登记两个只影响求解路径的常数（求解器参数，不进 `SolverConfig`）：
  - 一次风等效温度的二分：区间 200–2500 K，60 次；
  - 颗粒温度牛顿法差分的相对步长 1·10⁻⁶（ADR 0033 的补充）。
  实现注明 `求解器参数：ADR 0040`。
- **1-6**：ADR 0030 的冻结范围由“0001–0032”改为“截至 T26 派发时已批准的全部 ADR”。T26b 派发前，总司令核对 `docs/adr/` 中没有处于 proposed 的 ADR；有则先批准或撤回，不带未批准的参数运行。本 ADR 起草时，除本 ADR 外唯一未标批准的是 ADR 0020，由上一条处理。

## 4. ε_mf、φ_S 缺字段时不得回退（审计 1-4）

工况文件缺 `epsilon_mf` 或 `phi_s` 时现行代码静默回退到冻结值，S9–S12 写错键名会跑出基准结果。**裁定**：删去回退，缺字段即报错。这是实现修正（ADR 0024、ADR 0039），不改数值。

## 5. 两项诊断量的授权（审计 3-7）

ADR 0016、0030 要求报告“自由空间元素与质量闭合”与“数值积分与闭式的比对”；T25d 按 ADR 0039 第 3 项不得新算，留空。**授权**：

- **全自由空间闭合**：控制体为自由空间全部 cell 的全部相（气体、焦炭、灰、燃料 W 与 P）。控制体内的反应、热解释放、干燥、粒级迁移与灰释放都是相间或粒级间的转移，C、H、O 与总质量的净源为零，**不另加反应项**。用收敛后的单元解按下表记账，每股流只计一次：

  | 流 | 方向 | 位置 |
  |---|---|---|
  | 床区最上一格进入自由空间的气体 | 入 | 床面 |
  | 二次风（及其它进入自由空间的气体） | 入 | 侧面 |
  | 床面抛出的固体，F^ej,f 与 F^ej,t 全部 | 入 | 床面 |
  | 自由空间出口气体 | 出 | 出口 |
  | 普通带出固体（最上一格的 a·m，不含 C 的改送流） | 出 | 出口 |
  | 普通回落固体（最下一格的 b·m，不含 B 的改送流） | 出 | 床面 |
  | B 的改送流（ADR 0038 的四项，含 F^ej,t） | 出 | 床面 |
  | C 的改送流（ADR 0038 的四项，含 F^ej,t） | 出 | 出口 |

  B、C 下 F^ej,t 在入流中计一次、在改送出流中计一次，净为零，不另扣。A 下改送流为零。报告各元素与总质量的入流、出流、差值（kg/s）与相对差（分母为入流）。这是对收敛解的记账，不进入残差。测试须包括非零气固反应与 B、C 改送的构造例，不只用零反应基准。
- **数值积分与闭式的比对**：按 ADR 0016 第 11 条，闭式 (3.93)–(3.95) 只在常系数、Δ > 0 且相对速度分支不变的区间成立，只是单元测试基准。报告给出两部分：
  1. **固定构造基准**：沿用 T23 单元测试中 Δ > 0 的常气速构造参数，用本次运行的自由空间求解器参数（样本数、步长）积分，报告与闭式的最大相对偏差。
  2. **工况 1 条件下逐粒级的适用性**：预先固定输入——气体物性取收敛解中自由空间最下一格的温度、组成与压力；u_g 取该格的表观气速（常数）；初速取 ADR 0016 第 6 条床面抛出起始速度分布的中位数。逐粒级先算两个分支的 Δ 与所处分支：Δ ≤ 0 的粒级记 N/A 并写明 Δ 值，不改物性、不套用其它印刷闭式；Δ > 0 的粒级比较数值积分与闭式的 h(t)、u_P(t)，比较时段从 t = 0 起，到以下最早者截止：u_P = u_g（分支改变）、到达闭式实数域边界、到达自由空间出口或回到床面、ADR 0028 的时间上限。报告最大相对偏差（u_P 以 u_g 为尺度，h 以自由空间高度为尺度）。
  比对只在报告工具中执行，不参与求解，不设通过门，只报告。
- 两项的实现尽量放在 `tools/`；须读取 `hamel/` 中间量的部分才进 `hamel/`。

## 6. 颗粒温度数值参数的加密方案（审查补充，ADR 0033）

ADR 0033 只登记了默认值。首次运行的加密检查预先定为：在基准最终状态上，把 `particle_tolerance_w` 与 `coupling_tolerance_k` 各收紧到十分之一（1·10⁻⁵ W、1·10⁻⁴ K），`particle_max_iterations` 与 `coupling_max_iterations` 各加倍（50、32），重算残差。报告各 (cell, 粒级) 颗粒温度的最大变化（K）与重算残差的相对范数。门：颗粒温度变化 < 0,1 K（与 ADR 0012 第 2(a) 项的温度门同级），重算残差仍满足内层门 1·10⁻⁶。只报告，不据此改选。ADR 0016、0028（样本数、步长）与 ADR 0027（热解离散）沿用各自已登记的加密方案与门。

## 实现约束

- 第 1 项注明 `解释性选择：ADR 0040`；第 2 项见上；第 3 项各点见上；第 4 项注明 `实现修正：ADR 0024、ADR 0039、ADR 0040`。
- ADR 0030 补列 F26（T̄_FRB）、F27（X_C）、F28（床区流体力学气体物性），并按第 3 项修改冻结范围。
- 由 T26 任务卡的前置子项实现。

## 审查记录

- PR #107 审查：(1) 全自由空间闭合把 B、C 改送流列为入流，方向错误，且对整个控制体另加反应项会重复记账；(2) 闭式比对未处理 Δ ≤ 0 与分支变化，Δ > 0 并非常态；(3) T26b 把失败的中间运行也称为工况指标，与 ADR 0022 B 不符；(4) ADR 0020 仍为 proposed，不能声称 0001–0040 均已批准；(5) ADR 0033 的加密方案未预先登记。已修订：第 5 项改为逐股流的控制体账本、不加反应项，闭式比对改为固定构造基准加逐粒级适用性（Δ ≤ 0 记 N/A，预先固定物性、初速与截止条件）；第 3 项补登 ADR 0020 的批准并要求 T26b 派发前核对无 proposed ADR；新增第 6 项颗粒温度加密方案；T26b 只把满足 CHARTER §2.1 的结果计为工况指标。
