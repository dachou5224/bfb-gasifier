# 附录 A1：当前点已不满足式 (A.31) 时的一步阻尼

> **状态：已批准（2026-10-19）。** 编号为 0025：0023 已用于燃料粒级代表径（PR #85），0024 已用于床料空隙率与球形度（PR #88）。补充 ADR 0017 第 16 项，不改式 (A.26)、(A.34) 与收敛门。审查方为 codex。

## 问题

ADR 0017 第 16 项：每次迭代从 η = 0,5 开始，若式 (A.31) 对某个平衡组分不成立则减半，直到成立；减半 30 次仍不成立则失败。

式 (A.40) 用均匀摩尔分数解出的初始 λ，在第 1 关的温度下经常已经使若干平衡组分的指数大于 0。此时把 η 减向 0 只会更靠近这个不可行点，30 次减半必然失败，牛顿法进不了式 (A.31) 能够成立的区域。S. 167 只规定在 0 < η < 1 内选取使式 (A.31) 成立的 η，没有规定当前点本身已经越出该式时怎么走。

另外，残差与雅可比必须使用未截断的 exp(−c_j + Σ λ_k a_kj)。把指数截到有限区间会改掉式 (A.26)，CHARTER §5 不允许。

## 裁定

- 式 (A.26) 的残差、式 (A.28) 的雅可比和式 (A.34) 的收敛门都使用未截断指数。指数不是有限数，或使 exp 不能表示为有限浮点数时，平衡计算失败并报告，不截断。
- 若**当前** λ 已经不满足式 (A.31），本步取 η = 0,5，不减半。这一步不计入 30 次减半上限。
- 若当前 λ 已经满足式 (A.31），仍按 ADR 0017 第 16 项从 0,5 起减半；30 次后仍不成立则失败。
- 收敛门不变：未修改的式 (A.26) 全部各行与式 (A.34) 同时达到 1·10⁻¹⁰。

这是求解路径上的阻尼，不改残差。初值仍是 ADR 0017 第 16 项的均匀分布与式 (A.40)。
