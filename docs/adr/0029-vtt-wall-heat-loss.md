# VTT 壁面散热的计算形式（补齐 ADR 0014 X1）

> **状态：提议中。** ADR 0014 X1（目标所有者 2026-10-17 决定，CHARTER v0.11 §1 例外）规定取一个沿床区与自由空间相同的壁面传热系数，使模型的壁面总散热等于 KURKELA_1992 表 6 工况 1 的 21,7 kW，但没有写式 (2.7) 中 Q̇_W 的计算形式：外侧参考温度、各 cell 的散热面积、系数如何求得。本 ADR 补齐。外侧温度为目标所有者 2026-10-20 的决定。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 裁定

1. **形式**：Q̇_W,i = k_W·A_W,i·(T_i − T_amb)。k_W 为壁面传热系数（表 2.1 的 Wärmedurchgangskoeffizient der Reaktorwand），T_i 为 cell 温度（ADR 0017 第 5 项）。
2. **外侧参考温度**：T_amb = 298,15 K（目标所有者 2026-10-20：常规工程假设，对散热计算没有显著影响）。
3. **散热面积**：只计反应器侧壁内表面（式 2.7 的 Reaktorwand），不计布风板与顶部：
   - 床区各格（Ø 0,15 m）：A_W,i = π·0,15 m·Δh_i；
   - 锥段（自由空间第 1 格，Ø 0,15 → 0,25 m，ADR 0014 B）：A_W = π·(r₁ + r₂)·√(Δh² + (r₂ − r₁)²)，r₁ = 0,075 m、r₂ = 0,125 m、Δh = 0,2875 m；
   - 自由空间直筒各格（Ø 0,25 m）：A_W,i = π·0,25 m·Δh_i。
4. **系数的求法**：k_W 是外层量。每轮外层用当前单元解的温度求 k_W = 21 700 W / Σ_i A_W,i·(T_i − T_amb)，在牛顿内层保持不变（与 ADR 0009、ADR 0012 的分工一致）。外层收敛（ADR 0012 第 2(a) 项）时，壁面总散热与 21,7 kW 的相对差须小于 1·10⁻⁴，并在报告中给出。Σ_i A_W,i·(T_i − T_amb) ≤ 0 时报告并停止。
5. **范围**：21,7 kW 是 KURKELA 对整套装置做的能量平衡差额（as diff.），本 ADR 把它全部分配给反应器侧壁；连接管与旋风按 ADR 0014 X2、X2a 为不计传热的输运段，不另分配。
6. **换热面**：VTT 没有内置换热面，式 (2.7) 的 Q̇_WÜ,i = 0。
7. **绝热对照**：按 CHARTER v0.11 §1 第 3 条，另做 k_W = 0 的运行，在相同冻结设置下报告全部 7 个验收量及差值。

## 实现约束

- k_W 不进入 `PhysicalConfig` 的输入，作为外层计算量输出；`wall_heat_transfer_coefficient` 保持 missing（它是计算量，不是输入）。
- 21 700 W 由工况 1 的新字段 `wall_heat_loss`（单位 W，`cited`，KURKELA_1992 表 6 p. 18，note 写明 as diff. 与 ADR 0014 X1、ADR 0029）给出，本 PR 一并录入；其它工况保持 missing（CHARTER v0.11 §1 例外第 4 条，不外推）。
- 注明 `章程 v0.11 §1 例外；ADR 0014 X1；ADR 0029`。
