# 初值构造：固相、排灰与床区向下流联立牛顿求解（取代 ADR 0045 第 3 项的块顺序求解与 ADR 0049 的预启动）

> **状态：提议中。** 目标所有者 2026-10-31 同意起草。本 ADR 只改初值构造的求解路径，属求解手段（CHARTER §5），不改方程、闭合、收敛门与冻结值的定义。按 CHARTER v0.10 §8，审查方审查后由总司令批准，目标所有者可否决。

## 依据

- **三次停止同一根源**：T26g（负存量，PR #130）、T26j（闭合 A 超域，PR #133，已由 ADR 0051 处理）、T26k（排灰余额为负，PR #137）。研究底稿 `docs/research/initial-solids-drain.md` 表明，T26g 与 T26k 的停止都来自同一处不一致：初值构造中，床区整体向下流 Ṁ_ab（ADR 0009 第 2 项递推）与排灰（ADR 0014 A5）按预计算时的状态冻结，而该状态的自由空间回落为零、床区反应汇为零；固相块随后在这些冻结量下求解，回落进床顶的焦炭在向下流中没有对应的量。
- **诊断**（工况 1，初值气相，`tools/initial_solids_diagnostic.py`，只作诊断；诊断用最大范数与回溯，迭代中暂停有效域与可行检查，与第 1 项的正式写法不同）：固定气相与温度，对全部固相做牛顿迭代，每次评价残差时按当前状态重算排灰（A5）与 Ṁ_ab（ADR 0009 递推，回落取当前自由空间最下格的自由存量、反应汇取当前床区焦炭消耗）：
  - 1073 K：6 次迭代收敛；床区焦炭 3,46 kg（床层质量 3,96 kg），各床格惰性物约 0,058 kg 均为正；排灰中灰 0,197 g/s、焦炭 1,46 g/s；带出灰 0,29 g/s（燃料带入 0,49 g/s）；最大体积比 0,068。
  - 1123 K：6 次迭代收敛，各项同样可行。
  - 对照：只重算排灰、Ṁ_ab 用预计算冻结值时，同一温度下牛顿也收敛，但床区焦炭 5,89 kg，上部四个床格惰性物为负（最上一格 −1,68 kg）。
  - 一致的 Ṁ_ab 约 0,75 kg/s，冻结值约 0,48 kg/s；差值即回落 0,27 kg/s，与 T26g 报告的“伪净上行 0,265 kg/s”相同。
- ADR 0049 第 4 步试图以“预启动后重做预计算”修正这一不一致，但重做预计算要求中间状态可行（惰性物非负、排灰余额非负），而中间状态正因这一不一致而不可行。

## 裁定（求解手段）

### 1. 初值构造的固相求解

ADR 0045 第 3 项第 1、2 步（起点与第一次预计算）不变。其后改为：

1. **固相子系统**：固定气相、温度，以及除下列两项之外的全部冻结量，以全部固相未知量（床区焦炭；自由空间各状态的焦炭与灰）为未知量，求原残差的固相行为零。
2. **随状态重算的两项**（每次评价残差时）：
   - 排灰按 ADR 0014 A5：灰分量 = 燃料带入灰 − 带出灰（按当前自由空间最上格的自由灰存量与 a^f）− 随未转化燃料离开的灰；总流率按当前最底床格的灰质量分数；排出的焦炭按该格焦炭组成；
   - 床区整体向下流 Ṁ_ab 按 ADR 0009 第 2 项递推：上行流取冻结的 k_auf·M_i；回落取当前自由空间最下格的自由焦炭与灰存量乘 b^f，再加冻结的燃料回落；反应汇取当前床区焦炭消耗；排灰取上式。
   这两项与预计算中的写法相同，只是输入取当前状态，不另立公式。
3. **求解**：牛顿法。差分步长与行列缩放按 ADR 0043；阻尼按 ADR 0017 第 7 项（固相行归一残差的欧氏范数严格下降，i ≤ 30），可行条件沿用该项（存量非负、各床格 m_inert ≥ 0、残差有限），另加排灰灰分量非负；迭代上限取 ADR 0017 第 8 项的 ν_max。Ṁ_ab 与排灰使固相行出现非相邻依赖（自由空间最上、最下格与全部床格），本子系统的雅可比逐列差分，不按 ADR 0046 分组。
4. **收敛**：固相行满足 ADR 0012 第 1 项的固相门。
5. **交替**：以收敛的固相（连同按 `driver.solid_feedback` 回馈的床区反应汇、排灰、燃料回落与改送）重做预计算，回到第 1 步；两次之间床区界面上下行流与自由空间回落的相对变化都小于 1·10⁻²，或做满 5 次时停止（ADR 0045 第 3 项第 5 步的判据与次数不变）。
6. 第一次外层以构造的状态作为上一轮单元解（ADR 0045 不变）。

### 2. 撤销

- ADR 0045 第 3 项第 3 步（焦炭块 → 床区灰分配 → 自由空间灰块的块顺序线性求解与回代检查）；
- ADR 0049 全部（预启动、分阶段回代门、预启动后的重做预计算）。

### 3. 停止条件（取代 ADR 0045 第 4 项与 ADR 0049 的停止条件）

以下任一情形停止并报告，不截断、不绕过：

- 牛顿阻尼失败（ADR 0017 第 7 项，i 到 30 仍无可行且下降的试探点）或迭代数超过 ν_max；
- 收敛解上任一存量为负、任一床格惰性物为负、排灰灰分量为负，或最底床格灰分为零；
- 有效域拒绝（ADR 0026 第 5 项）：迭代中的试探点按不可行处理（缩步）；收敛解超域时停止，报告格、各状态存量、体积比与上限；
- 预计算报错。

### 4. 不变的部分

方程、闭合、冻结值的定义、ADR 0014 A5 与 ADR 0009 第 2 项的写法、ADR 0012 收敛门、主求解的内层与外层规则（主求解中 Ṁ_ab 与排灰仍由预计算冻结，每轮外层更新）。

## 已知情形（报告，不在本 ADR 处理）

- 1173 K 诊断中牛顿停在 |r|/ṁ_ref ≈ 1,09 不再下降（未收敛）。初值构造只在 T_init 下进行，本 ADR 不处理其它温度；若 T_init 下出现同类停滞，按第 3 项停止。
- ADR 0009 递推的最底格整体固体闭合差约 7,7·10⁻³ kg/s（1073 K 诊断）：递推把燃料加入整体计为固体，未扣热解与干燥释放的气体。按 ADR 0017 第 13 项报告；是否修改递推口径另行裁定。

## 实现约束

- 注明 `求解手段：ADR 0052`；ADR 0045 第 3、4 项与 ADR 0049 加补注指向本 ADR。
- 排灰与 Ṁ_ab 的重算复用预计算中的同一函数（`precalc._drain` 的余额式与 `precalc.bed_downflow`），不复制公式；预计算中的写法不变。
- 测试：
  - 小例子上，Ṁ_ab 与排灰按状态重算后，床区整体固体在各格守恒，递推结果与预计算在同一状态下的结果逐位相同；
  - 构造“冻结 Ṁ_ab 时床格惰性物为负、按状态重算后为正”的小例子；
  - 可行条件：试探点惰性物为负或排灰灰分量为负时缩步；收敛解违反第 3 项任一条时停止并报告；
  - 交替终止判据与次数；
  - 删除 ADR 0049 的预启动与分阶段回代门后，原相关测试改写或删除，在 PR 中逐一说明。
- 报告：每次交替的牛顿迭代数与残差历史、床区焦炭与各格惰性物、排灰（灰、焦炭）、带出灰、回落、Ṁ_ab（重算值与预计算冻结值）、递推最底格闭合差、自由空间各格体积比与悬停存量。
- 由 T26l 实现。
