# 正值未知量取对数作牛顿变量，差分步长逐列放大到可分辨

> **状态：提议中。** ADR 0041 的验证（T26d，PR #114，`reports/t26d-validation/`）按其停止条件停下。本 ADR 依据该验证修改 ADR 0041，只改求解手段，不改方程、残差、阻尼规则、收敛门与冻结值（CHARTER §5）。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 证据（T26d 验证）

ADR 0041 的相对步长 √ε·|x_n| 修好了一类问题，又出现两项观测：

- **修好的**：在 T26c 的基准失败点，牛顿方向在 h = 10⁻⁶…10⁻¹² 上都使归一残差下降；方向导数与差分的相对差由 4–5 降到 1,5·10⁻²。悬停焦炭列（x = 1,4·10⁻¹¹ kg）的旧差分列与新列相差 4,2·10³ 倍，旧列确是割线。
- **观测一，步长小到不可分辨**：在工况 1 的初值点，9 列恰好为零——自由空间 8 格的 C₁₀H₈（1,7–2,5·10⁻²⁰ mol/s）与床顶悬浮相 O₂（1,6·10⁻²³ mol/s）——因为 F(x + √ε·|x|) 与 F(x) 在浮点上相同。雅可比奇异，第 1 轮内层第 1 次迭代即停止（NOT_CONVERGED：雅可比不能求解）。
- **观测二，失败点的可行步长受限**：在失败点按新规则做的单步方向探针中，牛顿步范数 9,4·10³，h ≥ 10⁻⁵ 的试探点都使焦炭、灰存量变负；可行的 h 只到 10⁻⁶，g 只从 12,11167 降到 12,11166。这只是一个点上的单步探针，没有在新规则下连续迭代，不能据此断定 ν_max 次迭代内不可能收敛，也不能排除雅可比误差或病态性对大步的影响；它提示推进可能很慢，且受限的原因之一是试探点把接近零的存量推过零。对正值变量取对数正是为了避免负值试探；是否因此能够收敛，由下面的验证回答。

## 裁定（求解手段）

### 1. 正值未知量用对数作牛顿变量

- 牛顿迭代中，**物理上非负、当前值为正**的未知量——各相各组分的气体流量、焦炭与灰存量（自由、悬停与床区）——以 y_n = ln x_n 作迭代变量；温度与其它未知量不变。值恰为 0 的未知量（初值或迭代中为 0）保持线性变量，不取对数。
- 残差 F、归一范数、收敛门不变：仍在 x = exp(y) 处评价同一个 F(x)。雅可比按链式法则 J_y = J_x·diag(x_n)（对数变量所在列），或直接对 y 作差分；两者等价，由实现选一种并在 PR 中写明。
- 阻尼规则不变（Wirsum 第 4、5 步，ADR 0017 第 7 项）：试探点为 y + Δy/2ⁱ。对数变量在任何步长下都保持为正，ADR 0017 第 7 项中“存量与流量 ≥ 0”对这些变量自动满足；其余可行条件照常检查。
- 依据：这是未知量的重新参数化，F(x) = 0 的解集不变（对正值分量一一对应），不改方程；牛顿步在这些变量上按相对量级移动，试探点不会把它们推过零。这一改动能否解决收敛问题尚未证实，由验证回答。

### 2. 差分步长逐列放大到可分辨（修改 ADR 0041 第 1 项）

对第 n 列（线性变量取 x_n，对数变量取 y_n）：

- 起始步长：线性变量按 ADR 0041（x_n ≠ 0 时 √ε·|x_n|，x_n = 0 时 √ε·s_n）；对数变量取 √ε（即 x_n 的相对变化 √ε）。
- 若该列差分 ΔF 的归一范数（ADR 0012 参考流）不大于 ε_mach·‖F‖ 的归一范数——即在浮点上不可分辨——把步长乘以 10²，重算该列；最多放大 4 次（总共 10⁸ 倍）。
- 线性变量的步长不超过 ADR 0017 第 6 项的旧步长 √ε·max(|x_n|, s_n)；对数变量的步长不超过 1（x_n 变化 e 倍）。到上限仍不可分辨的列按上限步长的差分取值，并在诊断记录中列出（列名、x_n、最终步长）。
- 差分点仍须满足可行条件。

### 3. 线性求解的缩放

ADR 0041 第 2 项保留：行缩放 R 用 ADR 0012 参考流；列缩放 C 对线性变量取 max(|x_n|, s_n·[x_n = 0])，对数变量取 1。

## 验证（实现后、重跑之前，只报告；预先登记判据）

在 T26c 保存的基准失败点与工况 1 的初值点做：

1. 失败点：方向检查（h = 10⁻¹…10⁻¹²）、可行的最大 h、g 的下降量；
2. 初值点：雅可比是否奇异（最小奇异值与条件数）、被放大的列及其最终步长；
3. 从初值运行基准外层第 1 轮的内层牛顿，带 T26c 诊断记录。

**通过判据**：第 3 项中第 1 轮内层以 CONVERGED 终止。不通过时停止，不重跑，报告结果；不在本 ADR 范围内另试其它手段。

## 实现约束

- 注明 `求解手段：ADR 0042`；ADR 0041 第 1 项由本 ADR 第 2 项取代，第 2 项保留。
- 对数变换只在 `hamel/solver/newton.py`（或其调用处）的迭代变量层实现，不改 `residual.py` 与冻结量。
- ADR 0030 冻结清单的数值手段来源补列 ADR 0042。
- 由 T26e 实现与验证；验证通过后，按 T26b 的规则重跑全部 17 次运行。
