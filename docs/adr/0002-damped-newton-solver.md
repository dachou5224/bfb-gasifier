# 全局求解器采用 Hamel 所述的阻尼 Newton–Raphson，Wirsum（1998）在求解器与能量流写法上属于“Hamel 引用的文献”

Hamel §2.3 写明：cell 模型的衡算方程组是非线性方程组，求解基于 Wozny（1983）的 Newton–Raphson 算法；cell 沿主流方向一维排列，使雅可比矩阵呈块三对角结构，非相邻 cell 之间的物流（如旋风回料）产生块外元素；为改善初值远离解时的收敛性，采用 Wirsum（1998）的“阻尼”Newton 变体，详细描述见 Wirsum（1998）（PDF 20 / S. 20，Eq. 2.9）。Eq. 2.8 物流携带能量的写法同样引用 Wirsum 1998（PDF 19 / S. 19）。

因此，按 CHARTER §4.2，Wirsum 的博士论文（本地文件题为 1997 年 VDI-Dis.，Hamel 引作 1998）可以作为“Hamel 引用的文献”，用于阻尼 Newton 的具体做法与 Eq. 2.8 的能量流写法，引用时须同时给出 Hamel 的出处（§2.3 或 Eq. 2.8）。超出这两处的 Wirsum 内容（例如其污泥燃烧专用的子模型、两区或其它离散方式）不在许可范围内，需按 §4.3 另行批准。

这条也说明归档中 Wirsum 线的起点有据可依；偏离在于另建了一个不经 cell 模型的两区核，而不在于引用 Wirsum。

Hamel 还写明，初值可以按用户设定新生成，也可以取自之前的模拟结果（PDF 16 / S. 12）。这与 CHARTER §5 允许的求解路径辅助手段（初值构造、延拓）一致。
