# 自由空间轨迹的样本数、步长与时间上限

> **状态：已批准（2026-10-20）。** 编号为 0028。0025 已用于平衡初值的一步阻尼，0026 已用于悬停闭合，0027 已用于热解离散。本 ADR 登记三个 `SolverConfig` 字段，并把平均泡间距取为式 (3.57)。不改式 (3.66)、(3.67) 的其余因子，也不登记邻域 δ。审查方为 codex。

## 问题

抛出初速要离散成样本，运动方程要按步积分。样本数、步长和时间上限原文没有。ADR 0016 第 6、11 条把它们定为求解器参数。

悬停归宿、捕获区和 a^f、a^t、b^f、b^t 按 ADR 0026 第 2、3 项。把这些和抛出、气速、轨迹积分放进同一个 `hamel/freeboard/` 时，模块约 1 300 行，超过任务卡的 800 行停止条件。本卡因此只交抛出、初速、气速和轨迹积分。δ_h、δ_u 以及系数上的两组加密，留到下一张卡再登记。

S. 38 把两种平均泡间距并列：式 (3.57) 假定气泡均匀分布在整个床截面上；式 (3.58) 按 Baron 的气泡轨道，只计入被穿过的截面，分母多一个 α_t，而 α_t 要用 h_WS 和 A_0。冻结稿写明正文没有选定。ADR 0016 第 1–4 条裁定了 C、48°、σ 和 n_B = 5，没有选间距式。抛出通量一旦算出，F₀ 就进床面固体流，这一选择不是步长之类的数值参数。

## 裁定

平均泡间距取式 (3.57)，Δl_m / d_b = (6 ε_b / π)^{−1/3}。解释性选择：本卡的床面气泡量只有 ε_b、u_b、d_b，没有轨道份额 α_t 所需的 h_WS 和 A_0；在没有轨道数据时按 S. 38 的均匀截面假设。适用范围是 `hamel/freeboard/` 的抛出质量流。式 (3.58) 不在这条路径里实现。以后若要改用轨道修正，另写 ADR，不在代码里加开关。

## 求解器参数

`SolverConfig` 增加下列字段。`assemble_case` 使用 `SolverConfig()`，因此默认值就是本 ADR 的取值。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `freeboard_ejection_samples` | 48 | 正半轴等概率份数。代表点取该份的概率中位。u_P,0 ≤ 0 的份额用分布函数计入直接回落，不占这些样本 |
| `freeboard_max_step_s` | 2·10⁻⁴ s | 式 (3.82) 的步长上限。速度变号时把该步减半，格边界上提前停步 |
| `freeboard_time_limit_s` | 80 s | 只用于报错。到时粒子还没回到床面或飞出顶部，积分失败，不改判成回落或带出 |

积分把 Stokes 项做成精确的线性步，二次项和当地气速在步两端作预测－校正。步长趋于 0 时回到式 (3.82)。闭式 (3.93)–(3.95) 只用来对照常气速、Δ > 0 的短时积分。

加密，在气速比终端速度高 3 m/s、粒子从床面飞出 1 m 自由空间的情形下：

- 步长从 2·10⁻⁴ s 减半，飞出时间的相对变化为 6,8·10⁻⁸，出口速度的相对变化为 9,8·10⁻¹⁰。
- 样本数从 48 增到 96，份额加权的平均飞行时间相对变化为 4,2·10⁻⁵。

两处都小于 1·10⁻⁴。这是轨迹时间的检查，不是 a^f、a^t、b^f、b^t 的检查。

边界上速度恰好为零时，用该点的加速度判断是否正在离开。加速度向外，归宿时刻就是当前时刻，位置留在边界上，不先走一步到域外。加速度向内才进入相邻格，物性用所进入格的值。加速度为零则留在原地，直到时间上限报错，不把静止都判成离开。格面两侧加速度都指向对面时，进入哪一格没有定义，积分失败。
