# 床料的 ε_mf、φ_S、u_mf,0（阻塞项 X6）与 Geldart 分类的对接

> **状态：已批准（2026-10-19）。** 本 ADR 闭合 ADR 0022 C7 登记的阻塞项 X6，并裁定 Geldart (1973) 判据（ADR 0022 A2 批准引入）与本模型的对接。依据为 T28 原文答卷（`refs/hamel/answers/T28-bed-material-params.md`，PR #87）、Hamel 原文与已批准的 ADR。按 CHARTER v0.10 §8，审查方审查后批准，目标所有者可否决。

## 背景

- T28：Hamel 对 VTT、HTW 的褐煤焦炭床料没有给出 ε_mf、φ_S、u_mf,0、床料密度与粒径；全书没有任何工况的 u_mf,0 测量值。
- 式 (3.3)（S. 22）由环境条件下测得的 u_mf,0 反求 φ_S·d̄_P，式 (3.4) 再“mit bekannter Sphärizität”求操作条件下的 u_mf。式 (3.1)、(3.4) 与相间交换式 (3.47)–(3.50) 都用 ε_mf。
- 书中出现的数值：
  - S. 45（§3.2.4）：„Der entsprechende Mittelwert der Sphärizität ist eine Eingabegröße des Simulationsprogramms, sind keine Angaben bekannt, wird den Berechnungen eine mittlere Sphärizität von φ̄_S = 0,8 zugrundegelegt.“
  - Bild 3.6（S. 35）图内计算条件：ε_mf = 0,46、φ_S = 0,8（d_P = 0,7 mm、ρ_P = 2600 kg/m³、298,15 K）。物料未命名。

## 裁定

### 1. φ_S = 0,8（解释性选择，依据较强）

S. 45 写明：平均球形度是**模拟程序的输入**，没有数据时取 0,8。这句话描述的是 Hamel 程序的默认值，而不是某张图的条件；符号表把 φ̄_S 定义为“mittlere Sphärizität”。第 7 章的褐煤焦炭床料没有球形度数据，正属于“keine Angaben bekannt”的情形。**裁定**：床料的 φ_S 取 0,8，用于式 (3.1)–(3.4)，与自由空间轨迹（ADR 0016）使用同一个值。T28 记录的另一读法（0,8 只进入自由空间轨迹）不采用：同一程序对同一物料用两个球形度没有原文依据。

### 2. 不走式 (3.3)，u_mf,0 不需要

式 (3.3) 的唯一作用是由测得的 u_mf,0 反求 φ_S（S. 22）。φ_S 已由第 1 项给定，原文的下一步“mit bekannter Sphärizität”就是式 (3.4)。**裁定**：u_mf 由式 (3.4) 直接计算，式 (3.3) 不进入第 1 关的计算，u_mf,0 不再是需要的输入。式 (3.5) 的常数 C₁、C₂ 路线不采用（Hamel 在同页写 Ergun 式结果最好，且常数路线会消去球形度与空隙率的影响）。

### 3. ε_mf = 0,46（解释性选择）

Hamel 没有给出工况的 ε_mf。书中唯一与 φ_S = 0,8 成对出现的 ε_mf 是 Bild 3.6 的 0,46。**裁定**：床料的 ε_mf 取 0,46，各 cell 相同，不随温度、压力变化（原文没有这种依赖）。这是按 Hamel 自己成对使用的数值取值，不是 VTT 床料的测量值。

**敏感性（只报告，不据此改选，ADR 0013）**：ADR 0022 C6 要求给出 ε_mf、φ_S 同时变化时 ρ_P 的上下界及其对 7 个验收量的影响。首次运行报告按 ε_mf ∈ {0,40; 0,55} × φ_S ∈ {0,6; 0,9} 的 4 个角点另做 4 次运行，给出 ρ_P（ADR 0014 A4）、u_mf、K_bd、Geldart 判类（第 4 项）与 7 个验收量相对基准（0,46; 0,8）的差值。这两个区间沿用 T27 预检的临时扫描范围，只是预先登记的敏感性幅度，不是对褐煤焦炭实际空隙率、球形度的估计；S. 45 的 0,3 ≤ φ_S ≤ 1,0 描述的是自由空间轨迹中颗粒形状的分布，与这里的床料平均球形度扰动不是同一件事。角点运行中 φ_S 同时用于床区与自由空间（与第 1 项一致）。

### 4. Geldart 分类的对接

ADR 0011 第 8、9 条以 Geldart 类别限定式 (3.11)、(3.14)、(3.16) 的适用范围（T19 已按类别分式检查）。T28 指出三处口径差异，裁定如下：

1. **粒径**：Geldart 的判据用表面/体积平均径 d̄_sv = 1/Σ(x_k/d_sv,k)（p. 288），其中各粒级的 d_sv 是表面/体积直径（与颗粒体积/表面积之比相同的球的直径），不是筛孔尺寸或体积当量直径。本模型的粒级粒径 d_k 按球计算颗粒体积与颗粒数（ADR 0017 第 19 项：N_k = m_k/(ρ_P·π d_k³/6)；ADR 0023：筛孔尺寸按球径计），即 d_k 是体积当量直径。按球形度的定义（S. 44：等体积球的表面积与颗粒实际表面积之比），表面/体积直径 d_sv = 6V/S = φ_S·d_v。**裁定**：
   - 各粒级 d_sv,k = φ_S·d_k，φ_S 取第 1 项的 0,8；
   - 分类用 d̄_sv = 1/Σ(x_k/d_sv,k)，x_k 与 d_k 取床区焦炭（含灰）各粒级的质量分数与粒径（与 d̄_P 同一套存量，外层更新）；
   - 式 (3.1)–(3.4) 仍用 d̄_P（式 3.3、3.4 中以 φ_S·d̄_P 的乘积出现，与 d_sv = φ_S·d_v 的结构一致）。两者各按各自原文的定义，不互相替代。
2. **密度**：Geldart 的 ρ_s 是含内孔的颗粒密度（Geldart 符号表，T28 第 17 节），与 ADR 0014 A4 的 ρ_P（由压降确定的床料颗粒密度）是同一类量。**裁定**：ρ_s = ρ_P，ρ_f 取 cell 的气体密度；单位按 Geldart 换成 g/cm³ 与 μm 后代入式 (6)、(8)。
3. **压力**：式 (6)、(8) 的常数对应空气、室温、常压；Geldart p. 291 只定性写压力升高使 A/B 界右移，没有给出新常数。**裁定**：照印刷式 (6)、(8) 判类，不修正常数，在报告中注明这是常压判据。式 (6) 的不等号按印刷取 ≤，式 (8) 取 ≥（T28 已核对页面图像）。
4. **结果的用途**：判为 B 类，则 ADR 0011 第 8、9 条的式子适用；判为 D 类，式 (3.11) 仍适用，但式 (3.14)、(3.16) 的 ψ_b、υ_b 没有定义（ADR 0011 第 9 条），T19 按设计报错，第 1 关停止并上报；判为 A 或 C 类，同样报错上报。不因类别结果改写任何式子。

**风险提示**：用 T27 的 ρ_P 区间（约 910–1380 kg/m³）估算，(ρ_s − ρ_f)·(d′)² = 10⁶ 对应的 d̄_sv 约 0,85–1,05 mm，换成体积当量粒径（除以 φ_S = 0,8）约 1,06–1,31 mm；床区焦炭若落在这一带，B/D 的判定处在边界附近。床区粒径由外层迭代决定，事先无法确定。首次运行报告须给出各外层迭代的 d_sv、类别及与式 (8) 界线的距离。

## 实现约束

- `data/cases/vtt_pressurized.json` 增加床料的 `bed_minimum_fluidization_voidage`（0,46）与 `bed_sphericity`（0,8），`derived`，source 引 ADR 0024 与 Hamel S. 35、S. 45；由数据录入完成（可并入 T25 的装配，或单独一张小卡）。
- Geldart 判类写成 `hamel/hydrodynamics/` 中的一个函数，按第 4 项实现；分界式只用 Geldart 式 (6)、(8)，不数字化 Fig. 3 的 A/C 阴影：判为 A 或 C 时一律报错上报（第 4 项第 4 点），不需要区分二者。
- 第 1–3 项注明 `解释性选择：ADR 0024`；第 4 项注明 `ADR 0024`。

## 审查记录

- PR #88 审查：指出 (1) 敏感性只扰动 ε_mf，未满足 ADR 0022 C6 对 φ_S 的要求；(2) Geldart 的 d_sv 是表面/体积直径，不能直接用模型的粒级粒径取调和平均。已修订：敏感性改为 ε_mf × φ_S 的 4 个角点，写明区间性质并区分 S. 45 的形状分布；各粒级 d_sv,k = φ_S·d_k（由球形度定义推出，d_k 为体积当量直径），再取调和平均；风险提示的界线换算同步。
- **2026-10-19：总司令批准**（CHARTER v0.10 §8，目标所有者可否决）。审查方复审通过（PR #88）。阻塞项 X6 由本 ADR 闭合。
