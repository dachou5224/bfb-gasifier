## 3. 每轮的闭环

```text
选择一个有证据的假设
    ↓
检查是否已有失败样例；有则重放，没有则先做构造测试
    ↓
独立推导预期结果 + 文献/量纲/结构恒等式
    ↓
得到最小复现
    ├─ 未违反规格 → 标为排除或有依据近似，不改方程
    ├─ 规格有歧义 → 标为未闭合，保留分歧与影响，不私自选新模型
    └─ 确认错误 → 写失败测试 → 最小修复 → 单元/耦合回归
                                              ↓
                              历史状态冷评估 → 固定参数重新求根与认证
                                              ↓
                       成功后才允许扩展；失败按证据分类，不无限续预算
```

“求解慢”不是修改方程的证据；“改后收敛快”也不是修复正确的证据。每个修复必须附以下四件：规格依据、最小复现、失败测试、修改后独立验证。

每轮只改一个主要机制。比较时锁定输入、目标参数、初值和预算。不把方程改动与温度半径、ds、优化器或容差改动混在一起。

## 4. 第一轮具体审计队列

先审计 H1–H3；它们不要求先运行新的长求解。按“确认错误 / 有依据近似 / 排除 / 未闭合”裁定，不能预设一定有错。

### H1：同相浓度、分压、体积流量、密度的物种集合是否一致

检查 `_conc_major`、`c_tar_components`、P2 `ideal_gas_hydro`，追踪 R10/R11 与其他反应最终收到的输入。

当前主气体分母不含焦油，焦油分母含焦油；水力也只取主气体。s=0.418 悬浮相焦油占比约 0.129%，数值较小，不预设为慢收敛主因。

已有 `tests/test_wirsum_1997_named_f_p1.py::test_tar_dilute_shared_slot_vs_strict_eos` 明确记录旧 stage 6 的稀组分近似。它不能自动证明当前 stage 11 两相/两区版本正确，也不能被直接删除。

工作：建立每相物种集合表；核查 Hamel 对浓度、气速、密度及焦油代表物的定义；测试零焦油极限及非零焦油时的 EOS/分压一致性。若论文允许近似，量化误差并保留；若确认组装漏项，统一所有受影响消费者，而非只改一个分母。先列影响清单再改代码。

### H2：自由空间反应后，旋风回料的粒级组成是否仍沿用旧值

检查 `coupled_f_two_bin_pyro.edges_from_x`、`species_block_residual`、`char_face_flows_kg_s`。

构造两档炭都有离开流、自由空间消耗比例不同、旋风回料非零的合法状态。依据同一混合池/分离假设独立算出进入旋风和返回床层的粒级比例。检验总量和逐粒级账；仅验证总碳守恒不够。

当前 s=0.418 离开流为零，不能用该点“测试通过”来排除此问题。若旋风有明确的粒径选择性，按原模型的分离关系计算预期，不能强行要求回料组成等于入口。

### H3：自由空间库存与路径消耗分摊是否相容

检查 `fb_char_balance`、`path_char_consumption_kg_s`、`char_face_flows_kg_s` 和轨迹时间权重定义。

先明确 tau_return/tau_leave 是条件平均时间还是 w*t 加权和，避免重复乘概率。构造全回落、全离开、两路径共存且时间差较大的状态，检查：

- 无反应时库存和边流的解析极限；
- 有反应时抛出 = 回落 + 离开 + 消耗，在适用的稳态关系下成立；
- 合法稳态下每条路径边流非负；
- 床层失去/得到与自由空间得到/失去的流量及焓等大反号。

不要对任意非稳态试探库存强加稳态关系。区分“试探状态残差较大”与“模型允许的稳态仍有负出口”。若现有集总封闭与原文不同，记录其来源和有效范围；不能未经裁定改成另一种轨迹存活积分模型，更不能用 max(flow,0) 修补。

## 5. 第二轮起：由真实异常选下一假设

H1–H3 裁定后，若没有解释当前性能的问题，固定目标 s=0.410，使用已保存的同一预测初值做一次带完整记录的重放。不要从较远的旧 s=0.48 失败点启动。

按异常选择一个分支：

| 现象 | 下一项独立检查 |
|---|---|
| 某反应源异常大 | 单位、分压/浓度、相别、温度、体积/面积是否重乘 |
| 某块反复接近门限且拖慢其他块 | 分解其流入流出和各反应；检查符号、回路、重复源及保护约束活动 |
| 实际下降远小于预测，且绝对误差仍明显超门 | 当前实际 Jv 对完整 P(x) 的方向差商 |
| 温度边界持续活动，但结构检查通过 | 才做温度半径单因素对照，保持差商扰动不变 |
| 子问题求解失败 | 先排除 NaN、尺度或约束实现问题，不据此改物理方程 |
| 更换几乎相同的状态却出现残差跳变 | 重复求值、调用顺序、缓存失效、轨迹分支/截断、原文规定的分段点 |

Jv 比较必须使用同一实际迭代点、同一求解坐标下的实际方向；若用对数/焦油总量与比例坐标，就通过相同状态解包计算差商。按门尺度分块比较，用至少两个有效扰动尺度检查稳定性，微量正氧不能用大绝对扰动，也不能被裁到零。完整水力与冻结水力的差本身不是当前 J 的误差。

优先复核当前最昂贵的机制，不重读所有方程或批量新增与问题无关的测试。

分三层验收：

1. 单元：反应计量、单位转换、积分因子、传入相和温度。
2. 结构：任意合法状态下应成立的元素/内部流/分区能量恒等式，以及明确假设下的解析极限。
3. 求解：相同目标与初值，完整 P/F 和外部账联合认证，报告成本。

方程修复后旧根可能不再是根，这是正常结果。先保存旧状态在新 F 下的残差变化，分析变化是否落在预计行；然后在相同 s 重新求解并认证。不得要求新根等于旧根，也不得继续把旧状态称为新模型认证点。

至少重新认证受改动影响的最新点和一个代表性早期点；其余保存状态先冷评估，按影响范围决定是否重求。若预算不足，把状态标为未重新认证，不伪造通过。物理上有证据的修复不能只因为变慢就撤销以保住旧根；应保留清楚的修复记录并报告新的数值瓶颈。

## 7. 本次执行预算与恢复条件

- 本次最多 3 个“假设—审计—修复/排除”迭代；H1–H3 的轻量初筛可以合并，但每项因果修改分开验证。
- 所有耦合求解合计最多 6 次，每次最多 60 s；预测、校正、认证均计入该次预算。耗尽后不自动开启等价重试。
- 小型结构测试不算耦合求解次数，但单项不得用大范围参数扫描替代分析。保留已完成结果，预算不足时明确未做项。
- 经方程修改后，必须完成受影响状态的重新认证，才能恢复新参数推进。
- 没有未闭合的、影响当前路径的重大方程疑点，且至少一个慢点重放通过后，允许从最新重新认证状态最多增加 2 个参数点，累计预算最多 120 s，并包含在上述 6 次总预算内。
- 新参数失败回滚最近认证点，保存完整 trial；不自动连续减小 ds 凑通过数。是否缩小一次必须先由预测/校正记录说明原因，并仍计入预算。
- 发现外部资料缺口，不将整项任务停在索要资料上：标记未闭合，继续可独立执行的检查。触及内禀速率修改等禁止范围时，单独提交具体证据和所需决定。

性能评价采用通过认证的净参数推进/总耗时、每点 F/J/P 成本、拒步及预算耗尽次数。不能仅以测试数量、修改数量或同伦步数证明成功。
