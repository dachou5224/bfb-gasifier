Step 1 · 核心优化目标
最小化总吉布斯自由焓
G = Σⱼ μⱼ nⱼ → min 约束（元素守恒）： Σⱼ aᵢⱼ nⱼ − bᵢ = 0 (i = 1..N_E)
nⱼ 组分 j 的摩尔量（待求）；aᵢⱼ 组分 j 中元素 i 的原子数；bᵢ cell 内元素 i 的总摩尔量（守恒量）
Step 2 · Lagrange 乘子法
构造拉格朗日函数 F
F = Σⱼ μⱼ nⱼ + Σᵢ λᵢ* ( Σⱼ aᵢⱼ nⱼ − bᵢ ) 理想气体化学势展开： μⱼ = μⱼ⁰(T) + RT ln(P/P₀) + RT ln(nⱼ/N) 其中 N = Σⱼ nⱼ（气相总摩尔量）
Step 3 · 一阶最优性条件（Eq. A.14，p.165）
∂F/∂nⱼ = 0 → 非线性方程组
cⱼ + ln(nⱼ/N) − Σᵢ λᵢ aᵢⱼ = 0 无量纲化定义： cⱼ ≡ μⱼ⁰(T) / (RT) + ln(P/P₀) λᵢ ≡ −λᵢ* / (RT) 显式解： nⱼ = N · exp( Σₖ λₖ aₖⱼ − cⱼ )
将 N_s 个 nⱼ 未知量消去，问题降维为求解 N_E + 1 个未知量（λ₁…λ_NE 和 N）
Step 4 · 最终求解方程组（N_E + 1 个方程）
元素守恒 + 摩尔分数归一化
【方程组 I】元素守恒（N_E 个）： fᵢ = Σⱼ aᵢⱼ [ N · exp(Σₖ λₖ aₖⱼ − cⱼ) ] − bᵢ = 0 【方程组 II】归一化（第 N_E+1 个）： f_{NE+1} = Σⱼ exp(Σₖ λₖ aₖⱼ − cⱼ) − 1 = 0
Step 5 · 带阻尼 Newton-Raphson 迭代（Eq. A.27–A.30，p.167）
x^(k+1) = x^(k) − ω · J⁻¹ f(x^(k))
求解变量： x = [λ₁, …, λ_NE, ln N]ᵀ 阻尼因子： ω ∈ (0, 1] （防止迭代发散） Jacobian 解析表达式（避免数值差分）： J_{i,i'} = ∂fᵢ/∂λᵢ' = Σⱼ aᵢⱼ · aᵢ'ⱼ · nⱼ J_{i,NE+1} = ∂fᵢ/∂lnN = bᵢ （直接由守恒量填充） 初始值（Section A.1.2）：令 λ=0，Taylor 展开线性化得 [ Σⱼ aᵢⱼ aᵢ'ⱼ nⱼ⁰ ] δλᵢ' = bᵢ − Σⱼ aᵢⱼ nⱼ⁰
气化炉还原性气氛中，此数学框架强制将几乎所有 b_S（总硫量）分配至 n_H₂S，与实验观测一致。
