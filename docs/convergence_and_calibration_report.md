# BFB Gasifier 模型收敛与物理标定报告 (2026-03-21)

## 1. 数值收敛经验 (Numerical Insights)

### 1.1 残差归一化 (Residual Scaling)
*   **问题**：能量平衡残差 ($10^7$ W) 与组分平衡残差 ($10^{-1}$ mol/s) 存在 8 个数量级的差异，导致求解器“失明”，仅优化温度而忽略组分。
*   **经验**：必须在 `Cell.residuals()` 中实施物理缩放。气相、固相和能量项均除以其各自的进料量或特征流率。归一化后的残差使求解器能平衡感知所有守恒方程。

### 1.2 反应项预叠加 (Reaction Pre-stepping)
*   **问题**：当初始猜测值为 0（如合成气浓度）时，非线性求解器易陷入局部死区，动力学源项无法有效传播。
*   **经验**：在 Gauss-Seidel 扫描的每一步，先根据动力学源项执行一步显式更新（带 0.2 的松弛因子），为非线性求解器提供“有产物”的起点。

### 1.3 供应限制守恒 (Supply Limitation)
*   **经验**：在强反应区，必须在计算源项时引入“反应物供应限制”。强制单步耗氧量不超过供应量的 95%，有效防止了数值溢出和物理上的“负浓度”爆炸。

## 2. 物理与化学标定 (Physical & Chemical Calibration)

### 2.1 炭燃烧化学计量比 ($\Phi_c$)
*   **修正**：将 $R1$ ($C+O_2$) 的初级产物分配系数 $\alpha$ 设定为 0.55 ($\Phi_c = 1.8$)。
*   **理由**：实验数据显示出口 $CO$ 占主导。流化床内部扩散限制使得炭燃烧在表面并非完全氧化，初级产物含有大量 $CO$。

### 2.2 异相反应速率分级
*   **修正**：调低 $R1$ 和 $R2$ 的前置因子至原论文的 5%~10%。
*   **理由**：原动力学参数多基于单颗粒实验。在稠密流化床中，持料量巨大导致的表面积效应极强，若不调低常数，炭会在炉底 0.5m 内瞬间枯竭，导致后续 $O_2$ 无法消耗。

### 2.3 均相反应依赖性
*   **修正**：在 $R5$ (CO 氧化) 中引入 $10^{-4}$ atm 的水蒸气浓度下限。
*   **理由**：防止在 $R2$ 剧烈消耗水分后，二次氧化反应由于动力学方程中的 $y_{H2O}^{0.5}$ 项变为 0 而彻底停滞。
