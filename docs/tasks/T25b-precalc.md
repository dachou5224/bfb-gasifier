## 目标

在 `hamel/solver/` 中实现外层每轮要重算的预计算（T18 答卷第 4 节“预计算输出清单”，ADR 0017 第 2 项的顺序：流动 → 离析 → 干燥与热解 → 灰校正），以及第一次外层所需的初值（ADR 0017 第 9、10 项）。输出就是 T25a 残差函数所需的全部冻结量。

## 范围内

输入：工况文件、上一轮单元解（或第一次外层的初值）。输出：一个冻结量结构，含以下各项。

1. **流动**（T19；ADR 0009、0011、0014 A4、0024）：
   - 由上一轮各格温度、压力、气体组成与流量求物性（T21）；
   - 床料平均粒径 d̄_P（ADR 0015 第 11 项，焦炭粒级质量平均）与 Geldart 判类（ADR 0024 第 4 项：d_sv,k = φ_S·d_k 的调和平均，常压式 (6)、(8)；非 B 类报错停止）；
   - ε_mf = 0,46、φ_S = 0,8（ADR 0024）；u_mf 由式 (3.4) 直接算；
   - ρ_P 由 ADR 0014 A4 反求（床区几何存量 = M_bed = 3,963 kg）；
   - 各格 ε_b、u_b、d_b、ε_d、K_bd、V_b、两相气体体积，床内边界的 Ṁ_auf 与 K_auf = Ṁ_auf/M（ADR 0007）；布风器 n_0 = 139,5、h_A = 0（ADR 0019）；
   - 进料的两相分配份额（ADR 0017 第 3 项，式 3.7、3.8）。
2. **离析（自由空间）**（T23；ADR 0016、0026）：调用 T23 得床面抛出总量 F₀·A、各格各粒级的 a^f、a^t、b^f、b^t、F^ej 拆分、θ，以及“自由状态不存在”的标记。自由空间气体流量取上一轮单元解。
3. **干燥与热解**（T22；ADR 0015、0032）：
   - **扩展 `hamel/pyrolysis/release.py` 的接口**（ADR 0032 第 4 项）：床区照旧用单状态系数；自由空间接受按归宿拆分的 a^f、a^t、b^f、b^t、F^ej 拆分与“自由状态不存在”标记，W、P 在悬停格分自由与悬停两部分，悬停部分没有输运出流、原地转化；原有接口的测试须继续通过；
   - 以上一轮床层平均温度 T_WS、压力调用，输出各格（自由空间按状态）的 W、P 实际存量 W + (1 − x_w)P，水、热解气、焦油释放，**按状态**的焦炭与灰生成量，以及未转化燃料随排灰与带出离开的量；这些全部进入冻结量结构，供 T25a 使用；
   - 测试：非零捕获通量、部分燃料未完成干燥或热解、目标格没有自由状态三种情形下的释放与质量、元素闭合（ADR 0032 实现约束）。
4. **灰校正与排灰**（ADR 0009 第 4 项、ADR 0014 A5、ADR 0032 第 4 项）：m_inert,i = M_i − Σ m_C,k,i − Σ[W + (1 − x_w)P]（上一轮存量，含未转化燃料）；VTT 排灰的灰分量与总流率（灰分量 < 0 时报告并停止）；床区 Ṁ_ab 自上而下递推（ADR 0009 第 2 项，递推中的反应与热解项取上一轮单元解；最底格的整体守恒残差只报告，容差按 ADR 0017 第 13 项）。
5. **壁面传热系数**（ADR 0029 第 4 项）：k_W = 21 700 W / Σ A_W,i·(T_i − 298,15 K)，用上一轮温度；Σ ≤ 0 时报告并停止。绝热对照运行时 k_W = 0（由调用参数指定）。
6. **初值**（ADR 0017 第 9、10 项）：全炉进料的气相绝热平衡（T21 接口，扣除 21,7 kW；绝热对照运行不扣除）得 T_ad 与组成；各格温度 = T_ad；气体流与分相按第 9 项第 2 步；焦炭存量按第 3 步（w_A,0、燃料粒级质量分数）；自由空间各（格，粒级）的每个存在的状态（自由与悬停分别）焦炭存量取 1·10⁻⁶·M_tot、灰存量取 1·10⁻⁶·M_tot·w_A,0/(1 − w_A,0)，自由状态不存在的格只设悬停状态；W、P 的初值取第一次调用第 3 项的结果；第一次外层把初值当作上一轮单元解。
7. **测试** `tests/test_precalc.py`：
   - 每一项至少一个由已合并模块独立算出的对照；
   - ρ_P 反求后床区几何存量等于 M_bed；
   - k_W 使给定温度场下的总散热恰为 21,7 kW；
   - Geldart 判类的 B、D 两个构造例（D 类报错）；
   - Ṁ_ab 递推与整体守恒残差；
   - 初值的元素守恒与焓守恒；
   - docstring 引用 ADR 与原文式号。
