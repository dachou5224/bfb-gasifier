## 输入与单位

原式的速率基准各不相同，换算为 cell 的 mol/s 所需的体积或质量一律由调用方显式传入，不给默认值，本卡不自行选择基准：

| 反应 | 原式与原式单位 | 换算为 cell 的 mol/s 所乘的量（调用方传入） |
|---|---|---|
| R1、R2、R4（异相，按颗粒表面） | 式 (5.11)–(5.25)、(5.34)、(5.35)：单颗粒的 R_C（mol/s），A_C、A_P 为颗粒外表面 | 粒级 k 的颗粒数 N_k = m_k / (ρ_C·π d_k³/6)；m_k 为焦炭粒级存量（ADR 0007），d_k 为粒径，ρ_C 为焦炭颗粒密度（原文未给数值，取值由 ADR 0017 裁定）。冻结稿记 A_C 的几何意义原文未写；实现时若发现某式已按粒级质量给出，停下上报 |
| R3（异相，按焦炭质量） | 式 (5.26) 的 R*_C,0，单位 1/s；式 (5.33) R_C,0 = R*_C,0·m_j,k/M_C 已是焦炭种类 j、粒级 k 的速率（mol C/s，S. 89），原文写明忽略粒径影响 | 只乘 m_j,k/M_C 一次；**不乘 N_k**，不用 d_k、ρ_C |
| R5–R7、R10、R11（均相，浓度式） | 冻结稿第 10–12、15、16 节各式（式 5.36、5.38、5.40 与式 5.52–5.61 中的速率式）：dC/dt，mol/(m³·s)；某式的单位若不是每单位体积，停下上报 | 该相的气体体积：悬浮相 V_d,gas、气泡相 V_b,gas（m³，由流动模块的 ε_b、ε_d 与 cell 体积求得；自由空间按 ADR 0017 第 4、18 项） |
| R8（式 5.45） | mol CO/(s·kg_Asche)（S. 93） | cell 中**灰**的质量 m_A,i（kg）；不是焦炭加灰的总质量（ADR 0013 第 3 项） |
| R9（式 5.51） | mol/(s·kg_Asche)（S. 95） | 同上，cell 中灰的质量 |
| 焦油（Corella，表 5.4） | m³/(s·kg_Kat)，一级 | 催化剂质量 = cell 中焦炭加灰的质量（ADR 0014 A6；自由空间按 ADR 0017 第 18 项），并乘焦油浓度 |
| 焦油（Serio，表 5.4 中按反应体积的一行） | mol/(m³·s) | 该相的气体体积 |

式 (5.22) 的颗粒温度另需：对流传热系数 α_P,g（原文未给出，取法由 ADR 0017 裁定）、ε_P、σ，均为必填参数。

函数同时返回原式的比速率（每 m³、每 kg 灰、每颗粒；R3 为 1/s）与乘上换算量后的 mol/s，测试分别检验两者。

## 范围内

1. **Arrhenius 工厂**：CHARTER §6.4 规定全仓只能有一个统一的工厂函数。R3 的补全按 ADR 0010 第 8 条：R_g 取通用气体常数，T 取 cell 温度。
2. **异相 R1–R4**，冻结稿第 2–8 节，式 (5.8)–(5.35)：
   - 计量与机理因子：式 (5.8)–(5.10)；
   - 速率与氧气膜传质：式 (5.11)–(5.21)；
   - 化学速率常数：式 (5.23) 与表 5.2，莱茵褐煤用 Lignite A（ADR 0010 第 7 条）；
   - 粒级 k 的速率按“输入与单位”表换算：R1、R2、R4 为单颗粒速率乘颗粒数 N_k；R3 按式 (5.33) 乘 m_j,k/M_C，不乘 N_k。
3. **颗粒温度，式 (5.22)**：
   - 对流项的 α_P,g、辐射项的 ε_P（原文只给区间）与 σ（原文未给数值）都作为**必填参数**，不给默认值，docstring 注明“取值见 ADR 0017”。
   - 颗粒温度若须迭代求解，迭代的容差与轮数作为参数，并在 PR 中说明。
4. **均相 R5–R11**，冻结稿第 9–17 节：
   - 反应所在的相按冻结稿第 9 节；表 5.3 中悬浮相一栏的短横线按 ADR 0010 第 5 条处理。
   - 式 (5.51) 的 P_CH4 以 Pa 计（ADR 0010 第 4 条）。
   - 所有速率统一为有符号的反应进度速率（ADR 0010 第 11 条），R8 保留逆反应，不用 abs()。
   - R8 用式 (5.45)，a_R8 = 0,02，p 以 atm 计（ADR 0010 第 2 条；ADR 0013）。不实现式 (5.49) 作为替代路径。
   - k_eq,R8 取式 (5.43) 的 K_eq（ADR 0010 第 1 条）。标准化学势 μ_i^0(T) 由调用方以函数参数传入：本卡不实现物性，数据来源待目标所有者决定。
   - Corella 焦油反应按温度分段，频率因子以 m³/(s·kg_Kat) 计（ADR 0010 第 9 条）。催化剂质量由调用方传入（ADR 0014 A6：cell 中焦炭加灰的质量）；R8、R9 的灰质量是另一个参数，两者不得混用。
   - 十六烷（ADR 0010 第 10 条）不在第 1 关范围内，不实现。
5. **测试** `tests/test_kinetics.py`：
   - 每个速率式至少一组按原文公式的独立手算。
   - 式 (5.43) 用**合成的** μ^0 做独立手算与性质测试（例如 Σν_i μ_i^0 = 0 时 K_eq = 1，且随 Σν_i μ_i^0 单调变化），注明“合成数据，仅检验公式”。与 Bild 5.11 的物理比对不在本卡：它需要 ADR 0018 批准的 μ^0，由 T21 完成，并且是首次运行（T26）之前的完成门。
   - 性质测试：
     - 平衡组成下 R8 的速率为 0；
     - 速率的符号随偏离平衡的方向改变；
     - 氧气浓度为 0 时 R1 为 0；
     - 固定 T 与分压，m_k 加倍时 R3 加倍；固定 m_k 时改变 d_k，R3 不变；
     - 计量守恒：每个反应的元素变化为 0。
   - docstring 写 `Source: Hamel Eq.5.x, S. N`，`check_citations.py` 须通过。
