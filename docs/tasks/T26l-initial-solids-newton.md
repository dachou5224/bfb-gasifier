## 来由

T26g、T26k 的停止来自同一处不一致：初值构造中床区整体向下流 Ṁ_ab 与排灰按预计算时的状态冻结，而该状态的回落与床区反应汇为零。研究底稿 `docs/research/initial-solids-drain.md` 的诊断表明，按当前状态重算这两项后，初值温度下的固相稳态可行。ADR 0052 据此改写初值构造的固相求解。

## 范围内

### A. 实现（ADR 0052 第 1–3 项）

1. 初值构造在第一次预计算之后，改为固相子系统的牛顿求解：未知量为全部固相；每次评价残差时按当前状态重算排灰（A5）与 Ṁ_ab（ADR 0009 递推），复用 `precalc` 中的同一余额式与 `bed_downflow`，不复制公式。
2. 阻尼、可行条件与迭代上限按 ADR 0017 第 7、8 项，另加排灰灰分量非负；雅可比逐列差分，步长与缩放按 ADR 0043。
3. 收敛后按 `driver.solid_feedback` 回馈并重做预计算，交替判据与次数按 ADR 0045 第 3 项第 5 步。
4. 停止条件按 ADR 0052 第 3 项。
5. 删除 ADR 0049 的预启动与分阶段回代门，以及 ADR 0045 第 3 项第 3 步的块顺序求解；相关测试改写或删除，在 PR 中逐一说明。
6. 注明 `求解手段：ADR 0052`；测试按 ADR 0052“实现约束”各项。

### B. 验证（只报告，判据预先登记）

7. 报告写入 `reports/t26l-validation/`：每次交替的牛顿迭代数与残差历史、床区焦炭与各格惰性物、排灰（灰、焦炭）、带出灰、回落、Ṁ_ab（重算值与冻结值）、递推最底格闭合差、自由空间各格体积比与悬停存量；与研究底稿 1073 K 诊断结果的对照。
8. 初值构造正常结束时，从该初值运行基准外层第 1 轮的内层牛顿（ADR 0043、0046，带 T26c 的诊断记录）。
