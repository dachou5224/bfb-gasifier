## 目标

T30 的验收结论是不通过：`X_C`、`CO2`、`H2`、`H2O` 出界，`T̄_FRB` 与 `CH4` 边界待定，`CO` 通过。#178 把四个出界量归为两条链（链 A 挂 R11，链 B 挂 R5 与焦炭消耗路径），#179 查出 R11 在自由空间存在一段**未登记的温度外推**（Serio 表列 500–900 °C，自由空间达 1042.6 °C）。但这些都还只是**候选**。

本卡的目标是**用 Hamel 自己的轴向剖面曲线**（CHARTER §1 明列的主判据：「轴向剖面图中的模拟曲线」）把候选机制**逐一判为支持／反驳**，产出一张结论表，指明下一步该查哪里。**本卡不改模型、不改参数、不给出验收结论。**

## 待判的候选机制（本卡要逐一判定位证据是否指向它）

| 编号 | 候选 | 来源 | 该候选**按符号计量推出的**响应（须注意方向） |
|---|---|---|---|
| **H1** | 自由空间 R11 过强（Serio 外推 142.6 K ＋ 6.5 倍体积） | #178 假设 H、#179 F3/F4 | R11 计量 `C₆H₆ + 9/2 H₂O → 9/2 CO + 9/2 H₂ + 3/2 CH₄`：正向增强 → **H₂O↓、CO↑、H₂↑、CH₄↑**，CO₂ 不参与 |
| **H2** | 自由空间几何有误（0.108 m³ 偏大） | #179 §4.5 | 与 H1 同向（体积是 R11 的乘子），**剖面无法把 H1 与 H2 分开**；须靠几何核对 |
| **H3** | R6／R7 的浓度基准未定（R7 差 1000×、R6 差 31623×） | #178 P1、#179 | 改变 O₂ 消耗位置与床内 CO/CO₂ 分裂；对自由空间影响小 |
| **H4** | 自由空间 R8 偏弱 | #178 P2 | **注意方向**：本解自由空间 `Q/K > 1`，R8 进度为**逆向**（产 CO + H₂O，耗 CO₂ + H₂）。**增强**该逆向过程 → **CO↑、H₂O↑、CO₂↓、H₂↓**；因此「偏弱」对应的是**减弱**逆向过程的效果，即相对地 **CO↓、H₂O↓、CO₂↑、H₂↑** |
| **H5** | R5 在自由空间用气泡相参数（占耗氧 19.54 %） | #178 §8.1、T31 C.7 | R5 计量 `CO + ½O₂ → CO₂` → **CO↓、CO₂↑**，H₂/H₂O/CH₄ 不直接参与 |

**必须在报告里明确的一件事**：H4 的「偏弱」与「增强逆向」是**两个不同的比较对象**，不能混用。卡片此处给出的是「相对减弱逆向」的效应；若执行者要讨论「增强逆向」，须另列并注明符号相反。

**关于能否二选一的限制**：H1（CO↑）与 H5（CO↓）在 CO 方向上相反，H4 在「偏弱」口径下也落在 CO↓一侧。但**A 项只是摩尔分数曲线**，归一化总流量变化、其它反应与温度耦合都会影响趋势，**不能保证**该方向差异在耦合解里必然显现。故本卡**不设「强制二选一」**：允许结论为「不足以区分」。

## 判据预先登记（**看到数字后不得移动**）

本卡把两件事分开：**F1–F6 是「剖面特征是否一致」的定位证据**；H1–H5 的「支持／反驳／未定」是对这些特征的**综合解读**，且**必须允许「未定」**。

| 特征 | 参照 | 用法 |
|---|---|---|
| **F1** O₂ 耗尽位置 | 正文（PDF idx 76 右 / S. 135）称「Der Sauerstoff ist bereits in der zweiten Zelle verzehrt」；Bild 7.8 图例含 O₂ 曲线 | 对照 B 项 16 格的 O₂ 剖面；**该图的 O₂ 线能否读准单列不确定度**。若 O₂ 不可读，本项记「不可判」，只保留正文陈述作定位参考 |
| **F2** 床区 CO／H₂ 上升 | 正文「deutlich erkennbar am Anstieg von CO und H2」 | 形状对照；不一致则指向床区机制 |
| **F3** 二次风处 CO／H₂ 下降 + 温升 | 正文「Temperaturanstiegs verbunden mit einer Abnahme der CO- und H2-Konzentrationen」 | 三件事是否同时出现 |
| **F4** 二次风之后到出口的组分走向 | 图读 | **只记「一致／不一致／不可判」，不据此推「过强／偏弱」** |
| **F5** CO 与 CO₂ 的相对方向 | 图读 | 同上：只作定位证据。若 H1 与 H5 的方向差异在图上不可分辨，记「不足以区分」 |
| **F6** 温度峰的位置 | 图的温度曲线 | 与二次风高度的对应；须用 A.2 的全高坐标核验 |

**判定的量化底线**：
- F1–F6 只判**方向与位置**，不设数值容差；方向不可判就记「不可判」。
- **同号不能推出同量级**：速率差数倍的同一种反应可以产生同号剖面。因此**不得**由「与 Hamel 同向」直接断言「过强被反驳」或「偏弱被支持」。
- 反之，H₂O 不降也可能来自 R6／R8 产水或燃料释放水，**不得**由「H₂O 不降」直接强支持「R11 过强」。
- 若要声称「过强／偏弱」，须另附**独立的量级证据或源项证据**；仅凭正负号不足以支撑。

## 与既有结论的关系（执行时须知）

- 本卡**不推翻** #178 的 L1／L2（账目事实与两条链），也不推翻 #179 的 F1–F5；它只检验 #178 的 **L3 假设 H** 与 #179 的 P1／P2 是否站得住。
- **Hamel 与本模型共用同一套 cell 结构与动力学式**（#178 §6.3），所以剖面对照若显示「形状一致」，只能说明「该机制不能解释我们与 Hamel 的差异」，不能说明「该机制无关紧要」——报告须按此措辞。
- 若 F4 显示 Hamel 的自由空间走向与我们的**不同**，这是本关第一次拿到**方向性的、非验收量的**外部证据，应优先写清楚，供目标所有者决定是否立后续卡。
- **本卡不声称能判定「过强／偏弱」**。剖面只提供**定位**证据（差异在哪一段、哪个组分、方向如何）；「过强」属量级判断，需独立的源项或量级证据。报告须严格区分这两类结论。
- 本卡的 A 项（Bild 7.8 的数字化）与 D 项（几何、灰量、R6/R7 单位）都是**只读**产出，不改模型，故即使全部做完也不会改善验收指标——它的价值是把下一步的诊断方向**收窄**。
