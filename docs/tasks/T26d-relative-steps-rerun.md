## 范围内

### A. 实现（ADR 0041 第 1、2 项）

1. `hamel/solver/newton.py` 的 `_jacobian`：步长改为 x_n ≠ 0 时 √ε·|x_n|，x_n = 0 时 √ε·s_n。注明 `求解手段：ADR 0041`。
2. 牛顿步的线性求解改为行列缩放后求解（R 用 ADR 0012 参考流，C = diag(max(|x_n|, s_n·[x_n = 0]))，见 ADR 0041 第 2 项），不显式求逆。
3. 测试：
   - 构造 f(c) = −c − K·c^0,3 型的单变量问题，在 c = 10⁻²⁰ 处新步长给出的差分与解析导数相对差 < 10⁻⁶，旧步长不满足；
   - 行列缩放对良态问题的牛顿步与不缩放时一致（相对差 < 10⁻¹⁰）；
   - 阻尼、可行条件与收敛门的现有测试逐位不变。

### B. 验证（ADR 0041“验证”一节，只报告）

4. 在 `reports/t26c-diagnosis/baseline/failure.npz` 与 `frozen.pkl` 的失败点，用新规则重算 J 与牛顿步，按 T26c 第 6 项做方向检查。
5. 从工况 1 的初值点运行基准外层第 1 轮的内层牛顿，记录 T26c 的诊断信息与终止状态。
6. 结果写入 `reports/t26d-validation/`。**若方向在小步长上仍不是下降方向，或内层第 1 轮仍以 DAMPING_FAILED 终止，停止，不做 C 部分**，在 PR 与 STATUS 中写明。
