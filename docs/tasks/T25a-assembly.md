## 目标

在 `hamel/solver/` 中把各模块拼成第 1 关的完整残差 F(x; 冻结量)：给定未知向量 x 与本轮外层冻结的预计算量（由 T25b 提供，测试中可直接给定），返回式 (2.4)–(2.7) 按 cell、按变量的残差。完成后，T25c 的阻尼牛顿只需调用这个函数。

## 范围内

1. **cell 布局与未知向量**（ADR 0014 B；ADR 0017 第 3、4、5 项；ADR 0007；ADR 0026 第 3 项）：
   - 床区 8 格、自由空间 8 格，自下而上的几何与 `hamel/balances/` 的自上而下编号之间的映射写成一个函数并测试；
   - 床区每格两相、每相每组分一个出流 Ṅ_l,j,i；自由空间每格一个气相；每格一个温度 T_i；每格、每粒级一个焦炭存量 m_k,i；设有悬停状态的（格，粒级）再加 m^t，自由状态不存在的（ADR 0026 第 3 项 m̂ = 0）不设 m^f；
   - 打包、解包函数与变量名表，供 T25c 的雅可比与报告使用。
2. **气相**（式 2.4、2.5；ADR 0017 第 3、4、12 项；ADR 0011 第 3 条）：
   - 进料：一次风、蒸汽、吹扫氮按 ADR 0017 第 3 项的两相分配进入床区最下格（分配份额为冻结量）；二次风进入自由空间第 2 格（1,4875 m）；吹扫氮温度与组成按工况文件；
   - 热解与干燥释放：T22 给出的各格水、热解气、焦油释放（冻结量）进入该格悬浮相（床区）或气相（自由空间）；
   - 交换流 Ṅ_ex = K_bd·V_b·(C_d − C_b)，K_bd、V_b 冻结，浓度由当前未知量求得；
   - 反应源项：T20 各速率按“输入与单位”表换算到 mol/s，在当前未知量上计算；床区 R1–R4 只在悬浮相；均相反应按相；自由空间按 ADR 0017 第 18 项与 ADR 0022 C3（焦油只用 Serio）；R8、R9 用灰质量，Corella 用焦炭加灰质量（ADR 0014 A6）；式 (5.9)、(5.10)、(5.23) 的 d_c、T_c、T 按 ADR 0022 C1；颗粒温度式 (5.22) 的 α_P,g 按 ADR 0017 第 20 项。
3. **固相**（式 2.6；ADR 0007、0009、0014、0026、0031）：
   - 床区：向上流 K_auf·m（ADR 0007，K = Ṁ/M 冻结），向下流按冻结的 Ṁ_ab（ADR 0009 第 2 项，T25b 递推）；床区最上一格的向上出流为床面抛出总量 F₀·A 按该格存量份额 m_j,k/M 分配（ADR 0009 第 1 项、T23）；
   - 自由空间：按 ADR 0026 第 3 项的两状态方程，系数 a^f、a^t、b^f、b^t、F^ej 拆分、θ 为冻结量；
   - 粒级迁移与反应消耗按 ADR 0031；
   - 热解生成的焦炭按 T22 的各格生成量进入相应粒级（冻结量）；
   - 灰：床区按 ADR 0014 对 ADR 0009 的修订（m_inert,i = M_i − Σ m）；自由空间按 ADR 0026 第 4 项；排灰按 ADR 0014 A5（冻结量）；
   - 带出：自由空间出口格的向上出流（ADR 0016 第 4 步），连接管与旋风为不计反应与传热的输运段（ADR 0014 X2、X2a）。
4. **能量**（式 2.7、2.8；ADR 0029）：各股物流的焓流用 `hamel/properties/`；壁面散热 Q̇_W,i = k_W·A_W,i·(T_i − 298,15 K)，k_W 为冻结量；Q̇_WÜ = 0；固体焓流含灰（比热 950 J/(kg·K)）与焦炭（C(gr)）。
5. **有效域检查**（不截断，只报告或报错）：ADR 0026 第 5 项（无反应无迁移的悬停、滞留体积超过 (1 − ε_mf)、最小粒级被捕获且有灰）；速率式越出原文适用范围时抛出约定的异常类型，供 T25c 按 ADR 0022 C4 判为不可行（本卡不处理缩步）。
6. **测试** `tests/test_assembly.py`：
   - 打包与解包互逆；编号映射；
   - 守恒：所有格残差相加后只剩外部进出、反应与壁面散热；元素（C、H、O、N、S）与灰逐项守恒；
   - 两状态：ADR 0026 第 3 项的逐格守恒、自由状态不存在的格、ADR 0026 第 4 项灰的三个案例（空库存零流、灰焦比很大、燃尽后灰全部进入 k = 1）；
   - 粒级迁移：ADR 0031 实现约束中的三个测试；
   - 残差在试探点上计算（T18 答卷），不缓存上一步的反应项；
   - docstring 引用原文式号与 ADR，`check_citations.py` 通过。
