## 目标

T23 按任务卡的停止条件拆分：第 1–4 项（床面抛出、抛出初速、自由空间气速、轨迹积分）在 PR #95 交付；本卡完成第 5、6 项中与记账有关的部分，即由无反应参考轨迹得到各（cell，粒级）的输运系数，并按 ADR 0026 判定悬停与记账。完成后，T25b 可以拿到 T25a 所需的全部自由空间冻结量。

## 范围内

以 T23 卡第 5 项为准（`docs/tasks/T23-freeboard.md`，含三轮审查记录），要点：

1. **参考轨迹**：床面抛出样本（按 ADR 0016 第 6 条的初速分布离散）与当地生成参考轨迹（每格中点、以 u_g(h_i) − v_t,k 起步），用 T23 第 4 项的积分器，积到归宿确定。
2. **归宿与记账**（ADR 0026 第 2 项）：
   - 稳定平衡 h* 与捕获区 R*（h* 所在格；在界面上时为两格之并）；
   - 归宿只有回落、带出、进入 |h − h*| ≤ δ_h、|u_P| ≤ δ_u 三种；δ 只用于确定归宿，δ_h 不超过 h* 到 R* 外边界距离的一半；积分时间上限只用于报错；
   - 以最后一次进入 R* 为捕获时刻：此前计入自由状态的 m̂、Û、D̂，此后不计；最后一次进入时所穿越边界上的通量计入所进入格的悬停状态。
3. **系数与参考集合**（ADR 0026 第 3 项）：
   - 床面样本在格 j 内有自由段时，参考集合取床面样本；否则取所有格的当地生成轨迹在 j 内的自由段（含从相邻格穿入的段）；
   - 输出 a^f、a^t、b^f、b^t（a = Û/m̂、b = D̂/m̂ 按归宿拆分）、床面抛出的拆分 F^ej,f/F^ej、各格各粒级的 θ（当地生成轨迹捕获时刻为 0 时为 1）、各粒级的回落与带出份额；
   - m̂ = 0 时输出“自由状态不存在”，不输出系数数值，不用除数下限或零值代替。
4. **求解器参数 ADR**：T23 在 PR #95 中登记的参数 ADR 若未包含 δ_h、δ_u 与积分时间上限，本卡在 PR 内补登（同一 ADR 修订或新号），加密判据分两组报告：(i) 样本数与步长；(ii) δ 减半（验证 δ 已足够小）；相对变化均 < 1·10⁻⁴。
5. **测试**（按 ADR 0026 第 2、3 项与 T23 卡第 7 项）：
   - 单 cell 稳定结点的解析例（捕获时刻为 0、自由 m̂ = 0、δ 减半不变）与首轮审查的过阻尼数值例；
   - 欠阻尼振荡趋近；起步在平衡点；h* 恰在界面上（两侧来流分别记入所进入格，逐格与全炉守恒）；
   - 离开自由空间的对照（单调递增气速，或 v_t 高于、低于整段气速的递减剖面），不判捕获；
   - 参考 m̂ = 0、悬停有入流的格，输出“自由状态不存在”；
   - 无反应一致性：只对不悬停的粒级，按 a、b 的线性稳态解等于参考记账（ADR 0016 第 5 步）；
   - 加密收敛两组。
6. **冒烟**：工况 1 的临时输入下，列出各粒级的回落与带出份额、各格 a^f、a^t、b^f、b^t、捕获区所在格，与 T27 的情景 B、C 对照。
