## 来由

T26j 在预启动阶段因闭合 A 的悬停焦炭超出有效域停止（最下一格体积比 1,58）。研究底稿 `docs/research/hover-drift-closure.md` 表明：ADR 0048 之后悬停状态缺少粒级内的出口，缩小的颗粒应逐个界面上移并最终转入自由状态。目标所有者批准 ADR 0051 后，以“A 加粒级内漂移”为新基准；闭合 A 的登记结果保留并列报告。

## 范围内

### A. 窗口与冻结量（ADR 0051 第 2 项）

1. 在自由空间参考记账中，按 ADR 0048 的 φ_p 取样，对每个（格 j，粒级 k）求窗口 [d′_lo, d′_hi]、下沿去向、路径长度 L_p（含 ρ_k）、出口因子与权重 ω_p。v_t 对 d 二分求根，格 j 与格 j + 1 各用自己的物性。
2. 新增冻结量：漂移因子 δ_j,k、迁移因子 μ_j,k、漂移去向（格 j + 1 的悬停或自由状态）。漂移去向为悬停而该状态原本不存在时，须使其存在（参考记账与 `hover` 标记一致），在 PR 中说明做法。
3. 报告每个（格，粒级）的 δ、μ、去向与 ω_p。

### B. 衡算（ADR 0051 第 3 项）

4. 悬停状态的粒级迁移改用 α_s·μ（焦炭与灰），新增漂移 α_s·δ（焦炭与灰）从源状态扣除、进入格 j + 1 的去向状态；自由状态不变。
5. 漂移流在两格的能量方程中按源格温度计焓（与 ADR 0048 的 ↓ 传输同一写法，方向向上）。
6. S13、S14 下没有悬停状态，不产生漂移；S17 经 ū_g 进入窗口。核对改送账不重计。
7. ADR 0046：漂移只连接相邻格，确认 `jacobian_layout` 的依赖结构覆盖它；第 1 次内层迭代的逐位核对照常。
8. 注明 `解释性选择：ADR 0051`；测试按 ADR 0051“实现约束”各项，含退化到 ADR 0044 的逐位比较与逐格能量核对（不只全炉）。
