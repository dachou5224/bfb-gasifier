## 来由

T26l 按 ADR 0052 初稿实现，验证在第一次交替的第 1 次迭代阻尼失败：试探点上的存量、惰性物与排灰非负条件把迭代挡在可行域边界上。研究底稿 `docs/research/initial-solids-drain.md` 第 7 节与 `reports/research-initial-solids/study-strict-relaxed.json` 表明，试探点只要求残差有定义时，同一零起点 6 次迭代收敛到可行解。ADR 0052 据此修订；同时发现最上一格存在无入流的悬停状态，与 ADR 0048 第 2 项不符。

## 范围内

### A. ADR 0052 修订

1. 初值固相牛顿的试探点可行条件改为：残差有限、最底床格灰分为正、不被有效域拒绝。删去试探点上的存量非负、床格惰性物非负、排灰灰分量非负。
2. 收敛解检查（ADR 0052 第 3 项）：存量小于 −τ 停止，τ = 1·10⁻¹²·M_tot；床格惰性物、排灰灰分量与最底床格灰分的检查不变。τ 作为求解器参数写入 `SolverConfig`。
3. 主求解的内层牛顿（`newton.damped_newton` 在主求解中的可行条件）不改。若初值子系统复用同一函数，以参数区分，不改变主求解的行为；测试覆盖两者。

### B. 最上一格的悬停状态（ADR 0048 第 2 项，程序错误）

4. 查明工况 1 冻结量中最上一格粒级 3 悬停状态的来源（按衡算下标 0 为顶），修正为：悬停状态只设在作为某个界面下方格的格；最上一格不设悬停状态。在 PR 中说明原因与修正。
5. 测试：最上一格不设悬停状态；修正前后其余格的悬停标记、c、θ、漂移与 μ 不变（或逐项说明变化）。

### C. 验证（只报告，判据预先登记）

6. 报告写入 `reports/t26m-validation/`：每次交替的牛顿迭代数、范数历史与步长、床区焦炭与各格惰性物、排灰、带出灰、回落、Ṁ_ab（重算值与冻结值）、递推最底格闭合差、自由空间体积比与悬停存量、收敛解的最小存量；与研究底稿 relaxed 结果的对照。
7. 初值构造正常结束时，从该初值运行基准外层第 1 轮的内层牛顿（ADR 0043、0046，带 T26c 的诊断记录）。
8. **通过判据**：初值构造正常结束，且基准外层第 1 轮内层以 CONVERGED 终止。不通过即停止，在 PR 与 STATUS 中写明，不另试其它手段。不进入整批重跑。
