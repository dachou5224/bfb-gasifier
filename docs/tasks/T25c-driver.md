## 目标

在 `hamel/solver/` 中实现第 1 关的求解驱动：内层阻尼牛顿、外层对齐循环、收敛门与外部平衡，以及按 ADR 0030 执行基准运行与 16 次敏感性运行、生成首次运行报告的框架。完成后，T26 只需运行本卡的入口并提交报告。本卡交付的是**框架与小规模测试**，不交首次运行的结果（属于 T26）。

## 范围内

1. **内层阻尼牛顿**（ADR 0002；ADR 0011 第 5 条；ADR 0017 第 6–8 项）：
   - 解 J·Δx = −F（不显式求逆）；雅可比每次迭代在当前点用前向差分重算，步长 √ε_mach·max(|x_n|, s_n)，可按块结构分组；
   - 阻尼按 Wirsum 第 4、5 步：范数取 ADR 0012 参考流归一后的残差的欧氏范数，严格下降，i ≤ 30；试探点须满足可行条件（全部气体出流与固体存量 ≥ 0、T_i > 0、残差有限、ADR 0009 有效域第 3 条）；速率式越出原文适用范围的异常按 ADR 0022 C4 判为不可行、继续缩步；
   - 成功只按 ADR 0012 第 1 项的内层门；ν_max = 200 只作失败判据；阻尼失败即报告并停止。
2. **外层循环**（ADR 0012 第 2 项；ADR 0017 第 10 项）：每轮调用 T25b 重算冻结量，内层从上一轮单元解出发；判据 (a)：温度 0,1 K、固体流与存量、气体出流与交换流的相对变化 1·10⁻⁴（分母用全炉尺度）；(a) 通过后做 (b)：用最终单元解重算全部预计算输出，代入未修改的原方程，须再满足内层门；外层上限 100 轮只作失败判据。
3. **外部平衡与非负**（ADR 0012 第 3、4 项；ADR 0017 第 14 项）：C、H、O 元素 ≤ 0,1 %，总能量 ≤ 0,5 %（热损失为壁面散热，ADR 0029）；收敛解的非负与有效域。
4. **求解器参数**：ν_max、外层上限、硬超时（CHARTER §7）已在 ADR 0017 第 8 项登记；新增字段须在本 PR 内附 ADR 按字段名登记。
5. **运行框架**（ADR 0030）：
   - 一个入口按 ADR 0030 依次执行基准运行与 S1–S16 共 16 次敏感性运行，每次只改所列一项，其余冻结；每次运行带硬超时，超时记 TIMEOUT，未收敛如实记录，不省略；
   - S1 绝热对照：k_W = 0，初值不扣除壁面散热（ADR 0030 F19）；
   - 报告生成：7 个验收量与 Hamel 模拟值的比较（`data/digitized/fig_7_10.json`，按 CHARTER §2.2 的容差与“边界待定”规则，用 T9 的 `hamel/cases/judge.py`），收敛门与外部平衡，ADR 0030“必报诊断量”的全部各项，敏感性运行的差值表，数值加密检查单独成节；
   - 报告写成 `reports/` 下的一个 Markdown 文件与一个机器可读的 JSON（目录与文件名在 PR 中说明），报告中列出全部冻结选择及其来源（ADR 0013 实现约束）。
6. **测试** `tests/test_driver.py`：
   - 阻尼牛顿在小规模构造问题上的收敛与阻尼失败路径；
   - 不可行试探点的缩步（含速率式越界异常）；
   - 外层判据 (a)、(b) 的逻辑；
   - 外部平衡与非负检查；
   - 报告生成在一个快速的玩具工况上端到端可运行；
   - 完整工况的运行标为 `slow`，带硬超时（CHARTER §7）。
