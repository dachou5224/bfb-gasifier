## 范围内

全部为纯函数，numpy 数组，SI 单位；物性、气泡量、气体流量与粒径由调用方传入，不给默认值。

1. **床面抛出**（§3.2.1，式 3.49–3.67；ADR 0016 第 1–5 条，ADR 0009 第 1 项）：
   - 顶盖与尾涡的合成抛出按式 (3.66)、(3.67)，式 (3.67) 照式面用 (1 − ε_d)，ζ_w = 0,4、f_w = 0,25（S. 39）；
   - 聚并概率：C = 1 − cos ξ（式 3.61、3.62），半角 ξ = 48°（Briens–Baron），式 (3.55) 的 σ = 0,4 为 Δl/d_b 的无量纲标准差，P″_k = (1 − P″)^{k−1}·P″，求和自 k = 2 起，n_B = 5；
   - 输出按粒级的床面抛出质量流 F₀·A（kg/s），这就是 T19 所缺的床面边界向上流（ADR 0009 第 1 项）。
2. **抛出初速分布**（§3.2.2，式 3.72、3.73；ADR 0016 第 6 条）：u_P,0 ~ N(1,53·u_b, (0,6·u_b)²)，σ 为 u_P,0/u_b 的标准差；按 u_P,0 区间离散为样本，份额归一；u_P,0 ≤ 0 的部分计入床面回落。
3. **自由空间气速**（§3.2.3，式 3.74–3.76；ADR 0016 第 7 条）：u_g = u_gb(h) = u_0(h) + (u_gb,0 − u_0(h))·exp(−β_A·h)，u_gb,0 = u_b,WS，β_A = 1/(3·d_b,WS)（式 3.75）；u_0(h) 为当地表观气速，按调用方给出的各格气体体积流与截面（锥段线性变截面）计，二次风口以上计入二次风（ADR 0016 第 7 条）。
4. **颗粒运动**（§3.2.4，式 3.77–3.88；ADR 0016 第 8、11 条）：
   - 阻力按式 (3.85)，z 按式 (3.86) 取 Re_∞ → ∞ 的极限 z = 73,69·exp(−5,0784·φ_S)，φ_S 按 ADR 0024（0,8）；
   - **所有轨迹对式 (3.82)/(3.88) 与 dh/dt = u_P 作数值积分**，系数在每一步按当地 h 取值；不使用印刷的式 (3.93)–(3.96)、(3.98)、(3.99)、(3.103) 求解；式 (3.93)–(3.95) 只作常气速、Δ > 0 情形的单元测试基准。
5. **参考轨迹与输运系数**（ADR 0016 第 9、10 条；ADR 0026 第 2、3 项）：
   - 床面抛出样本与当地生成参考轨迹（床面样本到不了的 cell，从 cell 中点以 u_g(h_i) − v_t,k 起步）都要计算；
   - 记录各 cell 的停留时间与穿过边界的方向，得 m̂、Û、D̂，a = Û/m̂、b = D̂/m̂；
   - **悬停判定**按 ADR 0026 第 2 项：越过最高点后又由向下转为向上即判为悬停，起步向下的当地生成轨迹在出现最高点前的转向不计；判定时的份额计入 Ĉ，c = Ĉ/m̂，并给出 h* 所在 cell；
   - 回落份额与带出份额按 ADR 0016 第 9、10 条第 4 步定义；
   - m̂ = 0 的（cell，粒级）不删除，按当地生成参考轨迹给系数。
6. **新增求解器参数须登记 ADR**：样本数、积分步长或误差容差、判定所需的数值容差，写入 `SolverConfig`。按 CHARTER §9 在本 PR 内附一份 ADR 按字段名登记（编号取下一个空号），含加密判据：样本数加倍、步长减半时 a、b、c 与回落、带出份额的相对变化 < 1·10⁻⁴（ADR 0016 实现约束）。
7. **测试** `tests/test_freeboard.py`：
   - 每个抛出式与阻力式一组独立手算；
   - 常气速、Δ > 0 时数值积分与式 (3.93)–(3.95) 一致；
   - 无反应时，按 a、b 列出的线性稳态方程组的解等于参考轨迹的记账（回落 + 带出 = 抛出，存量 = Σ 质量流 × 停留时间；ADR 0016 第 5 步），只对没有悬停的粒级；
   - 悬停判定：单调递减气速中必判定，单调递增气速中不判定；起步向下的当地生成轨迹不误判；
   - 加密收敛；
   - docstring 写 `Source: Hamel Eq.3.x, S. N`，`check_citations.py` 通过。
8. **冒烟**：用 VTT 工况 1 的输入（气体流量与床层气泡量取测试中写明的临时值，注明“仅作冒烟”）列出各粒级的 F₀·A、回落与带出份额、各格 a、b、c、悬停所在 cell，并与 T27 的情景 B、C 结论对照。
