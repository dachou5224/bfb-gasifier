## 目标

按 ADR 0058 第 1 项把粒级内取样的等权求和改为按归宿边界分配权重，使自由空间系数随状态连续变化；按第 2 项在外层通过后把 [−ε_0, 0) 内的负固相存量置零并全部重检。在工况 1、φ = 1 上报告系数的实际变化、两态间扫描的跳变，以及外层与收敛后各项检验的结果。服务第 1 关。

**本卡不保证外层收敛。** ADR 0058 的可行性试验只细分了一行。终态是“未收敛”时，只要报告齐全，就是预期结果之一，不算本卡失败。

### B. 实现

1. `hamel/cases/config.py`：`freeboard_boundary_bisections: int = 6`（≥ 0 的整数），`final_negative_floor_kg: float = 1.0e-30`（有限、非负）。非法值报错。注明 `ADR 0058`。
2. `hamel/freeboard/accounting.py`（ADR 0058 第 1 项，注明 `解释性选择：ADR 0058`）：
   - **签名**：写一个函数，从 `TrajectoryFate` 取出全部进入记账的离散字段。在 PR 中逐项列出字段名，并说明每个字段在 `account_freeboard`／`_sum_ledgers` 中的用途；未列入的字段须说明为何不进入记账。
   - **节点与分段**：同一 φ_S 分位点、同一轨迹位（每个床面起始速度样本、每个格中点当地轨迹）沿 x = ln d：节点 x_a、x_1 … x_(N_d)、x_b；对两端签名不同的区间按 ADR 递归定位（停止条件 r − l ≤ Δ·2⁻ⁿ_b；第三种签名时两侧分别递归）。逐段分给代表轨迹（与原节点相邻的段归该节点；中间段归揭示其签名的中点轨迹；端部区间同样逐段分配，签名相同时整段归最近取样点）。
   - **权重表**：每行每轨迹位先得到“轨迹–权重”表，校验权重和为 1/N_φ（相对误差 ≤ 10⁻¹²，否则报错），再按现行记账规则累加。
   - **按节点的量**：现行“某格被该子样本任一轨迹触及即累加其权重与 v_t”（`touched`、`w_t`、`slip_t`）改为按节点累加，权重取该节点触及该格的各轨迹位权重的最大值，v_t 取该节点粒径。
   - 中点与端点轨迹的 `stable_equilibria` 按其粒径另算。`captured_phi` 等按 φ_S 归集的量用轨迹权重。
   - 不改：取样点与权重定义、轨迹推进、事件、归宿、捕获、窗口与漂移、ADR 0057 的停留下限。
3. `hamel/solver/driver.py`（ADR 0058 第 2 项）：
   - 外层通过外层门与现行 2(b) 复核后，把固相存量中 −ε_0 ≤ m < 0 的分量置零。无分量置零时行为不变。
   - 有分量置零时，在置零后的状态上**重做** 2(b)（再调用一次一致性预计算，灰平衡与内层收敛门），然后做外部平衡、壁面散热、底部残差与非负（τ = 0）。任何一项不过判为未收敛。交出与报告的是置零后的状态。
   - 诊断中记录置零的分量名、原值、个数，以及置零前后各分块残差比。
4. 登记：ADR 0030 冻结清单 F29 补注 ADR 0058 第 1 项、F20 补注第 2 项，两个新参数登记为求解器参数。

### C. 一致性

1. **单元层**：见“测试”。
2. **实际输入**：用第 A 项第 17 轮入参分别在实现前、后各做一次预计算。对**每一行每一轨迹位所有区间两端签名都相同**的粒级，冻结量中只属于该粒级的数值相对差应 ≤ 10⁻¹²；报告哪些粒级满足这一条件、比较结果。有不满足的，停下上报。其余粒级只报告新旧对照。

### D. 验证运行（只报告）

1. **初值点**：工况 1 初值点第一次预计算（φ_init = 0,3），新旧各一次。报告：各粒级端点轨迹条数、定位用中间轨迹条数、出现第三种签名的区间数、各粒级逐格 m̂、a_f、b_f、c↑、c↓、θ↑、θ↓ 新旧对照、预计算耗时。
2. **两态扫描**：按第 A.4 项插值，8×8，s = 0, 0,1, …, 1 共 11 点，每点只做预计算。报告冻结量各字段的相邻最大相对跳变（相对 11 点最大绝对值）与位置；θ、m̂、a_f、c↑、c↓ 的最大跳变；跳变处粒级 2、3 的签名变化（由轨迹级记录确认）。实现前同一扫描的总司令诊断：最大相邻跳变 0,298（悬停区生成项），θ 台阶 1/64。
3. **外层**：工况 1、φ = 1，`tools` 中外推 Corella，`driver.solve_case`，上限 26 轮，墙钟不超过 8 小时。逐轮：φ、w_f、|E − T|/T、床区焦炭、最小格惰性物、内层状态与迭代次数、投影计数、外层门四项。通过外层门时：2(b) 复核（灰平衡与三块残差比）、元素与能量平衡、壁面散热相对差、底部残差、非负；第 2 项置零的分量名与原值、置零后重检结果；终态。
4. **二分次数对照**：若第 3 项外层通过外层门，用最终状态（置零前）分别以 n_b = 6 与 8 各做一次预计算，报告冻结量的最大相对差及所在字段。未通过则跳过并说明。

## 测试（必须新增，ADR 0058“实现约束”逐条）

- 签名处处相同时，所有记账输出与现行相同（构造用例，逐位）。
- 每行每轨迹位权重之和为 1/N_φ，粒级总权重为 1：含端部区间签名相同与不同两种情形。
- 两签名 A/B：已知边界，定位误差 ≤ Δ·2^−(n_b+1)，两侧质量和等于区间质量。
- 三签名 A/C/B（C 宽于 Δ·2⁻ⁿ_b）：C 被找到，三段质量误差各 ≤ w·2^−(n_b+1)；C 区段整体平移（A/C 边界由 0,099999Δ 到 0,100001Δ）时各签名质量变化 ≤ w·2⁻ⁿ_b。
- 端部区间 A/C/B（端点 A、最近取样点 B、内部 C）：端点只得 A 段，B 段归取样点，C 段归中点轨迹；质量闭合。
- 边界连续移过取样点、从粒级外移入端部区间时，各归宿质量变化 ≤ w·2⁻ⁿ_b。
- 按节点累加的量取最大值规则。
- 非法参数（n_b 为负或非整数，ε_0 为负或非有限）报错。
- 第 2 项：[−ε_0, 0) 内负存量置零后重做 2(b)、平衡与非负；低于 −ε_0 时不置零、判未收敛；构造置零后某分块残差超门的例子，判未收敛；无负存量时行为不变。

签名、分段与权重表的测试可用构造的签名函数（以 ln d 为自变量的阶跃函数）直接测分段与权重函数，不必跑真实轨迹。
