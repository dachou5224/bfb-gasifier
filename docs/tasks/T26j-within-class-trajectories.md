## 范围内

1. **粒级内取样**（ADR 0048 第 1 项）：粒径 N_d = 8（质量在 ln d 上均匀的等分中点），球形度 N_φ = 8（[0,3; 1,0] 截断正态，σ_φ = 0,1，截断后均值 0,8 的等概率分位中点），每粒级 N_d × N_φ × 48 条参考轨迹按权重汇总；当地生成按 ADR 0048 第 2 项拆为 θ↑、θ↓（放宽 `frozen.py` 中“θ 只能是 0 或 1”的检查）；悬停状态的 u_r 取被捕获子样本的加权平均 v_t。反应、颗粒数、迁移、颗粒温度仍用代表粒径。
2. **半格捕获区与源格→目标格**（ADR 0048 第 2 项）：R*_j 为界面两侧各半格；悬停状态记在界面下方格；新增冻结量 c↑、c↓、θ↑、θ↓（a^t = b^t = 0，F^ej,t = 0）；残差按 ADR 0048 第 2 项“各项流的去向”装配，↓ 项作为相邻格传输写入两格衡算，组成与焓按源状态；S13、S14 的改送同步覆盖这些流；更新 ADR 0046 的依赖结构（c 只连接相邻格，应仍在节点邻域内；如不在，按 ADR 0046 第 3 项单独成组并在 PR 中说明）。
3. **S17**（ADR 0048 第 3 项）：`campaign.py` 登记逐格表观气速的敏感性运行；ADR 0030 由 16 次增为 17 次（同 PR 更新清单与报告框架）。
4. 注明 `解释性选择：ADR 0048`。测试按 ADR 0048“实现约束”各项，其中逐位复现现行结果的是**注入旧代表粒径与旧规则的兼容测试**，不是 N_d = 1 的生产取样。
