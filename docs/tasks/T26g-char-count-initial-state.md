## 来由

M3 审计与 T26f 预检表明，第 1 关内层不收敛的主因是 m_C → 0 处闭合的奇异（审计 4-1）与初值使第 1 轮冻结量自相矛盾（审计 3-1，床区每个界面伪净上行 0,265 kg/s）。ADR 0044 修改焦炭反应的颗粒数，ADR 0045 修改初值构造。本卡实现两者，先验证，通过后重跑。

## 范围内

### A. ADR 0044

1. R1、R2、R4 的反应颗粒数取 N_C = M_C/m_p,k（床区与自由空间）；R3、颗粒温度不变。
2. 各状态的单位焦炭质量消耗系数 α_s（ADR 0044 第 2 项），自由与悬停状态各用本状态输入（u_r 按 ADR 0035 第 4 项）。
3. 消耗 α_s·M_C、焦炭迁移 α_s·M_C·q_k、灰迁移 α_s·M_A·q_k、灰释放 α_s·M_A；删除 M_A/M_C 与 ADR 0026 第 4 项第 3 点的 m_C = 0 切换，一致处理灰输运、灰入流去向与状态有效域。
4. 注明 `解释性选择：ADR 0044`。测试按 ADR 0044“实现约束”各项。

### B. ADR 0045

5. 焦油初值：燃料加入格及以上，按 T_init 下表 4.3 的焦油产率另加 C₆H₆、C₁₀H₈，不经反应。
6. 固相初值按 ADR 0045 第 3 项的块顺序：焦炭块线性求解（先核对焦炭行对灰未知量导数为零）→ 床区灰分配 → 自由空间灰块线性求解 → 对完整固相行回代检查固相门；与预计算交替，至界面上下行流与回落相对变化 < 1·10⁻²，至多 5 次。
7. 第一次外层以构造的状态作为上一轮单元解。
8. 停止条件按 ADR 0045 第 4 项。**任何阶段发现自由空间体积超出有效域（ADR 0026 第 5 项）都停止并报告**：cell、各状态存量、总体积比与上限。现行 `evaluate_residual` 在装配固相行前做有效域检查，超域时会抛出 `FreeboardDomainError`；此时回代残差记为“未完成（有效域拒绝）”，不继续内层牛顿、不进入 D，不绕过有效域检查、不截断存量。只有已完成完整回代且满足固相门时，才可进一步表述为“给定气相、温度与冻结量下的固相稳态超域”。注明 `求解手段：ADR 0045`。
9. 测试：焦炭块不依赖灰未知量；构造的小例子上块顺序解与回代残差在舍入误差内；床区焦炭总量为零时停止；与预计算交替的终止判据。
