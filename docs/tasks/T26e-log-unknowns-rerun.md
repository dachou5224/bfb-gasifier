## 范围内

### A. 实现（ADR 0042）

1. 在牛顿迭代变量层实现：当前值为正的气体流量、焦炭与灰存量以 y = ln x 迭代，值为 0 的保持线性；F 仍在 x = exp(y) 处评价。注明 `求解手段：ADR 0042`。
2. 差分步长：线性变量起始按 ADR 0041，对数变量起始 √ε；不可分辨（‖ΔF‖ 归一 ≤ ε_mach·‖F‖ 归一）时乘 10²，最多 4 次，并受 ADR 0042 第 2 项的上限约束；到上限仍不可分辨的列写入诊断记录。
3. 线性求解的行列缩放按 ADR 0042 第 3 项。
4. 测试：
   - 正值变量在任意阻尼步长下保持为正；值为 0 的变量保持线性；
   - 构造“F 对某痕量变量在 √ε·|x| 上不可分辨”的例子，验证步长被放大且列非零，以及到上限时的记录；
   - 链式法则（或 y 空间差分）与解析导数在构造例上相对差 < 10⁻⁶；
   - 阻尼、可行条件与收敛门的现有测试逐位不变；对已在 x 空间收敛的良态构造例，新旧迭代给出同一解。
