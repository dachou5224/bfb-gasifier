## 来由

限时诊断中外层各轮的 A5 余额都为负（O7）：床灰按焦炭比例分到各粒级，细粒级灰量由焦炭粒级决定，带出灰多于燃料带入灰。闭合复核与三份文献审计后，目标所有者选定 B5（ADR 0055）：

- 飞灰 = φ·Ṁ_A，底灰 = (1 − φ)·Ṁ_A，φ 为工况输入，工况 1 主值 1，敏感性 S18 取 0,3；
- 床灰分为细灰（份额 w_f，全进最小粒级 k = 1）与粗灰（全进最大粒级 k = K）；
- w_f 每次预计算用端点响应加 Illinois 括号求根更新，使顶部带出灰 E = φ·Ṁ_A；
- 排灰灰分量不再由余额给出，不会为负；灰平衡作为外层收敛的独立条件检查。

本卡把 ADR 0055 写进 `hamel/`，并删除被取代的按焦炭比例分配与 A5 余额式。O4（Corella 有效域）不在本卡内。

### B. 实现

1. **φ 输入**：工况文件 `data/cases/vtt_pressurized.json` 工况 1 新增飞灰份额字段（名由 cursor 按现有命名定，值 1,0，来源 “KURKELA_1992 p. 7；ADR 0055 第 1 项”，状态按现有写法标为解释性选择）；其他工况不填，使用时按缺失输入停止。读入后检查 0 < φ ≤ 1、Ṁ_A > 0，否则按工况输入无效停止（ADR 0055 第 3 项）。ADR 0039 字段表、ADR 0030 冻结清单在本 PR 中补一行。
2. **Ṁ_A**：燃料带入灰 − 随未转化燃料离开的灰，沿用 `_drain_terms` 中现有的这两项（含 T26n 的干基项）；只此一份公式，排灰、目标 T 与灰平衡检查共用。
3. **床灰粒级分配**（ADR 0055 第 2 项）：新函数给出 share[i, 1] = w_f·m_inert,i，share[i, K] = (1 − w_f)·m_inert,i，其余为 0；w_f 对各床格相同，作为冻结量进入 `FrozenQuantities`，内层中不变。床面灰抛出、`redirect_ledger`、`particle_temperatures` 改用它。反应颗粒数（ADR 0044）不动。
4. **排灰**（ADR 0055 第 4 项）：排灰灰分量 = (1 − φ)·Ṁ_A；排灰焦炭仍按最底床格局部组成。φ = 1 时排灰为 0，不计算局部组成；因此“最底床格灰分 > 0”（ADR 0054 第 2 项第 2、3 层的初值构造附加项）只在 φ < 1 时检查。初值构造固相子系统中的 A5 同样改用此式。
5. **E(w) 的计算**（ADR 0055 第 3 项定义）：给定 w，取本轮预计算刚得到的冻结量，以及上一轮内层解（初值构造中用上一次固相解）中除自由空间灰存量以外的全部未知量；**只以自由空间灰存量（两个状态、各格各粒级）为未知量、只取自由空间灰衡算行**，用现有 `damped_newton`（恒等变换，ADR 0043 的行列缩放，收敛门取内层固体块的门）求解，起点为上一轮内层解中的灰存量。E = 该解的顶部带出灰。闭合 C（S14）下改送出口的灰计入 E（ADR 0026 第 6 项：悬停样本计为出口带出）；闭合 B 的改送回床不计入。
   - 子求解不收敛、或收敛解有灰存量 < −τ 时，报告并停止，不截断。
   - 不得用“保持顶部灰存量不变”的写法求 E（那样 E 与 w 无关）。
6. **w_f 更新**（ADR 0055 第 3 项，逐步照写）：T = φ·Ṁ_A；先求 E₀ = E(0)、E₁ = E(1)；当前 w_f 已满足 |E − T|/T < 1·10⁻⁶ 则保留；否则先查第 5 项三条停止（(E₀ − T)/T ≥ 1·10⁻⁶；(T − E₁)/T ≥ 1·10⁻⁶），再以 [0, 1] 为括号用 Illinois 法解 E(w) = T，|E − T|/T < 1·10⁻⁶ 结束，至多 50 次 E 评价，超出报告“求根失败”并停止。初值 w_f,0 = 燃料粒级 1 的质量分数。首次预计算（无上一轮解）不更新，用 w_f,0。
7. **灰平衡收敛条件**：外层收敛（ADR 0012 第 2(a) 项）时须 |E − T|/T < 1·10⁻⁴，此处 E 为内层解的顶部带出灰（闭合 C 含改送出口灰）；第 2(b) 项一致性复核重算后仍须满足。写法与 ADR 0029 第 4 项的壁面散热检查相同。
8. **敏感性 S18**：`campaign.py` 登记 “S18 | φ = 0,3（底灰 7、飞灰 3）| ADR 0055 第 1 项”，`overlay` 写入工况副本；`run_specs` 的范围扩到 S18。
9. **能量**（ADR 0055 第 6 项）：飞灰与底灰的焓流沿用现行带出、排灰的写法，不另立公式；核对排灰为 0 时排灰焓流为 0。
10. 代码注明 `解释性选择：ADR 0055`；被修订处的 docstring 更新 ADR 编号。

### C. 测试（ADR 0055“实现约束”逐条）

11. 外层不动点上飞灰 = φ·Ṁ_A、底灰 = (1 − φ)·Ṁ_A，灰的全炉平衡（Ṁ_A 进 = 飞灰 + 底灰）在容差内闭合；φ = 1 时排灰（灰与焦炭）为 0。
12. 括号求根的手算例（E 为 w 的已知函数，T = 1）：E = 2 + 10·w 停止（粗灰带出超过目标）；E = 1 + w 得 w_f = 0 且下一轮仍保留 0；E = 0,5 + w 从 w_f = 0 起得 0,5；E = 0,2 + 0,5·w 停止（细灰不足）；E ≡ 1 时任意 w_f 已满足；不连续函数使 50 次内不达容差时报告求根失败。
13. φ = 0、φ > 1、Ṁ_A = 0 作为输入时停止。
14. E(w) 按定义重新求自由空间灰稳态：同一冻结状态下 E(0) ≠ E(1)；子求解的解满足自由空间灰衡算行。
15. 床灰抛出只进入 k = 1 与 k = K；反应颗粒数与修改前逐位相同（ADR 0044）。
16. 外层收敛门：|E − T|/T ≥ 1·10⁻⁴ 时不宣布外层收敛；(b) 复核重算后不满足时停止。
