## 目标

去掉自由空间停留时间在近中性处的 1/|ε| 发散（ADR 0057），并在工况 1、φ = 1 上报告：系数在原诊断区间上的实际变化，以及外层能否按现行门收敛。服务第 1 关。

**本卡不保证外层收敛。** ADR 0057“影响”与“未决”已写明：去掉发散后剩下的不连续是否随样本数缩小、外层能否收敛，都待本卡验证。终态是“外层未收敛”时，只要报告齐全，就是预期结果之一，不算本卡失败。

3. **插值规则**（第 D.2 项与本项共用，写进工具与报告）：

### B. 实现（一个提交，注明 `解释性选择：ADR 0057`）

1. `SolverConfig.freeboard_residence_floor_m_s = 1.0e-2`（`hamel/cases/config.py`）。允许 0：取 0 时规则不起作用，结果与现行逐位相同。负值或非有限值报错。
2. `hamel/freeboard/accounting.py`：
   - `trace_until_fate` 中的 `close` 每次在一个解析段（`advance_cell` 一次调用）之后调用，所以 `segments` 的每一项就是一个解析段，段内 u_P 不变号，高度单调。给每一项补记段首、段尾高度。
   - `_classify` 计入停留时，先取自由部分（现行逻辑：整段在捕获前取整段；跨捕获时刻取前缀；捕获后不计）。跨捕获时刻时，自由部分的段尾高度取捕获事件的位置（半格 R* 的格中点，或 `captured_face` 的起点情形——起点情形自由部分为空）。自由部分计入 min(t_自由, |Δh_自由|/u_min)。
   - 自由部分的滑移按现行规则（段滑移按时长比例）取，再乘同一比例 t_计入/t_自由。
   - u_min 经 `trace_until_fate` 的 `config` 传入，不新增全局状态。
3. 不改：轨迹推进、事件、归宿、捕获判据与捕获时刻、穿越计数、θ、悬停、窗口与漂移、参考来源切换（`use_bed`）、“有穿出通量但停留为 0”的报错、严格中性格停止、样本数。
4. 登记：`hamel/solver/campaign.py` 登记 S19（u_min ∈ {3·10⁻³, 1·10⁻², 3·10⁻²} m/s，仿 S18）；ADR 0030 冻结清单补列本参数与 S19；ADR 0050 加补注，指向 ADR 0057。

### C. 一致性

- u_min = 0 时，用第 A 项保存的入参原样在两端各做一次预计算，冻结量与第 A.4 项快照**逐字段**比较（`np.array_equal`），列出 missing／extra／different。新增的报告字段若进入冻结量，逐个列出并排除。结果写进 PR。

### D. 验证运行（只报告）

1. **初值点对照**：工况 1 初值点的第一次预计算，u_min = 0 与 1·10⁻² 各一次。报告：停留计入被截短的轨迹条数（按粒级）、各粒级逐格 m̂、a_f、b_f、c↑、c↓ 新旧对照、预计算耗时。
2. **一维扫描**：按第 A.3 项的插值规则在两个端点之间插值（s ∈ [0, 1]），每点只做预计算。四组：u_min ∈ {0, 1·10⁻²} × 取样 {8×8, 16×16}，**两种取样都用同一组 11 个节点** s = 0, 0,1, …, 1。另在 8×8 上加 10 个中点（共 21 点），只用于定位窄峰，不进入取样间的比较。取样经工具中替换 `precalc.within_class_samples` 实现，不改正式路径。
   - 逐点记录粒级 1–4 逐格的 θ↑、θ↓、m̂、a_f、c↑、c↓、free_state、窗口去向、捕获格、参考来源（床面抛出或当地轨迹）以及 w_f。
   - 粒级 2、3 另记**轨迹级记录**：每个（d, φ_S, 起始速度）的归宿、进入格与进入方向（工具中包装 `trace_until_fate` 取得，不改正式路径）。
   报告：
   - 在共用的 11 个节点上：m̂、c↑、c↓、a_f 的相邻点最大跳变（相对该量在 11 点上的最大绝对值）及位置，8×8 与 16×16 并列比较；
   - 每个最大跳变的归因，分开列：(a) 轨迹归宿翻转（由轨迹级记录确认，写出是哪个样本）；(b) 捕获进入格或方向变化；(c) θ 变化；(d) 参考来源切换；(e) 捕获格变化；无证据的标为“未定位”。θ 是捕获事件的加权聚合，归宿翻转时可能不变，不能以 θ 代替 (a)；
   - 8×8 的 21 点上额外发现的窄峰，单列；
   - u_min = 0 一组是否复现 ADR 0057 依据中的极点（m̂ 在某处陡升后骤降），如未复现，如实报告。
   不预设结论。
3. **外层运行**：工况 1、φ = 1，u_min = 1·10⁻²，`tools` 中外推 Corella，经 `driver.solve_case` 跑外层，上限 26 轮，墙钟不超过 6 小时。逐轮报告：φ、w_f、E 与 |E − T|/T、床区焦炭、最小格惰性物、逐格床温、内层状态与迭代次数、投影计数、外层门四项（dT、固相流、存量、气相流）。若通过外层门，报告正式路径上 ADR 0012 第 2(b) 项复核的结果（灰平衡与三块残差比）及终态。

全部写进 `reports/t26s-validation/report.md`。**不得**在报告中给出出口组成、T̄_FRB、X_C，也不得用它们判断任何事。

## 测试（必须新增）

- 近中性格（|ε| 远小于 u_min 但不为中性）：计入的停留时间等于 Δh/u_min；u_min = 0 时恢复现行值。
- |Δh_自由|/t_自由 ≥ u_min 的段，计入值与现行逐位相同。
- 段内捕获的比例按自由部分计算：整段 20 s、位移 0,30 m，捕获前 10 s、位移 0,05 m，u_min = 0,01 m/s，计入 5 s（不是 10 s）。可用构造的段表直接测 `_classify`。
- 自由部分的滑移与停留按同一比例缩小。
- 归宿、穿越计数、θ 在 u_min = 0 与 1·10⁻² 下相同。
- 参考来源切换与“有穿出通量但停留为 0”的报错路径行为不变。
- u_min 为负或非有限时报错。
