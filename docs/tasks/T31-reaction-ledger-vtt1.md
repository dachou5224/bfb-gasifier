## 目标

T30 的验收结论是**不通过**：7 量中 `X_C`、`CO2`、`H2`、`H2O` 在合格区间外，`T̄_FRB`、`CH4` 边界待定。外部核算已确认偏差**不是元素账错误**（两侧元素闭合），而是反应路径的分配与生成量问题。

本卡把“分配”这一步**读出来**，不再靠推断：给出基准收敛解上**逐格、逐相（气泡／悬浮／自由空间）的 R1–R11 计量贡献**（`ν_i × 进度`，mol/s，按物种分列，**含全部非零项**），以及各格各相的温度、压力、相体积、气相摩尔流与 `O2`／`H2`／`H2O`／`CO`／`CO2`／`CH4` 的浓度和摩尔分数，并据此给出**物种账**：每种物种的**总消耗量、总生成量、带符号净值**，逐格分列。

产出是**诊断记录**，不是验收结论，也不是因果证明：本卡不改判定，不改任何数值，不产生新的验收量。

### C.0 统一的符号定义（下列各节一律照此，不得各自另立公式）

每条记录是 `q[j, i] = ν[j, i] × extent[j]` 的实数值（mol/s，带符号，产物为正、反应物为负），其中 `j` 遍历**全部实际发生的项**，含 `(zone, cell, phase, reaction, phi, tar)` 的每个分项（不同 φ 的 R1、两种焦油的 R10／R11 各自独立成项）。

对每个物种 `i`：

- `生成_i = Σ_j max(q[j, i], 0)`
- `消耗_i = Σ_j max(−q[j, i], 0)`
- `净_i = Σ_j q[j, i] = 生成_i − 消耗_i`

由此确立三条硬性要求：

1. **不得**用反应编号乘一个整数系数去凑某个物种的量。水在 R11 的系数是 `−4.5`（苯）或 `−23/3`（萘），写 `−R11` 只减了 1，少算 3.5 或 6.667 倍；R7 的系数已经是 `+2`，写 `+2·R7` 是重复计量。
2. **可逆反应按实际符号分类**。R8 可逆：正进度时 `ν_H2O = −1`（耗水、产氢），负进度时该记录 `q > 0`（**产水、耗氢**）。因此 **C.2 不得把 R8 固定写在耗水一侧，C.4 不得把 R8 固定写在产氢一侧**，两处都按 `q` 的实际符号落列。
3. **聚合只做“同一层内的相加”，拆分始终在保方向的实际记录层完成**。正负贡献的拆分**永远**在保留方向与分项（含格、相、φ、tar）的实际记录层做，即对每条记录取 `max(q, 0)` 与 `max(−q, 0)`；**不得**先把同一反应跨格／跨相的带符号 `q` 合并成一个数再拆列——那会隐藏反应周转（例：一格 R8 耗水 1、另一格逆向 R8 产水 0,8，逐记录拆分的全床合计是消耗 1、生成 0,8、净 −0,2；若先合并再拆，只剩消耗 0,2、生成 0，分母与占比都会变）。
   展示成格相表或全床表时，只把**已经拆好的**生成列与消耗列分别相加，净值另按 `Σq` 单列保留；**三列信息都要留下**，不得只留净值。

   **正确与错误的做法（本卡以此判分）**：

   | 做法 | 判定 |
   |---|---|
   | 逐记录取 `max(q,0)`／`max(−q,0)`，再按格相／全床分别求和 | **正确** |
   | 先把同反应跨格／跨相的 `q` 相加，再对合计取 `max`／`max(−)` | **错误**（丢周转） |
   | 只报 `净 = Σq`，不报生成与消耗 | **错误**（丢三列） |

1. **物种账**：C、O2、H2O、H2、CH4、CO、CO2 各自逐格的消耗量、生成量与净值（严格按 C.0），按反应分列，见上节清单（必须覆盖全部非零项）。
2. **水账专节**：按 C.0 给出逐格、逐反应的水 `q` 值，并按符号落列——消耗侧的 R2／R9／R11 与**正进度的 R8**，生成侧的 R6／R7 与**负进度的 R8**；再给 `净_H2O = Σ q[j, H2O]`，与入口水 0,1901 mol/s 对照（`净 < 0` 即净分解）。R11 必须按其**实际焦油代表物**取系数（苯 `−4.5`、萘 `−23/3`），不得写 `−R11`。必须能回答两件事：**水被谁消耗了多少**、**产水比“应有的”少了多少**。
3. **氧账专节**：各格 O2 入流（进口气 + 由下方来 + 相间交换）、R1／R5（气泡与悬浮分开）／R6／R7／R10 的消耗量与份额、该格 O2 出流；全床合计与总进氧 0,21 × 1,015 对照。R1 的氧系数按实际 φ 取 `−1/φ`。
4. **氢与甲烷专节**：H2 的生成（R2／R8／R9／R10／R11，**R8 按实际符号**）与消耗（R4／R6，以及**负进度的 R8**）；CH4 的生成（R4／R11）与消耗（R7／R9）。用于区分 H2 偏高是“产得多”还是“烧得少”。
5. **碳账专节**：焦炭消耗 R1／R2／R3／R4 各自份额（**四者都必须出现**），据此区分“燃烧”与“气化”；CO／CO2 的生成与相互转化（R1 按实际 φ 分项、R5、R8、R3），与 `X_C` = 86,639 % 对照。焦炭量按 C.0 的 `q[C]` 带符号记账（R1–R4 的 `ν_C = −1`，正进度即消耗），折算只用 `返回质量 / M_C`，**不得**再取负号。`X_C` 的口径照 T30 报告原文（出口气体含焦油碳 ÷ 加入碳），本卡不改。
6. **份额定义（供 C.2–C.5 统一使用，分母一律取自 C.0 的 `消耗_i`／`生成_i`）**：
   - 某分项的**消耗份额** = 该项的 `max(−q, 0)` ÷ 该物种的 `消耗_i`（全部同类消耗之和）；
   - **生成份额**同法，分母为 `生成_i`；
   - **净值单列**（`净_i`），带符号，不作份额分母；
   - 分母 < 1×10⁻¹² mol/s 时**不定义份额**，记“分母可忽略”，只报绝对量。此规则对占比登记表的四项同一适用。
   - **占比登记表里的“总耗水”＝ `消耗_H2O`，“总耗氧”＝ `消耗_O2`**，均按 C.0 定义，含各自的全部分项。

### D. 账目精度的两套判据（**必须分开，不得混用**）

审查意见指出：收敛解本身的物理残差不是零（T30 气相块 2,02×10⁻⁷），因此不能用“逐格闭合到 1×10⁻⁹”去要求物理收支，也不能把非零残差解释成记账漏项。本卡因此分两层：

1. **重建精度（本卡要求 ≤ 1×10⁻¹²，相对）**：账目重建出的物种源项，与同一 `evaluate_residual` 装配出的 `reaction_bed`／`reaction_free` **逐元素比较**：
   `|Σ(ν_i × 进度) − 装配值| ≤ 1×10⁻¹² × max(|装配值|, |Σ(ν_i × 进度)|, 1×10⁻¹⁵)`。
   这一层若不过，就是**记账漏项**，必须停下修记录（这正是本卡要排除的错误）。
2. **物理收支（照实报，不改门）**：该格的 `gas_mole_residual`（入流 + 回流 + 反应 − 出流 ± **相间交换**）按原样报出，附该题的**原有收敛门**（气相 1×10⁻⁶、固相 1×10⁻⁶、能量 1×10⁻⁶、元素 1×10⁻³）。逐相核对时**必须包含交换项**，否则会凭空出现同量级的假缺口。
   - 归一化尺度：每个 (格, 相, 物种) 的尺度取 `max(|入流|, |出流|, Σ|ν×进度|, |交换|, 1×10⁻¹²)`；零流量（尺度 < 1×10⁻¹²）时只报绝对量并标注，不报相对差。
   - 报告须明确：这一层**不是**本卡的通过条件，只需与 T30 的残差数值一致（相对差 ≤ 1×10⁻⁹），证明记录没有改动求解。
