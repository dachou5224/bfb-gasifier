# 悬停闭合研究：闭合 A 的有效域、温度敏感性与粒级内漂移

> 研究底稿，只作背景与裁定材料，不是修改闭合的授权或已验证证据（STATUS 2026-10-29 预先登记第 2 条）。不使用任何验收量。
> 数据：`tools/hover_drift_closure.py` → `reports/research-hover-drift/study.json`。工况 1，T26j（PR #133）链路运行到 ADR 0049 第 3 步的预启动焦炭块解出之后、自由空间灰块之前；气相与温度为初值（自由空间 T = 1073 K），床区焦炭 3,58 kg 固定，冻结量来自第 1 次预计算。为求系数而暂停有效域检查，只作诊断。

## 1. 闭合 A 在预启动点上的悬停平衡

粒级 3（0,25–0,5 mm）各悬停焦炭行线性：r = I − λ·M。差分得：

| 几何格（自下而上） | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 流入 I（g/s） | 6,70 | 5,01 | 4,95 | 3,29 | 4,08 | 2,44 | 0,81 |
| 悬停存量 M（kg） | 8,55 | 6,36 | 6,29 | 4,18 | 5,19 | 3,10 | 1,03 |

- λ = 7,84·10⁻⁴ s⁻¹，即 α(1 + q_3)，α = 7,17·10⁻⁴ s⁻¹、q_3 = 0,0935（ADR 0044 第 3 项）。悬停状态的平均停留 1/λ ≈ 1 275 s。粒级 3 进入悬停的总流 27,3 g/s。
- 粒级 3 悬停焦炭合计 **34,7 kg**，另有几何格 0 中粒级 4 的悬停 0,82 kg，悬停总量 35,5 kg（T26j 报告中“合计约 34,7 kg、粒级 3 约 33,9 kg”的两个数应分别为 35,5 与 34,7）。床区焦炭 3,58 kg。
- 体积比（自下而上）1,575 / 0,701 / 0,715 / 0,459 / 0,575 / 0,342 / 0,118 / 0,014。几何格 0 是锥段下沿，容量 6,04 kg，比其余各格的 9,26 kg 小。

悬停存量 = 流入 × 停留时间；停留时间由消耗速率 α 决定，与几何无关。

## 2. 温度敏感性（第 3 项）

自由空间温度整体改变，其余不变（流入不变）：

| T（K） | 1073 | 1123 | 1173 | 1223 | 1273 |
|---|---|---|---|---|---|
| λ（10⁻⁴ s⁻¹） | 7,84 | 15,2 | 28,2 | 49,9 | 85,3 |
| 几何格 0 体积比（按 1/λ 缩放） | 1,58 | 0,81 | 0,44 | 0,25 | 0,15 |

- 每升高 50 K，λ 约增大一倍。自由空间平均温度高于约 1 110 K 时，A 在该格回到有效域以内。
- 因此本次超域**强烈依赖初值温度**。但不能据此推断耦合解一定在有效域内：同一工况的 T_ad = 971,5 K 低于 T_init，自由空间温度由能量方程决定，也可能更低。预启动点的超域只说明：在初值的气相、温度与冻结量下，A 的固相超出有效域。
- 即使在 1123 K 回到有效域内，悬停焦炭（约 18 kg）仍是床区焦炭的 5 倍。

## 3. 粒级内漂移与不重复计账（第 1 项）

### 3.1 漂移从哪里来

- Hamel S. 86 式 (5.11)：焦炭颗粒按外表面反应、随转化缩小，焦炭密度恒定（ADR 0044 依据）。故 m ∝ d³，单位质量消耗 α 给出 d ln d/dt = −α/3。
- ADR 0047 第 3 项：粒径 d、球形度 φ 的颗粒只在 ū_g(下方格) > v_t(d, φ) > ū_g(上方格) 的界面上有稳定点。气速沿高度单调下降（本点 ū_g 自下而上为 1,226、1,125、1,041、0,972、0,917、0,871、0,834、0,804 m/s）。
- 所以一个悬停颗粒在缩小的过程中 v_t 连续下降，平衡界面逐个上移；v_t 低于最上一个稳定界面上方格的气速后，颗粒不再有稳定点，进入上方格的自由状态并被带出；若在此之前粒径先降到粒级下界 a_k，则按 ADR 0044 迁往 k − 1 级。
- ADR 0026 第 1 项把这一机制写成“悬停颗粒只能通过反应减少质量，并随缩粒迁移到更小的粒级……再被带出或回落”。在单一代表粒径、整格捕获区下，粒级迁移是唯一可分辨的出口。ADR 0048 引入粒级内取样与半格捕获区后，同一粒级被分到多个界面，粒级内部的界面窗口变得可分辨，而 A 仍只允许在跨出整个粒级时离开悬停。漂移是 ADR 0026 第 1 项同一机制在 ADR 0048 分辨率下的离散。

### 3.2 为什么不重复计账

把一个颗粒的状态记为 ln d（φ 不变）。缩粒使 ln d 以 α/3 的速率单调减小；ln d 轴上有两类边界：

1. 粒级边界 a_k：跨过即迁往 k − 1 级（ADR 0044 第 3 项的 q_k 项）；
2. 稳定窗口边界 d*_j(φ)，由 v_t(d*_j, φ) = ū_g,j 定义：跨过即从界面 j − 1 的悬停转到界面 j 的悬停；跨过最上一个窗口的上沿，转入上方格的自由状态。

每一次缩小只会跨过其中一条边界，每条边界上的通量只记一次。因此只要在悬停状态中：

- 粒级迁移只对窗口内含 a_k 的那部分悬停质量计入；
- 漂移只在粒级内部的窗口边界上计入，不在 a_k 处计入；

两者就不重复。现行 A 对每个悬停格的全部存量都按 q_k 计粒级迁移，相当于假定悬停质量在整个粒级内分布，与 ADR 0048 下该格只承接一个窗口的事实不一致。本点 φ = 0,8 的窗口对应 d ≈ 0,265–0,37 mm，整段在粒级 3 内部，这类颗粒在悬停中根本不会跨过 a_3 = 0,25 mm（v_t(0,25 mm, 0,8) = 0,753 m/s，低于最小气速 0,804 m/s）；φ = 1,0 的颗粒 v_t(0,25 mm) = 0,886 m/s，窗口跨过 a_3，才有粒级迁移。

自由状态的停留只有秒量级（a^f、b^f 为 10⁻²–10⁻¹ s⁻¹），漂移可忽略，不改。

## 4. 漂移闭合下的存量估算（第 2 项）

窗口宽度 W_j = ln(ū_g,j / ū_g,j+1) 自下而上为 0,0859、0,0777、0,0681、0,0591、0,0509、0,0434、0,0368（合计 0,422）。窗口内 d ln v_t/dt = −n·α/3，n = d ln v_t / d ln d 在本窗口内为 1,1–1,4（φ = 0,8 时 0,30 mm 处 1,22）。流入 I 与 α 取第 1 节的值，不重算预计算。两种离散：

- **精确链**：入射点在窗口内按 ln v_t 均匀分布，逐窗口积分质量；
- **一阶迎风**：每格一个悬停存量，漂移出流 κ_j·M_j，κ_j = n·α/(3 W_j)，进入上方格悬停。

| n | 离散 | 粒级 3 悬停（kg，几何格 0–6） | 合计 | 体积比最大值 |
|---|---|---|---|---|
| 1,0 | 精确链 | 1,11 / 2,47 / 3,02 / 3,09 / 2,98 / 2,76 / 2,31 | 17,7 | 0,362 |
| 1,0 | 迎风 | 1,92 / 2,73 / 3,15 / 3,02 / 3,01 / 2,66 / 2,15 | 18,6 | 0,479 |
| 1,2 | 精确链 | 0,94 / 2,12 / 2,63 / 2,73 / 2,66 / 2,49 / 2,10 | 15,7 | 0,321 |
| 1,2 | 迎风 | 1,65 / 2,39 / 2,79 / 2,70 / 2,71 / 2,42 / 1,97 | 16,6 | 0,436 |
| 1,4 | 精确链 | 0,81 / 1,86 / 2,33 / 2,45 / 2,40 / 2,26 / 1,93 | 14,0 | 0,297 |
| 1,4 | 迎风 | 1,45 / 2,12 / 2,50 / 2,44 / 2,46 / 2,21 / 1,82 | 15,0 | 0,403 |

对照 A：合计 34,7 kg，最大体积比 1,575。

- 漂移使悬停总量降到 A 的 40–54 %，并把质量从容量最小的锥段下沿推向上方各格；各格体积比都在 0,48 以下。
- 约 51–63 % 的悬停流入最终从最上一个窗口转入自由状态（被带出），其余在悬停中消耗。这个比例只由窗口宽度与 n 决定（αW/κ = 3W/n），**与 α 无关**：温度只改变存量，不改变悬停颗粒最终带出与消耗的分配。A 下这部分颗粒全部在悬停中消耗或迁往粒级 2。
- 两种离散相差约 6 %，几何格 0 相差最大（迎风格式把入射点都放在窗口上沿，低估了本格停留的分辨）。

## 5. 局限

- 只在预启动点上做：流入 I 取自床区焦炭的初值与第 1 次预计算，不随漂移闭合重算；漂移把质量送出自由空间顶部，会改变床区与自由空间的耦合。
- 用单一 n 与 φ = 0,8 的 v_t(d) 关系估窗口；正式实现应按 ADR 0048 的 (d, φ) 子样本确定各窗口的质量分配与 a_k 所在的窗口。
- 温度敏感性只改自由空间温度、不改气相组成与冻结量。

## 6. 结论（交目标所有者裁定）

1. A 的超域强烈依赖自由空间温度，在初值温度下超域，在约 1 110 K 以上不超域；温度由耦合解决定，这一点本身不能证明 A 在耦合解处不可行。
2. 漂移不是新增的机制，是 ADR 0026 第 1 项“缩粒后离开悬停”在 ADR 0048 分辨率下的离散；按第 3.2 节的边界划分，与粒级迁移不重复计账。它同时要求把悬停状态的粒级迁移限制在含 a_k 的窗口，这是对现行 A 的修正，不是叠加。
3. 漂移闭合下预启动点的悬停总量约为 A 的一半，各格都在有效域内，且对温度不再处于临界。
4. 改动 F17（悬停闭合）是模型边界变更，须目标所有者明确批准；按预先登记第 3 条，若采用，新结果作为新基准与 A 并列报告。
