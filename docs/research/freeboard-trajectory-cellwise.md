# 自由空间颗粒轨迹：Hamel 的逐格解析法、闭式核验与球形度分布（研究底稿）

> 2026-10-28，总司令。目标所有者问：按现行求解量，很难想象 Hamel 当年怎样算完一个工况。本稿复核原文中与计算量有关的选择，推导并核验轨迹闭式，估计逐格常系数与球形度分布对悬停的影响。只作研究；如需采用，另立 ADR 并按章程批准（涉及 ADR 0016 第 7、11 条与 ADR 0024 的冻结选择）。

## 1. 原文（页面图像已核）

现行实现（ADR 0016 第 7、11 条；ADR 0028）：u_g 取连续的 u_gb(h)，全部轨迹数值积分（48 个样本、步长 2·10⁻⁴ s、时限 80 s），单一 φ_S = 0,8（ADR 0024）。这正是 Hamel 为计算量而回避的做法，也是每轮预计算约 530 s 的主要来源。当初的理由是连续 u_gb(h) 下常系数前提不成立，且若干印刷闭式有误（T17）。

## 2. 闭式推导与核验

脚本 `tools/cellwise_trajectory_study.py`，结果 `reports/research-cellwise-trajectory/cellwise.json`。常系数区间内：

- **Δ > 0**：θ₀ = arctan((2A·u₀ + B)/√Δ)；u(τ) = [√Δ·tan(θ₀ + √Δ·τ/2) − B]/(2A)；h(τ) = h₀ − (1/A)·ln[cos(θ₀ + √Δ·τ/2)/cos θ₀] − B·τ/(2A)。与印刷式 (3.93)–(3.95) 相同。
- **Δ < 0**：s = √(−Δ)，Ψ = 2A·u + B，由 dτ = 2·dΨ/(Ψ² − s²) 得 E(τ) = [(Ψ₀ + s)/(Ψ₀ − s)]·exp(−s·τ)，Ψ = s·(E + 1)/(E − 1)，u = (Ψ − B)/(2A)；h(τ) = h₀ + [s·τ − B·τ − 2·ln|(E₀ − e^{sτ})/(E₀ − 1)|]/(2A)。
- **h(u)**：h = h₀ + (1/(2A))·ln|Q/Q₀| − (B/(2A))·∫du/Q，Q = A·u² + B·u + C；∫du/Q 在 Δ > 0 时为 (2/√Δ)·[arctan(Ψ/√Δ) − arctan(Ψ₀/√Δ)]，Δ < 0 时为 (1/s)·ln|((Ψ − s)(Ψ₀ + s))/((Ψ + s)(Ψ₀ − s))|。

三组系数（颗粒快于气体上行；被气流带起；下落）与 RK4 比较，u、h、h(u) 的相对差约 10⁻¹²。印刷式 (3.96) 的 ln 项系数应为 +1/(2A)；(3.98) 在 τ = 0 不返回 u₀（算例中 0,5 → −0,53、−0,5 → 0）；(3.103) 中 Ψ、Ψ₀ 的定义与对数配对不对。这些与 ADR 0016 第 11 条（T17）的核验一致，说明逐格解析法可以用自己推导的正确闭式实现，不依赖有误的印刷式。各格内阻力方向在 u_P 越过 u_g 时改变，相应换用另一套系数；越过的时刻可由 τ(u) 的闭式求出，仍是解析的。

## 3. 逐格常气速下的悬停

取工况 1 初值点第 1 轮预计算的 u_gb(h)，各格取格内平均（取格中点结果相同）：u_g = 1,225、1,123、1,039、0,969、0,913、0,867、0,830、0,799 m/s（自床面起第 1–8 格）。逐格常数时格内没有平衡点，颗粒只会在“下格 u_g > v_t > 上格 u_g”的界面被夹住。

- φ_S = 0,8 时，只有粒级 3（0,347 mm，v_t = 1,134 m/s）在第 1/2 格界面（0,2875 m，二次风入口）被夹住；其它粒级都不被夹住。悬停没有因逐格处理而消失，位置与连续剖面下相同。
- 夹住窗口很窄：1,123 < v_t < 1,225 m/s，粒级 3 的 v_t 只比下界高约 1 %。

## 4. 球形度分布（原文有、现行实现没有）

S. 45 与 S. 49 表明 Hamel 的轨迹是在球形度分布上算的，0,8 只是分布的平均值；分布形状原文未给。对 φ_S = 0,30、0,31 … 1,00 逐一用逐格平均气速检查**全部界面**（`traps`，夹住条件为下格 u_g > v_t > 上格 u_g）：

| 粒级 | d（mm） | 被夹住的界面（自床面起，m）与对应 φ_S | φ_S 并集 |
|---|---|---|---|
| 1、2、7 | 0,051、0,153、2,488 | 无 | — |
| 3 | 0,347 | 0,2875：0,80–0,85；0,575：0,75–0,79；0,8625：0,71–0,74；1,15：0,67–0,70；1,4375：0,64–0,66；1,725：0,62–0,63；2,0125：0,60–0,61 | 0,60–0,85 |
| 4 | 0,593 | 0,2875：0,57–0,59；0,575：0,53–0,56；……；2,0125：0,42 | 0,42–0,59 |
| 5 | 0,839 | 0,2875：0,47–0,50；……；2,0125：0,33–0,34 | 0,33–0,50 |
| 6 | 1,386 | 0,2875：0,36–0,39；0,575：0,33–0,35；0,8625：0,30–0,32 | 0,30–0,39 |

原因：逐格平均气速自下而上单调下降（1,225 → 0,799 m/s），每个界面都是“下格快、上格慢”；凡 v_t 落在最上格与最下格气速之间（约 0,80–1,225 m/s）的颗粒，总会在某个界面被夹住，只是高度不同。连续剖面下情形相同（u_gb(h) 单调衰减，ADR 0016 第 7 条）。

因此：

- 单一 φ_S = 0,8 并不是“恰好命中窄窗口”的偶然；任何 φ_S 只要使 v_t 落在上述区间都会被夹住。球形度分布改变的是**被夹住的位置**（分散到 7 个界面），不必然减少被夹住的总量。
- 被夹住的颗粒占多少，取决于球形度分布的形状（原文空白）与抛出起始速度（是否真能到达该界面），本稿没有计算；不能用球形度区间宽度代替质量或颗粒数占比。分散到多个界面后，单格的悬停存量可能下降，但这同样是待验证的假说。

## 5. 结论与可选方向

1. Hamel 能在 1990 年代末的计算机上完成计算，主要靠两点：块三对角求解，以及逐格常系数的解析轨迹（比数值积分快约 50 倍）。现行实现在轨迹上偏离了后一点。
2. 逐格处理本身**不消除**悬停：粒级 3 在 φ_S = 0,8 时仍在二次风入口被夹住；它让轨迹计算快几个数量级，并用界面夹住代替格内连续平衡点，悬停判定可以大大简化（ADR 0026、0034 的势能井与邻域机制大部分不再需要）。
3. 现行实现**遗漏了球形度分布**。但在单调衰减的自由空间气速下，悬停是 v_t 介于最上格与最下格气速之间的颗粒的普遍现象；球形度分布只把夹住位置分散到不同界面，是否明显减少悬停总量取决于分布形状与起始速度，须在模型中验证。悬停本身是 Hamel 气速模型（鬼泡衰减到表观气速）与单颗粒运动方程组合的结构性结果，不是单一 φ_S 的偶然。

可选方向（均须 ADR，涉及冻结项，须目标所有者批准）：

- **A. 逐格解析轨迹**（修订 ADR 0016 第 7、11 条）：按 S. 48 逐格常系数，用第 2 节的正确闭式；各格 u_g 的取法（格内平均、中点或边界值）原文未说明，须裁定。预计预计算耗时大幅下降，T23、T23b 的轨迹与悬停代码大部分替换，`hamel/` 行数可能减少。
- **B. 球形度分布**（修订 ADR 0024 对轨迹的单一 φ_S）：按 S. 45、S. 49 在 [0,3; 1,0] 上取若干球形度类，平均值 0,8；分布形状须裁定（原文空白）。床区仍用平均 φ_S。它使实现更贴近原文，并把悬停分散到不同高度，但不消除悬停。每个粒级的轨迹数乘以球形度类数，在 A 的解析法下代价可以接受，在现行数值积分下代价很高。
- A 与 B 都不消除悬停；B 需要 A 的速度才可行。悬停的处理仍需在闭合层面（ADR 0026 的 A/B/C 或研究底稿 `hover-particle-density.md` 的候选方向）另行裁定。

建议：先完成 T26g（ADR 0044、0045），同时把 A + B 作为下一阶段的候选（主要收益是贴近原文与计算速度），由目标所有者决定是否立 ADR；若 T26g 的初值构造因悬停超域停止，A + B 不能单独解决，仍须在悬停闭合上裁定。

## 审查记录

- PR #121 复审：(1) 球形度区间宽度不能代替分布权重，不能推出“只有一小部分被夹住”；(2) 只比较二次风界面不能代表整个自由空间，改变 φ_S 可能只是把夹住位置移到上方。已修订：对每个 φ_S 检查全部界面并列出并集；指出单调衰减气速下 v_t 介于最上格与最下格气速之间的颗粒总会被夹住，球形度分布只改变位置；占比与悬停量的变化改为依赖分布形状与起始速度的待验证假说；第 5 节与候选方向的作用判断同步改写。
