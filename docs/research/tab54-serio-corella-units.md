# Tab. 5.4 的 Serio／Corella：单位基准与适用温度区间复核

> 研究底稿，不是 ADR。依据：
> - Hamel（2001）原页，PDF idx 56–58（印刷 95–97）；
> - `docs/adr/0010-kinetics-source-gaps.md` 第 9、10 项；`0017` 第 18 项；`0022` C3；
> - T31 反应路径账（`main` 的 `639be05` 下 `reports/t31-reaction-ledger/`）。
>
> 起因：目标所有者 2026-11-25 提问「自由空间用 Serio 模型及参数的原文依据」，并指出「目前的证据可能指向自由空间高估了焦油转化」。
>
> **本底稿已按首轮审查（4 项 P2）修订。** 首轮结论 A（表下注符号与 ADR 0010 相反）**经原页图像核对后被否定**，相关段落已删除。

## 0. 结论

### 0.1 已由原文确认（与审查方一致）

| # | 事实 |
|---|---|
| **F1** | §5.2.6（PDF 58 / S. 97）明确：**Serio 用于无固体气泡相**（feststofffreie Blasenphase），**Corella 用于悬浮相**（Suspensionsphase）。**该段未指定自由空间。** |
| **F2** | 自由空间取 Serio 由 **ADR 0017 第 18 项**（「原文按相区分参数时，自由空间取无固体气泡相的一组」）+ **ADR 0022 C3**（自由空间焦油只用 Serio）覆盖。**程序合规**，但无原文直接规定。 |
| **F3** | Tab. 5.4 中 **Serio 1987** 为 **LR（空反应管）**、温区 **500–900 °C**、两对参数（5,42×10⁴ / 100,5 kJ/mol；9,96×10² / 64,5 kJ/mol）。 |
| **F4** | 自由空间最终温度最高 **1315.712 K = 1042.6 °C**，**超 Serio 表列温区上限 142.6 K**。该超限**未在任何 ADR 登记**（ADR 0059 只处理了 Corella 的 8.9 K 超限）。 |
| **F5** | Tab. 5.4 的单位基准：**`*` = 反应容积基准（1/s，Serio 用列头）**，**`**` = 催化剂质量基准（m³/(s·kg_Kat)，Corella 与 Simell 用）**。**ADR 0010 第 9 项的记载与原文一致，无需修订。** |

### 0.2 待检验的诊断假设（**未确认**）

**H：自由空间 R11 的焦油转化可能被高估。**

- **支持**：F4 的温度外推未登记；自由空间体积 0.108 m³ = 床区气相体积的 6.5 倍，而 Serio 是体积基速率；T31 出口焦油仅 54 ppm。
- **尚缺**：Hamel 对 VTT 工况 1 的模拟**没有给出出口焦油量**（Bild 7.10 的 7 个量不含焦油），无法直接对照；本文所有算术都是**理想化后处理**，不是模型重解。
- **结论**：H 只能作为**下一轮诊断的候选**，本文不足以确认「自由空间高估成立」或「主因是体积」。

## 4. 自由空间构型与理想化算术（**明确标注为后处理**）

### 4.1 现行 cell 模型的保真结构与 PFR 不同

现行逐格稳态衡算**用本格出流浓度构造反应**。单格无其它来源时，一级反应的保留率为：

```
F_out = F_in / (1 + k·τ)          （逐格）
总保留率 = ∏_i (1 + k_i·τ_i)^(-1)   （串联）
```

这与**活塞流** `1 − exp(−Σk·τ)` **不是同一个算式**，两者不能混用。下文的两个口径都列出。

### 4.2 逐格数据（τ 取自 T31 最终状态，冻结）

| 格 | T / K | τ / s | k / s⁻¹ | k·τ | 1+k·τ |
|---|---|---|---|---|---|
| 0 | 1066.0 | 0.4441 | 0.6450 | 0.2864 | 1.2864 |
| 1 | 1094.3 | 0.4327 | 0.8646 | 0.3741 | 1.3741 |
| 2 | 1131.7 | 0.4195 | 1.2458 | 0.5226 | 1.5226 |
| 3 | 1171.4 | 0.4065 | 1.7897 | 0.7275 | 1.7275 |
| 4 | 1213.2 | 0.3939 | 2.5529 | 1.0056 | 2.0056 |
| 5 | 1259.7 | 0.3812 | 3.6879 | 1.4059 | 2.4059 |
| 6 | 1315.7 | 0.3686 | 5.5483 | 2.0453 | 3.0453 |
| 7 | 1144.6 | 0.3437 | 1.4049 | 0.4829 | 1.4829 |
| **合计** | | **Στ = 3.1902** | | **Σk·τ = 6.8504** | **∏(1+k·τ) = 101.30** |

`k` 用 Serio 第一对（5,42×10⁴ s⁻¹、100,5 kJ/mol），与 F3 的暂定裁定一致。

### 4.3 三个情景（**均为「只留一级 Serio、冻结 τ」的理想化后处理**）

| 情景 | Σk·τ | PFR `1−e^(−Σkτ)` | cell 模型 `1−∏(1+kτ)⁻¹` |
|---|---|---|---|
| 实测温度剖面 | 6.8504 | 99.89 % | **99.01 %** |
| 全部截断到 900 °C | 4.4716 | 98.86 % | **97.01 %** |
| 全部在 1066 K（τ 冻结） | 2.0577 | 87.22 % | **83.96 %** |

**首轮的错误**：初稿写「全在 1066 K 时 Σk·τ = 0.284、转化率 24.7 %」——那是**单格**的 `k·τ`（0.4441 × 0.645 = 0.286），不是八格之和。八格应为 **2.0577**，PFR 口径 **87.2 %**（审查方指出的数值，已复核一致）。相应地，初稿「55 %」也不成立。

### 4.4 这些数字能说什么、不能说什么

**能说**（限定于上述理想化算例）：

- 在只留一级 Serio、冻结 τ 的算例里，把温度截断到 900 °C 使 cell 口径转化率从 **99.01 % → 97.01 %**（约 2 个百分点）；
- 即使温度完全不外推（全 1066 K），该算例仍有 **84–87 %** 的转化率——**说明该算例中温度外推不是唯一的驱动因素**。

**不能说**：

- **不能**把 99.01 %／97.01 %／84–87 % 当作现行模型的**实际**焦油转化率或截断影响。真实模型还含热解释放、R10、与气相反应的耦合，且 τ 会随温度与流量变化。
- **不能**据此确认「主因是体积」——体积大是必要背景，但本文没有提供独立对照。
- 「截断只影响 1 个百分点」这句（初稿）撤回；按 cell 口径为约 2 个百分点，且仍限于该理想化算例。

### 4.5 体积这一项本身（可保留的事实）

自由空间体积 **0.108 m³**，床区气相体积 **1.66×10⁻² m³**（悬浮 8.36×10⁻³ + 气泡 8.21×10⁻³），比值 **6.5 倍**。Serio 是反应体积基准，因此自由空间天然具备较大的转化容量。

但**这既不能证明自由空间几何有误**，也不构成「自由空间高估」的独立证据——它只是说明「若 R11 确实过强，体积是可能的放大器之一」。
