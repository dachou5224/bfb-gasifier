> 对照：`data/validation_cases.json` → `CASE_HTW_WESSELING_1`（Fig. 7.4 / Table 7.1）

## 0. 论文算法与当前实现：结构性差异（分层对照）

以下对照 Hamel & Krumm 论文 **Bild 2.2、§2.1–§2.3** 与当前 `src/core/reactor.py` + `src/core/cell.py` 实现。**这是与 §1–§8 并列的「算法/架构层」解释**：即使几何与参数完全对齐，下列差异也会阻止结果收敛到论文 Fig. 7.4 的精确曲线。

### 0.1 求解算法：全局 Newton–Raphson vs Gauss–Seidel 扫描

| 论文 | 当前代码 |
|------|----------|
| 所有 cell 的未知量打包为**全局向量** **x**，建立**分块三对角 Jacobian** **J**，**一次全局 NR** 同时更新全部 cell（Bild 2.2, §2.3） | `Reactor.solve()` 对 `cell[0]…cell[N-1]` **依次**调用 `solve_cell` → 内部 `fsolve`，属于 **Gauss–Seidel 式扫描** |

**后果**：

- 全局 NR 的 **J** 含 **cell i 对 cell i+1 的耦合**（固体自上而下、气体自下而上），能感知「改变 cell 3 的 T 如何影响 cell 7」。
- Gauss–Seidel **每步只解一个 cell**，解完即固定，下一格把它当作**已知边界**——**格间耦合在单次线性化中被切断**。强放热/吸热轴向传递（如底部燃烧区→上部气化区）时，易出现**迭代不稳定**或**收敛到非物理稳态**。

**结论**：当前结构能给出**数量级合理的剖面**，但**不能期望**与论文**同一套全局离散 NR**在数学上等价。

---

### 0.2 Vorabrechnung（预算模块）：完全缺失

**论文**：进入 NR 主循环前做一次**简化整体预算**，例如：

1. 用**平均床层温度**估算挥发分总释放量（DAEM **只算一次**）；
2. 计算全局水力学量（气泡增长速率、**u_b** 剖面等）；
3. 生成**化学上自洽**的初始猜测向量 **x₀**。

**当前代码**：`Reactor._build_cells()` 中 `cell.T` 等**写死初值**（如 ~1173 K），气相组分按 **O₂/H₂O/N₂ 进料比例**分配。若 CO/H₂ 尚未在物理上生成，**初值已接近「出口型」富产气组成**，则第一次 `fsolve` 的线性化在**错误的化学状态**附近，**难以收敛**。

---

### 0.3 干燥/热解（DAEM）在论文与代码中的角色

**论文**（与 Vorabrechnung 绑定）：在预算阶段用**平均反应器温度**跑一次 DAEM，得到**固定的**挥发分产率（VM yields），在后续 NR 迭代中作为**已知源项**输入，**不再重算**。

**当前代码（已部分缓解）**：`Reactor.solve` 在每个**外迭代**开始调用 `Cell.compute_vorabrechnung()`，将干燥+热解气/固源项写入缓存，**内层 `fsolve` 的 `residuals()` 不再每次重算** CN+DAEM（见 `cell.py`）。仍与论文「预算温度取床层平均、全炉一次预算」**不等价**：缓存仍按**各格当前 T** 在**每外迭代**更新一次，且非全局联立 NR。

**历史问题（缓存前）**：`_calc_drying_pyrolysis_gas_source()` 曾在每次残差评估中调用 → `fsolve` 有限差分 Jacobian **每次扰动都触发 DAEM** → **极慢**；DAEM 随 **T** 变化 → **强非线性** 残差。

---

### 0.4 循环流（Rezirkulation）：Jacobian 内闭合 vs 外循环显式赋值

**论文**：旋风返料从顶格到底格的连接作为 Jacobian 中的 **Nebenelemente（侧边块）**，可用 Sherman–Morrison 等处理；**含循环的系统仍在一个全局 NR 中求解**。

**当前代码**（`reactor.solve` 扫描**之后**）：

```python
self.cells[0].N_rez_d[:] = self.cells[-1].N_d * cfg.recirculation_frac
self.cells[0].m_solid_zu[:] = cfg.fuel_feed + top_solid * cfg.recirculation_frac
```

**不在** `fsolve` 的未知量与 Jacobian 内，需依赖**额外外迭代**才能闭合。循环气焓温已用 `T_rez_gas` 与顶格对齐（见 `cell.calc_energy_balance`），但**拓扑上仍非**论文的全局联立。

---

### 0.5 连接矩阵（Verbindungsmatrix）：完全缺失

**论文**（§2.1）：用户通过**拓扑连接矩阵**描述「哪 cell 连哪 cell」，同一程序可套 **实验室炉**（如 ~3.7 m VTT）与 **工业 HTW**（如 ~23 m Berrenrath）；**旋风、连接管** 亦离散为若干 cell，叠在床层序列之上（Fig. 7.4 中 **ξ > 1** 段对应旋风/连接管）。

**当前代码**：`Reactor._build_cells()` 仅生成**线性序号** `0…N−1` 的床层 cell，**无旋风 cell、无连接管 cell、无非线性拓扑**。这与 **`H_freeboard=0`、无自由板 cell** 同源：**没有机制**在 bed 之上追加轴向段。

---

### 0.6 收敛判据：默认宽松、UI 更宽松

`reactor.solve` 签名默认 `tol_global=1e-4`（单位：K），但终止条件为：

```text
dT < tol_global   或   max_res < tol_global * 50
```

- 当 `tol_global=5.0`（**Streamlit `app.py` 调用**）时，温度差 **< 5 K** 即可判停；且 **`max_res < 250`** 在 `tol_global=5` 时极易满足。
- `max_global_iter` 有限（如 20）时，**可能远未满足**论文意义的 **‖F‖ < 1e⁻⁴～1e⁻⁶（相对）**。

**后果**：返回的 `converged=True` **不保证**接近真实稳态残差。

---

### 0.7 三类差距小结

| 类别 | 论文 | 当前代码 | 对结果的影响 |
|------|------|----------|--------------|
| **算法结构** | 全局 NR，分块三对角 | Gauss–Seidel 扫描 + 单 cell `fsolve` | 格间耦合在单次线性化中不闭合；可能错稳态 |
| **缺失模块** | Vorabrechnung、连接矩阵 | 无 | 初值差→难收敛；无法模拟旋风/ξ>1 段 |
| **实现细节** | 循环在 Jacobian 内；DAEM 预算一次 | 循环在 Jacobian 外；DAEM 每残差重算 | 需额外外迭代；慢；NR 线性化失真 |

**工程上最高优先级**（若要对齐论文离散）：**全局 NR（或等效）替换扫描循环** + **简化版 Vorabrechnung 生成 x₀**；其次才是参数与几何标定。

## 2. 表观气速 `u0` 由当前气相流量反推（实现级 — 强耦合失真）

`cell.calc_hydrodynamics`（`cell.py`）：

```text
total_gas_mol_s = sum(N_b) + sum(N_d)
Q_gas = total_gas_mol_s * Rg * T / P
u0 = Q_gas / A_bed
```

- **论文/工程**：`u0`（或总干气量）通常由 **工况表 / 布气** **给定**，再算 **ε_b、d_b、K_bd**。
- **当前**：`u0` **随求解变量 N、T 变化**，反应生成 CO/H₂ 等会 **改变总摩尔流量**，进而 **改变 ε_b、V_b、V_d、K_bd、反应体积源**，形成 **强非物理耦合**。
- **后果**：局部可能出现 **u0 ≫ u_mf** → **ε_b → 0.95**、**气泡相体积过大** 或相反 **未充分流化**；与 **固定工况炉** 不一致。

**建议**：从 `validation_cases` 或 Table 7.1 **显式读入目标 u0 或总气量**，与 **ER 算出的进料** **校核** 后再驱动水力学。

## 3. 能量方程：固相仅显热，炭化学能路径可能未与气相生成焓严格闭合（守恒级）

`specs/01_conservation_equations.md` §2.3：**焓须含标准生成焓，使反应热进入守恒。**

- **气相**：`enthalpy_molar(sp, T)`（NASA）→ **含 h_f(298 K)**，**合理**。
- **固相**：`_calc_solid_enthalpy_flow` 使用 **加权 cp × (T − T_REF)**，**不显式**区分 **炭 vs 灰**，也 **未** 按 **元素碳** 的参考焓扣减。
- **炭消耗**：`R_solid` 减少固相质量；气相增加 CO/CO₂/CH₄ 等，其 **摩尔焓** 已含 **C(s)→CO** 等 **化学焓差**。若固相侧 **只扣显热、不按碳摩尔扣化学焓**，在 **稳态焓流差** 上可能与 **真实反应热** **不一致**，出现 **虚假高温/低温**。

**结论**：这是 **深耦合建模** 问题，需 **要么** 固相 **分含碳与惰性** 并采用 **一致参考态**，**要么** 在能量残差中 **显式加入反应热项**（与 Hamel 离散化方式一致）。当前实现 **更可能偏热** 或 **偏冷**，需 **逐项能量衡算审计**（非本文能证伪单值）。

## 4. 底部进料与循环的占位处理

| 项 | 风险 |
|----|------|
| `N_zu_b / N_zu_d` 固定 **0.7 / 0.3** 分配 | **无** 文献依据；改变 **气泡/乳化** 反应分配 |
| `recirculation_frac`：`N_rez_d = N_d_top * frac`，固体混合回 `m_solid_zu` | **真实** 循环为 **旋风返料 + 气体旁路**；**气相循环** **与** **N2** **载气** **质量衡算** **易** **不一致** |
| 顶格 `m_solid_in = 0` | 与 **真实** **顶部** **可能** **有** **回流** **颗粒** **不符** |

**后果**：**总氧 / 总惰性** 与 **炉内** **实际** **混合** **不同**，**出口组成** **整体** **偏移**。

## 5. 全局求解器：扫描迭代可能未真收敛

与 **§0** 互补：此处强调**现象与排查**，§0 给出**与论文 NR 的数学对照**。

- 每轮 **底→顶** `solve_cell`（`fsolve`），**Gauss–Seidel** 式扫描（§0.1）。
- 外循环判据：`dT < tol_global` **或** `max_res < tol_global * 50`；**UI** 常用 **`tol_global=5.0` K**（见 `app.py`），与论文 **‖F‖~1e⁻⁴～1e⁻⁶** 不等价（§0.6）。
- `max_global_iter` **有限**（如 20）；**单 cell** `fsolve` **converged** 可为 **假**（`ier` 非 1 仍继续）。

**后果**：**残差** 仍大时 **温度/组成** **冻结在非物理解**；曾观察到 **多组分 y 几乎相同** 的 **平台数**，符合 **未充分收敛** 或 **强约束下退化解**。

## 6. 动力学与停留时间：标定与工况错位

- **R1–R4** 用 Hamel **表 6.3** 等，但 **HTW** **实际** **焦/灰**、**粒径分布**（JSON 中 **1.5–3 mm**）与 **测试** **d_p=0.5 mm** **不同** → **表面积/转化率** **量级** **变**。
- **干热解/干燥** 与 **真实** **停留**、**升温史** **简化**（`tau_cell = dh/u_mf` 等）→ **挥发分** **与** **ER** **不匹配** 时，**气相** **初值** **偏离**。
- **R9**、**微量** **Gibbs** **路径** **占位** → **H₂S/NH₃** **影响** **主气** **若** **耦合** **则** **次要**。

## 7. 与 JSON 数字对比时的定义差异

- **温度**：JSON **exit_temperature_K / measured** 来自 **图线读数**，**±5–10%** 已注明；**模拟** 为 **单值 cell T**。
- **干基分率**：JSON **exit_gas_dry_mol_frac**；模拟 **wet** → **干基** 需 **除 (1−y_H₂O)**；**N₂** 在 JSON 中可为 **平衡算得**，**与** **当前** **O₂/N₂** **进料** **不一致** 时 **CO** **干基** **不可** **比**。
- **碳转化率**：JSON **95%** **为** **近似**；代码 **carbon_conv** 来自 **顶格摩尔流 × M_C / 进料碳**，**定义** **与** **论文** **可能** **不同**。

## 8. 建议的优先排查顺序（工程上）

**若目标是对齐论文离散与 Fig. 7.4 级曲线**（见 §0.7）：

1. **全局联立求解**（分块三对角 / 全局 NR 或等效）**替代**当前 Gauss–Seidel 扫描；循环、格间耦合纳入**同一 Jacobian 或同一联立方程组**。
2. **简化 Vorabrechnung**：平均床温下 **DAEM/干燥一次**，生成 **x₀**；迭代中挥发分源项**固定或弱更新**，避免每残差全算 DAEM（§0.2–0.3）。

**在保留当前扫描架构下的缓解措施**（仍无法消除 §0.1 的根本差异）：

3. **固定 u0 或总气量** 与 Table 7.1 **对齐**，**解耦** **N** **对** **水力学** **的反推**（§2）。
4. **能量衡算**：炭消耗与气相含碳产物焓差手算一格 cell 是否闭合（§3）。
5. **收敛**：**收紧** `tol_global`（避免 UI 默认 **5 K**）、**记录 ‖F‖ 或分块残差**；单 cell `fsolve` **tol/ier** 严化（§0.6、§5）。
6. **几何**：**连接矩阵 / 自由板 / 旋风 cell** 或至少 **H_freeboard**、分段 **u0**，再比 Fig. 7.4（§0.5、§1）。
7. **参数**：**d_p、ER、steam_to_o2_molar** 与 Table 7.1 **逐字对齐**（§6）。
