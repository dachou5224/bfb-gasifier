## 运行与复现

两条运行都由 `tools/campaign.py` 的运行表驱动（`baseline`、`S1` 两行），配置显式传入，不依赖 `SolverConfig` 的字段默认值：

| 项 | 值 | 来源 |
|---|---|---|
| `outer_round_limit` | 26 | 任务卡（参考 T26w 实测 16 轮 / 180 次 / 5 548 s） |
| 进程级硬墙钟 | 28 800 s（8 h） | 任务卡；`signal.setitimer(ITIMER_REAL, limit + 0.05)` + `_Timeout(BaseException)` |

| 绝热对照的定义 | k_W = 0、初值不扣散热 | ADR 0030 F19；ADR 0029 |

命令（两项互相独立，各跑一次；任一失败不阻止另一次）：

```
.venv/bin/python -c "from tools.campaign import run_campaign; \
  run_campaign('data/cases/vtt_pressurized.json', '<report dir>', \
               only=['baseline','S1'], outer_round_limit=26, timeout_s=28800.0)"
```

本次两次都没有超时：基准 5 474.4 s、S1 1 737.8 s，合计 7 212.3 s，远低于 28 800 s。

环境：arm64、Python 3.9.6、numpy 1.23.5、scipy 1.10.1。

**未调参声明**：两次运行之间没有改任何冻结值、容差、阻尼、初值策略、Corella 口径、收敛门或残差；没有重跑；S1 的失败按 ADR 0022 B 如实记录。

## C.6 `T̄_FRB` 与 `X_C` 的口径声明

两者都是 ADR 0040 第 1 项的解释性选择。原文因测点高度未知，只要求“平均自由空间温度”，**未指定权重与格集**；`X_C` 的原文只给出定义式的含义，没有给实现口径。

**`T̄_FRB` 的实际算式与格集**（逐字取自 `hamel/solver/driver.py::_measurements` 与 `tools/run_prep.py::_T_FRB`）：

```
T̄_FRB = Σ_i T_i·Δh_i / Σ_i Δh_i
```

- 求和范围：**自由空间全部 cell（含锥段）**，本次 8 格（锥段为自由空间第 1 格，8 × 0.2875 m）。
- `T_i` 为该格的气体温度，`Δh_i` 为该格高度。
- 8 格等高时公因子约去，实现走算术平均分支（与加权逐位相同）。
- 依据 ADR 0040 第 1 项、F26；声明为**已批准的解释性选择**，不是原文明确给出的积分范围。

**`X_C` 的实际算式与格集**（逐字取自同一处与 `_X_C`）：

```
X_C = 100 × [Σ_j (自由空间出口气体中组分 j 的摩尔流 × 该组分的碳原子数)] / [加入燃料的碳摩尔流]
```

- 分子：**自由空间出口气体（含焦油蒸气）中的碳**；求和覆盖出口全部含碳组分（CO、CO2、CH4、C2H4、C6H6、C10H8 等）。
- 分子**不计**带出焦炭与排灰中的碳。
- 分母：**加入燃料中的碳**（按收到基燃料流量与碳质量分数换算），**不是**预先扣除未转化碳后的燃料碳。
- 依据 ADR 0040 第 1 项、F27；原文依据 Hamel PDF 87 右 / S. 155 的 `Gesamtkohlenstoffumsatz`（随产品气离开的碳与加入碳之比，排灰与带出焦炭属碳损失）。
- 单位 %；目标值 78.1 % 是“干气 + 焦油”口径（`fig_7_10.json` 的 `quantity_definition.X_C`）。

**`H2O` 的湿基口径**：`fig_7_10.json` 的 `basis_gas = "wet"`，依据 KURKELA_1992 p. 9 表 5 的 “Gas composition, vol.%” 含 H2O。同页 Bild 7.9 的 `feucht` 不作本图依据，也不构成移除该量的理由。7 个验收量全部参与判定，`targets.registered_signature` 与 `judge._require_targets` 都要求完整集合。
