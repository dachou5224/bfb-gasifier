# T26o 验证记录：ADR 0054 预先登记的判据

工况 1（`data/cases/vtt_pressurized.json`），外层 1 轮，冻结模型（`21a255c` 之后的当前主线）。
工具 `tools/t26o_validate.py`；原始记录：

| 文件 | 内容 |
|---|---|
| `frozen.json`、`frozen.npy` | 不外推 Corella 的整次运行（初值构造 + 第 1 轮内层）与停止点 x |
| `extrapolated.json`、`extrapolated.npy` | 仅在工具内把 `_CORELLA_HIGH_K` 置为 `+inf` 的整次运行与收敛点 x |
| `verdict.json` | 逐条判据的数值与是否满足 |

复现命令（`PYTHONPATH` 指向仓库根）：

```
PYTHONPATH=. python tools/t26o_validate.py --only frozen
PYTHONPATH=. python tools/t26o_validate.py --only extrapolated
```

两次运行都给出 `--only` 时会一并重算 `verdict.json`。2026-11-05 的修订（PR #152 审查 P1、P2）
只重跑了冻结组（墙钟 1 449 s），外推组沿用 2026-11-04 的记录（2 381 s），
`verdict.json` 由 `compare()` 用新的 `frozen.json` 与既有的 `extrapolated.json` 重算。

## 1 冻结模型：判据 1

**初值构造**：4 次交替结束（判据 4 次），固相牛顿迭代 5／3／3／1，交替判据满足（`note` 为空）。
最后一次交替的排灰灰分量 **+1,5348·10⁻⁴ kg/s = +0,1535 g/s**（判据 +0,153 g/s ±1 %，区间 0,1515–0,1545）。
床区焦炭 3,4246 kg，固相归一整行残差 2,58·10⁻⁷。

**第 1 轮内层**：20 次迭代后停止，状态 `NOT_CONVERGED`。停止原因（`inner.reason`，差分点不可评价的原文）：

```
雅可比不能求解：差分点不可评价：KineticsInputError: Corella 参数只覆盖 600–900 °C，
ADR 0010 第 9 条没有批准外推
```

- 停止点最底床格温度 **899,999998 °C**，与 900 °C 相差 2·10⁻⁶ K；温度自下而上 793,57 → 900,00 °C。
- 第 18、19 次迭代的阻尼试探分别有 19、20 次同一 Corella 拒绝；第 20 次迭代的雅可比在差分点上
  被同一检查拒绝，所以矩阵不可解。
- 没有 O1（迭代数 20 > 0）、O2、O3、O5 类停止：没有阻尼失败，幂变量只有 1 次负 s 拒绝（随即减半接受）。
- y 上最大步长分量 **231,07**（< 1·10⁶）；第 1–19 次迭代的雅可比都可解。

**O4 的两条判据**（`verdict.json` 的 `frozen_o4`，PR #152 审查 P2）：(a) 停止原因是 Corella
范围拒绝的原文——成立，且路径是「差分点不可评价」；(b) 最底床格温度与 900 °C 相差 < 0,01 K——成立
（2·10⁻⁶ K）。只凭「雅可比不能求解」前缀不再判为 O4：任何差分点不可评价都带这个前缀。

## 2 Corella 外推：判据 2

第 1 轮内层 **CONVERGED**，85 次迭代（判据 ≤ 100）。
收敛点三块归一残差：

| 块 | 本卡 | 判据 | 诊断基线 `outer.json` rounds[0] |
|---|---|---|---|
| 气体 | 7,010419·10⁻⁷ | ≤ 1·10⁻⁶ | 7,010419·10⁻⁷ |
| 固相 | 3,233530·10⁻⁷ | ≤ 1·10⁻⁶ | 3,233530·10⁻⁷ |
| 能量 | 5,111816·10⁻⁸ | ≤ 1·10⁻⁶ | 5,111816·10⁻⁸ |

各格温度与 `reports/research-solver-path/diagnostic/outer.json` 的 `rounds[0]` **逐格相差 0,0 K**
（床区 8 格、自由空间 8 格，判据 < 1 K）。收敛解的第 3 层检查通过。
y 上最大步长分量 231,07（< 1·10⁶），85 次迭代的雅可比全部可解。

三块残差与温度与诊断逐位相同，说明合并后的正式路径在工况 1 的第 1 轮内层复现了诊断中
「gaslog + o2pow + relax + corellaX」的组合。这一组未在 2026-11-05 的重跑中重算。

## 4 判据结论

`verdict.json` 的 `all_ok` 为真：判据 1（4 次交替、+0,153 g/s、只停在 O4，且 O4 的两条都成立）与
判据 2（CONVERGED、85 ≤ 100、三块 ≤ 1·10⁻⁶、温度差 0 K）都满足。判据 4（Δy < 1·10⁶、逐次报告
雅可比是否可解）也满足。

本卡按 ADR 0054 只跑外层 1 轮，没有进入外层第 2 轮，也未实现 O₂ 投影。
`tools/solver_path_diagnostic.py` 的 `o2proj` 变体只作诊断保留，不参与上述两次运行。
