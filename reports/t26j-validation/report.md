## 2. 停止点与机制

`_precalculate` 的第 1 次调用在 `_segregate` → `account_freeboard` 处抛出
`FreeboardError("积分时间达到上限 80,0 s，归宿仍未确定")`，包成 `PrecalcError`。
按 ADR 0045 第 3 项第 2 步，初值构造需要这次预计算的冻结量，因此：

- 初值构造（ADR 0045 第 3 项、ADR 0049 第 3–5 步）**没有开始**，预启动阶段也没有执行；
- ADR 0049 的分阶段回代门、`solve_prelaunch`、交替中的回馈（PR #130 审查 P2）在本卡
  的验证路径上**未被执行到**；它们只有单元测试与集成测试（`tests/test_initial_state.py`）覆盖；
- 基准外层第 1 轮内层没有运行。

机制（`reports/t26j-trajectories/report.md` 与本节同一批诊断）：

1. ADR 0048 第 1 项把每个粒级拆成 8 个粒径 × 8 个球形度，共 64 个权重 1/64 的子样本；
   每个子样本有自己的稳定界面 h*（同一粒级内可以出现在不同界面，格 0–7 都出现过）。
2. 对 v_t 与该界面上下两格的格内平均气速相差很小的子样本，颗粒在界面附近往复振荡，
   每次穿越界面的越界距离与速度幅值按几何级数缓慢衰减；ADR 0034 的捕获判据要求
   `|u_P| ≤ δ_u = 1·10⁻² m/s` 且越界距离 `≤ δ_h = 1·10⁻³ m`，只有幅值衰减到这个量级才判定捕获。
3. 工况 1 初值点第 1 轮剖面上，粒级 3（0,25–0,5 mm）的 64 个子样本里有若干（例如
   d = 0,2611 mm / φ_S = 0,942、d = 0,3386 mm / φ_S = 0,716），其最长的捕获时刻为 971,1 s，
   远大于 ADR 0028 登记的 80 s。

## 3. 数字核对（只报告，不改登记值）

粒级 3 在 `N_d = N_φ = 8`、`σ_φ = 0,1`、半格 R* 下，把 ADR 0028 的报错时限逐步提高：

| 时限 | 结果 |
|---|---|
| 80 s（登记值） | 未定，`积分时间达到上限 80,0 s` |
| 1000 s | 仍未定 |
| 5000 s（只作诊断） | 全部子样本定归宿：回落 0,4094、带出 0,0933、捕获 0,4973；出现格内转入的格 0–6 |

即：**归宿是确定的，只是判定所需的物理时间超过登记时限**。80 s 在 ADR 0028 中写明
“只用于报错”，不是物理参数；它原先够用是因为每个粒级只有一条代表粒径轨迹。
粒级内取样把轨迹数放大 64 倍，同时引入了 v_t 与界面格气速几乎相等的子样本。

对照：粒级 1、2、4–7 在 80 s 内全部子样本都能定归宿（粒级 1、2 带出 ≈ 99,5 %，
粒级 4–7 全部回落），没有触发停止。整批 7 个粒级里只有粒级 3 触发。

## 5. 交裁定的问题

1. ADR 0028 的 `freeboard_time_limit_s = 80 s` 是“只用于报错”的数值参数。在 ADR 0048 的
   粒级内取样下，它已经不再是“足够宽裕的报错阈值”，而是能决定计算能否开始的判据。
   提高它是否允许、提高到多少、是否需要另行登记，属求解器参数，按 CHARTER §9 须 ADR 裁定，
   执行者不自行改动。
2. 另一种可能的方向是改捕获判据本身（δ_h、δ_u 或“记账与判据分离”的写法），那属于模型
   闭合与数值手段的变更，同样须 ADR 裁定；本卡范围内不做。
3. ADR 0049 的初值构造改动（分阶段回代门、预启动解、交替回馈）已在代码中实现并有测试，
   但在本卡未能于工况 1 上实际跑通；其可用性尚未得到端到端确认。

在上述裁定出来之前，T26j 的验证结论按停止条件记录，不另试其它手段。
