# T26t 验证报告（ADR 0058，工况 1、φ = 1）

入口 `tools/t26t_validate.py`（A、C、D 全部模式）。Corella 外推只在该工具里设置（`hamel.kinetics.homogeneous._CORELLA_HIGH_K = +inf`），不进入 `hamel/`。
第 A 项在基准提交 `b87fafb48da9f2a236745cbf5800dd0fb414d993`（`origin/main`，ADR 0058 已合并）上采集，采集时 `hamel/` 与该提交逐位相同（工具在采集前核对 `git diff`）。

报告只写预计算系数、外层门与收敛后各项检验。不含出口组成、T̄_FRB、X_C，也不用它们判断任何事。粒级下标 0 起（与代码一致）；自由空间的衡算下标 0 是最上格。

## 版本与作废说明

本报告有两轮结果，**第一轮的 C.2、D.1、D.2、D.3、D.4 全部作废，原表保留并加注，不删除**。

**第一轮（2026-11-16，作废）**：`account_freeboard` 的第二阶段只遍历原取样点，第一阶段分给粒级端点与第三种签名中点节点的权重从未累加，**记账丢质量**。总司令用第 17 轮入参复核：粒级 2 的床面抛出回落 + 带出 + 捕获之和为 0,8269，粒级 3 为 0,9927（应为 1）。因此该轮所有份额、系数、外层轨迹与外层门都不成立。

**第二轮（2026-11-17 至 11-18，有效）**：

1. 第二阶段改为遍历每行全部权重非零的节点——先按原取样点顺序（保证签名处处相同时仍逐位不变），再遍历端点与第三种签名的中点节点；每个节点用自己的粒径、v_t 与轨迹缓存，按节点取最大值的规则不变。
2. 累加后加闭合校验：床面抛出的三项份额与 1 的差、各格当地轨迹权重之和与 1 的差都不超过 1e-12，否则报 `FreeboardError`（`accounting._check_closure`）。第 17 轮入参的七个粒级都通过，无异常。
3. ε_0 按 ADR 0058 修订改为 1·10⁻¹⁵ kg（PR #168）。
4. 审查（codex）第 2 轮指出的阻塞问题：`nodes` 是同一 φ 行所有轨迹位共享的集合，而缓存只对实际探测过该节点的轨迹位存在。某条床面轨迹在二分中得到第三签名中点时，其它轨迹位（当地轨迹或另一条床面轨迹）可能既无该节点的权重、也无其缓存；无条件读取会在闭合校验之前抛出 `KeyError`。**已修**：每个轨迹位先取权重，为 0 则跳过、不读缓存；按节点求和的停留、滑移与穿出也只列入正权重的轨迹位。随机搜索 600 组构造中有 28 组在修复前抛 `KeyError`（例如 `('local', 3, 5)`、`('bed', 0, 11)`），修复后全部通过且份额闭合。
5. 上面两处修复都不改变已经通过的数值：用同一最终状态与第 17 轮入参重放，D.1 的 73 个冻结量字段、C.2 的七个粒级与 D.4 的 n_b 对照都**逐位相同**（见下）。

修复前后的对照（同一构造，两格、粒级两端跨在归宿翻转两侧）：修复前床面份额合计 0,4736（应为 1），修复后逐位为 1。

## C. 一致性

### C.1 单元层

`tests/test_boundary_quadrature.py`（21 项）逐条覆盖 ADR 0058「实现约束」与本次闭合要求。与本轮修复直接相关的五项：

- `test_endpoint_and_midpoint_mass_is_counted_and_shares_close_to_one`：经过 `account_freeboard` 的集成测试，构造同时出现端部签名不同与第三种签名（`boundary` 记录为定位轨迹 > 0、第三种签名 > 0），断言三项份额之和为 1（|差| ≤ 1e-12），且三种归宿份额都为正——端点与中点轨迹的质量确实计入。
- `test_endpoint_nodes_carry_mass_when_the_end_intervals_differ`：端部区间两端签名不同的构造，断言份额之和为 1、端点轨迹条数为 2·N_φ·轨迹位数。
- `test_bed_positions_own_a_node_the_local_positions_never_probe`：床面轨迹在二分中得到第三签名中点、当地轨迹不需要它的构造（测试先断言这种「床面独有节点」确实出现，否则测不到该路径）。修复前抛 `KeyError: ('local', 2, 7)`；现在份额之和为 1。
- `test_local_positions_own_a_node_the_bed_positions_never_probe`：反向构造。修复前抛 `KeyError: ('bed', 0, 11)`；现在份额之和为 1。
- `test_closure_check_rejects_lost_mass`：闭合校验对 0,8269 与 0,9927 这类丢质量的输入报 `FreeboardError`。

两项「独有节点」测试用 monkeypatch 记录每个轨迹位的缓存集合与正权重集合，断言「某位赋正权重而另一位没有该位的缓存」确实发生，再断言最终份额闭合；只校验 `boundary_weights` 的输出不足以回归这个缺陷。
