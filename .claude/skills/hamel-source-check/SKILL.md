# Hamel 原文核对（hamel-source-check）

本项目的全部算法和数据都来自 Hamel（2001，VDI Fortschritt-Berichte Reihe 6 Nr. 469）。agent 最常见的偏离不是公然违背原文，而是**悄悄填补原文空白**，或者**拿旧代码、旧转录当原文**。本 skill 把“先读原文”变成可检查的交付物。

依据：CHARTER §4（文献来源）、§5（求解手段边界）、§6.3（引用格式）、§8（审查与独立性）。

## 何时必须使用

- 任务卡涉及方程、常数、物性、反应速率、热解产率、衡算、流动关联式、工况输入：**动手写代码前**先交原文答卷，经总司令审查通过后才能写代码（CHARTER §4.4）。
- 原文独立转录任务（如 T4、T8）：转录文件本身就是答卷，按下文的格式和独立性规则执行。
- 审查上述 PR 时：审查方按“审查清单”逐项核对原页。

不涉及原文内容的任务（纯工具、纯流程文档）不需要答卷。

## 一、定位原文

1. **索引**：`refs/hamel/index.json`（随仓库提交）。
   - `equations`、`tables`、`figures`、`sections`：按式号、表号、图号、小节号查 `pdf_page`、`printed_page`、`side`（left/right；PDF 98–103 为 top/bottom）。
   - `printed_page_map`：从印刷页查 PDF 页。**不要按固定偏移换算页码**：原 PDF 有重复扫描（PDF 84、85 均为 S. 148–149）。印刷页 152–153 不在原扫描中，补页编为 PDF 114。
   - `source_issues`：重复式号（3.49、3.50）、重复表号（5.1、A.2.1.2）等。引用这些编号时必须带页码。
   - `cited_references`：Hamel 的参考文献，以及它们在正文中被引用的位置候选。这里的引用位置只是导航线索，不能自动当作某个方程的依据。
2. **页面图像**：`refs/hamel/pages/NNN.png`（300 dpi，NNN 为三位补零的 PDF 页序），仅本地保留，不入库。
   - 本地没有时，用 `python3 tools/build_hamel_corpus.py "<PDF 路径>"` 生成（需要 `pdfplumber`、`pypdf` 和 Poppler 的 `pdftoppm`）；PDF 在主工作目录的 `docs/` 下。
   - 裁图：`label_bbox_pt` 是相对页面图像左上角的 point 坐标，像素 = pt × 300/72。有 24 条方程（`locator: page_image`）没有坐标框，须打开整页查找。
3. **逐页文本** `refs/hamel/pages/NNN.txt` 是 OCR 文本层，**只能用来检索定位**。公式、数值、上下标、指数一律以页面图像为准：OCR 常把 `O₂` 识别成 `O9`，把指数和分式弄乱。

## 二、来源层级

1. Hamel 是唯一主来源。
2. Hamel 明确“采用”的其它文献，只能在被采用的范围内使用，并标注“Hamel 引用的 X（Hamel 出处）”。已裁定的范围见 `docs/adr/0002-damped-newton-solver.md`（Wirsum 1998 的四处采用）；其它文献在答卷中逐条说明 Hamel 的原句。
3. Hamel 没有引用的文献，须目标所有者批准（CHARTER §4.3）。
4. **禁止拿以下材料代替原文**：归档代码（tag `archive-2026-10-12`）、`docs/hamel_submodels/`、旧交接和审计报告、`data/hamel_fig7_parity_digitized.json`。它们只能在比对阶段作为比对对象。

## 三、原文答卷

### 存放位置

- 一般任务：`refs/hamel/answers/<任务卡号>-<主题>.md`，与代码放在同一 PR，或先于代码单独提交。
- 独立转录任务：转录文件即答卷（如 `refs/hamel/transcription/ch5_kinetics.md`）。

### 格式

每个被使用的方程、常数或数据项写一节，按下面六个问题编号作答。答卷开头写明任务卡号、执行者、会话是否为全新会话（独立任务必填）、日期。

```markdown
## Eq. 5.39（R6 速率常数）

❓ **Q1 出处**：PDF 55 右半页 / S. 91，§5.2.2，Eq. 5.38–5.39。
❓ **Q2 变量与单位**：k_ch,R6 — 单位 …；T — K，…；适用范围：原文给出的 … / 原文未说明。
❓ **Q3 德文原句**：„…“（只引关键的一句或短语）。
❓ **Q4 上游依赖**：C_H2、C_O2 来自 …（式号）；T 来自 …。
❓ **Q5 原文空白**：原文未说明 … 。可选解释：(a) …（影响 …）；(b) …（影响 …）。待总司令裁定。
❓ **Q6 与归档旧代码的差异**：（独立转录任务在比对阶段填写；一般任务可写“未查看归档”或列出差异。）
```

### 作答规则

- **Q1** 必须同时给出 PDF 页、印刷页、半页和式号（或表号、图号）。
- **Q2** 单位一律换算为 SI，并注明原文的单位；原文是非 SI 单位时，写出换算关系（如 R8 内部用 atm）。
- **Q3** 只引最关键的一句或一个短语，不大段照抄原文。
- **Q5 是最重要的一项**。原文没有说明的取值、边界条件、初值、封闭关系、适用范围，一律写“原文未说明”，并列出可选解释及影响，交总司令裁定。裁定结果登记为 ADR，代码注释中标为“解释性选择”。**禁止在答卷或代码里悄悄选一个值。**
- 发现原文自相矛盾（例如图注和正文不一致）时，列出各处原文和页码，同样写进 Q5，不自行取舍。

## 四、独立转录任务的额外规则

- 必须在**全新会话**中执行（CHARTER §8），并在答卷开头声明。
- 转录完成并 commit 冻结之前，只能打开 `refs/hamel/` 下的语料、本 skill、任务卡和 CHARTER；不得打开第二节第 4 条列出的材料，也不得打开 `docs/adr/CANDIDATES.md` 和 `GLOSSARY.md` 的旧编号表。
- 冻结后进入比对阶段，才能打开上述材料。比对中发现转录错误时，在差异表中记录，另起一节写更正，**不改写已冻结的转录**。

## 五、代码中的引用

核心函数的 docstring 写明来源，格式为：

```
Source: Hamel Eq.5.39, S. 91
```

- 重复编号必须带页码以示区分，例如 `Hamel Eq.3.49, S. 35`。
- 依据原文空白处的裁定写成的代码，加注 `解释性选择：ADR 00NN`。
- 引用校验脚本（T6 第 2 项）会检查式号和页码是否存在于 `refs/hamel/index.json` 中。

## 六、审查清单（总司令审查答卷；codex 审查转录与代码 PR）

逐节对照页面图像：

1. Q1 的页码、半页、式号能在原页上找到。
2. 公式、常数、指数、单位与原页图像一致（不能只对照 OCR 文本）。
3. Q5 是否完整：重点看初值、边界条件、取值范围、单位换算这几类最容易被悄悄填补的地方。
4. 是否用了第二节禁止的材料代替原文；引用的其它文献是否在 Hamel 的采用范围内。
5. 独立任务：是否声明了全新会话；冻结前后的内容是否被改写（看 commit 历史）。
6. 代码 PR：docstring 引用与答卷一致；“解释性选择”都有对应的 ADR。

审查结论写进 PR 评论（CHARTER §8），逐节给出“通过 / 退回（原因）”。全部通过后，执行者才能开始写代码，或将 PR 交付合并。
